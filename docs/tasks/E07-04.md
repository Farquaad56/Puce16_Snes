## Specification
Dans `suite/manifest.rs` (tests unitaires `#[cfg(test)] mod tests` dans le fichier, noms `e07_04_...`):
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum RegionSel { Auto, Ntsc, Pal }
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum Check { Hash, Ram, Ports, None }
#[derive(Clone, PartialEq, Eq, Debug)] pub struct RamExpect { pub addr: u32, pub value: u8 }
#[derive(Clone, PartialEq, Eq, Debug)]
pub struct RomEntry { pub name: String, pub path: String, pub region: RegionSel, pub frames: u32, pub optional: bool, pub epic: String, pub check: Check, pub expect_ram: Vec<RamExpect>, pub expect_ports: Option<[u8; 4]> }
pub fn parse(text: &str) -> Result<Vec<RomEntry>, String>;       // ordre du fichier conserve
pub fn epic_number(s: &str) -> Option<u32>;                      // "E04" -> Some(4) ; exactement 'E' majuscule + 2 chiffres, sinon None
```
Deserialisation avec `serde` + `toml` (structure brute `Raw { rom: Option<Vec<RawRom>> }`, champs optionnels avec defauts: `region="auto"`, `optional=false`, `check="hash"`). `expect_ram` = tableau de tables `{ addr, value }` (entiers TOML, hexa autorise), `expect_ports` = tableau de 4 entiers 0..255.
Validation (message d'erreur commencant par le nom de la ROM: `<name>: <probleme>`): `name` vide ou hors `[a-z0-9_]+` ; nom duplique ; `frames` hors 1..=100000 ; `epic` invalide ; `region` hors auto/ntsc/pal ; `check` hors hash/ram/ports/none ; `check = ram` sans `expect_ram` (ou vide) ; `addr` hors 0..=0xFFFFFF ; `check = ports` sans `expect_ports` de longueur 4. Un fichier sans `[[rom]]` donne `Ok(vec![])`. TOML invalide -> `Err` contenant `invalid manifest`.

## 5. Manifeste `tests/manifest.toml`

```toml
[[rom]]
name = "peterlemon_gfx_mode1"          # unique, [a-z0-9_]
path = "tests/roms/homebrew/peterlemon/GFX/Mode1/Mode1.sfc"   # chemin relatif a la racine du repo
region = "auto"                        # auto | ntsc | pal
frames = 120                           # nombre de frames a executer
optional = false                       # true: ignore si le fichier manque
epic = "E04"                           # plus petite epopee ou la ROM doit passer
check = "hash"                         # hash | ram | ports | none
# check = "ram"  -> expect_ram = [ { addr = 0x7E0010, value = 0x01 } ]
# check = "ports" -> expect_ports = [0xAA, 0xBB, 0x00, 0x00]   (valeurs vues par le CPU sur $2140-$2143)
```
`baseline.json`: `{ "version": 1, "roms": { "<name>": { "frames": 120, "frame_hash": "0x...", "state_hash": "0x...", "audio_hash": "0x..." } } }` (`audio_hash`: FNV-1a 64 de toutes les paires `[i16; 2]` produites par `Snes::take_audio` pendant les `frames` frames, chaque `i16` en little-endian, L puis R. Pour `check = "hash"` les TROIS hash sont calcules et compares.).

## Tests
Tous les tests sont prefixes par `e07_04_`.

- `e07_04_parse_full` : un manifeste de 3 entrees (une avec `check="ram"` + `expect_ram = [ { addr = 0x7E0010, value = 0x42 } ]`, une avec `check="ports"` + `expect_ports = [0xAA, 0xBB, 0, 0]`, une `optional = true` avec `region = "pal"`) -> 3 entrees dans l'ordre, tous les champs corrects (`addr == 0x7E0010`, `expect_ports == Some([0xAA,0xBB,0,0])`).
- `e07_04_defaults` : une entree avec seulement `name,path,frames,epic` : `region==Auto`, `optional==false`, `check==Check::Hash`, `expect_ram` vide, `expect_ports==None`.
- `e07_04_empty_manifest` : texte vide -> `Ok(vec![])`.
- `e07_04_bad_toml` : `"[[rom"` -> Err contenant `invalid manifest`.
- `e07_04_duplicate_name` : deux entrees `name="a"` -> Err contenant `a: duplicate`.
- `e07_04_bad_name` : `name="Bad-Name"` -> Err contenant `Bad-Name`.
- `e07_04_bad_frames` : `frames = 0` et `frames = 100001` -> Err chacun.
- `e07_04_bad_epic` : `epic = "E4"`, `"e04"`, `"E100"` -> Err chacun ; `"E04"` -> Ok.
- `e07_04_bad_enums` : `region = "jp"` -> Err ; `check = "crc"` -> Err.
- `e07_04_ram_needs_expect` : `check = "ram"` sans `expect_ram` -> Err contenant `expect_ram` ; avec `addr = 0x1000000` -> Err.
- `e07_04_ports_needs_four` : `check = "ports"` avec 3 valeurs -> Err contenant `expect_ports`.
- `e07_04_epic_number` : `epic_number("E04")==Some(4)`, `epic_number("E10")==Some(10)`, `epic_number("E4")==None`, `epic_number("e04")==None`, `epic_number("E100")==None`.
