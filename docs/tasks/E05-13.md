# E05-13 - ppu/mode7.rs: pixel mode 7 (BG1) et EXTBG (BG2)
Epopee: E05 | Type: code | Dependances: E05-12 | Taille estimee: ~130 lignes

## Contexte
Utilise `m7_sample` pour fabriquer les pixels du mode 7 (spec 05b section 8). `Ppu::m7_pixel(n, x, v)` renvoie le pixel de BG1 (n = 0) ou de BG2 en mode EXTBG (n = 1). Pour le mode 7 la VRAM est lue par OCTETS : la carte 128x128 dans les octets BAS des mots 0..16383, les pixels (8 bits) dans les octets HAUTS. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'. Aides de test (a recopier dans le fichier de test): `fn put_vram(p: &mut Ppu, addr: u16, w: u16) { p.write(0x15,0x80); p.write(0x16,(addr & 0xFF) as u8); p.write(0x17,(addr >> 8) as u8); p.write(0x18,(w & 0xFF) as u8); p.write(0x19,(w >> 8) as u8); }` ; `fn put_cgram(p: &mut Ppu, i: u8, w: u16) { p.write(0x21,i); p.write(0x22,(w & 0xFF) as u8); p.write(0x22,(w >> 8) as u8); }`. Un `Ppu::new(Region::Ntsc)` neuf est en forced blank: toutes ces ecritures sont autorisees. Chaque test construit SA scene sur un `Ppu` neuf.

## Specification
Ajoute a `ppu/mode7.rs`:
```rust
impl Ppu { pub fn m7_pixel(&self, n: usize, x: usize, v: usize) -> Option<Pix>; }
```
1. `None` si `regs.bg_mode != 7` ; `None` si `n == 1 && !extbg` ; `None` si `n > 1`.
2. mosaique : `(xm, vm) = mosaic_xy(regs.mosaic_size(), (regs.mosaic_en >> n) & 1 != 0, x, v)`.
3. `(px, py) = m7_sample(&m7, xm as i32, vm as i32)`.
4. Si `(px | py) & !0x3FF != 0` (hors 0..1023) : si `!m7.outside` : `px &= 0x3FF ; py &= 0x3FF` puis comme dans la boucle normale ; sinon si `!m7.fill` : `None` ; sinon `tile = 0` et `fx = px & 7`, `fy = py & 7` (avec px/py non masques).
   Cas normal : `tile = vram[((py >> 3) << 7) + (px >> 3)] & 0xFF` ; `fx = px & 7`, `fy = py & 7`.
5. `idx = (vram[tile * 64 + fy * 8 + fx] >> 8) & 0xFF` ; `idx == 0` -> `None`. (adresses & 0x7FFF)
6. BG1 (`n == 0`) : `rgb = if regs.direct_color { direct_color_m7(idx) } else { cgram[idx] }`, `prio = 0`. BG2 EXTBG (`n == 1`) : `prio = idx >> 7`, `i7 = idx & 0x7F` ; `i7 == 0` -> `None` ; `rgb = cgram[i7]`.
`obj_pal` vaut toujours 0.

## 8. Mode 7 (fonction pure + pixel)
Registres: `m7a, m7b, m7c, m7d: i16`; `m7_cx, m7_cy, m7_hofs, m7_vofs: i32` (13 bits signes). M7SEL: `flip_x` (bit0), `flip_y` (bit1), `outside` (bit7), `fill` (bit6).
```
fn clip(n: i32) -> i32 { if n & 0x2000 != 0 { n | !0x3FF } else { n & 0x3FF } }
fn m7_sample(x, v) -> (i32 px, i32 py):
    sx = if flip_x { 255 - x } else { x }
    sy = if flip_y { 255 - v } else { v }
    a, b, c, d as i32
    ox = ((a * clip(m7_hofs - m7_cx)) & !63) + ((b * clip(m7_vofs - m7_cy)) & !63) + ((b * sy) & !63) + (m7_cx << 8)
    oy = ((c * clip(m7_hofs - m7_cx)) & !63) + ((d * clip(m7_vofs - m7_cy)) & !63) + ((d * sy) & !63) + (m7_cy << 8)
    px = (ox + a * sx) >> 8        // decalage arithmetique
    py = (oy + c * sx) >> 8
```
Pixel mode 7 (avec mosaique appliquee a `x` et `v` avant): 
```
si (px | py) & !0x3FF != 0 (hors 0..1023):
    si !outside:      px &= 0x3FF ; py &= 0x3FF            // repetition
    sinon si !fill:   transparent
    sinon:            tuile = 0 ; fx = px & 7 ; fy = py & 7  // remplissage avec la tuile 0
sinon tuile = (vram[((py >> 3) << 7) + (px >> 3)] & 0xFF)  // carte 128x128 en octets BAS
indice = (vram[tuile * 64 + (fy * 8 + fx)] >> 8) & 0xFF     // pixels en octets HAUTS
```
(avec `fx = px & 7`, `fy = py & 7`). Indice 0 = transparent. BG1: `rgb = cgram[indice]` (ou couleur directe section 3). EXTBG (SETINI bit6): BG2 utilise le MEME echantillon: `prio = indice >> 7`, `idx7 = indice & 0x7F` (0 = transparent), `rgb = cgram[idx7]`. Priorite BG1 en mode 7: niveau unique (traite comme prio 0 dans la table; voir section 2).
`UNKNOWN - to confirm`: bits de remplacement de flip_y avec `v` (deja decale d'une ligne) et alignement horizontal en overscan; validation par ROM de test mode 7.

## 9. Mosaique
`size = mosaic_size + 1`. Pour un BG `n` avec bit d'activation et `size > 1` (aussi BG1 mode 7): `xm = x - (x % size)`, `vm = v - ((v - 1) % size)`. Sinon `(x, v)`. Pas de mosaique sur les sprites. (hi-res: ignoree en v1, `UNKNOWN`.)
