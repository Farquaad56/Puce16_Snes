# E09-09 - S-DD1: sauvegarde d'etat et hash
Epopee: E09 | Type: code | Dependances: E09-08 | Taille estimee: ~80 lignes

## Contexte
Les registres du S-DD1 et les copies des registres DMA entrent dans `Cart::save` / `load` / `hash_into` quand la cartouche a un S-DD1 (spec section 8). Le format des cartouches sans S-DD1 ne change pas d'un octet. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## Specification
1. `Sdd1`: ajouter `pub fn save(&self, w: &mut StateWriter)` / `pub fn load(&mut self, r: &mut StateReader) -> Result<(), StateError>` / `pub fn hash_into(&self, h: &mut Fnv64)` (dans un nouveau fichier ou `regs.rs`): ordre `r4800, r4801, mmc[0..4], pour n in 0..8: dma_addr[n] (u32), dma_size[n] (u16)`; au chargement `dma_ready = false` et le decompresseur est remis a `Decompressor::new()`.
2. `Cart::save/load/hash_into`: appeler les methodes de `Sdd1` APRES les donnees actuelles, uniquement si `sdd1.is_some()`.
3. Regarder comment `Cart::save` ecrit la SRAM et comment les tests `e08_*` utilisent `StateWriter` / `StateReader` pour copier le style.

## 8. Etat, sauvegardes d'etat, hash
Etat a sauver (quand la cartouche a un S-DD1 uniquement; le format des autres cartouches ne change PAS): `r4800, r4801, r4804..r4807` (6 octets), pour chaque canal `addr` (u32 -> 3 octets) et `size` (u16). Le decompresseur n'est pas sauve: le DMA se termine toujours dans la frame (les sauvegardes se font entre deux frames) et `dma_ready = false` apres chargement. `hash_into` inclut les memes champs.

## Tests
Tous les tests sont prefixes par `e09_09_`.

- `e09_09_roundtrip_registers` : cart S-DD1: io_write($4800,3), ($4801,2), ($4805,0x82), dma_write($4342,0x10), ($4343,0x20), ($4344,0xC0), ($4345,0x08), ($4346,0x00); save; nouvelle cartouche identique; load; io_read($4800/$4801/$4805) = Some(3)/Some(2)/Some(0x82); dma_channel(4) = (0xC02010, 8)
- `e09_09_non_sdd1_format_unchanged` : chipset 0x00: la taille du flux de Cart::save est la meme qu'une cartouche sans S-DD1 (comparer a la longueur de `sram().len()` + les champs existants, ou a une cartouche `make_rom` equivalente: egalite des longueurs et des octets)
- `e09_09_hash_changes_with_registers` : hash_into avant et apres io_write($4804, 0x05) differents; hash identique pour deux cartouches avec les memes ecritures
- `e09_09_load_resets_streaming` : apres load, dma_ready est faux: une decompression en cours est abandonnee (un nouveau mcu_read relance init)
