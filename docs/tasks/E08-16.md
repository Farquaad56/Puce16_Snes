## Specification
Ajoute dans `audio.rs` (sans modifier `AudioRing`):
```rust
pub struct Resampler { step: f64, pos: f64, buf: Vec<[f32; 2]> }
impl Resampler {
    pub fn new(src_rate: u32, dst_rate: u32) -> Resampler;      // step = src_rate / dst_rate ; buf = 8 trames nulles (historique) ; pos = 8.0
    pub fn process(&mut self, input: &[[f32; 2]], out: &mut Vec<[f32; 2]>);   // ajoute input a buf puis produit des sorties
}
```
Algorithme: tant que `pos + 8.0 <= (buf.len() - 1) as f64`: `n = pos.floor() as usize`, `f = pos - n as f64` (0 <= f < 1) ; pour `k` de -7 a 8 inclus: `x = f - k as f64` ; `w[k] = sinc(x) * hann(x)` avec `sinc(x) = if x == 0 {1} else {sin(pi x)/(pi x)}` et `hann(x) = if |x| < 8 {0.5 * (1 + cos(pi x / 8))} else {0}` ; sortie = `sum(buf[n + k] * w[k]) / sum(w)` (normalisation: gain continu exactement 1) pour chaque canal ; `pos += step`. Ensuite jeter les trames devenues inutiles: garder a partir de l'indice `floor(pos) - 7` et decaler `pos` en consequence (flux inchange). Indices `n + k` entre `n - 7` et `n + 8` : jamais hors du tampon grace a la condition de la boucle et aux 8 trames d'historique.

## 5. Audio (`cpal`)

- Le core produit des echantillons stereo `[i16; 2]` a ~32 040 Hz (`Snes::take_audio`). Le thread audio consomme un anneau (`Vec<[i16;2]>` circulaire, capacite 8192 trames).
- Re-echantillonnage vers la frequence du peripherique par interpolation sinc fenetree (Hann), 16 points, en `f32` (autorise ici). Volume 0..100 % applique en sortie. Muet = silence.
- Latence cible 60 ms (anneau ~ 2000 trames pleines). Sous-alimentation: repeter le dernier echantillon ; sur-alimentation (anneau > `RING_WAIT_ABOVE` = 3072 trames, ~96 ms; constante reglable): le thread d'emulation attend par pas de 1 ms, au plus 100 ms par frame (c'est l'horloge de synchronisation).
- Pas de peripherique audio: l'emulation continue avec le minuteur (message dans la barre d'etat).

## Tests
Tous les tests sont prefixes par `e08_16_`.

- `e08_16_identity_rate` : `Resampler::new(32040,32040)`, entree de 100 trames `[i as f32 / 1000.0, -(i as f32) / 1000.0]` : `out.len()==92` et pour i in 0..92 : `|out[i] - in[i]| < 1e-4` sur les deux canaux.
- `e08_16_dc_is_preserved_upsampling` : `new(32040,48000)`, 1000 trames `[0.5,0.5]` : `out.len()` entre 1480 et 1500 ; toutes les sorties d'indice >= 16 sont a moins de 1e-4 de 0.5.
- `e08_16_dc_preserved_downsampling` : `new(48000,32040)`, 1000 trames `[0.25,-0.25]` : sorties d'indice >= 16 a moins de 1e-4 de `[0.25,-0.25]` ; `out.len()` entre 660 et 680.
- `e08_16_streaming_equals_one_shot` : meme signal (sinusoide 440 Hz echantillonnee a 32040, 2000 trames) traite en un bloc ou en blocs de 7, 100, 1 (cycle) avec `new(32040,44100)` : memes longueurs de sortie et ecart max < 1e-6.
- `e08_16_sine_amplitude` : sinusoide 1000 Hz amplitude 0.5 a 32040 Hz, `new(32040,48000)`, 4000 trames : l'amplitude max des sorties (apres les 100 premieres) est entre 0.49 et 0.51.
- `e08_16_empty_input` : `process(&[], ..)` n'ajoute aucune sortie et ne panique pas.
- `e08_16_output_rate` : `new(32040,48000)` sur 32040 trames d'entree : `out.len()` entre 47 975 et 48 000.
- `e08_16_channels_independent` : entree `[0.5, 0.0]` constante : sorties (indice >= 16) `[~0.5, ~0.0]`.
