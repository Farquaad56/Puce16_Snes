## Specification
Ajoute a `mov.rs::exec`:
- Transferts avec `set_nz`: `5D` MOV X,A ; `7D` MOV A,X ; `DD` MOV A,Y ; `FD` MOV Y,A ; `9D` MOV X,SP. Sans flag: `BD` MOV SP,X.
- `8F` MOV dp,#imm: octets `op imm dp` (`imm = fetch8` PUIS `dp = fetch8`) ; `ea = P | dp` ; lecture factice de `ea` puis ecriture.
- `FA` MOV dp,dp: octets `op src dst` ; lit la source, ecrit la destination (PAS de lecture factice de la destination).
- `BF` MOV A,(X)+: `a = rd(P|X)` ; `x += 1` ; `set_nz(a)`. `AF` MOV (X)+,A: `ea = P|X` ; lecture factice ; ecriture de A ; `x += 1`.
- `BA` MOVW YA,dp: `b = fetch8` ; `lo = rd(P|b)` ; `hi = rd(P|((b+1)&0xFF))` ; `ya = (hi<<8)|lo` ; N = bit 15, Z = (ya == 0).
- `DA` MOVW dp,YA: `b = fetch8` ; lecture factice de `P|b` ; ecrit A en `P|b` puis Y en `P|((b+1)&0xFF)` ; aucun flag. (`UNKNOWN - to confirm`: ce sont 5 acces pour 4 cycles dans le TSV; `step` renverra 5; l'oracle tranche en E06-14.)

### 6.1 MOV (41 opcodes) - aucun flag sauf indication
- Chargements `MOV A|X|Y, src`: `N,Z` selon la valeur. Idem `MOV A,X`, `MOV A,Y`, `MOV X,A`, `MOV Y,A`, `MOV X,SP`. `MOV SP,X`: pas de flag. `MOV A,(X)+`: lit `(X)` puis `X+=1`.
- Stockages (`MOV dst, A|X|Y`, `MOV dp,#imm`, `MOV dp,dp`, `MOV (X)+,A`, `MOV [dp+X],A`, ...): pas de flag. Chaque stockage fait une **lecture factice** de la destination avant l'ecriture (sauf `MOV dp,dp` qui lit la source puis ecrit la destination) (`UNKNOWN - to confirm` via les cycles des tests). Important pour `$FD-$FF` (lecture efface le compteur).
- `MOVW YA,dp`: lit octet bas puis haut (haut en `P|((b+1)&0xFF)`), `YA = mot`, `N` = bit 15, `Z` = (YA==0). `MOVW dp,YA`: lecture factice de l'octet bas, puis ecrit bas (A) puis haut (Y); pas de flag.
