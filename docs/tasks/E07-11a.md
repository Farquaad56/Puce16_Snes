# E07-11a - TUNE: DSP echo, spc_dsp6 echoue a Echo/echo calc (Failed 03)
Epopee: E07 | Type: code | Dependances: E07-11 | Taille estimee: ~100 lignes

## Contexte
Tache de reglage creee a l'etape E07-12 (docs/03_KANBAN_HERMES.md section 6). La ROM `tests/roms/homebrew/blargg/spc/spc_dsp6.sfc` (manifeste: `blargg_spc_spc_dsp6`, 300 frames) affiche un ecran ROUGE avec `Failed 03` apres le sous-test `Echo/echo calc`. Les sous-tests `Echo/basics`, `esa_changes`, `edl_changes`, `wrap_around` et `zero_length` passent. Le DSP a ete valide contre les specs en E06; il reste un ecart sur le calcul de l'echo (filtre FIR, retour EFB, sortie EVOL, ou ecriture dans le tampon).

## Specification
1. Reproduire: `cargo build --release -p puce16-cli` puis `target/release/puce16-cli run tests/roms/homebrew/blargg/spc/spc_dsp6.sfc --frames 300 --dump-ppm tests/out/e07_11a_dsp6.ppm`. Le pixel (0,0) est rouge tant que le test echoue (bleu quand il passe).
2. Relire dans `specs/07b_DSP.md` et `specs/07d_DSP_DESIGN.md` la formule exacte de l'echo (historique, 8 coefficients FIR, ordre et saturation 16 bits, EFB, EVOL, bit d'ecriture du tampon dans FLG) et la comparer a `apu/dsp/echo.rs`. Ne rien deviner: toute valeur ou ordre non specifie -> commentaire `UNKNOWN - to confirm` + question bloquante.
3. Regle de tuning: UNE seule modification a la fois (une constante, un ordre d'operations, une saturation), puis relancer la commande de l'etape 1 et noter le resultat dans le commit. Pas de modification groupee.
4. Ajouter un test de non-regression qui echoue avant la correction et passe apres, avec des valeurs concretes tirees de la cause trouvee.
5. Apres trois essais sans progres: ecrire la question et bloquer la tache; le GATE E07-12 documentera alors la ROM en `UNKNOWN` avec la cause.
