# E05-16 - ppu/mod.rs: compose_pixel branche dans step_dot (rendu non hi-res complet)
Epopee: E05 | Type: code | Dependances: E05-15 | Taille estimee: ~140 lignes

## Contexte
Assemble tout le rendu non hi-res: a chaque dot visible, le pixel est calcule par `compose_pixel(x, v)` (echantillons -> ecran principal et sous-ecran -> color math -> BGR555), puis converti en XRGB avec la luminosite (E04-13/14).
Les sprites de la ligne sont evalues a `dot == 0` (ordre de la spec 05 5.3: AVANT le dessin des pixels de la ligne). Le hi-res (modes 5/6, pseudo hi-res) arrive en E05-17/18: ici on rend TOUJOURS une colonne par pixel. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'. Aides de test (a recopier dans le fichier de test): `fn put_vram(p: &mut Ppu, addr: u16, w: u16) { p.write(0x15,0x80); p.write(0x16,(addr & 0xFF) as u8); p.write(0x17,(addr >> 8) as u8); p.write(0x18,(w & 0xFF) as u8); p.write(0x19,(w >> 8) as u8); }` ; `fn put_cgram(p: &mut Ppu, i: u8, w: u16) { p.write(0x21,i); p.write(0x22,(w & 0xFF) as u8); p.write(0x22,(w >> 8) as u8); }` ; `fn set_scroll(p: &mut Ppu, reg: u8, v: u16) { p.write(reg,(v & 0xFF) as u8); p.write(reg,(v >> 8) as u8); }`. Un `Ppu::new(Region::Ntsc)` neuf est en forced blank: toutes ces ecritures sont autorisees. Chaque test construit SA scene sur un `Ppu` neuf. Aide locale de test: `fn at(p: &mut Ppu, v: u32, dot: u32) { for _ in 0..(v * 340 + dot) { p.step_dot(); } }` (NTSC, frame 0, sans entrelace).

## Specification
Dans `ppu/mod.rs` :
- Remplace la fonction privee `pixel_bgr555(&self, x)` de E04-14 par `pub fn compose_pixel(&self, x: usize, v: usize) -> u16` (BGR555 final avant luminosite) :
  `layers = sample_layers(x, v)` ; `order` et `extbg = self.extbg` ; `main = pick_layers(order, &layers, regs.tm, [layer_hidden(true,l,x) pour l in 0..5], cgram[0])` ; `fixed = fixed_color(regs.fixed_r, regs.fixed_g, regs.fixed_b)` ; `sub = if regs.addend_subscreen { pick_layers(order, &layers, regs.ts, [layer_hidden(false,l,x)...], fixed) } else { Pick { rgb: fixed, layer: LAYER_BACKDROP, obj_pal: 0 } }` ; `(black, prevent) = color_window_flags(x)` ; retourne `color_math(&main, &sub, black, prevent, &regs)`.
- `step_dot`, a `dot == 0` et `1 <= v <= vis_last` : appelle `render_obj_line((v - 1) as u16)` (dans l'ordre de la section 5.3 : avant l'evenement LINE_START... l'ordre entre cet appel et les autres evenements de dot 0 n'a pas d'effet observable ici).
- Dessin d'un pixel (point 3 de `step_dot`, E04-14) : `argb = if forced_blank { 0xFF000000 } else { bgr555_to_xrgb(compose_pixel(x, v as usize), brightness) }`.
Le reste de `step_dot` est inchange. Les tests ci-dessous utilisent la SCENE H (decrite plus bas), `VOFS BG1 = -1` pour que la rangee de sortie 0 montre la rangee 0 de la carte, et `at(p,225,1)` (225*340 + 1 steps) pour capturer la frame (`frame().pixels[row*256 + col]`).

### 5.3 Evenements par (v, dot), dans CET ordre dans `step_dot`
1. `dot == 0`:
   - `v == 0`: debut de frame: `time_over = range_over = false`; evenement VBLANK_END.
   - `1 <= v <= vis_last`: **evaluation des sprites** pour la ligne (05b section 6) -> remplit `line_obj[256]`.
   - `v == vblank_start`: evenement VBLANK_START; rechargement OAM (2.1) si `!forced_blank`.
   - evenement LINE_START (toujours).
2. `dot == 274`: evenement HBLANK_START. `dot == 1`: HBLANK_END. (bornes `UNKNOWN - to confirm`, spec 02 3.1: 1096 clocks / 4.)
3. Si `1 <= v <= vis_last` et `22 <= dot <= 277`: `x = dot - 22`; **composer le pixel x** (05b section 11) et l'ecrire dans le framebuffer (section 6).
4. Avancer `dot += 1`; si `dot == line_dots(v)`: `dot = 0; v += 1; si v > last_line {v = 0; field ^= 1; FRAME_START}`.

`step_dot` retourne un petit ensemble de drapeaux (`DotEvents`: LINE_START, HBLANK_START, HBLANK_END, VBLANK_START, VBLANK_END) et `scheduler` gere NMI/IRQ/HDMA/auto-joypad a partir de la position (spec 02/03). Le PPU ne connait ni DMA ni NMI.

### 11.4 Color math (mode non hi-res)
```
main = pick(Main, x) ; sub = pick(Sub, x) (seulement si addend_subscreen)
base = if black { 0 } else { main.rgb }
layer_ok = match main.layer { 0..=3 => cgadsub.bit(layer), 4 => cgadsub.bit(4) && main.obj_pal >= 4, _ => cgadsub.bit(5) }
si layer_ok && !prevent:
    (add, sub_is_back) = if addend_subscreen { (sub.rgb, sub.layer == BACKDROP) } else { (fixed_color, false) }
    halve = math_half && !(addend_subscreen && sub_is_back)
    pour chaque canal c5 de (base, add):
        t = if math_sub { base_c - add_c } else { base_c + add_c }
        si halve { t >>= 1 }                 // decalage arithmetique
        c = clamp(t, 0, 31)
sinon c = base
sortie = convert(c) (05 section 6: luminosite puis expansion 8 bits)
```
`fixed_color` = BGR555 forme de `fixed_r/g/b` (COLDATA). Si `forced_blank`: sortie noire (pas de calcul).
