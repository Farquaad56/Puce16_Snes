## Specification
1. `docs/tools/gen_tables.py` (Python 3, stdlib seulement): lit `docs/specs/data/opcodes_65816.tsv`, ecrit `crates/puce16-core/src/cpu/table.rs` avec en tete `// GENERATED by docs/tools/gen_tables.py - do not edit` .
2. Contenu genere: enum `Mn` (92 variantes, ordre alphabetique), enum `Am` (31 variantes, ordre de la section ci-dessus), `pub static MN: [Mn; 256]`, `pub static AM: [Am; 256]`, `impl Mn { pub fn name(self) -> &'static str }` (match sur chaque variante, nom en MAJUSCULES: `Mn::Adc => "ADC"`). Derive `Clone, Copy, PartialEq, Eq, Debug` sur les deux enums.
3. Option `--check`: ne rien ecrire; code de sortie 1 si `table.rs` differe de la sortie generee (sinon 0). Le script doit echouer (exit 1, message clair) si le TSV contient un mnemonique ou un mode inconnu de la table de correspondance.
4. Lancer le script une fois pour produire `table.rs`.

## Tests
Tous les tests sont prefixes par `e02_04_`.

- `e02_04_known_ops` : MN/AM: 0x00 -> (Brk, Brk) ; 0x01 -> (Ora, DpXInd) ; 0x20 -> (Jsr, Abs) ; 0x22 -> (Jsl, Long) ; 0x4C -> (Jmp, Abs) ; 0x5C -> (Jml, Long) ; 0x69 -> (Adc, Imm) ; 0x6C -> (Jmp, AbsInd) ; 0x7C -> (Jmp, AbsXInd) ; 0xDC -> (Jml, AbsIndLong) ; 0xFC -> (Jsr, AbsXInd).
- `e02_04_more_ops` : 0x0A -> (Asl, Acc) ; 0x44 -> (Mvp, Blk) ; 0x54 -> (Mvn, Blk) ; 0x62 -> (Per, Per) ; 0x80 -> (Bra, Rel) ; 0x82 -> (Brl, RelL) ; 0x83 -> (Sta, Sr) ; 0x93 -> (Sta, SrIndY) ; 0xB1 -> (Lda, DpIndY) ; 0xB7 -> (Lda, DpIndLongY) ; 0xC2 -> (Rep, Imm8) ; 0xD4 -> (Pei, Pei) ; 0xEA -> (Nop, Imp) ; 0xF4 -> (Pea, Pea) ; 0x42 -> (Wdm, Wdm) ; 0xFB -> (Xce, Imp).
- `e02_04_names` : `Mn::Adc.name() == "ADC"`, `Mn::Xce.name() == "XCE"`.
- `e02_04_all_variants_used` : Parcourir MN et AM en les mettant dans un `Vec` sans doublon (les enums derivent `PartialEq`; pas besoin de Hash): MN contient exactement 92 valeurs distinctes, AM exactement 31.
