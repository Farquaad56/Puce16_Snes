## Specification
- Bxx (`Am::Rel`): `off = fetch8 as i8`; condition: BCC C=0, BCS C=1, BNE Z=0, BEQ Z=1, BPL N=0, BMI N=1, BVC V=0, BVS V=1, BRA toujours. Si condition vraie: `target = cpu.pc.wrapping_add(off as i16 as u16)`; `bus.idle()`; si `cpu.e` et `(cpu.pc & 0xFF00) != (target & 0xFF00)`: un 2e `bus.idle()`; `cpu.pc = target`. (`cpu.pc` = adresse apres l'operande.)
- BRL (`Am::RelL`): `lo = fetch8`, `hi = fetch8`; `bus.idle()`; `pc = pc.wrapping_add(off16)`. 4 cycles.
- Le PC reste dans la banque `pb` (wrap 16 bits).

## 7. Controle de flux (cycles exacts, apres le cycle opcode)

| Instruction | Cycles |
|---|---|
| Bxx (rel) | `R(pc++)=off`; si pris: `IO`; en E=1 si franchissement de page (pc apres l'offset vs cible): `IO` supplementaire. Non pris: 2 total. Cible = pc(apres operande) + off signe (wrap 16 bits dans la banque). |
| BRA | idem, toujours pris |
| BRL | `R(pc++)`=lo; `R(pc++)`=hi; `IO`; PC += off16 (total 4) |
| JMP a | `R(pc++)`x2; PC=a (total 3) |
| JMP al (JML) | `R(pc++)`x3; PB=bank, PC=a (total 4) |
| JMP (a) | `R(pc++)`x2; `R(0:a)`=PCL; `R(0:a+1)`=PCH (a+1 wrap 16 bits en banque 0) (total 5) |
| JML [a] | + `R(0:a+2)`=PB (total 6) |
| JMP (a,x) | `R(pc++)`x2; `IO`; `R(PB:a+X)`=PCL; `R(PB:a+X+1)`=PCH (total 6; wrap dans PB) |
| JSR a | `R(pc++)`x2; `IO`; push PCH; push PCL; PC=a (total 6). PC pousse = adresse du DERNIER octet de l'instruction (PC-1). |
| JSR (a,x) | `R(pc++)`=aal; push PCH; push PCL; `R(pc++)`=aah; `IO`; `R(PB:a+X)`x2 (total 8) |
| JSL | `R(pc++)`x2 (aal,aah); push PB; `IO`; `R(pc++)`=bank; push PCH; push PCL (total 8); PB=bank |
| RTS | `IO`; `IO`; pull PCL; pull PCH; `IO`; PC = pulled + 1 (total 6) |
| RTL | `IO`; `IO`; pull PCL; PCH; PB (total 6); PC = pulled + 1 |
| RTI | `IO`; `IO`; pull P; pull PCL; pull PCH; [pull PB si E=0] (total 6 en E=1, 7 en E=0); PC non incremente |
| BRK / COP | `R(pc++)`=signature; [push PB si E=0]; push PCH; push PCL; push P; `R(vec)`lo; `R(vec+1)`hi (total 7 en E=1, 8 en E=0). Apres: I=1, D=0, PB=0. P pousse: B=1 en E=1. |
| WAI | `IO`; `IO` puis le CPU s'arrete jusqu'a une interruption (voir 8) |
| STP | `IO`; `IO` puis arret definitif jusqu'a RESET |
| WDM | `R(pc++)`=signature ignoree (total 2) |
| NOP | `IO` (total 2) |
| MVN/MVP | `R(pc++)`=dst bank; `R(pc++)`=src bank; DB=dst bank; `R(src:X)`; `W(dst:Y)`; `IO`; `IO`; X,Y += 1 (MVN) ou -= 1 (MVP) (si X=1 8 bits sinon 16); A -= 1 (16 bits toujours); si A != $FFFF: PC -= 3 (l'instruction recommence). Total 7 par octet. |

Vecteurs (bank $00): natif COP $FFE4, BRK $FFE6, ABORT $FFE8, NMI $FFEA, (reserve $FFEC), IRQ $FFEE;
emulation COP $FFF4, (reserve $FFF6), ABORT $FFF8, NMI $FFFA, RESET $FFFC, IRQ/BRK $FFFE.

## 6. Tests d'unite des familles (convention)

Les tests utilisent `FlatBus` (`cpu/testbus.rs`): `FlatBus::new()` ; `bus.poke(addr, &[octets])` ecrit sans journal ; `bus.peek(addr) -> u8` ;
`bus.log: Vec<Cycle>` avec `Cycle { addr: u32, val: u8, kind: CycleKind }`, `CycleKind::{Read, Write, Idle}` (un cycle `Idle` a `addr = 0` et `val = 0`) ;
`bus.clear_log()`. Un test pose le programme en `00:8000` (`cpu.pb = 0; cpu.pc = 0x8000`), fixe les registres a la main, fait `cpu.step(&mut bus)`, puis verifie
registres, memoire et `bus.log.len()` (= nombre de cycles de l'instruction, opcode compris) et, quand c'est precise, la suite exacte des cycles.
Un test peut ecrire `let cycles: Vec<(char, u32, u8)>` ou 'R'/'W'/'I' est le type: a lui de choisir une forme lisible, tant que adresse, valeur, ordre sont verifies.

## Tests
Tous les tests sont prefixes par `e02_32_`.

- `e02_32_bne_not_taken` : e=false, p=0x22 (Z=1), pc=0x8000, `D0 10`: pc==0x8002, cycles=2.
- `e02_32_bne_taken` : p=0x20 (Z=0), `D0 10`: pc==0x8012, cycles=3 (log: R, R, Idle).
- `e02_32_bra_negative` : `80 FE` en 0x8000: pc==0x8000, cycles=3.
- `e02_32_emulation_page_cross` : e=true, p=0x30, pc=0x80F0, `D0 20` (Z=0): apres operande pc=0x80F2, cible 0x8112 -> pc==0x8112, cycles=4.
- `e02_32_native_page_cross_no_penalty` : e=false, meme programme: cycles=3.
- `e02_32_emulation_same_page` : e=true, pc=0x8000, `D0 10`: cycles=3.
- `e02_32_all_conditions` : table de verite: BCC (C=0), BCS (C=1), BEQ (Z=1), BNE (Z=0), BMI (N=1), BPL (N=0), BVC (V=0), BVS (V=1): pour chaque opcode (90 B0 F0 D0 30 10 50 70), pris/non pris selon le flag, offset +4.
- `e02_32_brl` : `82 00 01` en 0x8000: pc==0x8103, cycles=4. `82 FD FF`: pc==0x8000.
- `e02_32_wrap_in_bank` : pb=0x05, pc=0xFFF0, `80 20`: apres operande 0xFFF2 + 0x20 -> pc==0x0012, pb==0x05.
