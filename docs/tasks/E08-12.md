## Specification
1. `bus/mod.rs`: `impl State for SysBus` : `master` (u64), `ppu_t` (u64), `mdr`, `memsel`, `pending_dma`, `pending_hdma_init`, `pending_hdma_run`, ET tout compteur de VBlank/frames utilise par `Snes::frame_count()` et `run_frame` (ex. `vblank_count`, drapeau de VBlank pris), puis dans l'ordre: `wram`, `mmio`, `dma`, `timing`, `ppu`, `apu`, `joy`, `cart` (SRAM seulement). `region` n'est pas sauvee ici (`// not saved`).
2. `snes.rs` : `Snes::save_state(&self) -> Vec<u8>` et `Snes::load_state(&mut self, data: &[u8]) -> Result<(), StateError>` (variant reel ; variant motif de test: `save_state` renvoie un blob d'au moins l'en-tete et `load_state` l'accepte, sans plus). Format: `u32 STATE_VERSION`, `u8 region` (Ntsc 0, Pal 1), `u64 frame`, `u64 cpu_master` (= `sys.master`), puis `Cpu::save`, puis `SysBus::save`. `load_state`: version differente -> `Err(Version(v))` ; region differente de la region de la console -> `Err(Mismatch("region"))` ; octets restants -> `Mismatch("trailing data")` ; le Snes n'est modifie qu'apres lecture reussie de l'en-tete (si le corps est corrompu, l'etat peut etre incoherent: documente-le par un commentaire; le desktop recharge alors la ROM).
3. `Snes::state_hash` reste inchange.

## 9. Save states (core, `savestate.rs`)

- Format binaire maison: octets little-endian, `u32` version du blob (1 au debut). Aucun serde, aucune dependance.
- Ecriture/lecture par un trait: `trait State { fn save(&self, w: &mut StateWriter); fn load(&mut self, r: &mut StateReader) -> Result<(), StateError>; }` implemente par chaque composant, dans CET ordre: `master` (+ phase APU `apu_acc: i64`), Cpu, Bus (WRAM 128 Kio, registres $4200-$421F, mdr), DMA (8 canaux + etat HDMA), timing, Ppu (registres, VRAM, CGRAM, OAM, latchs, position, `line_obj`, framebuffer 512x478), Apu (RAM 64 Kio, SMP, timers, ports, DSP: registres, voix, echo, tampons), joypads, Cart (SRAM seulement ; la ROM n'est PAS sauvee).
- `StateWriter`: `u8/u16/u32/u64/i64/bool/bytes(&[u8])/slice_u16`; `StateReader` symetrique avec verification de fin de donnees (erreur `StateError::Truncated`/`Version`/`Mismatch`).
- Aller-retour: `load_state(save_state())` laisse `state_hash` inchange, et executer N frames apres un `load_state` donne le meme `state_hash` que sans passer par le save state.
- Taille attendue: ~1.3 Mio ; pas de compression en v1.

## 5. API publique de `puce16-core` (stable, ne pas changer sans question)

```rust
pub enum Region { Ntsc, Pal }
pub struct Snes { /* prive */ }
impl Snes {
    pub fn new(rom: &[u8], region: Option<Region>) -> Result<Snes, LoadError>; // None = deduit du header
    pub fn reset(&mut self);
    pub fn run_frame(&mut self);                       // jusqu'au debut du prochain VBlank
    pub fn run_master(&mut self, master_clocks: u64);  // pour les tests de timing
    pub fn step_instruction(&mut self);                // une instruction CPU complete (debugger)
    pub fn frame_count(&self) -> u64;
    pub fn frame(&self) -> FrameView<'_>;              // { width, height, pixels: &[u32] } XRGB8888
    pub fn take_audio(&mut self, out: &mut Vec<[i16; 2]>); // echantillons DSP 32 kHz-ish
    pub fn set_joypad(&mut self, port: usize, buttons: u16); // port 0 ou 1; bits = format JOY1L/H
    pub fn load_sram(&mut self, data: &[u8]);
    pub fn sram(&self) -> Option<&[u8]>;               // Some si la cartouche a de la SRAM
    pub fn state_hash(&self) -> u64;
    pub fn save_state(&self) -> Vec<u8>;
    pub fn load_state(&mut self, data: &[u8]) -> Result<(), StateError>;
    pub fn debug(&self) -> DebugSnapshot;              // registres CPU/APU, H/V, master (pour rapports d'echec)
}
```
Accesseurs ajoutes par des taches (la tache qui les cree fait foi): `cart_info`, `master`, `peek_wram` (E03-35), `apu_port` (E07-07), `debug_vram/cgram/oam/ppu_regs/smp/dma/wram_page/run_until_pc` (E08-32). `Snes` n'a pas d'autre acces a l'etat interne.

Framebuffer: tampon fixe 512x478 u32; `FrameView` expose la zone utile
(256x224, 256x239, 512x224, 512x448, 512x478 selon SETINI). Details dans specs/05_PPU.md.

## Tests
Tous les tests sont prefixes par `e08_12_`.

- `e08_12_roundtrip_hash` : ROM `common::make_rom(&[0x78,0x18,0xFB,0x80,0xFE], Map::LoRom)` ; `Snes::new` ; 5 `run_frame` ; `blob = save_state()` ; `Snes` neuf ; `load_state(&blob)` Ok ; `state_hash()` egal.
- `e08_12_blob_size` : `blob.len()` entre 1_000_000 et 1_600_000 (VRAM+WRAM+RAM APU+framebuffer).
- `e08_12_resave_identical` : `load_state(&blob)` puis `save_state()` == `blob` (octet a octet).
- `e08_12_continue_equals_uninterrupted` : A: 5 frames, save, 5 frames, hash. B: neuf, `load_state` de la sauvegarde de A, 5 frames, hash : egaux.
- `e08_12_bad_version` : blob dont les 4 premiers octets sont remplaces par `[2,0,0,0]` -> `Err(Version(2))`.
- `e08_12_region_mismatch` : blob d'une console NTSC charge dans une console PAL -> `Err(Mismatch("region"))`.
- `e08_12_truncated` : blob coupe a la moitie -> `Err(Truncated)` ; blob + 1 octet -> `Err(Mismatch("trailing data"))`.
- `e08_12_frame_count_restored` : apres `load_state` dans une console neuve, `frame_count()` egale celui de la console sauvee, et un `run_frame()` de plus donne `frame_count()` + 1 (pas de repart a zero).
- `e08_12_sram_roundtrip` : ROM avec SRAM (chipset 0x02, ram_log2 3, via `make_rom_with`) : `load_sram` d'un motif avant `save_state`; apres `load_state` dans une console neuve, `sram()` == motif.
