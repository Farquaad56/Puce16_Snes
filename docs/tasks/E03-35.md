## 7. Boucle d'une frame
`Snes::run_frame`: `loop { cpu.step(&mut sys); if sys.take_vblank_flag() { break } }` (le drapeau est pose quand `TimingOut.vblank_start` est vu). Garde-fou: si plus de 2 000 000 instructions sans VBlank -> `panic!("run_frame: no vblank")` (CPU arrete par STP, par exemple).
`Snes::run_master(n)`: `let end = sys.master + n; while sys.master < end { cpu.step(..) }`.
`frame_count` = nombre de `vblank_start` vus.

## Tests
Tous les tests sont prefixes par `e03_35_`.

- `e03_35_run_frame_basic` : ROM `make_rom(&[0x78,0x18,0xFB,0xA9,0x42,0x8D,0x10,0x00,0x80,0xFE], LoRom)`: `run_frame()` : `peek_wram(0x10)==0x42`, `frame_count()==1`, `debug().pb==0`, `debug().pc==0x8008`, `debug().e==false` (XCE a passe en natif), `debug().v==225`, `debug().dot <= 20`.
- `e03_35_frame_master_range` : apres le 1er `run_frame`: `306_905 <= master() && master() <= 307_000` ; apres le 2eme : `master() - m1` entre 357_268 et 357_468 ; apres le 3eme (frame avec ligne 240 courte) : delta entre 357_264 et 357_464.
- `e03_35_run_master_exact` : `m0 = master()` (le reset du CPU a deja consomme quelques cycles) ; `run_master(1000)` : `master() >= m0 + 1000` et `master() < m0 + 1000 + 80` (la derniere instruction peut depasser) ; `run_master(0)` ne change pas `master()`.
- `e03_35_step_instruction` : juste apres `new`, 3 `step_instruction()` executent SEI, CLC, XCE : `debug().e==false` apres le 3eme et `debug().pc==0x8003`.
- `e03_35_state_hash_determinism` : deux `Snes::new` identiques : meme `state_hash` apres `run_frame()` x3 ; des hash differents entre 2 et 3 frames ; `run_master(1000)` des deux cotes : meme hash.
- `e03_35_joypad_api` : `set_joypad(0,0x8000)`: `joypad(0)==0x8000`, `joypad(1)==0` ; `set_joypad(2,1)` ignore ; le hash change apres `set_joypad(0,1)`.
- `e03_35_sram_option` : ROM sans SRAM : `sram()==None`. ROM `make_rom_with(&[0xEA],LoRom,15,3,0x02,1)` : `sram().unwrap().len()==8192`; `load_sram(&[1,2,3])` puis `sram().unwrap()[..4]==[1,2,3,0]`.
- `e03_35_cart_info` : `cart_info().unwrap()` pour `make_rom` LoRom: title=="PUCE16 TEST ROM", map==LoRom, region==Ntsc, rom_len==32768, sram_len==0, battery==false. Pour `new_test_pattern`: `cart_info()==None`.
- `e03_35_pattern_debug_default` : `Snes::new_test_pattern(Ntsc).debug()`: tous les champs 0 sauf `frame` (== frame_count).
- `e03_35_frame_view_real` : `frame().width==256`, `height==224`, `pixels.len()==256*224`, tous `0xFF000000`.
- `e03_35_stp_still_reaches_vblank` : ROM `[0x78,0x18,0xFB,0xDB]` (SEI, CLC, XCE, STP) : STP arrete le CPU mais, selon 01b section 4, un CPU arrete execute des cycles `idle` qui font avancer le temps : `run_frame()` revient (VBlank atteint) et `frame_count()==1`, `debug().pc==0x8004`.
