# E05-18 - ppu/mod.rs: hi-res et pseudo hi-res dans step_dot, export 512 colonnes
Epopee: E05 | Type: code | Dependances: E05-17 | Taille estimee: ~150 lignes

## Contexte
Rendu des lignes hi-res: modes 5/6 et pseudo hi-res (SETINI bit 3). Une ligne hi-res ecrit DEUX colonnes par pixel de 256 (`2x` = ecran secondaire, `2x+1` = ecran principal).
La vue exportee fait 512 colonnes des qu'au moins une rangee de la frame est hi-res; les rangees non hi-res sont alors doublees horizontalement SANS modifier le tampon interne (`fb`). Rappel `UNKNOWN - to confirm`: color math des colonnes secondaires, bornes de fenetre en hi-res (on utilise `x`), OBJ en entrelace (sprites inchanges). Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'. Aides de test (a recopier dans le fichier de test): `fn put_vram(p: &mut Ppu, addr: u16, w: u16) { p.write(0x15,0x80); p.write(0x16,(addr & 0xFF) as u8); p.write(0x17,(addr >> 8) as u8); p.write(0x18,(w & 0xFF) as u8); p.write(0x19,(w >> 8) as u8); }` ; `fn put_cgram(p: &mut Ppu, i: u8, w: u16) { p.write(0x21,i); p.write(0x22,(w & 0xFF) as u8); p.write(0x22,(w >> 8) as u8); }` ; `fn set_scroll(p: &mut Ppu, reg: u8, v: u16) { p.write(reg,(v & 0xFF) as u8); p.write(reg,(v >> 8) as u8); }`. Un `Ppu::new(Region::Ntsc)` neuf est en forced blank: toutes ces ecritures sont autorisees. Chaque test construit SA scene sur un `Ppu` neuf. Aide locale de test: `fn at(p: &mut Ppu, v: u32, dot: u32) { for _ in 0..(v * 340 + dot) { p.step_dot(); } }` (NTSC, frame 0, sans entrelace). Capture de la frame 0 = `at(p,225,1)`; la frame suivante est capturee 262*340 steps plus tard (sans entrelace).

## Specification
Dans `ppu/mod.rs` ajoute au `Ppu` (etat derive de l'image, NON hache, remis a zero par `reset`) : `line_hires: bool` et `row_hires: Vec<bool>` (478 elements, faux).
```rust
impl Ppu {
    pub fn hires_line(&self) -> bool;                              // regs.bg_mode == 5 || regs.bg_mode == 6 || self.pseudo_hires
    pub fn compose_hires(&self, x: usize, v: usize) -> (u16, u16);  // (colonne 2x, colonne 2x+1) en BGR555 avant luminosite
}
```
`compose_hires(x, v)` (hors du dernier point la logique est celle de `compose_pixel`, E05-16) :
- `order` et `extbg` comme `compose_pixel` ; `lm = sample_layers_hx(x, 2*x+1, v)` ; `ls = sample_layers_hx(x, 2*x, v)` ; `fixed = fixed_color(fixed_r, fixed_g, fixed_b)`.
- `main = pick_layers(order, &lm, regs.tm, [layer_hidden(true,l,x) ...], cgram[0])` ; `sub = pick_layers(order, &ls, regs.ts, [layer_hidden(false,l,x) ...], fixed)` (toujours calcule, meme si `addend_subscreen` est faux) ; `(black, prevent) = color_window_flags(x)`.
- colonne `2x+1` = `color_math(&main, &sub, black, prevent, &regs)`.
- colonne `2x` : `base = if black { 0 } else { sub.rgb }` ; si `!regs.addend_subscreen && !prevent && math_layer_ok(sub.layer, sub.obj_pal, regs.math_mask)` alors `blend(base, fixed, regs.math_sub, regs.math_half)` sinon `base`.
`step_dot` (point 3, E04-14/E05-16) :
- Au dot 22 de chaque ligne visible (`1 <= v <= vis_last`) : `row = output_row((v-1), field, interlace)` ; `line_hires = hires_line()` ; `row_hires[row] = line_hires`.
- Pour chaque dot visible : si `line_hires` : `(e, o) = compose_hires(x, v)` (noir 0xFF000000 pour les deux si `forced_blank`) ; `fb.set(2*x, row, argb(e))` ; `fb.set(2*x+1, row, argb(o))` ; sinon comportement de E05-16 (colonne `x` seulement).
- Capture (a `dot == 0`, `v == vblank_start()`, APRES le rechargement OAM) : `h = vis_last * (if interlace {2} else {1})` ; `frame_hires = row_hires[0..h].iter().any(|b| *b)` ; si `frame_hires` : `w = 512` ; `fb.set_view(512, h)` ; `view` = pour chaque rangee `r` de `0..h` : si `row_hires[r]` les 512 colonnes de `fb` ; sinon `pixel_double` des 256 premieres colonnes de `fb` ; si non : `w = 256` et `view = fb.compact()` comme avant. `view_w = w`, `view_h = h`.

## 12. Hi-res et pseudo hi-res
`hires_line = (mode == 5 || mode == 6 || hires_bit)`.
- **Pseudo hi-res** (SETINI bit3, modes autres que 5/6): colonne `2x+1` = ecran principal (calcul 11.4 normal), colonne `2x` = ecran secondaire `pick(Sub, x)` avec color math UNIQUEMENT si `!addend_subscreen` et couche autorisee (`layer_ok` calcule sur `sub.layer`) et `!prevent`: `blend(sub.rgb, fixed_color)`; sinon `sub.rgb` brut. `black` s'applique aux deux colonnes. (`UNKNOWN - to confirm`.)
- **Modes 5 et 6**: les fonds sont evalues sur 512 colonnes: `bg_pixel_hires(n, hx, v)` avec `hx = 2x + 1` pour l'ecran principal et `hx = 2x` pour le secondaire. Les sprites sont a 256 colonnes (meme pixel pour les deux). Tuile BG: 16 px de large (carte), BGMODE choisit 16x8 ou 16x16. Position: `px = hx + (hofs[n] << 1)`; entree de carte `(px >> 4, py >> 3 ou >> 4)`; demi-tuile gauche/droite: `xs = ((px >> 3) & 1) ^ H`, numero `T + xs (+ ys*16 si tuile 16 haute)`; pixel `fx = (px & 7) ^ (H?7:0)`. Memes regles de priorite/palette/couleur que 7. Entrelacement (SETINI bit0): `py = vm_il + vofs[n]` avec `vm_il = (v << 1) | field` (sinon `v`) `UNKNOWN - to confirm`. OPT mode 6: `UNKNOWN`, a faire en dernier.
Ecriture dans le framebuffer: voir 05 section 6.

## 6. Sortie: framebuffer

- Tampon interne fixe: `[u32; 512 * 478]`, pixel XRGB8888 avec octet haut `0xFF`: `0xFF000000 | r8 << 16 | g8 << 8 | b8`.
- Conversion finale d'un canal 5 bits `c5` (apres math et luminosite): `c5b = c5 * brightness / 15` (division entiere; brightness 0..15), puis `c8 = (c5b << 3) | (c5b >> 2)` (D-010). `forced_blank` -> `0xFF000000` (noir).
- Rangee de sortie: `row = if frame_interlaced { 2 * r + field_as_u8 } else { r }`. Les rangees de l'autre field gardent leur contenu precedent (image entrelacee complete = 448 ou 478 lignes).
- Colonne: mode 256: `x` (largeur utile 256). Mode hi-res (SETINI.3 ou BG mode 5/6, voir 05b section 12): colonnes `2x` (sous-ecran) et `2x+1` (ecran principal) dans le tampon 512.
- Si la ligne n'est pas hi-res mais que la frame l'est (`frame_hires` = au moins une ligne hi-res dans la frame courante), chaque pixel est duplique sur `2x`, `2x+1` a l'export.
- `FrameView` (spec 01_ARCHITECTURE section 5) est calcule au debut de VBlank (`v == vblank_start`): `width = if frame_hires {512} else {256}`, `height = (vis_last) * (if frame_interlaced {2} else {1})`, avec `frame_interlaced = interlace` lu a ce moment. `pixels` = copie compacte de la zone utile (stride = width). `Ppu::frame()` retourne la derniere frame complete.
- Les lignes non visibles ou ligne 0: non ecrites.
