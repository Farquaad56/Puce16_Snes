## Specification
Dans `ppu/output.rs` (garde `FrameView`, `FrameBuf`, `pixel_double`, `make_view` de E01-05):
```rust
pub fn channel8(c5: u8, brightness: u8) -> u8;          // c5 0..=31, brightness 0..=15 ; c5b = c5 as u32 * brightness as u32 / 15 ; ((c5b << 3) | (c5b >> 2)) as u8
pub fn bgr555_to_xrgb(rgb: u16, brightness: u8) -> u32; // r5 = rgb & 31, g5 = (rgb >> 5) & 31, b5 = (rgb >> 10) & 31 ; 0xFF000000 | r8 << 16 | g8 << 8 | b8
pub fn output_row(r: usize, field: bool, interlaced: bool) -> usize;   // interlaced: 2 * r + field as usize ; sinon r
```
`brightness > 15` est traite comme 15 (`min`). Les bits 15 de `rgb` sont ignores.

## 6. Sortie: framebuffer

- Tampon interne fixe: `[u32; 512 * 478]`, pixel XRGB8888 avec octet haut `0xFF`: `0xFF000000 | r8 << 16 | g8 << 8 | b8`.
- Conversion finale d'un canal 5 bits `c5` (apres math et luminosite): `c5b = c5 * brightness / 15` (division entiere; brightness 0..15), puis `c8 = (c5b << 3) | (c5b >> 2)` (D-010). `forced_blank` -> `0xFF000000` (noir).
- Rangee de sortie: `row = if frame_interlaced { 2 * r + field_as_u8 } else { r }`. Les rangees de l'autre field gardent leur contenu precedent (image entrelacee complete = 448 ou 478 lignes).
- Colonne: mode 256: `x` (largeur utile 256). Mode hi-res (SETINI.3 ou BG mode 5/6, voir 05b section 12): colonnes `2x` (sous-ecran) et `2x+1` (ecran principal) dans le tampon 512.
- Si la ligne n'est pas hi-res mais que la frame l'est (`frame_hires` = au moins une ligne hi-res dans la frame courante), chaque pixel est duplique sur `2x`, `2x+1` a l'export.
- `FrameView` (spec 01_ARCHITECTURE section 5) est calcule au debut de VBlank (`v == vblank_start`): `width = if frame_hires {512} else {256}`, `height = (vis_last) * (if frame_interlaced {2} else {1})`, avec `frame_interlaced = interlace` lu a ce moment. `pixels` = copie compacte de la zone utile (stride = width). `Ppu::frame()` retourne la derniere frame complete.
- Les lignes non visibles ou ligne 0: non ecrites.

## Tests
Tous les tests sont prefixes par `e04_13_`.

- `e04_13_channel8_extremes` : `channel8(31,15)==255` ; `channel8(31,0)==0` ; `channel8(0,15)==0` ; `channel8(1,15)==8` ; `channel8(16,15)==132` ; `channel8(31,1)==16` ; `channel8(31,7)==115` ; `channel8(31,8)==132` ; `channel8(10,5)==24`.
- `e04_13_channel8_clamp` : `channel8(31,200)==255` (brightness plafonnee a 15).
- `e04_13_primary_colors` : `bgr555_to_xrgb(0x7FFF,15)==0xFFFFFFFF` ; `(0x001F,15)==0xFFFF0000` (rouge) ; `(0x03E0,15)==0xFF00FF00` (vert) ; `(0x7C00,15)==0xFF0000FF` (bleu) ; `(0x0000,15)==0xFF000000`.
- `e04_13_brightness_scaling` : `bgr555_to_xrgb(0x7FFF,0)==0xFF000000` ; `(0x7FFF,8)==0xFF848484` ; `(0x0421,15)==0xFF080808` (r=g=b=1).
- `e04_13_bit15_ignored` : `bgr555_to_xrgb(0x801F,15)==bgr555_to_xrgb(0x001F,15)`.
- `e04_13_output_row` : `output_row(0,false,false)==0` ; `(5,true,false)==5` ; `(5,false,true)==10` ; `(5,true,true)==11` ; `(237,true,true)==475` ; `(223,false,true)==446`.
