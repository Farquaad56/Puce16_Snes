## Specification
Dans `dma/mod.rs` (garde `pub mod hdma;`):
```rust
#[derive(Default, Clone)]
pub struct Channel { pub dmap: u8, pub bbad: u8, pub a1t: u16, pub a1b: u8, pub das: u16, pub dasb: u8, pub a2a: u16, pub nltr: u8, pub unused: u8,
                     pub(crate) do_transfer: bool, pub(crate) done: bool, pub(crate) line_counter: u8 }
#[derive(Default, Clone)] pub struct Dma { pub ch: [Channel; 8] }
impl Dma {
    pub fn new() -> Dma;       // tous les registres a 0xFF (u16: 0xFFFF), done=true, do_transfer=false, line_counter=0
    pub fn read(&self, reg: u16) -> Option<u8>;        // reg 0x4300..=0x437F ; None = open bus
    pub fn write(&mut self, reg: u16, v: u8);
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);   // pour chaque canal: dmap bbad (u8), a1t (u16), a1b, das (u16), dasb, a2a (u16), nltr, unused, do_transfer done (u8 0/1), line_counter
}
```
Decodage: `n = ((reg >> 4) & 7) as usize`, `off = reg & 0xF`. Offsets: 0 dmap, 1 bbad, 2 a1t bas, 3 a1t haut, 4 a1b, 5 das bas, 6 das haut, 7 dasb, 8 a2a bas, 9 a2a haut, 0xA nltr, 0xB et 0xF `unused` (le MEME octet), 0xC-0xE: lecture `None`, ecriture ignoree. `reg` hors `0x4300..=0x437F`: lecture `None`, ecriture ignoree.

## 1. Registres (8 canaux, n = 0..7, adresse $43n0-$43nF)

| Reg | Addr | Power-on | Description |
|---|---|---|---|
| DMAPn | $43n0 | $FF | `DI.A APPP`: D=direction (0: A->B, 1: B->A); I=HDMA indirect; bit5 inutilise; A (bits 4-3)=ajustement adresse A (0 incremente; 2 decremente; 1 ou 3 fixe); P (bits2-0) = pattern |
| BBADn | $43n1 | $FF | adresse B-bus: $2100 + valeur |
| A1TnL/H/B | $43n2/3/4 | $FFFFFF | adresse A-bus source (DMA) ou debut de table (HDMA) |
| DASnL/H | $43n5/6 | $FFFF | nombre d'octets (DMA; 0 = 65536) ou adresse indirecte (HDMA) |
| DASBn | $43n7 | $FF | banque de l'adresse indirecte HDMA |
| A2AnL/H | $43n8/9 | $FFFF | adresse courante dans la table HDMA (banque = A1Bn) |
| NLTRn | $43nA | $FF | HDMA: `RLLL LLLL` flag repetition + compteur de lignes |
| UNUSEDn | $43nB et $43nF | $FF | un octet partage, lecture/ecriture sans effet |
| (autres) | $43nC-$43nE | - | open bus |

Tous les registres $43xx sont lisibles et ecrivables (acces a 6 clocks).

### 3.7 Dma (`dma/mod.rs`, `dma/hdma.rs`)
```rust
pub trait DmaBus {
    fn a_read(&mut self, addr: u32) -> u8;      // lecture A-bus SANS avancer le temps (le moteur DMA gere le temps)
    fn a_write(&mut self, addr: u32, v: u8);
    fn b_read(&mut self, reg: u8) -> u8;        // $2100 + reg
    fn b_write(&mut self, reg: u8, v: u8);
    fn elapse(&mut self, clocks: u32);          // avance master et appelle catch_up
    fn master(&self) -> u64;
}
#[derive(Default)] pub struct Channel { pub dmap: u8, pub bbad: u8, pub a1t: u16, pub a1b: u8, pub das: u16, pub dasb: u8, pub a2a: u16, pub nltr: u8, pub unused: u8,
                                         /* etat HDMA prive */ do_transfer: bool, done: bool, line_counter: u8 }
#[derive(Default)] pub struct Dma { pub ch: [Channel; 8] }
impl Dma { pub fn new() -> Dma;                                   // valeurs de power-on de la spec 03
    pub fn read(&self, reg: u16) -> Option<u8>; pub fn write(&mut self, reg: u16, v: u8);    // $4300-$437F ; None = open bus
    pub fn run_general<B: DmaBus>(&mut self, bus: &mut B, mask: u8);
    pub fn hdma_init<B: DmaBus>(&mut self, bus: &mut B, mask: u8);
    pub fn hdma_run_line<B: DmaBus>(&mut self, bus: &mut B, mask: u8);
    pub fn hash_into(&self, h: &mut Fnv64); }
```
`SysBus` appelle `let mut d = std::mem::take(&mut self.dma); d.run_general(self, mask); self.dma = d;` (evite l'emprunt double). `SysBus` implemente `DmaBus`.

## Tests
Tous les tests sont prefixes par `e03_17_`.

- `e03_17_power_on` : `Dma::new()`: pour n in 0..8 et off in {0..=0xB, 0xF}: `read(0x4300|n<<4|off)==Some(0xFF)` ; `ch[3].a1t==0xFFFF`, `ch[3].das==0xFFFF`, `ch[3].a2a==0xFFFF`.
- `e03_17_unmapped` : `read(0x430C)==None`, `read(0x430D)==None`, `read(0x437E)==None` ; `read(0x4380)==None` ; `read(0x42FF)==None`.
- `e03_17_a1t_a1b` : `write(0x4312,0x34); write(0x4313,0x12); write(0x4314,0x7E)` -> `ch[1].a1t==0x1234`, `ch[1].a1b==0x7E`, `read(0x4312)==Some(0x34)`, `read(0x4313)==Some(0x12)`, `read(0x4314)==Some(0x7E)`.
- `e03_17_das` : `write(0x4325,0x00); write(0x4326,0x01); write(0x4327,0x7F)` -> `ch[2].das==0x0100`, `ch[2].dasb==0x7F` ; relire donne les memes octets.
- `e03_17_dmap_bbad` : `write(0x4300,0x01); write(0x4301,0x18)` -> `ch[0].dmap==1`, `ch[0].bbad==0x18`.
- `e03_17_a2a_nltr` : `write(0x4348,0xCD); write(0x4349,0xAB); write(0x434A,0x85)` -> `ch[4].a2a==0xABCD`, `ch[4].nltr==0x85`.
- `e03_17_unused_shared` : `write(0x435B,0x77)` -> `read(0x435F)==Some(0x77)` ; `write(0x435F,0x11)` -> `read(0x435B)==Some(0x11)` ; `write(0x436C,1)` ignore et `read(0x436C)==None`.
- `e03_17_hash` : hash identique pour deux `Dma::new()` ; differe apres `write(0x4300,0)` ; differe aussi apres modification de `ch[7].das`.
