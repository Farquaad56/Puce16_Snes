## Specification
Dans `bus/route.rs`: `impl SysBus { pub fn write_inner(&mut self, addr: u32, v: u8) { ... } }` (ne touche pas `mdr`, n'avance pas le temps).
- Banques 00-3F / 80-BF (`bank & 0x7F <= 0x3F`), selon `a`:
  `0x0000..=0x1FFF` -> `wram.write(a as u32, v)` ; `0x2100..=0x213F` -> `ppu.write((a - 0x2100) as u8, v)` ; `0x2140..=0x217F` -> `apu.port_write((a & 3) as usize, v)` ;
  `0x2180` -> `wram.data_write(v)` ; `0x2181` -> `wram.set_addr_l(v)` ; `0x2182` -> `set_addr_m` ; `0x2183` -> `set_addr_h` ;
  `0x4016` -> `joy.write_out(v & 1 != 0)` ;
  `0x4200..=0x420D` -> `match mmio.write(a, v, self.master) { Mdmaen(m) => { self.pending_dma = m; self.dma_wait = true; } Hdmaen(_) => {} Memsel(b) => self.memsel = b, Wrio{old,new} => self.ppu.wrio_write(old, new), None => {} }` ;
  `0x4300..=0x437F` -> `dma.write(a, v)` ;
  `0x6000..=0xFFFF` -> `cart.write(bank, a, v)` (resultat ignore) ; autre: rien.
- Banques 7E/7F: `wram.write(((bank & 1) << 16) | a, v)`.
- Autres banques: `cart.write(bank, a, v)`.
(`dma_wait` sert a E03-32: le DMA demarre apres le cycle SUIVANT l'ecriture.) Dans les tests: `mod common; use common::*;` puis `fn mk(code: &[u8]) -> SysBus { SysBus::new(Cart::from_bytes(&make_rom(code, Map::LoRom)).unwrap(), Region::Ntsc) }` (imports: `puce16_core::bus::SysBus`, `puce16_core::cart::Cart`, `puce16_core::Region`).

## 6. Open bus et routage (`read_inner` / `write_inner`)
Banque `b = addr >> 16`, `a = addr & 0xFFFF`. Zones systeme pour `(b & 0x7F) <= 0x3F` (banques 00-3F et 80-BF):
| a | read | write |
|---|---|---|
| 0000-1FFF | `wram.read(a)` | `wram.write(a, v)` |
| 2100-213F | `ppu.read(a-0x2100, mdr, wrio bit7)` (E03: renvoie mdr) ; met a jour `mdr` | `ppu.write(a-0x2100, v)` |
| 2140-217F | `apu.port_read(a & 3)` | `apu.port_write(a & 3, v)` |
| 2180 | `wram.data_read()` | `wram.data_write(v)` |
| 2181-2183 | open bus (mdr) | `wram.set_addr_l/m/h(v)` |
| 4016 | `(mdr & 0xFC) \| joy.read_port(0)` | `joy.write_out(v & 1 != 0)` |
| 4017 | `(mdr & 0xE0) \| 0x1C \| joy.read_port(1)` | ignoree |
| 4200-420D | open bus | `mmio.write(..)` puis appliquer l'effet (Mdmaen -> `pending_dma = v`; Hdmaen -> `mmio.hdmaen = v` ; Memsel -> `self.memsel`; Wrio -> `ppu.wrio_write(old,new)`) |
| 4210-421F | `mmio.read(..)` | ignoree |
| 4300-437F | `dma.read(a)` (None -> mdr) | `dma.write(a, v)` |
| 6000-FFFF | `cart.read(b, a)` (None -> mdr) | `cart.write(b, a, v)` |
| autre | open bus (mdr) | ignoree |
Banques 40-7D / C0-FF: `7E-7F` = `wram.read(((b & 1) << 16) | a)` ; autres: `cart.read(b, a)` (None -> mdr). Les ecritures cartouche passent par `cart.write`.
Les lectures ne mettent `mdr` a jour que quand la valeur renvoyee provient du bus de donnees externe: en v1, `mdr = valeur lue` pour TOUTE lecture CPU.

## Tests
Tous les tests sont prefixes par `e03_28_`.

- `e03_28_wram_writes` : `write_inner(0x7E0020,0x12)` -> `wram.read(0x20)==0x12` ; `write_inner(0x000020,0x34)` -> 0x34 ; `write_inner(0x3F0021,0x56)` -> `wram.read(0x21)==0x56` ; `write_inner(0x7F0000,5)` -> `wram.read(0x10000)==5` ; `write_inner(0x7FFFFF,9)` -> `wram.read(0x1FFFF)==9`.
- `e03_28_wmadd_port` : `write_inner(0x002181,0x34); 0x002182 <- 0x12; 0x002183 <- 0x01; 0x002180 <- 0xCC`: `wram.read(0x11234)==0xCC` et `wram.addr==0x11235`.
- `e03_28_nmitimen_effects` : `write_inner(0x004200,0x81)` -> `mmio.nmitimen==0x81` ; `write_inner(0x00420C,0x05)` -> `mmio.hdmaen==5` ; `write_inner(0x00420D,0x01)` -> `memsel==true` ; `write_inner(0x00420D,0x00)` -> false.
- `e03_28_mdmaen_pending` : `write_inner(0x00420B,0x05)` -> `pending_dma()==5` ; `write_inner(0x00420B,0x00)` -> `pending_dma()==0`.
- `e03_28_wrio` : `write_inner(0x004201,0x7F)` -> `mmio.wrio==0x7F`.
- `e03_28_joyout` : `bus.joy.set_buttons(0,0x8000)`; `write_inner(0x004016,1)`: `read_inner(0x004016)&1` vaut 1 trois fois de suite (out0 vrai) ; `write_inner(0x004016,0)` puis lecture suivante: bit 15 (1) puis les lectures suivantes donnent 0.
- `e03_28_dma_regs` : `write_inner(0x004300,0x01)` -> `dma.ch[0].dmap==1` ; `write_inner(0x004372,0x34)` -> `dma.ch[7].a1t & 0xFF==0x34` (partie basse).
- `e03_28_ppu_apu` : `write_inner(0x002100,0x0F)` -> `ppu.forced_blank()==false` ; `write_inner(0x002100,0x80)` -> true ; `write_inner(0x002142,0x09)` -> `apu.cpu_to_apu(2)==9` ; `write_inner(0x002146,0x07)` -> `apu.cpu_to_apu(2)==7`.
- `e03_28_rom_and_sram` : ROM sans SRAM: `write_inner(0x008000,0x77)`: `read_inner(0x008000)` inchange (0xEA). ROM avec SRAM (`make_rom_with(&[0xEA],LoRom,15,3,0x02,1)`): `write_inner(0x700000,0x5A)` -> `cart.read(0x70,0)==Some(0x5A)` et `read_inner(0x700000)==0x5A`.
- `e03_28_ignored_zones` : `write_inner` sur 0x002000, 0x0021FF, 0x004100, 0x004210, 0x004380, 0x005000 ne panique pas et ne change pas le hash du bus (comparer `hash_into` avant/apres).
- `e03_28_unknown_mmio_reg` : `write_inner(0x00420E,0xFF)` et `write_inner(0x00420F,0xFF)` ne changent rien (hash identique).
