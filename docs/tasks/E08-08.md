# E08-08 - State pour Ppu (position, tampons de ligne, framebuffer)
Epopee: E08 | Type: code | Dependances: E08-07 | Taille estimee: ~140 lignes

## Contexte
Assemble l'etat du PPU: appelle les `State` de Vram/Cgram/Oam/Scroll/M7Regs/Regs puis sauve les champs propres de `Ppu` (position `v`/`dot`/`field`, drapeaux d'entrelacement et de surbalayage, latchs H/V, tampons de ligne des fonds et des sprites, `line_obj`, tampons de fenetre, framebuffer 512x478 complet, `row_hires`...). Regle commune des sauvegardes d'etat (spec 08 section 9, spec 09 section 9): `impl State for X` sauve, DANS L'ORDRE DE DECLARATION, tous les champs de X qui (a) sont couverts par `hash_into`, ou (b) influencent le comportement futur. Ne sauve PAS les constantes derivees de la region ou de la ROM (reconstruites par le constructeur): les lister dans un commentaire `// not saved: <champ> (<raison>)`.
Les tableaux de taille fixe s'ecrivent sans prefixe de longueur (`bytes`, `slice_u16`), les `Vec` de taille variable avec prefixe (`vec_u8`, `vec_u16`). Un enum est sauve par un `u8` d'indice explicite; une valeur inconnue au chargement donne `StateError::Mismatch("<champ>")`. `load` ecrase les champs en place.
Les tests sont des tests unitaires DANS le fichier (`#[cfg(test)] mod tests`, noms `e08_NN_...`): ils peuvent donc ecrire les champs prives. Forme des tests: (1) `roundtrip_all_fields`: mettre CHAQUE champ sauve a une valeur non nulle et distincte, `save`, `load` dans une instance neuve (constructeur habituel du type), puis re-`save` de la copie = memes octets ET `hash_into` identique (si le type en a un); (2) `truncated`: pour n dans {0, len/2, len-1}, `load` sur `data[..n]` renvoie `Err(StateError::Truncated)`; (3) un test comportemental propre au type (indique ci-dessous). Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## Specification
`impl State for Ppu` dans `ppu/mod.rs`. Ordre: `region` (u8: Ntsc 0, Pal 1; au load, une region differente de celle de l'instance donne `Mismatch("region")`), puis les sous-structures (vram, cgram, oam, scroll, m7, regs) par leur `save`, puis les champs restants de `Ppu` dans l'ordre de declaration. Le framebuffer `fb` (512*478 `u32`) s'ecrit avec `slice_u32`. Les tampons de ligne (rendus precedemment) sont sauves aussi: un save state au milieu d'une ligne doit redonner la meme image.
Test comportemental: deux `Ppu` (original et restaure en milieu de frame, par exemple `v = 100`, `dot = 77`, apres 120 000 `step_dot` d'une scene de VRAM/CGRAM ecrite par les registres) executent 50 000 `step_dot` de plus : `hash_into` egaux et `frame()` identiques pixel a pixel.

## 9. Save states (core, `savestate.rs`)

- Format binaire maison: octets little-endian, `u32` version du blob (1 au debut). Aucun serde, aucune dependance.
- Ecriture/lecture par un trait: `trait State { fn save(&self, w: &mut StateWriter); fn load(&mut self, r: &mut StateReader) -> Result<(), StateError>; }` implemente par chaque composant, dans CET ordre: `master` (+ phase APU `apu_acc: i64`), Cpu, Bus (WRAM 128 Kio, registres $4200-$421F, mdr), DMA (8 canaux + etat HDMA), timing, Ppu (registres, VRAM, CGRAM, OAM, latchs, position, `line_obj`, framebuffer 512x478), Apu (RAM 64 Kio, SMP, timers, ports, DSP: registres, voix, echo, tampons), joypads, Cart (SRAM seulement ; la ROM n'est PAS sauvee).
- `StateWriter`: `u8/u16/u32/u64/i64/bool/bytes(&[u8])/slice_u16`; `StateReader` symetrique avec verification de fin de donnees (erreur `StateError::Truncated`/`Version`/`Mismatch`).
- Aller-retour: `load_state(save_state())` laisse `state_hash` inchange, et executer N frames apres un `load_state` donne le meme `state_hash` que sans passer par le save state.
- Taille attendue: ~1.3 Mio ; pas de compression en v1.

## Tests
Tous les tests sont prefixes par `e08_08_`.

- `e08_08_roundtrip_all_fields` : regle commune (position et tampons de ligne non nuls obtenus en faisant tourner le PPU avec une scene).
- `e08_08_region_mismatch` : sauver un `Ppu::new(Ntsc)` et charger dans `Ppu::new(Pal)` -> `Err(Mismatch("region"))`.
- `e08_08_behaves_identically_midframe` : voir ci-dessus.
- `e08_08_framebuffer_roundtrip` : pixel (10,20) du framebuffer a 0xFF123456 avant save : identique apres load.
- `e08_08_truncated` : regle commune (n = 0, len/2, len-1).
