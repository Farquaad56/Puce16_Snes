## Specification
Implementer `pub(super) fn ea<B: Bus>(cpu, bus, am, store) -> Ea` pour (apres le cycle opcode, le PC pointe sur l'operande):
- `Am::Abs`: `aa = cpu.fetch16(bus)`; `base = (db << 16) | aa`; `lo = base`, `hi = (base + 1) & 0xFFFFFF`.
- `Am::AbsX` / `Am::AbsY`: meme base; `idx = cpu.x` (resp. `cpu.y`); `addr = (base + idx) & 0xFFFFFF`; `cross = (base >> 8) != (addr >> 8)`; cycle `bus.idle()` SI `store || !cpu.x8() || cross` (note: pour Y comme pour X c'est le flag X qui compte); `lo = addr`, `hi = (addr + 1) & 0xFFFFFF`.
- `Am::Long`: `v = cpu.fetch24(bus)`; `lo = v`, `hi = (v + 1) & 0xFFFFFF`.
- `Am::LongX`: `v = fetch24`; `addr = (v + cpu.x) & 0xFFFFFF`; aucun cycle supplementaire; `hi = (addr + 1) & 0xFFFFFF`.
- Tout autre mode: `unreachable!()`.
L'ordre des lectures d'operande est octet bas puis octet haut. Aucune lecture de la donnee elle-meme ici (c'est `read_data`).

## Tests
Tous les tests sont prefixes par `e02_08_`.

- `e02_08_abs` : e=false, db=0x7E, pc=0x8000, poke(0x8000,&[0x34,0x12]): ea(Abs,false) == Ea{lo:0x7E1234, hi:0x7E1235} ; log = 2 lectures (0x008000, 0x008001), pc==0x8002.
- `e02_08_abs_bank_cross` : db=0x01, operande 0xFFFF: Ea{lo:0x01FFFF, hi:0x020000}.
- `e02_08_absx_8bit_no_cross` : e=false, p=0x10 (X=1), x=0x05, db=0, operande 0x1210: lo==0x001215 ; log = 2 lectures (aucun Idle).
- `e02_08_absx_8bit_cross` : meme p, x=0x20, operande 0x12F0: lo==0x001310 ; log = 2 lectures + 1 Idle (en dernier).
- `e02_08_absx_store_no_cross` : X=1, x=0x05, operande 0x1210, store=true: log = 2 lectures + 1 Idle.
- `e02_08_absx_16bit_index` : e=false, p=0x00 (X=0), x=0x0001, operande 0x1210, store=false: lo==0x001211 ; log = 2 lectures + 1 Idle.
- `e02_08_absx_carry_to_bank` : p=0x00, db=0x01, x=0x0020, operande 0xFFF0: lo==0x020010, hi==0x020011.
- `e02_08_absy` : p=0x10, y=0x03, operande 0x2000, db=0: lo==0x002003, log = 2 lectures.
- `e02_08_long` : poke(0x8000,&[0x56,0x34,0x12]): ea(Long) == Ea{lo:0x123456, hi:0x123457} ; log = 3 lectures ; avec [0xFF,0xFF,0x12]: hi==0x130000.
- `e02_08_longx` : p=0x00, x=0x0010, operande [0x56,0x34,0x12]: lo==0x123466 ; log = 3 lectures seulement.
- `e02_08_rmw_abs_8bit` : e=false, p=0x20, db=0, poke(0x8000,&[0x34,0x12]), poke(0x1234,&[0x41]); `rmw(cpu,bus,Am::Abs,|_,v,_| v+1)`: peek(0x1234)==0x42 ; log = [R 0x8000, R 0x8001, R 0x1234, Idle, W 0x1234=0x42].
- `e02_08_rmw_abs_16bit` : p=0x00, poke(0x1234,&[0xFF,0x00]); rmw avec |_,v,_| v+1: peek(0x1234)==0x00, peek(0x1235)==0x01 ; les 4 derniers cycles du journal: R 0x1234, R 0x1235, Idle, W 0x1235=0x01, W 0x1234=0x00 (5 cycles apres les 2 lectures d'operande : ecriture octet HAUT d'abord).
