## Specification
1. `dma.rs`: `impl Sdd1 { ... }` (champs `pub(super)`):
   - `pub fn dma_write(&mut self, reg: u16, v: u8)`: `reg` dans `0x4300..=0x437F`; canal `n = ((reg >> 4) & 7) as usize`; selon `reg & 0xF`: 2 -> bits 0-7 de `dma_addr[n]`, 3 -> bits 8-15, 4 -> bits 16-23, 5 -> bits 0-7 de `dma_size[n]`, 6 -> bits 8-15; les autres sont ignores.
   - `pub fn dma_channel(&self, n: usize) -> (u32, u16)` renvoie `(dma_addr[n], dma_size[n])`.
   - `pub fn mmc_read(&self, addr: u32, rom: &[u8]) -> u8` = `rom[self.mmc_offset(addr) & (rom.len() - 1)]` (la longueur de `rom` est une puissance de 2).
   - `pub fn mcu_read(&mut self, addr: u32, rom: &[u8]) -> u8`: algorithme de la section 5 (bloc `si (r4800 & r4801) != 0`). La fermeture de ROM du decompresseur est `|a: u32| rom[mmc_offset(a) & mask]` avec une COPIE de `mmc` (pour ne pas emprunter `self` deux fois): par exemple `let mmc = self.mmc; let f = |a: u32| rom[((((mmc[((a >> 20) & 3) as usize] & 0x0F) as usize) << 20) | (a as usize & 0xFFFFF)) & mask];`.
2. Le decompte utilise `wrapping_sub(1)` sur `dma_size[n]`; quand il atteint 0: `dma_ready = false` et `r4801 &= !(1 << n)`.
3. Ajouter `pub mod dma;` a `sdd1/mod.rs`.
4. Construction des donnees de test: ROM = `vec![0u8; 1 << 20]`; flux compresse = `lcg_bytes(0x1000 + k, 4096)` avec `data[0] = (data[0] & 0x0F) | (k << 4)`, copie en `rom[0x100..0x100 + 4096]`; les adresses `0xC00100` pointent dessus (mmc par defaut).
Generateur de flux de test (identique a `docs/tools/sdd1_ref.py`): `fn lcg_bytes(seed: u32, n: usize) -> Vec<u8> { let mut x = seed; (0..n).map(|_| { x = x.wrapping_mul(1664525).wrapping_add(1013904223); (x >> 24) as u8 }).collect() }`. Fermeture de ROM des tests: `let rom = |a: u32| data[(a as usize) % data.len()];` (lecture cyclique).

## 5. Interception DMA
Le S-DD1 espionne les ecritures du S-CPU aux registres DMA `$43x2-$43x6` (x = canal 0..7) et garde pour chaque canal une copie:
```
$43x2 -> addr bits 0-7     $43x3 -> addr bits 8-15     $43x4 -> addr bits 16-23
$43x5 -> size bits 0-7     $43x6 -> size bits 8-15      (size: u16; la valeur 0 reste 0, voir ci-dessous)
```
L'ecriture est quand meme transmise au DMA normal. Les jeux programment un DMA en mode **adresse A fixe** (bit 3 de `$43x0`): chaque lecture de l'octet suivant se fait donc a la meme adresse source, et c'est le S-DD1 qui renvoie un octet decompresse different a chaque lecture.

Lecture a une adresse `addr` dans les banques C0-FF (`mcu_read`):
```
si (r4800 & r4801) != 0:
    pour n = 0..7:
        si (r4800 bit n) et (r4801 bit n) et addr == dma[n].addr:
            si !dma_ready: decompressor.init(addr); dma_ready = true
            octet = decompressor.read()
            dma[n].size = dma[n].size.wrapping_sub(1)
            si dma[n].size == 0: dma_ready = false; r4801 &= !(1 << n)
            retourner octet
retourner rom[mmc_offset(addr)]          // pas de decompression: ROM normale
```
Le decompresseur lit les octets compresses par la fenetre MMC (`rom[mmc_offset(a)]` pour une adresse 24 bits `a` qui commence a `addr` et s'incremente). Une taille initiale 0 signifie 65536 octets (le decompte `0 -> 0xFFFF` fait le tour).

## Tests
Tous les tests sont prefixes par `e09_06_`.

- `e09_06_stream_matches_golden_header_00` : k = 0: io_write($4800,1), io_write($4801,1), dma_write($4302,0x00), ($4303,0x01), ($4304,0xC0), ($4305,4), ($4306,0): 4 mcu_read(0xC00100) renvoient 0x75 0x12 0x24 0x91; ensuite io_read($4801) = Some(0) (canal 0 termine)
- `e09_06_after_finish_reads_plain_rom` : apres le test precedent, mcu_read(0xC00100) renvoie rom[0x100] (octet d'en-tete compresse, ici 0x02)
- `e09_06_stream_matches_golden_header_30` : k = 3 (en-tete 0x30), canal 2: dma_write($4322.. $4326) taille 8; 8 mcu_read(0xC00100) renvoient 45 56 11 a4 ff bb 37 ed; $4800 = $4801 = 0x04 au depart, io_read($4801) = Some(0) a la fin
- `e09_06_inactive_cases_return_rom` : r4800 = 0 (mais r4801 = 1), ou adresse differente de dma_addr (ex. 0xC00101), ou canal non active: mcu_read renvoie la ROM normale et ne touche pas dma_size
- `e09_06_size_zero_wraps` : dma_size = 0: apres 1 lecture, dma_channel(0).1 == 0xFFFF et $4801 inchange
- `e09_06_dma_write_assembles_fields` : ecritures de 0x12, 0x34, 0xC5 en $4332,$4333,$4334 et 0x56, 0x78 en $4335,$4336: dma_channel(3) == (0xC53412, 0x7856)
