# E07-01 - T-ROMS: telecharger les ROM de test homebrew (reseau)
Epopee: E07 | Type: tooling | Dependances: E06-50 | Taille estimee: ~0 lignes

## Contexte
Les ROM de test homebrew (N3) servent a valider le PPU, le DMA et l'APU contre des images connues. Elles ne sont jamais commitees (dossier ignore par git). Aucune ROM commerciale ici (D-006: celles-ci sont fournies par l'utilisateur).
Aucune URL n'est supposee: chaque depot est RETROUVE par recherche web.

## Specification
1. Pour chaque candidat du tableau (PeterLemon/SNES, gilyon/snes-tests, undisbeliever/snes-test-roms, tests SPC700/DSP de blargg, tests bsnes/higan): retrouver le depot (recherche web), cloner en `--depth 1` dans un dossier TEMPORAIRE hors du depot, puis COPIER seulement les ROM `.sfc` / `.smc` deja compilees dans `tests/roms/homebrew/<auteur>/` en gardant l'arborescence relative du depot. Si le depot ne fournit que des sources: ne pas compiler, noter `source only`. Limite: 300 Mo au total; si un depot est plus gros, utiliser un clone partiel/sparse (`git clone --filter=blob:none --sparse` puis `git sparse-checkout set <dossiers>`).
2. Ecrire `tests/roms/README.md` (commite) avec, pour chaque candidat: nom, URL reelle, date de telechargement, licence si indiquee, nombre de ROM copiees, et un tableau `chemin | taille | sha256` (calcule par script, jamais a la main). Un candidat introuvable: ligne `not found`.
3. Ajouter a la fin du README une section `## Jeux commerciaux (fournis par l'utilisateur)` qui dit: placer les ROM dans `tests/roms/games/` sous les noms exacts `smw.sfc`, `alttp.sfc`, `smb_allstars.sfc` (jamais commitees).
4. Verifier avec `git status` qu'aucune ROM n'apparait comme fichier a ajouter (le `.gitignore` les couvre).
5. Reseau bloque ou aucun candidat accessible: question `tooling` (docs/02_QA_PROTOCOL.md) et arrete-toi.

## 4. ROM de test homebrew (N3): candidats (tous `UNKNOWN - to confirm` : URL, nom de fichier, licence)

La tache `T-ROMS` : pour chaque candidat, retrouver le depot, telecharger les `.sfc`/`.smc` (ou construire s'ils sont fournis en source ET qu'un assembleur est installe: sinon ignorer), les ranger dans `tests/roms/homebrew/<auteur>/`, et remplir `tests/roms/README.md` (nom, URL reelle, date, taille, sha256). Un candidat introuvable est note `not found` (pas d'invention d'URL).

| Candidat | Contenu attendu | Utilite | Epopee |
|---|---|---|---|
| PeterLemon/SNES (depot GitHub, aussi nomme "krom") | nombreux petits programmes: tests CPU, modes graphiques, mode 7, fenetres, mosaique, HDMA, DMA, SPC700/BRR | rendu PPU (images attendues connues visuellement) | E04-E06 |
| gilyon/snes-tests | tests d'instructions CPU (basic/full), resultat affiche a l'ecran | validation CPU globale | E02 |
| undisbeliever/snes-test-roms | tests de timing (HDMA, DMA, IRQ, registres) | timing exact | E03-E04 |
| tests SPC700/DSP de blargg (programmes `spc_*`) | tests SMP/DSP, resultat par checksum ou texte | SPC700 + DSP | E06 |
| autres tests de bsnes/higan (depot de tests) | divers | optionnel | E08 |

Pour toute ROM sans critere de reussite automatique: la reussite = **hash framebuffer stable** apres N frames, valide UNE FOIS par l'utilisateur sur une capture (GATE), puis fige dans `tests/baseline.json`.
