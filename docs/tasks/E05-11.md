# E05-11 - ppu/obj.rs: tranches de sprites, tampon de ligne, limites et erratum de flip
Epopee: E05 | Type: code | Dependances: E05-10 | Taille estimee: ~150 lignes

## Contexte
Suite des sprites (spec 05b 6.3): pour une rangee `r`, remplit un tampon de 256 pixels `line_obj`. Ajoute au `Ppu` le champ `line_obj: [Option<Pix>; 256]` (None) -- il est DERIVE (calcule a dot 0 de chaque ligne) donc exclu du hash; les etats sauvegardes se prennent entre deux frames (E08).
Le lecture du pixel et les drapeaux `range_over` / `time_over` sont exposes pour le test. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'. Aides de test (a recopier dans le fichier de test): `fn put_vram(p: &mut Ppu, addr: u16, w: u16) { p.write(0x15,0x80); p.write(0x16,(addr & 0xFF) as u8); p.write(0x17,(addr >> 8) as u8); p.write(0x18,(w & 0xFF) as u8); p.write(0x19,(w >> 8) as u8); }` ; `fn put_cgram(p: &mut Ppu, i: u8, w: u16) { p.write(0x21,i); p.write(0x22,(w & 0xFF) as u8); p.write(0x22,(w >> 8) as u8); }`. Un `Ppu::new(Region::Ntsc)` neuf est en forced blank: toutes ces ecritures sont autorisees. Chaque test construit SA scene sur un `Ppu` neuf. Aides OAM (a recopier): `fn load_oam(p: &mut Ppu, img: &[u8; 544]) { p.write(0x02,0); p.write(0x03,0); for b in img.iter() { p.write(0x04,*b); } }` ; `fn spr(img: &mut [u8; 544], i: usize, x: i16, y: u8, tile: u8, attr: u8, large: bool) { img[i*4] = (x & 0xFF) as u8; img[i*4+1] = y; img[i*4+2] = tile; img[i*4+3] = attr; let sh = (i % 4) * 2; let hb = 512 + i / 4; img[hb] &= !(3u8 << sh); let x8 = ((x >> 8) & 1) as u8; img[hb] |= (x8 | if large { 2 } else { 0 }) << sh; }`. Une image OAM neuve est `[0u8; 544]`: ATTENTION, un sprite a zero a x = 0, y = 0, 8x8: il est visible aux rangees 1..=8. Pour sortir les sprites inutilises de la zone visible, utilise `fn hide_all(img: &mut [u8; 544]) { for i in 0..128 { spr(img, i, -200, 0, 0, 0, false); } }` (x = -200 : hors ecran pour toutes les tailles, donc jamais dans la liste, et different de -256 qui compte toujours); puis place les sprites voulus. Les regles d'attribut sont : `attr = V H PP CCC t` (bit 7 = V flip, bit 6 = H flip, bits 5-4 = priorite, bits 3-1 = palette, bit 0 = bit de table de noms).

## Specification
Ajoute a `ppu/obj.rs` :
```rust
impl Ppu {
    pub fn render_obj_line(&mut self, r: u16);       // evalue la rangee r et remplit line_obj
    pub fn obj_pixel(&self, x: usize) -> Option<Pix>; // line_obj[x] (None si x >= 256)
}
```
`render_obj_line(r)` :
1. `line_obj = [None; 256]` ; `(list, overflow) = sprite_list(r)` ; si `overflow` : `range_over = true` (ne repasse JAMAIS a false ici).
2. `slivers = 0` ; pour `i` dans `list.iter().rev()` (du dernier au premier) : `s = sprite(i)` ; `(w, h)` ; `row = ((r as i32) - (s.y as i32) - 1) & 0xFF` ; pour `c` dans `0..(w/8)` : `sx = s.x as i32 + c * 8` ; `counts = (sx > -8 && sx < 256) || s.x == -256` ; si `!counts` continuer ; si `slivers == 34` : `time_over = true` et ARRETER toute la boucle (fin) ; `slivers += 1` ; `fetch_sliver(s, c, row, sx)`.
3. `fetch_sliver` : `tc = if s.hflip { w/8 - 1 - c } else { c }` ; `rv = row` ; si `s.vflip` : si `w == h` (carre) `rv = h - 1 - row` ; sinon (16x32, 32x64) : `half = h / 2 ; rv = (row / half) * half + (half - 1 - row % half)` (erratum materiel : chaque moitie est retournee sur place) ; `tile_row = rv >> 3 ; fine_y = rv & 7`.
   `tx = ((s.tile & 15) as u32 + tc) & 15 ; ty = ((s.tile >> 4) as u32 + tile_row) & 15 ; tile8 = ty * 16 + tx` ; `addr = (regs.obj_base + (if s.tbit { regs.obj_name_gap } else { 0 }) + tile8 * 16 + fine_y) & 0x7FFF` (calcul en u32) ; `lo = vram[addr]` ; `hi = vram[(addr + 8) & 0x7FFF]`.
   Pour `px` in `0..8` : `bit = if s.hflip { px } else { 7 - px }` ; `i = ((lo >> bit) & 1) | (((lo >> (8 + bit)) & 1) << 1) | (((hi >> bit) & 1) << 2) | (((hi >> (8 + bit)) & 1) << 3)` ; `dest = sx + px` ; si `i != 0 && 0 <= dest < 256` : `line_obj[dest] = Some(Pix { rgb: cgram[obj_palette_index(s.pal, i)], prio: s.prio, obj_pal: s.pal })` (ecrase : le sprite d'indice le plus bas gagne car il est traite en dernier).
Accesseurs publics : `range_over()`, `time_over()` (existent depuis E04-10).

### 6.3 Recuperation des tranches (slivers, 34 max) et tampon de ligne
```
line_obj = [None; 256]; slivers = 0
for i in list.iter().rev():                  // du plus grand index au plus petit
    for c in 0..(w/8):                        // ordre ecran gauche -> droite
        sx = x + c*8
        counts = (sx > -8 && sx < 256) || x == -256
        if !counts: continue
        if slivers == 34 { time_over = true; goto fin }
        slivers += 1
        fetch_sliver(i, c)  // ecrit dans line_obj les pixels non transparents (ecrase: l'index le plus bas gagne car traite en dernier)
```
`fetch_sliver`: `tc = if H { w/8 - 1 - c } else { c }`; rangee de sprite `rv = row`; si V flip: pour tailles carrees `rv = h - 1 - row`; pour 16x32 et 32x64 (tailles non carrees: indices 6 et 7 grand/petit rectangulaire) chaque moitie est retournee SUR PLACE: `half = h/2; rv = (row / half) * half + (half - 1 - row % half)` (erratum materiel). `tile_row = rv >> 3`, `fine_y = rv & 7`.
```
tx = ((t & 15) + tc) & 15 ; ty = ((t >> 4) + tile_row) & 15 ; tile8 = ty * 16 + tx
addr = (obj_base + (if tbit { obj_name_gap } else { 0 }) + tile8 * 16 + fine_y) & 0x7FFF
lo = vram[addr] ; hi = vram[(addr + 8) & 0x7FFF]       // plans 0,1 / plans 2,3
pour px in 0..8 (ordre ecran): bit = if H { px } else { 7 - px }; indice = 4 plans; dest = sx + px
si indice != 0 et 0 <= dest < 256: line_obj[dest] = Some(Pix { rgb: cgram[128 + CCC*16 + indice], prio: PP, obj_pal: CCC })
```
Les flags `range_over` (plus de 32 sprites, STAT77 bit 7) et `time_over` (plus de 34 tranches, STAT77 bit 6) sont remis a faux au debut de chaque frame (v == 0, dot 0) et mis a vrai ici; ils restent a vrai jusque-la.
La couleur est lue de CGRAM lors de l'evaluation (a dot 0); acceptable (`UNKNOWN - to confirm`).
