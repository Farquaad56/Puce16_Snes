## Specification
1. `lib.rs`: ajouter `pub mod cheat;` (apres `pub mod cart;` ou a la suite des autres `pub mod`).
2. `cheat/mod.rs`: `pub mod par;` et `pub use par::{parse_par, ParCode, ParseError};` (les taches suivantes ajoutent leurs propres lignes).
3. `cheat/par.rs`: `ParCode { pub addr: u32, pub value: u8 }` et `ParseError { Length(usize), NotHex(char), LooksLikeGameGenie }`, les deux avec `#[derive(Clone, Copy, Debug, PartialEq, Eq)]` (`ParCode` implemente aussi `Display`: `{:06X}{:02X}`).
4. `parse_par(s: &str) -> Result<ParCode, ParseError>`: `trim()` du texte; si le texte contient `-` -> `LooksLikeGameGenie` (verification en premier); sinon, si le nombre de caracteres (`chars().count()`) n'est pas 8 -> `Length(n)`; sinon chaque caractere doit etre un chiffre hexadecimal ASCII, le premier invalide donne `NotHex(c)`; `addr` = les 6 premiers chiffres, `value` = les 2 derniers.
5. Pas de `unsafe` (`puce16-core` est `#![forbid(unsafe_code)]`), pas de dependance nouvelle.

## 2. Format d'un code

- Exactement 8 chiffres hexadecimaux (majuscules ou minuscules), sans separateur: `AAAAAA` (adresse 24 bits `bank:offset`) puis `VV` (valeur 8 bits). Exemple: `7E0DBF99` = ecrire `0x99` en `$7E:0DBF`.
- Les espaces au debut et a la fin sont ignores.
- Un texte contenant un tiret `-` est refuse avec l'erreur `LooksLikeGameGenie` (les codes Game Genie `XXXX-XXXX` n'utilisent que des chiffres hexadecimaux et seraient pris a tort pour des codes PAR).
- Erreurs (enum `ParseError`): `Length(usize)` (nombre de caracteres apres nettoyage, different de 8), `NotHex(char)` (premier caractere invalide), `LooksLikeGameGenie`.
- Affichage canonique (`Display` de `ParCode`): `{:06X}{:02X}` (majuscules, 8 caracteres).

## Tests
Tous les tests sont prefixes par `e10_01_`.

- `e10_01_valid_uppercase` : parse_par("7E0DBF99") = Ok(ParCode { addr: 0x7E0DBF, value: 0x99 })
- `e10_01_valid_lowercase_and_spaces` : parse_par("  7e0dbf99 ") = Ok(ParCode { addr: 0x7E0DBF, value: 0x99 }); parse_par("00000000") = Ok(ParCode { addr: 0, value: 0 }); parse_par("FFFFFFFF") = Ok(ParCode { addr: 0xFFFFFF, value: 0xFF })
- `e10_01_wrong_length` : parse_par("") = Err(Length(0)); parse_par("7E0DBF9") = Err(Length(7)); parse_par("7E0DBF990") = Err(Length(9))
- `e10_01_not_hex` : parse_par("7E0DBG99") = Err(NotHex('G')); parse_par("ZZ0DBF99") = Err(NotHex('Z'))
- `e10_01_game_genie_shape_refused` : parse_par("DF4B-7D6E") = Err(LooksLikeGameGenie); parse_par("7E0D-BF99") = Err(LooksLikeGameGenie)
- `e10_01_display_is_canonical` : format!("{}", parse_par("7e0dbf99").unwrap()) = "7E0DBF99"; format!("{}", ParCode { addr: 0x12, value: 0x3 }) = "00001203"
