## Specification
1. `cheat/mod.rs`: ajouter `pub mod list;` et `pub use list::{format_cheat_file, parse_cheat_file, CheatEntry, CheatFileError, CheatFileErrorKind};`.
2. `cheat/list.rs`: `CheatEntry { pub name: String, pub enabled: bool, pub codes: Vec<ParCode> }`, `CheatFileErrorKind { MissingSign, MissingEquals, EmptyName, NoCode, BadCode(ParseError) }`, `CheatFileError { pub line: usize, pub kind: CheatFileErrorKind }` (tous `Clone, Debug, PartialEq, Eq`).
3. `parse_cheat_file(text: &str) -> Result<Vec<CheatEntry>, CheatFileError>`: parcourir `text.lines()` (`lines()` gere `\r\n`) avec le numero de ligne a partir de 1. Ignorer les lignes vides (apres `trim()`) et celles dont le premier caractere non blanc est `#`. Sinon: le premier caractere non blanc doit etre `+` ou `-` (sinon `MissingSign`); chercher le premier `=` dans le reste (sinon `MissingEquals`); nom = texte avant `=` trim (vide -> `EmptyName`); les codes = texte apres `=` decoupe sur les espaces et les virgules (segments vides ignores); aucun segment -> `NoCode`; chaque segment passe par `parse_par`, la premiere erreur donne `BadCode(e)`. Premiere erreur rencontree = resultat.
4. `format_cheat_file(entries: &[CheatEntry]) -> String`: premiere ligne `# Puce16 cheats`, puis pour chaque entree `<+ ou -> <nom> = <code> <code>...` (codes affiches avec `Display`, separes par un espace), chaque ligne terminee par `\n`. Un nom qui contient `=` ou un retour a la ligne n'est pas valide: la fonction ne verifie rien (c'est le role de l'appelant, tache E10-06).
5. Pas de `unsafe`, pas de dependance nouvelle.

## 3. Fichier de triches (.cht)

Fichier texte UTF-8, une triche par ligne:

```
# commentaire (ligne ignoree)
+ Vies infinies = 7E0DBE05
- Invincible = 7E1497FF 7E1490FF
```

- `+` = triche active, `-` = inactive (premier caractere non blanc de la ligne).
- Le nom est le texte entre le signe et le premier `=`, sans les blancs de debut et de fin; il ne doit pas etre vide et ne contient pas `=`.
- Apres le `=`: un ou plusieurs codes PAR separes par des espaces ou des virgules. Au moins un code.
- Les lignes vides et les lignes qui commencent par `#` sont ignorees. Fin de ligne `\n` ou `\r\n` acceptee en lecture; ecriture avec `\n`.
- Toute ligne invalide fait echouer la lecture entiere: `CheatFileError { line: usize (1 = premiere ligne), kind: CheatFileErrorKind }` avec `kind` parmi `MissingSign`, `MissingEquals`, `EmptyName`, `NoCode`, `BadCode(ParseError)`.
- Ecriture (`format_cheat_file`): un en-tete `# Puce16 cheats` puis une ligne par triche: `<+|-> <nom> = <code> <code>...` (codes au format canonique separes par un espace), chaque ligne terminee par `\n`. `parse(format(x)) == x` pour toute liste valide.

## Tests
Tous les tests sont prefixes par `e10_02_`.

- `e10_02_parse_two_entries` : texte "# note\n+ Vies = 7E0DBE05\n\n- Invincible = 7E1497FF, 7E1490FF\n" -> 2 entrees: ("Vies", enabled, [7E0DBE/05]) et ("Invincible", disabled, [7E1497/FF, 7E1490/FF])
- `e10_02_parse_crlf_and_blanks` : meme contenu avec \r\n et des lignes d'espaces: meme resultat; un fichier vide ou fait de commentaires -> Ok(vec![])
- `e10_02_error_missing_sign` : "Vies = 7E0DBE05" -> Err(line 1, MissingSign); "# a\n\n= 7E0DBE05" -> Err(line 3, MissingSign)
- `e10_02_error_missing_equals_name_code` : "+ Vies 7E0DBE05" -> MissingEquals; "+  = 7E0DBE05" -> EmptyName; "+ Vies =" -> NoCode; "+ Vies = , " -> NoCode
- `e10_02_error_bad_code_reports_line` : "+ A = 7E0DBE05\n+ B = 7E0DBE0" -> Err(line 2, BadCode(Length(7))); "+ B = 7E0DBE0G" -> BadCode(NotHex('G'))
- `e10_02_format_exact_text` : format_cheat_file de [("Vies", true, [0x7E0DBE/0x05]), ("Inv", false, [0x7E1497/0xFF, 0x7E1490/0xFF])] = "# Puce16 cheats\n+ Vies = 7E0DBE05\n- Inv = 7E1497FF 7E1490FF\n"
- `e10_02_roundtrip` : parse_cheat_file(&format_cheat_file(&v)) == Ok(v) pour 3 listes (vide, une entree, trois entrees avec plusieurs codes)
