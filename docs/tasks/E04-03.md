## Specification
Dans `ppu/oam.rs`:
```rust
pub struct Oam { mem: [u8; 544], oamadd_reg: u16 /* 9 bits */, internal: u16 /* 10 bits, adresse octet */, latch: u8, rotation: bool }
impl Oam {
    pub fn new() -> Oam;                           // tout a 0 / false
    pub fn reset_regs(&mut self);                  // oamadd_reg = internal = latch = 0, rotation = false ; memoire CONSERVEE
    pub fn set_addr_l(&mut self, v: u8);           // OAMADDL: oamadd_reg = (oamadd_reg & 0x100) | v ; recalcul
    pub fn set_addr_h(&mut self, v: u8);           // OAMADDH: bit 0 -> bit 8 de oamadd_reg ; bit 7 -> rotation ; recalcul
    pub fn reload(&mut self);                      // recalcul: internal = (oamadd_reg & 0x1FF) << 1
    pub fn write(&mut self, v: u8, ok: bool);      // OAMDATA, section 2.1
    pub fn read(&mut self, ok: bool) -> u8;        // OAMDATAREAD, section 2.1 ; 0 si !ok ; l'adresse s'incremente dans les deux cas
    pub fn internal(&self) -> u16;  pub fn oamadd_reg(&self) -> u16;  pub fn rotation(&self) -> bool;
    pub fn byte(&self, i: usize) -> u8;            // mem[i]
    pub fn set_byte(&mut self, i: usize, v: u8);   // debug/test
    pub fn mem(&self) -> &[u8; 544];
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);   // mem (write), oamadd_reg (u16), internal (u16), latch (u8), rotation (u8)
}
```
`write(v, ok)` (a = internal) :
- table haute (`a & 0x200 != 0`) : si `ok`, `mem[0x200 + (a & 0x1F)] = v`.
- sinon, `a` pair : si `ok`, `latch = v` ; `a` impair : si `ok`, `mem[a-1] = latch ; mem[a] = v`.
- dans tous les cas `internal = (a + 1) & 0x3FF`.
`read(ok)` : `idx = if a & 0x200 != 0 { 0x200 + (a & 0x1F) } else { a }` ; octet = `mem[idx]` si `ok` sinon 0 ; `internal = (a + 1) & 0x3FF`.

### 2.1 OAMDATA ($2104) et lecture OAMDATAREAD ($2138)
```
a = internal_oamadd                                  // 10 bits
if a & 0x200 != 0:                                   // table haute (32 octets, miroir tous les 32)
    oam[0x200 + (a & 0x1F)] = v                      // ecriture immediate (si acces autorise, voir 3)
else:
    if a & 1 == 0: oam_latch = v                     // octet pair: memorise
    else: oam[a-1] = oam_latch; oam[a] = v           // octet impair: ecrit le mot
internal_oamadd = (a + 1) & 0x3FF
```
Lecture $2138: `a = internal_oamadd`; octet = `oam[ if a&0x200 {0x200 + (a&0x1F)} else {a} ]`; puis `internal_oamadd = (a+1) & 0x3FF`.
Rechargement: a chaque debut de VBlank (V = vblank_start, dot 0), si `!forced_blank`: `internal_oamadd = (oamadd_reg & 0x1FF) << 1`. (`UNKNOWN - to confirm`: rechargement aussi quand forced_blank retombe a 0; defaut: non.)

## 3. Regles d'acces pendant l'affichage
```
fn vram_ok() -> bool { forced_blank || v >= vblank_start }        // V=0 NON accessible (UNKNOWN - to confirm)
fn oam_ok()  -> bool { forced_blank || v >= vblank_start }
```
- VRAM: voir 2.3. OAM: si `!oam_ok()`: les ecritures $2104 sont ignorees (l'adresse s'incremente quand meme) et la lecture $2138 retourne 0 (`UNKNOWN - to confirm`).
- `vblank_start = if overscan {240} else {225}` (lu en direct a chaque usage).

## Tests
Tous les tests sont prefixes par `e04_03_`.

- `e04_03_addr_regs` : `set_addr_l(0x05)` -> `internal()==0x0A`, `oamadd_reg()==5` ; `set_addr_h(0x01)` -> `oamadd_reg()==0x105`, `internal()==0x20A` ; `set_addr_h(0x80)` -> `oamadd_reg()==5`, `internal()==0x0A`, `rotation()==true` ; `set_addr_h(0x00)` -> `rotation()==false`.
- `e04_03_word_write` : `set_addr_l(0)`; `write(0x11,true)` -> `byte(0)==0` (seulement memorise), `internal()==1` ; `write(0x22,true)` -> `byte(0)==0x11`, `byte(1)==0x22`, `internal()==2`.
- `e04_03_sequence` : `set_addr_l(0)`; ecrire 0x11,0x22,0x33,0x44 -> octets 0..4 = [0x11,0x22,0x33,0x44], `internal()==4`.
- `e04_03_odd_start` : `set_addr_l(0)`; `write(0x55,true)` (internal 1) ; `set_addr_l(0)` repositionne internal a 0 et le latch garde 0x55 ; `write(0x66,true)` (internal pair) memorise 0x66 ; `write(0x77,true)` -> `byte(0)==0x66`, `byte(1)==0x77`. Autre cas (nouvel `Oam`, sans repositionner): apres `write(0x55,true)` (internal 1) un 2eme `write(0x66,true)` donne `byte(0)==0x55`, `byte(1)==0x66`.
- `e04_03_high_table` : `set_addr_h(0x01)` (internal 0x200) : `write(0xAA,true)` -> `byte(0x200)==0xAA`, `internal()==0x201` ; `write(0xBB,true)` -> `byte(0x201)==0xBB`.
- `e04_03_high_mirror` : `set_addr_h(0x01); set_addr_l(0x10)` -> internal 0x220 ; `write(0xCC,true)` -> `byte(0x200)==0xCC` (miroir tous les 32), `internal()==0x221` ; `set_addr_l(0x11)` -> internal 0x222 ; `write(0xDD,true)` -> `byte(0x202)==0xDD`.
- `e04_03_wrap_10bits` : `set_addr_l(0xFF); set_addr_h(0x01)` -> `internal()==0x3FE` ; `write(1,true); write(2,true)` -> `byte(0x21E)==1`, `byte(0x21F)==2`, `internal()==0`.
- `e04_03_read_low_table` : `set_byte(0,0x10); set_byte(1,0x20)` ; `set_addr_l(0)` : `read(true)==0x10`, `read(true)==0x20`, `internal()==2`.
- `e04_03_read_high_table` : `set_byte(0x204,0x66); set_byte(0x205,0x77)` ; `set_addr_h(0x01); set_addr_l(0x02)` (internal 0x204) : `read(true)==0x66`, `read(true)==0x77`, `internal()==0x206`. Miroir: `set_byte(0x200,0x99)`, `set_addr_l(0x10)` (internal 0x220) : `read(true)==0x99`.
- `e04_03_blocked` : `set_addr_l(0)`; `write(9,false)` -> `byte(0)==0`, `byte(1)==0`, `internal()==1` ; `write(0x31,true)` (impair) -> `byte(0)==0` (latch non modifie par l'ecriture bloquee), `byte(1)==0x31`. `set_byte(5,0x5A)`, `set_addr_l(2)` (internal 4) : `read(false)==0` et `internal()==5`, puis `read(true)==0x5A`.
- `e04_03_reload` : `set_addr_l(0x07)` (internal 14) ; trois `write(1,true)` -> `internal()==17` ; `reload()` -> `internal()==14` ; avec `set_addr_h(0x01)` (reg 0x107) : `reload()` -> `internal()==0x20E`.
- `e04_03_hash` : hash identique pour deux `Oam::new()` ; differe apres `set_byte(7,1)` ; differe apres `set_addr_l(1)` ; differe apres `set_addr_h(0x80)` (rotation).
