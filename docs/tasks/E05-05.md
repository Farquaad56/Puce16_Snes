# E05-05 - ppu/bg.rs: bg_pixel (tuiles 8x8, defilement, palette)
Epopee: E05 | Type: code | Dependances: E05-04 | Taille estimee: ~140 lignes

## Contexte
Premier rendu d'un fond: `Ppu::bg_pixel(n, x, v)` pour les modes 0-6 (la partie mode 7 est en E05-12/13; en mode 7 cette fonction renvoie None).
Cette tache ne gere QUE les tuiles 8x8 SANS flips (E05-06), SANS mosaique (E05-07), SANS offset-per-tile (E05-08). `v` est le compteur de ligne du PPU (1 = premiere ligne visible): `py = v + vofs`, donc un jeu met VOFS = -1 pour afficher la rangee 0 de sa carte a la premiere ligne. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'. Aides de test (a recopier dans le fichier de test): `fn put_vram(p: &mut Ppu, addr: u16, w: u16) { p.write(0x15,0x80); p.write(0x16,(addr & 0xFF) as u8); p.write(0x17,(addr >> 8) as u8); p.write(0x18,(w & 0xFF) as u8); p.write(0x19,(w >> 8) as u8); }` ; `fn put_cgram(p: &mut Ppu, i: u8, w: u16) { p.write(0x21,i); p.write(0x22,(w & 0xFF) as u8); p.write(0x22,(w >> 8) as u8); }` ; `fn set_scroll(p: &mut Ppu, reg: u8, v: u16) { p.write(reg,(v & 0xFF) as u8); p.write(reg,(v >> 8) as u8); }` (reg = 0x0D HOFS BG1, 0x0E VOFS BG1, 0x0F/0x10 BG2, 0x11/0x12 BG3, 0x13/0x14 BG4). Un `Ppu::new(Region::Ntsc)` neuf est en forced blank: toutes ces ecritures sont autorisees. Chaque test construit SA scene sur un `Ppu` neuf.

## Specification
Ajoute a `ppu/bg.rs` (sous-module de `ppu`: `impl Ppu` y accede aux champs prives `regs`, `scroll`, `vram`, `cgram`, `m7`):
```rust
impl Ppu { pub fn bg_pixel(&self, n: usize, x: usize, v: usize) -> Option<Pix>; }
```
Algorithme (n = 0..=3 pour BG1..BG4 ; `mode = regs.bg_mode`) :
1. `bpp = bpp(mode, n)` ; si `bpp == 0` ou `mode == 7` -> `None`.
2. `px = (x + scroll.hofs(n) as usize) & 0x3FF` ; `py = (v + scroll.vofs(n) as usize) & 0x3FF`.
3. `tx = px >> 3 ; ty = py >> 3` ; `entry = decode_entry(vram_word(map_entry_addr(regs.map_base[n], regs.map_x2[n], regs.map_y2[n], tx, ty)))`.
4. `fx = px & 7 ; fy = py & 7` ; `words = 8 / 16 / 32` pour bpp 2 / 4 / 8 ; `tile_word = (regs.chr_base[n] + entry.tile * words) & 0x7FFF` ; `row = (tile_word + fy) & 0x7FFF` ; `i = decode_row(vram, row, bpp)[fx]` ; si `i == 0` -> `None`.
5. `rgb` : si `regs.direct_color && n == 0 && bpp == 8 && (mode == 3 || mode == 4)` : `direct_color_bg(i, entry.pal)` ; sinon `cgram[bg_palette_index(mode, n, bpp, entry.pal, i)]`.
6. `Some(Pix { rgb, prio: entry.prio, obj_pal: 0 })`.

## 7. Fonds (modes 0-6, hors hi-res): `bg_pixel(n, x, v) -> Option<Pix>`
```
bpp = BPP[mode][n]; si 0 -> None
(xm, vm) = mosaic(n, x, v)                       // section 9
hofs_use = hofs[n]; vofs_use = vofs[n]
si offset-per-tile applicable (section 7.1): remplacer hofs_use / vofs_use pour cette colonne
px = (xm + hofs_use) & 0x3FF ; py = (vm + vofs_use) & 0x3FF
entree = vram[map_entry_addr(...)] ; tuile, flips, palette, priorite selon section 5
i = decode_row(...)[fx]; si i == 0 -> None
Some(Pix { rgb: palette(section 3), prio: P, obj_pal: 0 })
```
Remarque de decalage vertical: `vm = v` (1 pour la premiere rangee visible), donc la rangee de carte affichee a la premiere ligne est `vofs + 1` (les jeux mettent VOFS = -1 pour aligner).

### 7.1 Offset-per-tile (modes 2, 4, 6; couche BG1 ou BG2)
```
n_col = (xm + (hofs[n] & 7)) >> 3          // colonne de 8 px depuis la gauche; 0 = tuile partielle de gauche, jamais modifiee
si n_col >= 1:
    ex = ((n_col - 1) + (hofs[2] >> 3))      // colonne dans la carte de BG3 (hofs/vofs de BG3)
    ey = vofs[2] >> 3
    mode 2: eh = entree_BG3(ex, ey)  ;  ev = entree_BG3(ex, ey + 1)     // ev = "comme si 8 etait ajoute a VOFS"
    mode 4: e = entree_BG3(ex, ey) ; si e.bit15 == 0 { eh = e ; ev = 0 } sinon { eh = 0 ; ev = e }
    mode 6: hi-res: voir UNKNOWN (colonnes de 16 px hi-res)
    bit_enable = 13 pour BG1 (n = 0), 14 pour BG2 (n = 1)
    si eh.bit(bit_enable): hofs_use = (eh & 0x3F8) | (hofs[n] & 7)
    si ev.bit(bit_enable): vofs_use = ev & 0x3FF
```
`entree_BG3` utilise la carte de BG3 (`map_base[2]`, tailles de BG3) via `map_entry_addr` (tuiles 8x8, tx/ty modulo la taille de la carte). En mode 4 et mode 6, eh ou ev vaut 0 quand l'autre est utilise.

## Tests
Tous les tests sont prefixes par `e05_05_`.

- `e05_05_scene_mode1_basic` : Scene A (mode 1, BG1 4 bpp) : `write(0x05,0x01)` ; `write(0x07,0x04)` (carte a 0x400, 32x32) ; `write(0x0B,0x01)` (chr BG1 a 0x1000) ; tuile 2 a 0x1020 : `put_vram(0x1020,0x0080)` (rangee 0, pixel 0 = indice 1), `put_vram(0x1021,0x8000)` (rangee 1, pixel 0 = indice 2) ; `put_vram(0x400,0x0402)` (tuile 2, pal 1, prio 0) ; `put_vram(0x401,0x2402)` (prio 1) ; `put_cgram(p,17,0x1234)` ; `put_cgram(p,18,0x2345)`. Attendu : `bg_pixel(0,0,0)==Some(Pix{rgb:0x1234,prio:0,obj_pal:0})` ; `bg_pixel(0,1,0)==None` ; `bg_pixel(0,0,1)==Some(Pix{rgb:0x2345,prio:0,obj_pal:0})` ; `bg_pixel(0,8,0)==Some(Pix{rgb:0x1234,prio:1,obj_pal:0})`.
- `e05_05_vofs_minus_one` : Scene A + `set_scroll(&mut p,0x0E,0x3FF)` (VOFS BG1 = -1) : `bg_pixel(0,0,1)==Some(Pix{rgb:0x1234,prio:0,obj_pal:0})` (py = (1+1023)&1023 = 0) ; `bg_pixel(0,0,2)==Some(Pix{rgb:0x2345,..})` (py = 1).
