## Specification
`exec` traite `Mn::Adc`: `wide = !cpu.m8()`; `m = addr::read_operand(cpu, bus, am, wide)`; si `cpu.flag(FLAG_D)` -> `adc_decimal(cpu, m, wide)` sinon `adc_binary(cpu, m, wide)`; retourne `true`.
`adc_binary` (fonction privee): `a = cpu.a` (octet bas si 8 bits); `r = a + m + C` (u32); `C = r > mask` (mask 0xFF / 0xFFFF); `V = ((a ^ r) & (m ^ r) & signbit) != 0` (signbit 0x80 / 0x8000); resultat tronque au mask; ecrire dans A (8 bits: l'octet haut de A est conserve); `set_nz(result, wide)`.
Garder `adc_decimal` comme `fn adc_decimal(_cpu: &mut Cpu, _m: u16, _wide: bool) { unimplemented!("E02-19") }`.

## 6. ADC / SBC

Binaire (D=0): `r = A + m + C`; C = depassement; V = `~(A ^ m) & (A ^ r) & signbit`; N,Z sur r tronque.
SBC binaire: meme formule avec `m = ~m` (complement), i.e. `A + ~m + C`.

Decimal (D=1) - algorithme de reference de depart (a valider par les tests JSON; ne PAS modifier au hasard):

```
ADC 8 bits:
  r = (A & 0x0F) + (m & 0x0F) + C
  if r > 0x09: r += 0x06
  C = r > 0x0F
  r = (A & 0xF0) + (m & 0xF0) + (C << 4) + (r & 0x0F)
  V = (~(A ^ m) & (A ^ r) & 0x80) != 0
  if r > 0x9F: r += 0x60
  C = r > 0xFF ; A.l = r & 0xFF ; N,Z sur A.l
ADC 16 bits: meme principe sur 4 quartets (masques 0x000F,0x00F0,0x0F00,0xF000; seuils 0x0009,0x009F,0x09FF,0x9FFF; corrections 0x6,0x60,0x600,0x6000), V calcule avant la correction du dernier quartet.

SBC 8 bits (m' = m ^ 0xFF):
  r = (A & 0x0F) + (m' & 0x0F) + C
  if r <= 0x0F: r -= 0x06
  C = r > 0x0F
  r = (A & 0xF0) + (m' & 0xF0) + (C << 4) + (r & 0x0F)
  V = (~(A ^ m') & (A ^ r) & 0x80) != 0
  if r <= 0xFF: r -= 0x60
  C = r > 0xFF ; A.l = r & 0xFF ; N,Z sur A.l
SBC 16 bits: meme principe sur 4 quartets.
```

## 6. Tests d'unite des familles (convention)

Les tests utilisent `FlatBus` (`cpu/testbus.rs`): `FlatBus::new()` ; `bus.poke(addr, &[octets])` ecrit sans journal ; `bus.peek(addr) -> u8` ;
`bus.log: Vec<Cycle>` avec `Cycle { addr: u32, val: u8, kind: CycleKind }`, `CycleKind::{Read, Write, Idle}` (un cycle `Idle` a `addr = 0` et `val = 0`) ;
`bus.clear_log()`. Un test pose le programme en `00:8000` (`cpu.pb = 0; cpu.pc = 0x8000`), fixe les registres a la main, fait `cpu.step(&mut bus)`, puis verifie
registres, memoire et `bus.log.len()` (= nombre de cycles de l'instruction, opcode compris) et, quand c'est precise, la suite exacte des cycles.
Un test peut ecrire `let cycles: Vec<(char, u32, u8)>` ou 'R'/'W'/'I' est le type: a lui de choisir une forme lisible, tant que adresse, valeur, ordre sont verifies.
