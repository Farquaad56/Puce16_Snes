## Specification
Dans `joypad.rs` ajoute (pour l'instant seulement ceci; l'etat des ports vient en E03):
`pub const BTN_B: u16 = 1 << 15;` ... `BTN_R: u16 = 1 << 4;` (douze constantes, valeurs du texte ci-dessus) et
`pub fn filter_opposites(b: u16) -> u16` : si `BTN_LEFT` et `BTN_RIGHT` sont tous deux a 1, les deux sont mis a 0 ; idem `BTN_UP`/`BTN_DOWN`. Les autres bits inchanges.

## 1. Manettes (core, `joypad.rs`)

Format 16 bits de `Snes::set_joypad(port, buttons)` (identique a JOY1H:JOY1L, spec 02 section 6.5):
```
bit15 B   bit14 Y   bit13 Select  bit12 Start  bit11 Up   bit10 Down  bit9 Left  bit8 Right
bit7  A   bit6  X   bit5  L       bit4  R      bits3-0 = 0
```
`const BTN_B: u16 = 1 << 15; BTN_Y = 1 << 14; BTN_SELECT = 1 << 13; BTN_START = 1 << 12; BTN_UP = 1 << 11; BTN_DOWN = 1 << 10; BTN_LEFT = 1 << 9; BTN_RIGHT = 1 << 8; BTN_A = 1 << 7; BTN_X = 1 << 6; BTN_L = 1 << 5; BTN_R = 1 << 4;`
Contraintes: le core n'empeche pas Haut+Bas / Gauche+Droite simultanes (c'est le desktop qui peut les filtrer, option `block_opposite_dirs` active par defaut: si Gauche et Droite sont appuyes, aucun des deux).

## Tests
Tous les tests sont prefixes par `e01_12_`.

- `e01_12_values` : `BTN_B==0x8000`, `BTN_Y==0x4000`, `BTN_SELECT==0x2000`, `BTN_START==0x1000`, `BTN_UP==0x0800`, `BTN_DOWN==0x0400`, `BTN_LEFT==0x0200`, `BTN_RIGHT==0x0100`, `BTN_A==0x0080`, `BTN_X==0x0040`, `BTN_L==0x0020`, `BTN_R==0x0010`.
- `e01_12_no_overlap` : toutes les constantes sont deux a deux disjointes et leur OU vaut 0xFFF0.
- `e01_12_filter_lr` : `filter_opposites(BTN_LEFT|BTN_RIGHT|BTN_A) == BTN_A`.
- `e01_12_filter_ud_keep` : `filter_opposites(BTN_UP|BTN_LEFT) == BTN_UP|BTN_LEFT` ; `filter_opposites(BTN_UP|BTN_DOWN|BTN_LEFT|BTN_RIGHT) == 0`.
