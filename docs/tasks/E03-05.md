## Specification
Ajoute a `cart/mod.rs`:
```rust
#[derive(Clone)]
pub struct Cart { rom: Vec<u8>, rom_mask: usize, map: MapMode, sram: Vec<u8>, has_battery: bool, header: Header, region: Region }
impl Cart {
    pub fn from_bytes(data: &[u8]) -> Result<Cart, CartError>;
    pub fn from_bytes_forced(data: &[u8], map: Option<MapMode>, region: Option<Region>) -> Result<Cart, CartError>;
    pub fn header(&self) -> &Header;  pub fn map_mode(&self) -> MapMode;  pub fn region(&self) -> Region;
    pub fn has_battery(&self) -> bool;  pub fn sram(&self) -> &[u8];  pub fn rom_len(&self) -> usize;
}
```
`from_bytes` = `from_bytes_forced(data, None, None)`. Etapes de `from_bytes_forced`:
1. `d = strip_copier_header(data)`; si `d.len() < 0x8000` -> `Err(TooSmall)`.
2. `rom = normalize(d)`; `rom_mask = rom.len() - 1`.
3. `map = forced.unwrap_or(pick_header(&rom)?)`.
4. `header = parse_header(&rom, header_pos(map)).ok_or(NoHeader)?`.
5. `(battery, coproc) = chipset_info(header.chipset)`; si `coproc = Some(n)` -> `Err(UnsupportedCoprocessor(n))`.
6. `sram = vec![0; sram_bytes(header.ram_log2)]` ; `has_battery = battery` ; `region = forced.unwrap_or(region_from_country(header.country))`.
Les methodes `read`/`write`/`load_sram` viennent a la tache suivante.

## Tests
Tous les tests sont prefixes par `e03_05_`.

- `e03_05_lorom` : `Cart::from_bytes(&make_rom(&[0xA9,0x01], Map::LoRom))`: Ok ; `map_mode()==LoRom` ; `region()==Ntsc` (pays 1) ; `rom_len()==32768` ; `has_battery()==false` ; `sram().len()==0` ; `header().title=="PUCE16 TEST ROM"`.
- `e03_05_hirom` : meme chose avec HiRom: `map_mode()==HiRom`, `rom_len()==65536`.
- `e03_05_exhirom` : avec ExHiRom (8 Mio): `map_mode()==ExHiRom`, `rom_len()==8*1024*1024`.
- `e03_05_copier_header` : `[0u8;512] ++ make_rom(..LoRom)` donne Ok avec `map_mode()==LoRom` et `rom_len()==32768`.
- `e03_05_too_small` : `Cart::from_bytes(&[0u8; 0x7FFF]).err()==Some(CartError::TooSmall)` ; une entree vide aussi.
- `e03_05_coprocessor` : `make_rom_with(&[],Map::LoRom,15,0,0x13,1)` -> `err()==Some(UnsupportedCoprocessor("GSU"))` ; chipset 0x34 -> `UnsupportedCoprocessor("SA-1")`.
- `e03_05_sram_battery` : `make_rom_with(&[],Map::LoRom,15,3,0x02,1)`: `has_battery()==true`, `sram().len()==8192`, tous les octets de sram a 0.
- `e03_05_forced` : `from_bytes_forced(&make_rom(&[0x78],Map::LoRom), Some(LoRom), Some(Region::Pal))` -> `region()==Pal`. `from_bytes_forced(&lorom32k, Some(HiRom), None).err()==Some(NoHeader)` (32 Kio ne contient pas l'en-tete HiRom a 0xFFC0).
- `e03_05_pal_country` : `make_rom_with(&[],Map::LoRom,15,0,0,2)` -> `region()==Pal`.
