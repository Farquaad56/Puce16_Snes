## Specification
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum CycleKind { Read, Write, Idle }
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub struct Cycle { pub addr: u32, pub val: u8, pub kind: CycleKind }
pub struct FlatBus { mem: Vec<u8> /* 0x100_0000 octets */, touched: Vec<u32>, pub log: Vec<Cycle>, pub nmi: bool, pub irq: bool }
impl FlatBus {
    pub fn new() -> FlatBus;                    // memoire a zero, journal vide
    pub fn poke(&mut self, addr: u32, bytes: &[u8]);   // ecrit bytes[i] en addr+i (addr masque a 24 bits, wrap), SANS journal; memorise les adresses touchees
    pub fn peek(&self, addr: u32) -> u8;        // lecture sans journal
    pub fn clear_log(&mut self);
    pub fn reset_mem(&mut self);                // remet a zero uniquement les adresses touchees (rapide); vide aussi le journal
}
impl Default for FlatBus { ... }
impl Bus for FlatBus { ... }
```
- `read(addr)`: masque `addr & 0xFFFFFF`, ajoute `Cycle { addr, val, kind: Read }` au journal, renvoie la valeur. `write(addr, v)`: ecrit, memorise l'adresse touchee, journalise `Write`. `idle()`: journalise `Cycle { addr: 0, val: 0, kind: Idle }`.
- `nmi_pending()`: renvoie `self.nmi` et le remet a false. `irq_asserted()`: renvoie `self.irq`.
- Allouer la memoire en une fois (`vec![0u8; 1 << 24]`).

## 6. Tests d'unite des familles (convention)

Les tests utilisent `FlatBus` (`cpu/testbus.rs`): `FlatBus::new()` ; `bus.poke(addr, &[octets])` ecrit sans journal ; `bus.peek(addr) -> u8` ;
`bus.log: Vec<Cycle>` avec `Cycle { addr: u32, val: u8, kind: CycleKind }`, `CycleKind::{Read, Write, Idle}` (un cycle `Idle` a `addr = 0` et `val = 0`) ;
`bus.clear_log()`. Un test pose le programme en `00:8000` (`cpu.pb = 0; cpu.pc = 0x8000`), fixe les registres a la main, fait `cpu.step(&mut bus)`, puis verifie
registres, memoire et `bus.log.len()` (= nombre de cycles de l'instruction, opcode compris) et, quand c'est precise, la suite exacte des cycles.
Un test peut ecrire `let cycles: Vec<(char, u32, u8)>` ou 'R'/'W'/'I' est le type: a lui de choisir une forme lisible, tant que adresse, valeur, ordre sont verifies.

## Tests
Tous les tests sont prefixes par `e02_06_`.

- `e02_06_read_write_log` : write(0x7E1234, 0x5A) puis read(0x7E1234)==0x5A ; log == [Write{0x7E1234,0x5A}, Read{0x7E1234,0x5A}].
- `e02_06_idle_log` : idle() ajoute Cycle{addr:0,val:0,kind:Idle}.
- `e02_06_poke_peek` : poke(0x001000, &[1,2,3]) -> peek(0x1001)==2 ; le journal reste vide.
- `e02_06_addr_mask` : read(0x1000005) lit la meme case que 0x000005 (apres poke(5,&[9]) -> 9).
- `e02_06_poke_wrap` : poke(0xFFFFFF, &[7,8]) -> peek(0xFFFFFF)==7 et peek(0)==8.
- `e02_06_reset_mem` : poke(0x10,&[5]) ; reset_mem() -> peek(0x10)==0 et journal vide.
- `e02_06_nmi_consumed` : nmi=true: nmi_pending() renvoie true puis false ; irq=true: irq_asserted() renvoie true deux fois de suite.
