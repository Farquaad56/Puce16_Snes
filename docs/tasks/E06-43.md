## Specification
Dans `dsp/envelope.rs`:
```rust
use super::{Dsp, voice::Mode, reg, tables::poll};
impl Dsp {
    pub(super) fn run_envelope(&mut self, x: usize);      // 07b section 4.2, sur self.voices[x]
    pub fn debug_run_envelope(&mut self, x: usize);       // appelle run_envelope
    pub fn counter(&self) -> u16;
    pub fn debug_set_counter(&mut self, c: u16);
}
```
`run_envelope` suit le pseudo-code de la section 4.2 sans le reinterpreter. `adsr1 = regs[vreg(x,ADSR1)]`, `adsr2 = regs[vreg(x,ADSR2)]`, `gain = regs[vreg(x,GAIN)]`. Les calculs sont des `i32`; `data` est un `u8` etendu en `i32` pour `data >> 5` et `data << 4`; `poll(self.counter, rate as u8)`. Mode `Release`: `env = max(env - 8, 0); hidden_env = env;` puis retour immediat.

### 4.2 Enveloppe (11 bits, 0..0x7FF)
```
if mode == Release { env = max(env - 8, 0); hidden = env; return }      // a chaque echantillon, sans taux
let rate; let mut e = env; let mut data = ADSR2;
if ADSR1 & 0x80 {                                   // ADSR
    if mode >= Decay { e -= 1; e -= e >> 8; rate = if mode == Decay { ((ADSR1 >> 4) & 7) * 2 + 16 } else { ADSR2 & 0x1F } }
    else { rate = (ADSR1 & 0xF) * 2 + 1; e += if rate < 31 { 32 } else { 1024 } }
} else {                                            // GAIN
    data = GAIN; let m = data >> 5;
    if m < 4 { e = (data as i32) << 4; rate = 31 }
    else { rate = data & 0x1F;
           if m == 4 { e -= 32 } else if m < 6 { e -= 1; e -= e >> 8 }
           else { e += 32; if m > 6 && hidden_env >= 0x600 { e += 8 - 32 } } }
}
if (e >> 8) == (data >> 5) && mode == Decay { mode = Sustain }
hidden_env = e
if e < 0 || e > 0x7FF { e = if e < 0 { 0 } else { 0x7FF }; if mode == Attack { mode = Decay } }
if poll(rate) { env = e }
```
(Le mode GAIN direct (m<4) a le taux 31 donc s'applique a chaque echantillon.)

## 2. Compteur de periodes (partage: enveloppes + bruit)
`counter` (u16): a chaque echantillon `counter = if counter == 0 { 0x77FF } else { counter - 1 }`.
Tables (index = taux 0..31):
```
PERIOD = [0 (jamais),2048,1536,1280,1024,768,640,512,384,320,256,192,160,128,96,80,64,48,40,32,24,20,16,12,10,8,6,5,4,3,2,1]
OFFSET[r] = 0 si r%3==1 ; 1040 si r%3==2 ; 536 si r%3==0   (r >= 1)
fn poll(rate) -> bool { rate != 0 && (counter + OFFSET[rate]) % PERIOD[rate] == 0 }
```
(Les periodes sont en echantillons DSP; 30720 = 0x7800 est divisible par toutes.)

## Tests
Tous les tests sont prefixes par `e06_43_`.

- `e06_43_attack_rate31` : `Dsp::new()`; voix 0: `ADSR1=0x8F`, `mode=Attack`, `env=0` : `debug_run_envelope(0)` -> `env==1024`, `hidden_env==1024`, `mode==Attack` ; second appel -> `env==0x7FF`, `hidden_env==2048`, `mode==Decay`.
- `e06_43_attack_slow_rate_needs_poll` : `ADSR1=0x81` (taux 3: periode 1280, offset 536), `mode=Attack`, `env=0` : avec `debug_set_counter(0)` -> `env==0` mais `hidden_env==32` ; avec `debug_set_counter(744)` -> `env==32`.
- `e06_43_attack_overflow_slow` : `ADSR1=0x81`, `mode=Attack`, `env=hidden_env=0x7F0`, `counter=744` : `env==0x7FF`, `hidden_env==2064`, `mode==Decay`.
- `e06_43_decay_to_sustain` : `ADSR1=0xF0`, `ADSR2=0x20`, `mode=Decay`, `env=hidden_env=0x201`, `counter=0` : `env==510`, `mode==Sustain`.
- `e06_43_decay_stays_decay` : `ADSR1=0xF0`, `ADSR2=0xE0`, `mode=Decay`, `env=hidden_env=0x400` : `env==1020`, `mode==Decay`.
- `e06_43_sustain_exponential` : `ADSR1=0x80`, `ADSR2=0x1F`, `mode=Sustain`, `env=hidden_env=0x400` : `env==1020`.
