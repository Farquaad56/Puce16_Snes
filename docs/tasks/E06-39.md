## 2. Compteur de periodes (partage: enveloppes + bruit)
`counter` (u16): a chaque echantillon `counter = if counter == 0 { 0x77FF } else { counter - 1 }`.
Tables (index = taux 0..31):
```
PERIOD = [0 (jamais),2048,1536,1280,1024,768,640,512,384,320,256,192,160,128,96,80,64,48,40,32,24,20,16,12,10,8,6,5,4,3,2,1]
OFFSET[r] = 0 si r%3==1 ; 1040 si r%3==2 ; 536 si r%3==0   (r >= 1)
fn poll(rate) -> bool { rate != 0 && (counter + OFFSET[rate]) % PERIOD[rate] == 0 }
```
(Les periodes sont en echantillons DSP; 30720 = 0x7800 est divisible par toutes.)

## Tests
Tous les tests sont prefixes par `e06_39_`.

- `e06_39_period_table` : `PERIOD.len()==32`, `PERIOD[0]==0`, `PERIOD[1]==2048`, `PERIOD[2]==1536`, `PERIOD[13]==128`, `PERIOD[31]==1` ; pour r in 1..32 : `30720 % PERIOD[r] as u32 == 0`.
- `e06_39_offsets` : `offset(0)==0`, `offset(1)==0`, `offset(2)==1040`, `offset(3)==536`, `offset(4)==0`, `offset(30)==536`, `offset(31)==0`.
- `e06_39_poll_rate0_never` : pour counter in 0..0x7800 : `poll(counter, 0)` est faux.
- `e06_39_poll_rate31_always` : pour counter in 0..0x7800 : `poll(counter, 31)` est vrai.
- `e06_39_poll_counts_full_cycle` : pour r in 1..32 : le nombre de `counter` dans `0..0x7800` tels que `poll(counter, r)` vaut exactement `30720 / PERIOD[r]`.
- `e06_39_poll_known_points` : `poll(0, 2)` est faux (1040 % 1536 != 0) ; `poll(496, 2)` est vrai (496 + 1040 = 1536) ; `poll(744, 3)` est vrai (744 + 536 = 1280) ; `poll(0, 1)` est vrai (offset 0, 0 % 2048 == 0) ; `poll(1, 1)` est faux.
- `e06_39_gauss_invariants` : `gauss::GAUSS.len()==512`, `GAUSS[0]==0`, `GAUSS[511]==1305` ; non decroissante ; pour f in 0..256 : `GAUSS[255-f] + GAUSS[511-f] + GAUSS[256+f] + GAUSS[f]` dans `2045..=2051`.
