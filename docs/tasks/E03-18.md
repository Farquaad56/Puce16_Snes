## Specification
Ajoute a `dma/mod.rs`:
```rust
pub trait DmaBus {
    fn a_read(&mut self, addr: u32) -> u8;      // lecture A-bus; le moteur DMA gere le temps (pas d'avance de master ici)
    fn a_write(&mut self, addr: u32, v: u8);
    fn b_read(&mut self, reg: u8) -> u8;        // registre $2100 + reg
    fn b_write(&mut self, reg: u8, v: u8);
    fn elapse(&mut self, clocks: u32);          // fait avancer master et appelle catch_up
    fn master(&self) -> u64;
}
pub fn pattern_offsets(p: u8) -> &'static [u8];    // p = dmap & 7 ; P0 [0] ; P1 [0,1] ; P2 [0,0] ; P3 [0,0,1,1] ; P4 [0,1,2,3] ; P5 [0,1,0,1] ; P6 = P2 ; P7 = P3
pub fn a_step(dmap: u8) -> i32;                    // bits 4-3: 0 -> +1 ; 2 -> -1 ; 1 ou 3 -> 0
pub fn is_wram_addr(addr: u32) -> bool;            // banques 7E-7F ; ou banque (b & 0x7F) <= 0x3F avec adresse < 0x2000
pub fn step_a(a1t: u16, step: i32) -> u16;         // wrapping dans 16 bits
```

## 2. Patterns de transfert (octets envoyes a BBADn + offset)

| P | Octets par unite | Offsets B-bus | HDMA: octets par entree |
|---|---|---|---|
| 0 | 1 | 0 | 1 |
| 1 | 2 | 0,1 | 2 |
| 2 | 2 | 0,0 | 2 |
| 3 | 4 | 0,0,1,1 | 4 |
| 4 | 4 | 0,1,2,3 | 4 |
| 5 | 4 | 0,1,0,1 | 4 |
| 6 | 2 | 0,0 (= 2) | 2 |
| 7 | 4 | 0,0,1,1 (= 3) | 4 |

L'offset B est applique a BBADn: adresse B = $2100 + ((BBADn + offset) & 0xFF).

## Tests
Tous les tests sont prefixes par `e03_18_`.

- `e03_18_offsets` : `pattern_offsets(0)==[0]` ; `(1)==[0,1]` ; `(2)==[0,0]` ; `(3)==[0,0,1,1]` ; `(4)==[0,1,2,3]` ; `(5)==[0,1,0,1]` ; `(6)==[0,0]` ; `(7)==[0,0,1,1]` ; `(0x0B)` (masque 7) == `(3)`.
- `e03_18_a_step` : `a_step(0x00)==1` ; `a_step(0x08)==0` ; `a_step(0x10)==-1` ; `a_step(0x18)==0` ; `a_step(0x81)==1` (bits hors 4-3 ignores) ; `a_step(0x41)==1`.
- `e03_18_wram_addr` : `is_wram_addr(0x7E0000)`, `0x7FFFFF`, `0x000000`, `0x001FFF`, `0x3F1234`, `0x800100`, `0xBF1FFF` vrais ; `0x002000`, `0x00FFFF`, `0x7D0000`, `0xC00000`, `0x400000`, `0x018000` faux.
- `e03_18_step_a` : `step_a(0x1000,1)==0x1001` ; `step_a(0xFFFF,1)==0` ; `step_a(0,-1)==0xFFFF` ; `step_a(0x1234,0)==0x1234`.
- `e03_18_trait_object_safe_enough` : une struct de test `Dummy` qui implemente `DmaBus` (toutes methodes triviales) compile et `Dummy.master()==0`.
