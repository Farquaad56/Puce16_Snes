## Specification
Dans `apu/mod.rs` (garde `pub mod spc700; pub mod dsp; pub mod timer; pub mod ipl; pub mod io;`):
```rust
pub struct Apu { spc: Spc700, io: ApuIo, acc: i64, last_master: u64, master_hz: u64 }
impl Apu {
    pub fn new() -> Apu;                       // master_hz = MASTER_HZ_NTSC ; spc = Spc700::new() avec pc = 0xFFC0 (vecteur de l'IPL : (IPL_ROM[63] << 8) | IPL_ROM[62]) ; acc = 0 ; last_master = 0
    pub fn reset(&mut self);                   // io.reset() ; spc = Spc700::new() + pc comme ci-dessus ; acc = 0 ; last_master = 0 (master_hz conserve)
    pub fn set_region(&mut self, r: Region);   // master_hz = r.master_hz()
    pub fn port_read(&self, i: usize) -> u8;   // io.port_out[i & 3]
    pub fn port_write(&mut self, i: usize, v: u8);   // io.port_in[i & 3] = v
    pub fn step_to(&mut self, master: u64);    // 07d section 4 (si master <= last_master : ne fait rien)
    pub fn cpu_to_apu(&self, i: usize) -> u8;  // io.port_in[i & 3]
    pub fn debug_set_from_apu(&mut self, i: usize, v: u8);   // io.port_out[i & 3] = v
    pub fn take_audio(&mut self) -> Vec<i16>;  // io.dsp.take_audio()
    pub fn debug_poke(&mut self, addr: u16, bytes: &[u8]);   // ecrit dans io.ram sans tick (wrap 16 bits)
    pub fn debug_peek(&self, addr: u16) -> u8;               // io.ram[addr]
    pub fn debug_set_pc(&mut self, pc: u16);   pub fn debug_pc(&self) -> u16;
    pub fn debug_dsp_write(&mut self, reg: u8, v: u8);       // io.dsp.write(reg, v)
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);     // spc : a x y sp (u8) pc (u16) psw halted (u8) ; acc (u64 as i64) ; last_master (u64) ; puis io.hash_into
}
```
`step_to`: `acc += (master - last_master) as i64 * APU_RESONATOR_HZ as i64 ; last_master = master ; while acc > 0 { let c = spc.step(&mut io) ; acc -= c as i64 * 24 * master_hz as i64 }`.
Dans `bus/mod.rs`: `SysBus::new(cart, region)` appelle `apu.set_region(region)` juste apres la creation de l'Apu ; `SysBus::reset` conserve la region de l'Apu (rien d'autre a changer).

## 4. APU (integration)
`ApuIo` (io.rs) possede `ram: Box<[u8; 65536]>`, `dsp: Dsp`, `timers: [Timer; 3]`, `port_in: [u8; 4]` (ecrits par le S-CPU, lus par le SMP en $F4-$F7), `port_out: [u8; 4]` (ecrits par le SMP, lus par le S-CPU), `control: u8` (power-on 0xB0), `dspaddr: u8`, `dsp_div: u8`. Il implemente `SmpBus`: chaque `read`/`write`/`idle` effectue l'acces PUIS `tick()` (3 timers `tick()`, `dsp_div += 1`, et a 32: `dsp_div = 0; dsp.run_sample(&mut ram)`). (`UNKNOWN - to confirm`: tick avant ou apres l'acces.)
`Apu { spc: Spc700, io: ApuIo, acc: i64, last_master: u64, master_hz: u64 }`; `step_to(master)`: `acc += (master - last_master) as i64 * APU_RESONATOR_HZ as i64; last_master = master; while acc > 0 { let c = spc.step(&mut io); acc -= c as i64 * 24 * master_hz as i64 }`.
Les ports vus par le S-CPU: `port_read(i) = io.port_out[i & 3]`, `port_write(i, v)`: `io.port_in[i & 3] = v`.

## 8. Interface Rust
```rust
pub trait SmpBus { fn read(&mut self, addr: u16) -> u8; fn write(&mut self, addr: u16, v: u8); fn idle(&mut self); }
pub struct Spc700 { pub a: u8, pub x: u8, pub y: u8, pub sp: u8, pub pc: u16, pub psw: u8, pub halted: bool }
impl Spc700 {
    pub fn new() -> Self;
    pub fn reset(&mut self, bus: &mut impl SmpBus);      // PC = read16($FFFE)
    pub fn step(&mut self, bus: &mut impl SmpBus) -> u32; // execute 1 instruction, retourne le nombre de cycles
}
pub struct Apu { /* ram[65536], spc700, dsp, timers[3], port_in[4], port_out[4], control, dspaddr, acc: i64, last_master: u64 */ }
impl Apu {
    pub fn new() -> Self;  pub fn reset(&mut self);
    pub fn run_to(&mut self, master: u64);                 // rattrapage (voir 7.1)
    pub fn cpu_read_port(&mut self, n: u8) -> u8;          // $2140+n, appelle run_to avant par le bus
    pub fn cpu_write_port(&mut self, n: u8, v: u8);
    pub fn take_audio(&mut self) -> Vec<i16>;              // paires L,R
}
```
### 8.1 Rattrapage `run_to` (entier uniquement)
```
acc += (master - last_master) as i64 * APU_RESONATOR_HZ as i64; last_master = master
while acc > 0 { spc.step(bus) }          // chaque cycle SMP: acc -= 24 * MASTER_HZ (signe: peut devenir negatif = dette d'une instruction)
```
`MASTER_HZ` = NTSC ou PAL selon la region. Le S-CPU appelle `run_to(master)` juste avant tout acces `$2140-$2143`. `UNKNOWN - to confirm`: le SMP peut etre en avance de moins d'une instruction.

## Tests
Tous les tests sont prefixes par `e06_35_`.

- `e06_35_new_defaults` : `Apu::new()`: `port_read(i)==0` pour i in 0..4 ; `cpu_to_apu(i)==0` ; `debug_pc()==0xFFC0`.
- `e06_35_handshake_aa_bb` : `step_to(100_000)`: `port_read(0)==0xAA` et `port_read(1)==0xBB` (miroirs : `port_read(4)==0xAA`).
- `e06_35_not_yet_before_clear_loop` : `step_to(10_000)`: `port_read(0)==0` (l'IPL efface encore la RAM).
- `e06_35_step_to_is_incremental` : A: `step_to(100_000)` ; B: `step_to(50_000)` puis `step_to(100_000)` : les deux ont le meme hash (la decoupe n'a pas d'effet).
- `e06_35_step_to_backwards_noop` : apres `step_to(100_000)`, `step_to(50_000)` ne change pas le hash.
- `e06_35_ipl_clears_low_ram` : `debug_poke(0x0010,&[0x99])` puis `step_to(100_000)` : `debug_peek(0x0010)==0`.
- `e06_35_port_write_visible_to_smp` : apres le handshake, `port_write(0,0xCC)`: `cpu_to_apu(0)==0xCC` ; `port_read(0)` reste `0xAA` tant que le SMP n'a pas repondu.
- `e06_35_set_region_pal` : `set_region(Region::Pal)` puis `step_to(100_000)` : handshake AA/BB aussi (pas de panique).
- `e06_35_reset_restarts_ipl` : apres le handshake, `reset()`: `port_read(0)==0`, `debug_pc()==0xFFC0`, puis `step_to(100_000)` redonne 0xAA.
- `e06_35_debug_dsp_write` : `debug_dsp_write(0x0C,0x40)` puis `hash` different de celui d'un Apu neuf.
- `e06_35_take_audio_empty` : `take_audio()` est vide juste apres `new()`.
- `e06_35_determinism` : deux `Apu::new()` avances de la meme facon donnent le meme hash.
