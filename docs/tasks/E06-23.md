## Specification
Dans `bits.rs::exec` (`n` = numero de bit 0..=7):
- `SET1 dp.n` = `n*0x20 + 0x02` (02 22 42 62 82 A2 C2 E2) ; `CLR1 dp.n` = `n*0x20 + 0x12` : `b = fetch8` ; `ea = P|b` ; `v = rd(ea)` ; `wr(ea, v | bit)` (resp. `v & !bit`). Aucun flag.
- `BBS dp.n,rel` = `n*0x20 + 0x03` ; `BBC dp.n,rel` = `n*0x20 + 0x13` : octets `op dp rel` (`b = fetch8`, `rel = fetch8`) ; `v = rd(P|b)` ; saute (`cpu.branch(bus, rel)`) si le bit vaut 1 (BBS) / 0 (BBC). Aucun flag.
- `0E` TSET1 !abs: `ea = fetch16` ; `t = rd(ea)` ; `r = a.wrapping_sub(t)` ; `set_nz(r)` (N = bit 7 de r, Z = (r == 0)) ; `wr(ea, t | a)`. `4E` TCLR1 !abs: idem avec `wr(ea, t & !a)`.

### 6.4 Bits
- `SET1/CLR1 dp.n` (opcodes `n*0x20 + 0x02` / `+0x12`): positionne/efface le bit n de `dp`. Pas de flag.
- `BBS/BBC dp.n,rel` (`+0x03` / `+0x13`): saute si le bit est 1 / 0. Pas de flag.
- `TSET1 !abs`: `t = M`; flags `N,Z` calcules sur `A - t` (comme CMP); `M = t | A`. `TCLR1`: idem mais `M = t & ~A`.
- `OR1 C,m.b`: `C |= bit`; `OR1 C,/m.b`: `C |= !bit`; `AND1 C,m.b`: `C &= bit`; `AND1 C,/m.b`: `C &= !bit`; `EOR1 C,m.b`: `C ^= bit`; `MOV1 C,m.b`: `C = bit`; `MOV1 m.b,C`: ecrit le bit; `NOT1 m.b`: inverse le bit. Seul C change (sauf NOT1/MOV1 memoire: aucun flag).

## Tests
Tous les tests sont prefixes par `e06_23_`.

- `e06_23_set1` : poke(0x10,&[0x00]), `02 10` (SET1 dp.0): peek(0x10)==0x01, cycles 4 ; `E2 10` (dp.7) sur 0: peek==0x80 ; `42 10` (dp.2): 0x04.
- `e06_23_clr1` : poke(0x10,&[0xFF]), `72 10` (CLR1 dp.3): peek(0x10)==0xF7, cycles 4 ; `12 10` (dp.0) sur 0xFF -> 0xFE.
- `e06_23_set_clr_no_flags` : psw=0xC3, `02 10`: psw==0xC3.
- `e06_23_bbs_taken` : poke(0x10,&[0x04]), `43 10 05` (BBS dp.2,+5): pc==0x0208 (0x0203 + 5), cycles 7.
- `e06_23_bbs_not_taken` : poke(0x10,&[0x00]), `43 10 05`: pc==0x0203, cycles 5.
- `e06_23_bbc_taken_backward` : poke(0x10,&[0x00]), `33 10 FC` (BBC dp.1,-4): pc==0x01FF, cycles 7.
- `e06_23_bbc_not_taken` : poke(0x10,&[0x02]), `33 10 FC`: pc==0x0203, cycles 5.
- `e06_23_bbs_dp_n_opcodes` : BBS dp.7 = `E3`, BBC dp.7 = `F3` : poke(0x10,&[0x80]) `E3 10 02`: pc==0x0205 ; `F3 10 02`: pc==0x0203.
- `e06_23_tset1` : a=0x0F, poke(0x3000,&[0xF0]), `0E 00 30`: peek(0x3000)==0xFF, N=0, Z=0 (0x0F-0xF0 = 0x1F), cycles 6 ; a=0x80, mem 0x80: Z=1, mem 0x80 ; a=0x01, mem 0x02: N=1 (0xFF), mem 0x03.
- `e06_23_tclr1` : a=0x0F, poke(0x3000,&[0xFF]), `4E 00 30`: peek(0x3000)==0xF0, N=0, Z=0 (0x0F-0xFF = 0x10), cycles 6.
- `e06_23_tset1_keeps_c_v` : psw=F_C|F_V, a=0, mem 0, `0E 00 30`: C et V toujours a 1, Z=1.
