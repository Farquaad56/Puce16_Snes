## Specification
Dans `ppu/bg.rs`:
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub struct Pix { pub rgb: u16, pub prio: u8, pub obj_pal: u8 }
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub struct Pick { pub rgb: u16, pub layer: u8, pub obj_pal: u8 }
pub const LAYER_OBJ: u8 = 4;  pub const LAYER_BACKDROP: u8 = 5;
pub fn bpp(mode: u8, bg: usize) -> u8;      // table BPP[mode][bg] ; mode > 7 ou bg > 3: 0
pub fn priority_order(mode: u8, bg3_priority: bool, extbg: bool) -> &'static [(u8, u8)];
```
`bpp` : mode 0 -> [2,2,2,2] ; 1 -> [4,4,2,0] ; 2 -> [4,4,0,0] ; 3 -> [8,4,0,0] ; 4 -> [8,2,0,0] ; 5 -> [4,2,0,0] ; 6 -> [4,0,0,0] ; 7 -> [8,0,0,0].
`priority_order` (couche, niveau): sprites `Sp` = (4, p) ; fond `nH` = (n-1, 1), `nL` = (n-1, 0). Tables (declare-les en `const`/`static`):
- mode 0 : S3 1H 2H S2 1L 2L S1 3H 4H S0 3L 4L (12 entrees)
- mode 1, `bg3_priority == false` : S3 1H 2H S2 1L 2L S1 3H S0 3L (10) ; `bg3_priority == true` : 3H S3 1H 2H S2 1L 2L S1 S0 3L (10)
- modes 2, 3, 4, 5 : S3 1H S2 2H S1 1L S0 2L (8)
- mode 6 : S3 1H S2 S1 1L S0 (6) -> (4,3) (0,1) (4,2) (4,1) (0,0) (4,0)
- mode 7, `extbg == false` : S3 S2 S1 1 S0 -> (4,3) (4,2) (4,1) (0,0) (4,0) ; `extbg == true` : S3 S2 2H S1 1 S0 2L -> (4,3) (4,2) (1,1) (4,1) (0,0) (4,0) (1,0)
`bg3_priority` ne compte qu'en mode 1 ; `extbg` ne compte qu'en mode 7. Le BACKDROP n'est pas dans les tables (toujours en dernier).

## 1. Types de base
```rust
pub struct Pix { pub rgb: u16, pub prio: u8, pub obj_pal: u8 }   // rgb = BGR555 final (0bbbbbgggggrrrrr); obj_pal = palette sprite 0..7 (seulement pour OBJ)
// Couches: 0..=3 = BG1..BG4, 4 = OBJ, 5 = BACKDROP
pub struct Pick { pub rgb: u16, pub layer: u8, pub obj_pal: u8 }
```
Convention couleur: `r5 = w & 31`, `g5 = (w >> 5) & 31`, `b5 = (w >> 10) & 31`. Index 0 d'une tuile (2/4/8 bpp) = transparent (BG et OBJ), meme en couleur directe.

## 2. Modes BG: profondeur de bits par couche et tables de priorite

`BPP[mode][bg]` (0 = couche non rendue):
| Mode | BG1 | BG2 | BG3 | BG4 | Remarque |
|---|---|---|---|---|---|
| 0 | 2 | 2 | 2 | 2 | base CGRAM BGn = (n-1)*32 |
| 1 | 4 | 4 | 2 | 0 | |
| 2 | 4 | 4 | 0 | 0 | BG3 = donnees offset-per-tile (non affichee) |
| 3 | 8 | 4 | 0 | 0 | BG1 couleur directe possible |
| 4 | 8 | 2 | 0 | 0 | BG3 = OPT (un seul mot) |
| 5 | 4 | 2 | 0 | 0 | hi-res force, tuiles 16 px de large |
| 6 | 4 | 0 | 0 | 0 | hi-res force, BG3 = OPT |
| 7 | 8 | (EXTBG 7 bits) | 0 | 0 | voir section 8 |

Ordre de priorite, de l'AVANT vers l'ARRIERE. Notation: `Sp` = sprites de priorite p (0..3); `nH`/`nL` = BG n avec bit de priorite de tuile 1 / 0; en mode 7: `1` = BG1 (une seule priorite), EXTBG: `2H`/`2L` = bit 7 de l'indice.
```
Mode 0:  S3 1H 2H S2 1L 2L S1 3H 4H S0 3L 4L
Mode 1 (BGMODE bit3 = 0): S3 1H 2H S2 1L 2L S1 3H S0 3L
Mode 1 (BGMODE bit3 = 1): 3H S3 1H 2H S2 1L 2L S1 S0 3L
Mode 2,3,4,5: S3 1H S2 2H S1 1L S0 2L
Mode 6:  S3 1H S2 S1 1L S0
Mode 7:  S3 S2 S1 1 S0
Mode 7 + EXTBG: S3 S2 2H S1 1 S0 2L
```
Implementation: `const PRIORITY: [&[(u8 /*couche*/, u8 /*niveau*/)]; ...]` (niveau = priorite 0..3 pour OBJ, 0/1 pour BG; mode 6: BG1 H/L; mode 7: BG1 niveau 0 ou "tous"). Le fond (backdrop) vient toujours en dernier.
Pour une couche BG non rendue (BPP = 0), ou dont le bit TM/TS est a 0, l'entree est ignoree.

## Tests
Tous les tests sont prefixes par `e05_01_`.

- `e05_01_bpp_table` : `bpp(0,*)==[2,2,2,2]` ; `bpp(1,*)==[4,4,2,0]` ; `bpp(2,*)==[4,4,0,0]` ; `bpp(3,*)==[8,4,0,0]` ; `bpp(4,*)==[8,2,0,0]` ; `bpp(5,*)==[4,2,0,0]` ; `bpp(6,*)==[4,0,0,0]` ; `bpp(7,*)==[8,0,0,0]` (pour bg 0..4) ; `bpp(8,0)==0` ; `bpp(0,4)==0`.
- `e05_01_order_mode0` : `priority_order(0,false,false)==[(4,3),(0,1),(1,1),(4,2),(0,0),(1,0),(4,1),(2,1),(3,1),(4,0),(2,0),(3,0)]`.
- `e05_01_order_mode1` : `priority_order(1,false,false)==[(4,3),(0,1),(1,1),(4,2),(0,0),(1,0),(4,1),(2,1),(4,0),(2,0)]` ; `priority_order(1,true,false)==[(2,1),(4,3),(0,1),(1,1),(4,2),(0,0),(1,0),(4,1),(4,0),(2,0)]`.
- `e05_01_order_modes_2_to_5` : pour m in 2..=5 : `priority_order(m,false,false)==[(4,3),(0,1),(4,2),(1,1),(4,1),(0,0),(4,0),(1,0)]` (et identique avec `bg3_priority` vrai).
- `e05_01_order_mode6` : `priority_order(6,false,false)==[(4,3),(0,1),(4,2),(4,1),(0,0),(4,0)]`.
- `e05_01_order_mode7` : `priority_order(7,false,false)==[(4,3),(4,2),(4,1),(0,0),(4,0)]` ; `priority_order(7,false,true)==[(4,3),(4,2),(1,1),(4,1),(0,0),(4,0),(1,0)]`.
- `e05_01_bg3_priority_only_mode1` : `priority_order(0,true,false)==priority_order(0,false,false)` ; `priority_order(2,true,false)==priority_order(2,false,false)` ; `priority_order(1,true,false)!=priority_order(1,false,false)`.
- `e05_01_types` : `Pix{rgb:1,prio:2,obj_pal:3}` et `Pick{rgb:1,layer:5,obj_pal:0}` se construisent, sont `Copy` et comparables ; `LAYER_OBJ==4`, `LAYER_BACKDROP==5`.
