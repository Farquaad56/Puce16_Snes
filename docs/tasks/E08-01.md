## Specification
Dans `savestate.rs` (le module est deja declare dans lib.rs):
```rust
pub const STATE_VERSION: u32 = 1;
#[derive(Clone, Debug, PartialEq, Eq)] pub enum StateError { Truncated, Version(u32), Mismatch(&'static str) }
impl std::fmt::Display for StateError { ... }     // "state truncated" / "unsupported state version <n>" / "state mismatch: <what>"
impl std::error::Error for StateError {}
pub struct StateWriter { buf: Vec<u8> }
impl StateWriter {
    pub fn new() -> StateWriter;  pub fn len(&self) -> usize;  pub fn finish(self) -> Vec<u8>;
    pub fn u8(&mut self, v: u8);  pub fn u16(&mut self, v: u16);  pub fn u32(&mut self, v: u32);  pub fn u64(&mut self, v: u64);
    pub fn i16(&mut self, v: i16); pub fn i32(&mut self, v: i32); pub fn i64(&mut self, v: i64); pub fn bool(&mut self, v: bool);   // bool = 0 ou 1
    pub fn bytes(&mut self, v: &[u8]);            // brut, sans prefixe
    pub fn slice_u16(&mut self, v: &[u16]);       // brut, 2 octets LE chacun
    pub fn slice_u32(&mut self, v: &[u32]);       // brut, 4 octets LE chacun
    pub fn vec_u8(&mut self, v: &[u8]);           // prefixe u32 (longueur) puis octets
    pub fn vec_u16(&mut self, v: &[u16]);         // prefixe u32 (nombre d'elements) puis elements
}
pub struct StateReader<'a> { data: &'a [u8], pos: usize }
impl<'a> StateReader<'a> {
    pub fn new(data: &'a [u8]) -> StateReader<'a>;  pub fn remaining(&self) -> usize;
    pub fn u8(&mut self) -> Result<u8, StateError>;  /* u16 u32 u64 i16 i32 i64 */  pub fn bool(&mut self) -> Result<bool, StateError>;   // octet > 1 -> Mismatch("bool")
    pub fn bytes_into(&mut self, out: &mut [u8]) -> Result<(), StateError>;
    pub fn slice_u16_into(&mut self, out: &mut [u16]) -> Result<(), StateError>;
    pub fn slice_u32_into(&mut self, out: &mut [u32]) -> Result<(), StateError>;
    pub fn vec_u8(&mut self) -> Result<Vec<u8>, StateError>;      // longueur > restant -> Truncated (ne jamais allouer avant de verifier)
    pub fn vec_u16(&mut self) -> Result<Vec<u16>, StateError>;
    pub fn finish(self) -> Result<(), StateError>;                // octets restants -> Mismatch("trailing data")
}
pub trait State { fn save(&self, w: &mut StateWriter); fn load(&mut self, r: &mut StateReader) -> Result<(), StateError>; }
```
Toute lecture au-dela de la fin renvoie `StateError::Truncated` (jamais de panique).

## 9. Save states (core, `savestate.rs`)

- Format binaire maison: octets little-endian, `u32` version du blob (1 au debut). Aucun serde, aucune dependance.
- Ecriture/lecture par un trait: `trait State { fn save(&self, w: &mut StateWriter); fn load(&mut self, r: &mut StateReader) -> Result<(), StateError>; }` implemente par chaque composant, dans CET ordre: `master` (+ phase APU `apu_acc: i64`), Cpu, Bus (WRAM 128 Kio, registres $4200-$421F, mdr), DMA (8 canaux + etat HDMA), timing, Ppu (registres, VRAM, CGRAM, OAM, latchs, position, `line_obj`, framebuffer 512x478), Apu (RAM 64 Kio, SMP, timers, ports, DSP: registres, voix, echo, tampons), joypads, Cart (SRAM seulement ; la ROM n'est PAS sauvee).
- `StateWriter`: `u8/u16/u32/u64/i64/bool/bytes(&[u8])/slice_u16`; `StateReader` symetrique avec verification de fin de donnees (erreur `StateError::Truncated`/`Version`/`Mismatch`).
- Aller-retour: `load_state(save_state())` laisse `state_hash` inchange, et executer N frames apres un `load_state` donne le meme `state_hash` que sans passer par le save state.
- Taille attendue: ~1.3 Mio ; pas de compression en v1.

## Tests
Tous les tests sont prefixes par `e08_01_`.

- `e08_01_little_endian_bytes` : `w.u16(0x1234); w.u32(0x01020304); w.u64(0x0102030405060708)` -> `finish()` == `[0x34,0x12, 0x04,0x03,0x02,0x01, 8,7,6,5,4,3,2,1]`.
- `e08_01_signed_and_bool` : `w.i16(-2); w.i32(-3); w.i64(-4); w.bool(true); w.bool(false)` -> octets `[0xFE,0xFF, 0xFD,0xFF,0xFF,0xFF, 0xFC,0xFF*7, 1, 0]` et relecture identique.
- `e08_01_roundtrip_all` : ecrire un u8, un u16, un u32, un u64, un i16, un i32, un i64, deux bool, `bytes([1,2,3])`, `slice_u16([0x1111,0x2222])`, `slice_u32([7,8])`, `vec_u8([9,9])`, `vec_u16([5])` ; relire dans le meme ordre : valeurs egales ; `finish()` Ok.
- `e08_01_slice_layouts` : `slice_u16(&[0x0102])` -> `[2,1]` ; `slice_u32(&[1])` -> `[1,0,0,0]` ; `vec_u8(&[7,8])` -> `[2,0,0,0,7,8]` ; `vec_u16(&[0x0A0B])` -> `[1,0,0,0,0x0B,0x0A]`.
- `e08_01_truncated_scalars` : lecteur sur `[1]` : `u16()` == Err(Truncated) ; sur `[]` : `u8()` == Err(Truncated) ; sur 7 octets : `u64()` == Err(Truncated).
- `e08_01_truncated_bytes_into` : `bytes_into` d'un tampon de 4 sur 3 octets -> Err(Truncated) ; idem `slice_u16_into` de 2 elements sur 3 octets.
- `e08_01_vec_huge_length` : lecteur sur `[0xFF,0xFF,0xFF,0xFF, 1]` : `vec_u8()` == Err(Truncated) sans allocation enorme ni panique.
- `e08_01_bool_invalid` : lecteur sur `[2]` : `bool()` == Err(Mismatch("bool")).
- `e08_01_finish_trailing` : ecrire 2 octets, n'en lire qu'un : `finish()` == Err(Mismatch("trailing data")) ; tout lire : Ok.
- `e08_01_display` : `format!("{}", StateError::Truncated)=="state truncated"` ; `Version(3)` -> `"unsupported state version 3"` ; `Mismatch("region")` -> `"state mismatch: region"`.
- `e08_01_trait_object_free_roundtrip` : un type local de test `struct P{a:u16,b:bool}` implemente `State` (ecrit `a` puis `b`) : save -> load dans un `P` neuf -> egal.
- `e08_01_version_constant` : `STATE_VERSION==1`.
