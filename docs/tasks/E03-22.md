# E03-22 - dma/hdma.rs: hdma_run_line (un transfert par scanline)
Epopee: E03 | Type: code | Dependances: E03-21 | Taille estimee: ~140 lignes

## Contexte
Execution HDMA d'une scanline (spec 03 sections 4.2, 4.3). Pour chaque canal actif (bit dans `mask` ET `done == false`): surcout, transfert eventuel, puis mise a jour du compteur de lignes.
Temps: `elapse(18)` une fois (seulement s'il y a au moins un canal actif), `elapse(8)` par canal actif, `elapse(8)` par octet transfere (avant la copie). Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## Specification
Ajoute a `impl Dma` (dans `dma/hdma.rs`): `pub fn hdma_run_line<B: DmaBus>(&mut self, bus: &mut B, mask: u8);`
1. `active = mask & bits des canaux dont done == false`. Si `active == 0`: retourner. `bus.elapse(18)`.
2. Pour chaque canal actif n (0..7): `bus.elapse(8)`.
   a. Si `do_transfer`: `offs = pattern_offsets(dmap & 7)`; pour chaque `k` de `offs`: `bus.elapse(8)` ; source = si `dmap & 0x40 == 0` (direct): `(a1b << 16) | a2a` puis `a2a += 1` (wrap 16 bits) ; si indirect: `(dasb << 16) | das` puis `das += 1` ; `v = bus.a_read(src)` ; `bus.b_write(bbad.wrapping_add(k), v)`. (Le bit de direction est ignore.)
   b. `line_counter -= 1`.
   c. Si `line_counter == 0`: lire `b = bus.a_read((a1b << 16) | a2a)`, `a2a += 1`, `nltr = b` ; si `b == 0`: `done = true; do_transfer = false` ; sinon `line_counter = (b & 0x7F) ou 128 si 0 ; do_transfer = true` et, en mode indirect, lire `lo`,`hi` (comme en init) dans `das`.
      Sinon (compteur > 0): `do_transfer = (nltr & 0x80) != 0`.
Pas de gestion de `forced blank` (HDMA ecrit meme en forced blank).

### 4.2 Table et transfert (chaque scanline, V = 0..derniere ligne visible-1)
Octet de ligne `NLTRn` = `R LLLLLLL`:
- `$00`: fin de la table; arret du canal pour la frame.
- `$01-$80` (R=0): **une** ecriture (pattern complet), puis attendre L lignes (L = 1..128; $80 = 128).
- `$81-$FF` (R=1): une ecriture **a chaque ligne** pendant L-$80... : nombre de lignes = (valeur & 0x7F); une ecriture par ligne.
  (Le wiki: `$81-$FF` = X-$80 lignes en mode repete.)

A chaque scanline (fin de la partie active, juste apres la zone visible; `HDMA_RUN_HCLOCK` defaut = 1104 clocks, `UNKNOWN - to confirm`), pour chaque canal actif non termine:
1. Si "do transfer" (compteur de ligne = debut d'entree ou flag repetition): transferer `octets du pattern` (table 2) depuis:
   - direct: `(A1Bn:A2An)`, `A2An += n`;
   - indirect: `(DASBn:DASn)`, `DASn += n`;
   vers B-bus (`BBADn + offset`). (Direction bit D=1 interdit en HDMA: comportement `UNKNOWN`, ne pas implementer.)
2. Decrementer le compteur de lignes (`NLTRn & 0x7F`).
3. Si le compteur atteint 0: lire le prochain octet de ligne (comme 4.1 items 2-4), etablir le flag "do transfer" = vrai; si l'octet vaut 0: canal termine.
   Sinon: flag "do transfer" = vrai seulement si R=1 (repetition).
- La premiere entree est executee a la fin de la scanline 0. L'entree pour la ligne N doit donc etre prevue avec le compteur de l'entree precedente.
- Dernier cycle: les canaux HDMA termines ne font plus rien jusqu'a l'initialisation suivante.

### 4.3 Timing HDMA (defauts)
- Surcout par scanline si au moins un canal HDMA actif: 18 clocks (`UNKNOWN - to confirm`) + 8 clocks par canal actif + 8 clocks par octet transfere.
- HDMA a priorite sur DMA general et sur le CPU: execute a des dates fixes de la ligne.
- HDMA ecrit meme pendant le forced blanking (INIDISP bit7 ne le coupe pas).

## Tests
Tous les tests sont prefixes par `e03_22_`.

- `e03_22_repeat_free_entry` : FakeBus. ch0: dmap=0x00, bbad=0x26, a1b=0x7E, a1t=0x2000 ; table 7E:2000 = [0x03, 0xAA, 0x82, 0xBB, 0xCC, 0x00]. `hdma_init(1)` puis 6 appels `hdma_run_line(1)`: `b_writes()==[(0x26,0xAA),(0x26,0xBB),(0x26,0xCC)]` ; apres le 5eme appel `hdma_state(0).3==true` (done) ; le 6eme appel ne produit AUCUN evenement.
- `e03_22_states_walk` : meme table, etat apres chaque `hdma_run_line`: apres le 1er: `(0x2002, 2, false, false)` ; 2eme: `(0x2002, 1, false, false)` ; 3eme: `(0x2003, 2, true, false)` (lu 0x82) ; 4eme: `(0x2004, 1, true, false)` ; 5eme: `(0x2005 + 1, 0, false, true)`.
- `e03_22_timing_first_call` : apres `hdma_init` (master 26): le 1er `hdma_run_line` ajoute 18+8+8==34 -> `bus.master==60` ; le 2eme (pas de transfert) ajoute 26 -> 86.
- `e03_22_event_order_run` : le 1er run_line (apres l'init): evenements `[Elapse(18), Elapse(8), Elapse(8), ARead(0x7E2001), BWrite(0x26,0xAA)]` (ignorer les evenements de l'init en les effacant avec `bus.ev.clear()` avant).
- `e03_22_pattern_p1` : dmap=0x01, bbad=0x18, table [0x01, 0x11, 0x22, 0x00]: 1er run: `b_writes()==[(0x18,0x11),(0x19,0x22)]` ; temps 18+8+16 apres l'init ; apres ce 1er run: `hdma_state(0).3==true` (done, l'octet suivant est 0x00) ; un 2eme run ne produit aucun evenement.
- `e03_22_indirect_repeat` : dmap=0x40, dasb=0x7F, bbad=0x26, table 7E:3000 = [0x82, 0x00, 0x40, 0x00], donnees 7F:4000 = [0x55, 0x66]: apres init `das==0x4000` ; 1er run ecrit 0x55 (das->0x4001, do_transfer reste vrai) ; 2eme run ecrit 0x66 (das->0x4002) puis lit le 0x00 -> done.
- `e03_22_indirect_non_repeat` : meme avec octet 0x02 (non repete): seul 0x55 est ecrit (1er run) ; le 2eme run ne transfere pas mais lit l'octet suivant (0x00) -> done.
- `e03_22_line_count_128` : octet 0x80: `line_counter==128` apres init ; apres 127 runs `line_counter==1` ; au 128eme run la table est relue.
- `e03_22_mask_excludes` : avec `mask` ne contenant pas le canal: aucun evenement. Canal `done`: aucun evenement.
- `e03_22_two_channels` : ch0 et ch1 avec chacun une entree d'1 ligne P0 (1 octet): 1er run: `Elapse(18)` une seule fois, puis ch0 (8 + 8 + octet) puis ch1 (8 + 8 + octet) ; temps total apres l'init: 18 + 2*(8+8)==50.
- `e03_22_a2a_wrap_in_run` : a2a==0xFFFF en direct: l'octet lu est 7E:FFFF et a2a repasse a 0.
