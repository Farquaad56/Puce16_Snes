## Contexte

Chaque acces (`read`, `write`, `idle`) fait l'acces PUIS un `tick()` (timers + diviseur DSP). ## Specification
Cree `apu/io.rs` et declare `pub mod io;` dans `apu/mod.rs` (sans rien changer d'autre).
```rust
pub struct ApuIo { pub ram: Box<[u8; 65536]>, pub dsp: Dsp, pub timers: [Timer; 3], pub port_in: [u8; 4], pub port_out: [u8; 4], pub control: u8, pub dspaddr: u8, dsp_div: u8 }
impl ApuIo { pub fn new() -> ApuIo; pub fn reset(&mut self); pub fn hash_into(&self, h: &mut crate::hash::Fnv64); }
impl SmpBus for ApuIo { fn read(&mut self, addr: u16) -> u8; fn write(&mut self, addr: u16, v: u8); fn idle(&mut self); }
```
`new`: RAM a 0 (`UNKNOWN - to confirm`), `control = 0xB0`, timers `Timer::new(128)`, `Timer::new(128)`, `Timer::new(16)`, ports 0, `dspaddr = 0`, `dsp_div = 0`, `Dsp::new()`. `reset`: ports 0, `control = 0xB0`, `dspaddr = 0`, `dsp_div = 0`, timers neufs, `dsp.reset()`; la RAM est CONSERVEE.
`tick()` (prive, appele apres chaque acces): `for t in timers { t.tick() }` ; `dsp_div += 1` ; si `dsp_div == 32` : `dsp_div = 0` ; `dsp.run_sample(&mut *ram)`.
`read(addr)`: `$F0`->0 ; `$F1`->0 ; `$F2`-> `dspaddr & 0x7F` ; `$F3` -> `dsp.read(dspaddr & 0x7F)` ; `$F4..=$F7` -> `port_in[addr-0xF4]` ; `$F8`,`$F9` -> RAM ; `$FA..=$FC` -> 0 ; `$FD..=$FF` -> `timers[addr-0xFD].read_out()` ; `$FFC0..=$FFFF` -> `IPL_ROM[addr-0xFFC0]` si `control & 0x80 != 0` sinon RAM ; sinon RAM.
`write(addr, v)`: `$F0` ignore ; `$F1` : `control = v` ; `timers[i].set_enable(v >> i & 1 != 0)` pour i in 0..3 ; si `v & 0x10` : `port_in[0] = port_in[1] = 0` ; si `v & 0x20` : `port_in[2] = port_in[3] = 0` ; `$F2` : `dspaddr = v` ; `$F3` : si `dspaddr & 0x80 == 0` : `dsp.write(dspaddr, v)` ; `$F4..=$F7` -> `port_out[addr-0xF4] = v` ; `$F8`,`$F9` -> RAM ; `$FA..=$FC` -> `timers[addr-0xFA].set_target(v)` ; `$FD..=$FF` ignore ; toute autre adresse (y compris `$FFC0..=$FFFF`, meme IPL visible) -> RAM. (Les ecritures dans `$F0-$F7` et `$FA-$FF` ne modifient PAS la RAM.)
`idle()` ne fait que le `tick()`.

## 3. Registres $F0-$FF
| Addr | Nom | Lecture | Ecriture |
|---|---|---|---|
| $F0 | TEST | `$00` | ignore en v1 (power-on $0A). `UNKNOWN`: ne PAS emuler les etats d'attente |
| $F1 | CONTROL | `$00` | bit0/1/2: active timer 0/1/2 (transition 0->1: remet a 0 les compteurs internes `stage1` et la sortie `out` du timer); bit4: efface les ports d'entree 0 et 1 ($F4,$F5); bit5: efface les ports d'entree 2 et 3; bit7: IPL ROM visible. Power-on/reset: `$B0` |
| $F2 | DSPADDR | valeur ecrite (bit7 lu a 0, selon le wiki) | octet complet stocke |
| $F3 | DSPDATA | `dsp.read(DSPADDR & 0x7F)` | si `DSPADDR` bit7 = 0: `dsp.write(DSPADDR & 0x7F, v)`; sinon ignore |
| $F4-$F7 | CPUIO0-3 | octet ecrit par le S-CPU dans `$2140-$2143` (`port_in[n]`) | stocke dans `port_out[n]` (lu par le S-CPU) |
| $F8,$F9 | - | RAM normale | RAM normale |
| $FA-$FC | T0-T2 TARGET | `$00` | cible du timer |
| $FD-$FF | T0-T2 OUT | compteur 4 bits (`out & 0x0F`), **remis a 0 par la lecture** | ignore |

Les ecritures dans $F0-$FF vont aussi dans la RAM sous-jacente (relecture impossible, mais utile pour les save states): `UNKNOWN - to confirm`; defaut: la RAM n'est pas modifiee pour $F0-$FF.
Ports (cote S-CPU, decrits dans `02_BUS_TIMING.md`): lecture de `$2140+(a&3)` = `port_out[a&3]`; ecriture = `port_in[a&3]`. Reset: les 8 valeurs a `0`. Le cas "lu au meme cycle qu'ecrit" n'est PAS emule.

### 3.1 Timers
Timer 0 et 1: diviseur `128` cycles SMP (8 kHz). Timer 2: diviseur `16` cycles SMP (64 kHz).
Etat par timer: `stage0: u16` (diviseur interne, tourne en permanence, jamais remis a 0 par CONTROL), `stage1: u8`, `out: u8` (4 bits), `enable: bool`, `target: u8`.
A chaque cycle SMP:
```
stage0 += 1
if stage0 == divider { stage0 = 0; if enable { stage1 = stage1.wrapping_add(1); if stage1 == target { stage1 = 0; out = (out + 1) & 0x0F } } }
```
(`target == 0` equivaut donc a 256, grace au `u8` qui deborde.) Lecture de `$FD+n`: retourne `out`, puis `out = 0`.

## 2. Memoire 64 Kio
| Plage | Contenu |
|---|---|
| $0000-$00EF | RAM (page directe, P=0) |
| $00F0-$00FF | registres (section 3) |
| $0100-$01FF | RAM (pile) |
| $0200-$FFBF | RAM |
| $FFC0-$FFFF | IPL ROM si `CONTROL bit7 = 1`, sinon RAM. Les ecritures vont TOUJOURS dans la RAM. |

RAM au power-on: `0x00` (`UNKNOWN - to confirm`). Les acces du DSP a la RAM (BRR, echo) lisent/ecrivent la RAM directement (pas l'IPL).

## 4. APU (integration)
`ApuIo` (io.rs) possede `ram: Box<[u8; 65536]>`, `dsp: Dsp`, `timers: [Timer; 3]`, `port_in: [u8; 4]` (ecrits par le S-CPU, lus par le SMP en $F4-$F7), `port_out: [u8; 4]` (ecrits par le SMP, lus par le S-CPU), `control: u8` (power-on 0xB0), `dspaddr: u8`, `dsp_div: u8`. Il implemente `SmpBus`: chaque `read`/`write`/`idle` effectue l'acces PUIS `tick()` (3 timers `tick()`, `dsp_div += 1`, et a 32: `dsp_div = 0; dsp.run_sample(&mut ram)`). (`UNKNOWN - to confirm`: tick avant ou apres l'acces.)
`Apu { spc: Spc700, io: ApuIo, acc: i64, last_master: u64, master_hz: u64 }`; `step_to(master)`: `acc += (master - last_master) as i64 * APU_RESONATOR_HZ as i64; last_master = master; while acc > 0 { let c = spc.step(&mut io); acc -= c as i64 * 24 * master_hz as i64 }`.
Les ports vus par le S-CPU: `port_read(i) = io.port_out[i & 3]`, `port_write(i, v)`: `io.port_in[i & 3] = v`.
