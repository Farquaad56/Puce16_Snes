## Specification
Dans `bus/wram.rs`:
```rust
pub struct Wram { mem: Vec<u8> /* 0x20000 octets a 0x55 */, pub addr: u32 }
impl Wram {
    pub fn new() -> Wram;  pub fn reset_addr(&mut self);                 // addr = 0 (la memoire est conservee)
    pub fn read(&self, idx: u32) -> u8;  pub fn write(&mut self, idx: u32, v: u8);     // idx & 0x1FFFF
    pub fn data_read(&mut self) -> u8;   pub fn data_write(&mut self, v: u8);          // $2180: acces a addr puis addr = (addr + 1) & 0x1FFFF
    pub fn set_addr_l(&mut self, v: u8); pub fn set_addr_m(&mut self, v: u8); pub fn set_addr_h(&mut self, v: u8);
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);               // toute la memoire puis addr (u32)
}
```
`set_addr_l`: `addr = (addr & !0xFF) | v` ; `set_addr_m`: `addr = (addr & !0xFF00) | (v << 8)` ; `set_addr_h`: `addr = (addr & 0xFFFF) | ((v & 1) << 16)`.

## 5. WRAM et registres $2180-$2183
- WRAM = `[u8; 131072]`. Adresses $7E0000-$7FFFFF = index 0..0x1FFFF. $00-$3F/$80-$BF:$0000-$1FFF = index addr & 0x1FFF.
- WMADD = 17 bits (WMADDL, WMADDM, WMADDH bit0). `$2181` ecrit bits 7-0, `$2182` bits 15-8, `$2183` bit 0 -> bit 16 (seul bit 0 utilise).
- `$2180` ecriture: `wram[wmadd] = v; wmadd = (wmadd + 1) & 0x1FFFF`. Lecture: `v = wram[wmadd]` puis meme increment.
- Power-on: WMADD = 0 (`UNKNOWN - to confirm`).
- DMA vers/depuis $2180 : voir 03_DMA.md.

## Tests
Tous les tests sont prefixes par `e03_10_`.

- `e03_10_power_on` : `Wram::new()`: `read(0)==0x55`, `read(0x1FFFF)==0x55`, `addr==0`.
- `e03_10_mask` : `write(0x20005, 9)` puis `read(5)==9` ; `read(0x40005)==9`.
- `e03_10_addr_regs` : `set_addr_l(0x34); set_addr_m(0x12); set_addr_h(0x01)` -> addr==0x11234 ; `set_addr_l(0x99)` -> 0x11299 ; `set_addr_h(0xFE)` -> bit 16 a 0 (addr==0x1299) ; `set_addr_h(0x03)` -> bit16 a 1.
- `e03_10_data_write_wrap` : addr=0x1FFFE (l=0xFE, m=0xFF, h=1) ; `data_write(1); data_write(2); data_write(3)` -> read(0x1FFFE)==1, read(0x1FFFF)==2, read(0)==3, addr==1.
- `e03_10_data_read` : apres `write(0x10,0xAA); write(0x11,0xBB)`, addr=0x10: `data_read()==0xAA`, `data_read()==0xBB`, addr==0x12.
- `e03_10_reset_addr` : `reset_addr()` met addr a 0 sans modifier la memoire (read(0x10) inchange).
- `e03_10_hash` : hash identique pour deux `Wram::new()` ; differe apres `write(5,1)` ; differe aussi apres un simple changement de `addr`.
