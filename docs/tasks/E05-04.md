## Specification
Ajoute a `ppu/bg.rs`:
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub struct TileEntry { pub tile: u16, pub pal: u8, pub prio: u8, pub hflip: bool, pub vflip: bool }
pub fn decode_entry(w: u16) -> TileEntry;     // bit15 V, bit14 H, bit13 P (prio 0/1), bits 12-10 palette, bits 9-0 tuile
pub fn map_entry_addr(map_base: u16, x2: bool, y2: bool, tx: u16, ty: u16) -> u16;
```
`map_entry_addr` : `tx &= if x2 { 63 } else { 31 }` ; `ty &= if y2 { 63 } else { 31 }` ; `scr = ((tx >> 5) & (x2 as u16)) + ((ty >> 5) & (y2 as u16)) * (if x2 { 2 } else { 1 })` ; `addr = (map_base + scr * 0x400 + (ty & 31) * 32 + (tx & 31)) & 0x7FFF` (calcul en `u32` puis masque).

## 5. Tilemap (fonction pure `map_entry_addr`)
Entree de 16 bits: `VHPC CCTT TTTT TTTT`: bit15 V (flip vertical), bit14 H (flip horizontal), bit13 P (priorite), bits12-10 palette, bits9-0 numero de tuile.
Position d'entree `(tx, ty)` en unites de tuile de la carte (apres division par 8 ou 16 selon la taille):
```
scr = ((tx >> 5) & map_x2) + ((ty >> 5) & map_y2) * (if map_x2 {2} else {1})
addr = (map_base + scr * 0x400 + (ty & 31) * 32 + (tx & 31)) & 0x7FFF
```
`tx` est masque par la largeur: `tx & (if map_x2 {63} else {31})`, `ty & (if map_y2 {63} else {31})` avant le calcul ci-dessus.
Tuile 8x8: `tx = px >> 3`, `ty = py >> 3`. Tuile 16x16 (BGMODE bit pour ce BG): `tx = px >> 4`, `ty = py >> 4`; sous-tuile: `xs = ((px >> 3) & 1) ^ H`, `ys = ((py >> 3) & 1) ^ V`; `tuile = T + xs + ys * 16` (`& 0x3FF`). Flip dans la tuile 8x8: `fx = (px & 7) ^ (if H {7} else {0})`, `fy = (py & 7) ^ (if V {7} else {0})`.

## Tests
Tous les tests sont prefixes par `e05_04_`.

- `e05_04_decode_entry` : `decode_entry(0xFFFF)`: tile 0x3FF, pal 7, prio 1, hflip, vflip vrais. `decode_entry(0x2000)`: prio 1, tile 0, pal 0, flips faux. `decode_entry(0x0C00)`: pal 3. `decode_entry(0x1400)`: pal 5. `decode_entry(0x03FF)`: tile 0x3FF, prio 0. `decode_entry(0x4001)`: hflip vrai, vflip faux, tile 1. `decode_entry(0x8001)`: vflip vrai, hflip faux.
- `e05_04_map32x32` : base 0x1000, x2=false, y2=false : `(3,5) -> 0x10A3` ; `(35,5) -> 0x10A3` (tx masque) ; `(0,0) -> 0x1000` ; `(31,31) -> 0x13FF` ; `(3,37) -> 0x10A3` (ty masque).
- `e05_04_map64x32` : x2=true, y2=false : `(35,5) -> 0x14A3` ; `(64,5) -> 0x10A0` (wrap a 64) ; `(31,5) -> 0x10BF` ; `(32,5) -> 0x14A0`.
- `e05_04_map32x64` : x2=false, y2=true : `(3,37) -> 0x14A3` (ecran 1 sous l'ecran 0) ; `(3,5) -> 0x10A3` ; `(35,37) -> 0x14A3` (tx masque a 31).
- `e05_04_map64x64` : x2=true, y2=true : `(35,37) -> 0x1CA3` (ecran 3) ; `(35,5) -> 0x14A3` (ecran 1) ; `(3,37) -> 0x18A3` (ecran 2) ; `(63,63) -> 0x1FFF`.
- `e05_04_addr_wraps_15_bits` : base 0x7C00, x2=y2=true, `(63,63)` -> `0x0BFF` (masque 0x7FFF).
- `e05_04_tx_beyond_127` : tx est deja en unites de tuile mais peut depasser 63 (position en pixels / 8 jusqu'a 127) : base 0, x2=false : `(127,0) -> 31` ; x2=true : `(100,0) -> (100 & 63 = 36) -> 0x400 + 4 = 0x404`.
