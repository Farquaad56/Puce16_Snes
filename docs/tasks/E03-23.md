```rust
pub const NMI_FLAG_DOT: u16 = 2;  pub const IRQ_H_OFFSET_DOTS: u16 = 1;  pub const AUTOREAD_START_DOT: u16 = 33;
pub const AUTOREAD_CLOCKS: u64 = 4224;  pub const HDMA_INIT_DOT: u16 = 3;  pub const HDMA_RUN_DOT: u16 = 276;
#[derive(Clone, Copy, Default, Debug, PartialEq, Eq)] pub struct TimingOut { pub hdma_init: bool, pub hdma_run: bool, pub vblank_start: bool, pub frame_end: bool }
pub struct Timing { line_start: u64, refreshed_this_line: bool, nmi_edge: bool, nmi_line_prev: bool, autoread_end: Option<u64> }
impl Timing {
    pub fn new() -> Timing;        // tout a 0/false/None
    pub fn on_dot(&mut self, mmio: &mut Mmio, joy: &mut Joypads, ppu: &Ppu, t: u64) -> TimingOut;
    pub fn take_nmi_edge(&mut self) -> bool;                   // renvoie nmi_edge puis le met a false
    pub fn hclock(&self, master: u64) -> u32;                  // (master - line_start) as u32
    pub fn refresh_due(&self, master: u64) -> bool;            // !refreshed_this_line && hclock(master) >= consts::DRAM_REFRESH_HCLOCK
    pub fn mark_refreshed(&mut self);
    pub fn autoread_busy(&self, master: u64) -> bool;          // E03-25 ; ici: false
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);       // line_start u64, refreshed u8, nmi_edge u8, nmi_line_prev u8, autoread_end (0 ou 1 + u64)
}
```
`on_dot` (cette tache: points 1 a 3 seulement; `v = ppu.v()`, `dot = ppu.dot()` APRES le step):
1. `dot == 0`: `line_start = t ; refreshed_this_line = false` ; si `v == 0`: `out.frame_end = true ; mmio.rdnmi_flag = false`.
2. `v == ppu.vblank_start() && dot == NMI_FLAG_DOT`: `mmio.rdnmi_flag = true ; out.vblank_start = true`.
3. `line = mmio.rdnmi_flag && (mmio.nmitimen & 0x80 != 0)` ; si `line && !nmi_line_prev`: `nmi_edge = true` ; `nmi_line_prev = line`.
Les points 4 (IRQ), 5 (auto-read), 6 (HDMA) sont E03-24 et E03-25.

## 8. Algorithme de `Timing::on_dot` (position = (ppu.v(), ppu.dot()) APRES le step, `t` = debut de ce dot)
Dans cet ordre:
1. `dot == 0`: `line_start = t`; `refreshed_this_line = false`. Si de plus `v == 0`: `out.frame_end = true`; `mmio.rdnmi_flag = false` (fin du VBlank).
2. `v == ppu.vblank_start() && dot == NMI_FLAG_DOT`: `mmio.rdnmi_flag = true`; `out.vblank_start = true`.
3. Ligne NMI: `line = mmio.rdnmi_flag && (mmio.nmitimen & 0x80 != 0)`; si `line && !nmi_line_prev`: `nmi_edge = true`; `nmi_line_prev = line`.
4. IRQ H/V: `mode = (mmio.nmitimen >> 4) & 3`; si `mode != 0`: mode 1: `dot == htime + IRQ_H_OFFSET_DOTS`; mode 2: `v == vtime && dot == IRQ_H_OFFSET_DOTS`; mode 3: `v == vtime && dot == htime + IRQ_H_OFFSET_DOTS` ; `htime > 339` ou `vtime > derniere ligne` : jamais. Si vrai: `mmio.timeup_flag = true; mmio.irq_line = true`.
5. Auto-read: si `nmitimen & 1 != 0 && v == vblank_start && dot == AUTOREAD_START_DOT`: `autoread_end = Some(t + AUTOREAD_CLOCKS)`. Puis, si `autoread_end == Some(e)` et `t >= e`: `mmio.joy = joy.autoread_values()`; `autoread_end = None`.
6. HDMA: `mmio.hdmaen != 0`: `v == 0 && dot == HDMA_INIT_DOT` -> `out.hdma_init`; `v <= vis_last && dot == HDMA_RUN_DOT` -> `out.hdma_run`.
`mmio.read` de `$4210` efface `rdnmi_flag` ; de `$4211` efface `timeup_flag` ET `irq_line` ; `mmio.write(NMITIMEN)` avec bits V/H = 00 efface `timeup_flag` et `irq_line`.

## Tests
Tous les tests sont prefixes par `e03_23_`.

- `e03_23_hclock_line_start` : `Rig::new(Ntsc)`; `run_until(1,0)`: `timing.hclock(rig.t)==0` ; `run_until(1,10)`: `hclock(rig.t)==40` ; `run_until(1,324)`: hclock==1297.
- `e03_23_refresh_due` : `run_until(1,134)` (hclock 536): `refresh_due(t)==false` ; `run_until(1,135)` (hclock 540): true ; apres `mark_refreshed()`: false ; `run_until(2,0)` puis `run_until(2,135)`: de nouveau true.
- `e03_23_rdnmi_flag_timing` : `run_until(225,1)`: `mmio.rdnmi_flag==false` ; un `step()` de plus (position (225,2)): `rdnmi_flag==true` et le `TimingOut` de CE step a `vblank_start==true` ; le step suivant a `vblank_start==false`.
- `e03_23_one_vblank_per_frame` : sur 262*340 steps NTSC: exactement 1 `vblank_start==true` et exactement 1 `frame_end==true` (le step qui arrive en (0,0)).
- `e03_23_frame_end_clears_flag` : apres le vblank, `rdnmi_flag==true` ; en arrivant en (0,0) de la frame suivante: `rdnmi_flag==false` et `frame_end==true`.
- `e03_23_nmi_edge_enabled` : `mmio.nmitimen=0x80` avant de commencer ; `run_until(225,2)`: `take_nmi_edge()==true` ; un 2eme appel: false ; apres 100 steps de plus: `take_nmi_edge()==false`.
- `e03_23_nmi_edge_disabled` : nmitimen=0: `run_until(230,0)`: `take_nmi_edge()==false`. Puis `mmio.nmitimen=0x80` et UN `step()`: `take_nmi_edge()==true` (le flag RDNMI est encore vrai).
- `e03_23_nmi_flag_cleared_by_read` : nmitimen=0x80 ; `run_until(225,2)` ; `take_nmi_edge()` consomme ; `mmio.rdnmi_flag=false` (comme une lecture de $4210) ; 5 steps ; `take_nmi_edge()==false` ; ensuite sur la frame suivante, a (225,2): un nouveau front (`true`).
- `e03_23_overscan_pal` : NTSC `rig.ppu.write(0x33,0x04)`: le front `vblank_start` arrive en (240,2) ; PAL (sans overscan): en (225,2).
- `e03_23_hash` : deux `Timing::new()` ont le meme hash ; apres `mark_refreshed()` il differe.
