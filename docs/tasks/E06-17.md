## Specification
Dans `alu.rs`:
```rust
impl Spc700 { pub fn cmp_op(&mut self, a: u8, b: u8) -> u8; }   // r = a.wrapping_sub(b); C = (a >= b); set_nz(r); retourne r
```
Dans `exec`: `kind` 0x60 -> `alu_form(.., cmp_op, write_back = false)` (aucune ecriture, pour dp,dp / dp,#imm / (X),(Y) la comparaison est `destination - source`). Ajoute les comparaisons X et Y (`cmp_op(x, v)`, `cmp_op(y, v)`): `C8` CMP X,#imm ; `3E` X,dp ; `1E` X,!abs ; `AD` CMP Y,#imm ; `7E` Y,dp ; `5E` Y,!abs. Formes (rappel de 07c section 4): `form = op & 0x1F`: `0x04` A,dp ; `0x05` A,!abs ; `0x06` A,(X) ; `0x07` A,[dp+X] ; `0x08` A,#imm ; `0x09` dp,dp ; `0x14` A,dp+X ; `0x15` A,!abs+X ; `0x16` A,!abs+Y ; `0x17` A,[dp]+Y ; `0x18` dp,#imm ; `0x19` (X),(Y). Formes A: `v = lecture (ou fetch8 pour #imm)` puis `a = op(a, v)`. `dp,dp`: `src = fetch8`, `dst = fetch8`, lit src puis dst, `dst = op(dst, src)`. `dp,#imm`: `imm = fetch8`, `dst = fetch8`, lit dst, `dst = op(dst, imm)`. `(X),(Y)`: lit `P|Y` puis `P|X`, `(X) = op((X), (Y))`.

### 6.2 Logique et arithmetique 8 bits
- `OR/AND/EOR`: resultat -> destination (A, ou memoire pour `dp,dp`, `dp,#imm`, `(X),(Y)`), `N,Z`.
- `ADC a,b`: `r = a + b + C`; `C = r > 0xFF`; `H = ((a & 0xF) + (b & 0xF) + C_in) > 0xF`; `V = (~(a ^ b) & (a ^ r) & 0x80) != 0`; `N,Z` sur `r & 0xFF`.
- `SBC a,b`: equivaut a `ADC a, ~b` avec les memes definitions (donc `C = 1` si pas d'emprunt, `H = ((a&0xF) + ((~b)&0xF) + C_in) > 0xF`, `V` avec `b' = ~b`).
- `CMP a,b`: `r = a - b` (sur 9 bits); `C = (a >= b)`; `N,Z` sur `r & 0xFF`; V et H inchanges. `CMP (X),(Y)`, `CMP dp,dp`, `CMP dp,#imm` comparent sans ecrire.
- `INC/DEC` (A, X, Y, dp, dp+X, !abs): `N,Z` seulement (C inchange).
- `ASL`: `C = bit7; r = v << 1`; `LSR`: `C = bit0; r = v >> 1`; `ROL`: `r = (v<<1)|C, C=bit7`; `ROR`: `r = (v>>1)|(C<<7), C=bit0`. `N,Z,C` (LSR met N=0).
- `XCN A`: echange les quartets, `N,Z`.
- `DAA A`: `if C || A > 0x99 { A += 0x60; C = 1 }; if H || (A & 0xF) > 9 { A += 6 }`; `N,Z`.
- `DAS A`: `if !C || A > 0x99 { A -= 0x60; C = 0 }; if !H || (A & 0xF) > 9 { A -= 6 }`; `N,Z`.
- `MUL YA`: `r = Y * A` (16 bits); `A = r & 0xFF; Y = r >> 8`; `N,Z` selon **Y**.
- `DIV YA,X`: 
  ```
  ya = (Y << 8) | A
  V = (Y >= X); H = ((Y & 15) >= (X & 15))
  if Y < (X << 1) { A = ya / X; Y = ya % X }
  else { A = 255 - (ya - (X << 9)) / (256 - X); Y = X + (ya - (X << 9)) % (256 - X) }
  N,Z selon A   // calculs en u32; X = 0 ne doit pas paniquer
  ```
