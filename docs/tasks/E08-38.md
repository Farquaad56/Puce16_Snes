## Specification
Dans `debugger.rs`:
```rust
pub fn parse_pc(text: &str) -> Option<u32>;        // hexadecimal, espaces autour ignores, prefixe optionnel `0x` ou `$` ; 4 chiffres (ou moins) -> banque 0 ; 6 chiffres -> BBPPPP ; plus de 6 chiffres ou caractere non hexadecimal ou vide -> None ; la valeur renvoyee est (banque << 16) | pc
pub fn sprite_line(s: &SpriteInfo, obj_size: u8) -> String;   // "NNN x=XXXX y=YYY t=TTT p=P pr=R hv=HV WxH" : voir exemples dans les tests
```
Format exact de `sprite_line`: `format!("{:03} x={:4} y={:3} t={:03X} p={} pr={} {}{} {}x{}", index, x, y, tile, palette, priority, if hflip {'H'} else {'-'}, if vflip {'V'} else {'-'}, w, h)` avec `(w, h) = sprite_dims(obj_size, large)`.
Onglets UI:
- **OAM**: tableau scrollable de 128 lignes `sprite_line` (monospace) issues de `decode_oam(&last.oam)` ; `obj_size` vient de `ppu_regs.obj_size`; les sprites hors ecran (y >= 224 et y < 240, ou x <= -w) sont affiches en gris.
- **Memoire**: bascule WRAM (par page de 256 octets: boutons -256 / +256, champ page hexadecimal ; envoie `SetWramPage(page)` a chaque changement) ; affiche `hex_rows(&last.wram_page, (page as u32) * 256)` (monospace, adresses de WRAM 0x000000..0x01FFFF).

## 8. Debugger (fenetre egui separee, ouverte par F10)

Envoie `RequestDebug(true)` ; le thread d'emulation joint a chaque frame un `DebugData` = `{ snapshot: DebugSnapshot, vram: Vec<u16> (32768), cgram: Vec<u16> (256), oam: Vec<u8> (544), wram_page: Vec<u8> (256 octets de la page choisie), ppu_regs: Option<PpuRegsSnapshot>, smp: Option<SmpSnapshot>, dma: Option<[DmaChanSnapshot; 8]> }` (les `Vec` sont vides et les `Option` sont `None` pour le motif de test).
Panneaux (v1):
1. **Registres**: CPU (A, X, Y, S, D, DB, PB, PC, P avec drapeaux N V M X D I Z C et e), SMP (A, X, Y, SP, PC, PSW), position (frame, V, H, master), registres PPU principaux (INIDISP, BGMODE, TM, TS, CGWSEL, CGADSUB, SETINI), registres DMA actifs.
2. **VRAM - tuiles**: grille de tuiles 8x8, choix profondeur 2/4/8 bpp, palette (0..15 ou 0..7), adresse de base en mots (curseur par pas de 0x400), zoom 1-4.
3. **VRAM - cartes**: rendu de la carte d'un BG (1..4) avec ses reglages courants (taille de carte, tuile 8/16) ; mode 7 : carte 128x128 en 1024x1024.
4. **Palettes**: 256 pastilles CGRAM, survol = indice + valeur.
5. **OAM**: tableau des 128 sprites (x, y, tuile, palette, priorite, taille, flips).
6. **Memoire**: vue hexadecimale de WRAM (page de 256 octets, navigation par 256).
Commandes d'execution: Pause, Reprendre, Avancer une frame, Avancer une instruction CPU (via commande `StepInstruction`), Executer jusqu'a un PC (un seul point d'arret `PC`, saisi en hexadecimal). Pas de desassembleur en v1 (hors perimetre).

## Tests
Tous les tests sont prefixes par `e08_38_`.

- `e08_38_parse_pc_forms` : `parse_pc("8008")==Some(0x008008)` ; `"008008"` -> `Some(0x008008)` ; `"7E1234"` -> `Some(0x7E1234)` ; `"0x8000"` -> `Some(0x8000)` ; `"$00FF00"` -> `Some(0x00FF00)` ; `"  12  "` -> `Some(0x12)`.
- `e08_38_parse_pc_invalid` : `""`, `"  "`, `"xyz"`, `"12345678"`, `"80 08"`, `"-1"` -> `None`.
- `e08_38_sprite_line_format` : sprite `{index 3, x -16, y 32, tile 0x105, palette 2, priority 1, hflip true, vflip false, large true}`, obj_size 0 : `"003 x= -16 y= 32 t=105 p=2 pr=1 H- 16x16"`.
- `e08_38_sprite_line_small` : sprite `{index 127, x 255, y 0, tile 0, palette 7, priority 3, hflip false, vflip true, large false}`, obj_size 6 : `"127 x= 255 y=  0 t=000 p=7 pr=3 -V 16x32"`.
