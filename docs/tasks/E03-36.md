## Specification
1. `tests/common/prog.rs` (declare par `#[path = "common/prog.rs"] mod prog;` apres `mod common;` ; utilise `crate::common::{make_rom_with, set_vector, Map}`):
```rust
/// blocks: (offset relatif a $00:8000, octets). vectors: (nom, adresse) pour set_vector. LoRom 32 Kio.
pub fn build_rom(blocks: &[(usize, &[u8])], vectors: &[(&str, u16)]) -> Vec<u8>;
pub fn build_rom_with(blocks: &[(usize, &[u8])], vectors: &[(&str, u16)], sram_log2: u8, chipset: u8) -> Vec<u8>;   // pays = 1
```
Le tampon de code est de longueur max(offset+len) (zeros ailleurs), passe a `make_rom_with(&code, Map::LoRom, 15, sram_log2, chipset, 1)`; puis pour chaque vecteur `set_vector(&mut rom, Map::LoRom, nom, addr)`. `build_rom` = `build_rom_with(.., 0, 0x00)`.
2. Programme BOOT (a mettre dans le test), `PROG_BOOT`:
`78 18 FB  A9 42  8D 10 00  A9 99  8F 20 00 7E  80 FE` = SEI ; CLC ; XCE ; LDA #$42 ; STA $0010 ; LDA #$99 ; STA $7E0020 ; BRA -2 (la boucle `BRA` est a l'offset 0x0E, soit pc 0x800E). Chaque fichier de test commence par `mod common; #[path = "common/prog.rs"] mod prog;` (et `#[path = "common/fake_dma_bus.rs"]` n'est pas utile ici), puis `use puce16_core::snes::Snes; use prog::build_rom;`. Helper de test: `fn snes(rom: Vec<u8>) -> Snes { Snes::new(&rom, None).ok().unwrap() }`. Les programmes sont du code machine 65816 assemble A LA MAIN (octets donnes); l'adresse CPU de l'octet i du programme est 0x8000 + i. `settle(&mut s)` = `for _ in 0..12 { s.step_instruction(); }` (laisse le temps au CPU de prendre une interruption apres `run_frame`).

## 7. Tests internes sans ROM externe (a faire des que le composant existe)

| Test | Verifie |
|---|---|
| Handshake IPL | apres reset, ~100 000 clocks maitres (l'IPL efface d'abord $00-$EF, ~50 000 clocks): lecture CPU de $2140 = $AA et $2141 = $BB (le SPC700 execute la ROM IPL, spec 07) |
| Transfert IPL | un programme CPU synthetique (mis dans une ROM LoROM fabriquee en code) envoie un petit programme SPC700 par le protocole IPL et le lance; la reponse sur les ports prouve l'execution |
| DMA WRAM | ROM synthetique: DMA general 256 octets ROM -> $2180; relecture par le CPU |
| NMI/IRQ | ROM synthetique: NMI incremente un compteur en WRAM une fois par frame; apres 60 frames compteur = 60 (ou 59/60 selon alignement, tolerance +-1 documentee) |
| Auto-joypad | `set_joypad` -> lecture de $4218/$4219 apres 2 frames = valeur injectee |
| Determinisme | meme ROM + memes entrees, deux executions -> `state_hash` egal a chaque frame |
| Save state | `save_state` puis `load_state` puis N frames == N frames sans passer par le save state (hash identique) |

Une ROM synthetique est fabriquee par une fonction de test `make_rom(code: &[u8], mode: MapMode) -> Vec<u8>` (en-tete valide, vecteur RESET = $8000, checksum correct) : fournie par la tache `E01-xx` dans `crates/puce16-core/tests/common/mod.rs`.

## Tests
Tous les tests sont prefixes par `e03_36_`.

- `e03_36_build_rom_layout` : `build_rom(&[(0,&[1,2]),(0x10,&[3])],&[])`: len==32768, rom[0..2]==[1,2], rom[0x10]==3, rom[2]==0, rom[0x0F]==0. Avec `&[("nmi",0x8123)]`: rom[0x7FEA..0x7FEC]==[0x23,0x81] ; avec `&[("reset",0x8010)]`: rom[0x7FFC..0x7FFE]==[0x10,0x80].
- `e03_36_build_rom_checksum` : `rom = build_rom(&[(0,&[1,2,3])], &[("nmi",0x8100)])` : copie `rom`, ecrase les octets 0x7FDC..0x7FE0 par [0xFF,0xFF,0x00,0x00], somme u16 (wrapping) de tous les octets == mot LE lu a 0x7FDE de l'original ; et mot LE a 0x7FDC == !checksum.
- `e03_36_boot_writes_wram` : `snes(build_rom(&[(0, PROG_BOOT)], &[]))` ; `run_frame()` : `peek_wram(0x10)==0x42`, `peek_wram(0x20)==0x99`, `debug().pc==0x800E`, `debug().pb==0`, `debug().e==false`.
- `e03_36_reset_vector_respected` : `build_rom(&[(0x10, PROG_BOOT)], &[("reset",0x8010)])` : juste apres `Snes::new`, `debug().pc==0x8010` ; apres `run_frame()`: `peek_wram(0x10)==0x42` et `debug().pc==0x801E`.
- `e03_36_wram_initial_untouched` : avant tout `step_instruction`, `peek_wram(0x10)==0x55` et `peek_wram(0x20)==0x55` ; apres `run_frame()` ils valent 0x42 / 0x99 ; `peek_wram(0x11)` reste 0x55.
- `e03_36_starts_in_emulation_mode` : juste apres `new`, `debug().e==true` ; apres 3 `step_instruction()` : `debug().e==false`.
