## Specification
Dans `input.rs` (module deja declare dans lib.rs; egui = `eframe::egui`):
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Key { Up, Down, Left, Right, Z, S, Q, D, X, K, C, L, W, J, V, I, A, U, E, O, Enter, Backspace, ShiftRight, Other }
pub fn default_buttons(pressed: &[Key]) -> u16;   // OU des BTN_* selon le tableau du texte (sans filtrage)
pub fn from_egui_key(k: egui::Key) -> Key;          // correspondance egui::Key -> Key (Other si absente)
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Hotkey { Pause, FrameAdvance, Reset, SaveState, LoadState, SlotPrev, SlotNext, Screenshot, Fullscreen, Debugger, Mute, FastForward, OpenRom, Quit }
pub fn hotkey_for(k: egui::Key, ctrl: bool) -> Option<Hotkey>;   // P, N, F12, F5, F7, PageUp->SlotPrev, PageDown->SlotNext, F2, F11, F10, M, Tab, Ctrl+O, Escape
```
Dans `app.rs`: a chaque frame UI, lire les touches maintenues (`ctx.input`), calculer `filter_opposites(default_buttons(...))` et envoyer `Command::SetJoypad(0, bits)` seulement quand la valeur change. Raccourcis Pause / FrameAdvance / Reset / Quit branches sur les commandes existantes; les autres sont ignores pour l'instant (log dans la barre d'etat: `hotkey not implemented`).

## 2. Clavier (AZERTY) - touches LOGIQUES

Defaut modifiable dans `config.json` (touche -> bouton, plusieurs touches par bouton). Les noms sont ceux d'`egui::Key`.
| Bouton SNES | Touches par defaut |
|---|---|
| Haut / Bas / Gauche / Droite | fleches ; Z / S / Q / D |
| B | X ; K |
| A | C ; L |
| Y | W ; J |
| X | V ; I |
| L | A ; U |
| R | E ; O |
| Start | Entree |
| Select | Retour arriere ; Maj droite |

Raccourcis emulateur (aucune touche chiffre: sur AZERTY elles exigent Maj):
| Action | Touche |
|---|---|
| Pause / reprise | P |
| Avancer d'une frame (en pause) | N |
| Reset (bouton) | F12 |
| Sauvegarder l'etat (slot courant) | F5 |
| Charger l'etat (slot courant) | F7 |
| Slot precedent / suivant (0..9) | Page precedente / Page suivante |
| Capture d'ecran (PNG non requis: PPM) | F2 |
| Plein ecran | F11 |
| Debugger (fenetre) | F10 |
| Muet | M |
| Avance rapide (maintenu) | Tab |
| Ouvrir une ROM | Ctrl+O |
| Quitter | Echap (avec confirmation si un fichier SRAM est en attente: ecriture automatique d'abord) |

## Tests
Tous les tests sont prefixes par `e01_13_`.

- `e01_13_buttons_dpad` : `default_buttons(&[Key::Up, Key::Right])==BTN_UP|BTN_RIGHT` ; `default_buttons(&[Key::Z, Key::D])==BTN_UP|BTN_RIGHT` (Z=haut, D=droite).
- `e01_13_buttons_face` : `default_buttons(&[Key::X])==BTN_B` ; `[Key::C]==BTN_A` ; `[Key::W]==BTN_Y` ; `[Key::V]==BTN_X` ; `[Key::A]==BTN_L` ; `[Key::E]==BTN_R` ; `[Key::K]==BTN_B` ; `[Key::L]==BTN_A`.
- `e01_13_buttons_start_select` : `[Key::Enter]==BTN_START` ; `[Key::Backspace]==BTN_SELECT` ; `[Key::ShiftRight]==BTN_SELECT`.
- `e01_13_buttons_combo` : `default_buttons(&[Key::X, Key::C, Key::Enter])==BTN_B|BTN_A|BTN_START` ; `default_buttons(&[Key::Other])==0` ; `default_buttons(&[])==0`.
- `e01_13_hotkeys` : `hotkey_for(egui::Key::P,false)==Some(Hotkey::Pause)` ; `F12 -> Reset` ; `O` avec ctrl=true -> `OpenRom` ; `O` sans ctrl -> `None` ; `PageUp -> SlotPrev`.
