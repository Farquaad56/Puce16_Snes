## Contexte
Mosaique des fonds (spec 05b section 9): fonction pure + branchement dans `bg_pixel`. Pas de mosaique sur les sprites. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'. Aides de test (a recopier dans le fichier de test): `fn put_vram(p: &mut Ppu, addr: u16, w: u16) { p.write(0x15,0x80); p.write(0x16,(addr & 0xFF) as u8); p.write(0x17,(addr >> 8) as u8); p.write(0x18,(w & 0xFF) as u8); p.write(0x19,(w >> 8) as u8); }` ; `fn put_cgram(p: &mut Ppu, i: u8, w: u16) { p.write(0x21,i); p.write(0x22,(w & 0xFF) as u8); p.write(0x22,(w >> 8) as u8); }` ; `fn set_scroll(p: &mut Ppu, reg: u8, v: u16) { p.write(reg,(v & 0xFF) as u8); p.write(reg,(v >> 8) as u8); }` (reg = 0x0D HOFS BG1, 0x0E VOFS BG1, 0x0F/0x10 BG2, 0x11/0x12 BG3, 0x13/0x14 BG4). ## Specification
Ajoute a `ppu/bg.rs`:
```rust
pub fn mosaic_xy(size: u8, enabled: bool, x: usize, v: usize) -> (usize, usize);
```
`size` = `regs.mosaic_size()` (1..=16). Si `enabled && size > 1` : `xm = x - (x % size)` ; `vm = v - (v.saturating_sub(1) % size)` ; sinon `(x, v)`. (Les lignes visibles commencent a `v = 1`: avec size 4 les lignes 1-4 donnent vm = 1, les lignes 5-8 vm = 5.)
Dans `Ppu::bg_pixel`, avant le calcul de `px`/`py`: `(xm, vm) = mosaic_xy(regs.mosaic_size(), regs.mosaic_en >> n & 1 != 0, x, v)` et utiliser `xm`, `vm` a la place de `x`, `v`.

## 9. Mosaique
`size = mosaic_size + 1`. Pour un BG `n` avec bit d'activation et `size > 1` (aussi BG1 mode 7): `xm = x - (x % size)`, `vm = v - ((v - 1) % size)`. Sinon `(x, v)`. Pas de mosaique sur les sprites. (hi-res: ignoree en v1, `UNKNOWN`.)
<!-- end -->

## Tests
Tous les tests sont prefixes par `e05_07_`.

- `e05_07_mosaic_xy_disabled` : `mosaic_xy(4,false,6,6)==(6,6)` ; `mosaic_xy(1,true,6,6)==(6,6)`.
- `e05_07_mosaic_xy_size4` : `mosaic_xy(4,true,6,6)==(4,5)` ; x : 0..=3 -> 0, 4..=7 -> 4 ; v : 1..=4 -> 1, 5..=8 -> 5, 9 -> 9 : `mosaic_xy(4,true,0,1)==(0,1)`, `(3,4)->(0,1)`, `(7,5)->(4,5)`, `(7,8)->(4,5)`, `(8,9)->(8,9)`.
- `e05_07_mosaic_xy_size16` : `mosaic_xy(16,true,255,224)` : xm = 255 - 15 = 240 ; vm = 224 - (223 % 16 = 15) = 209 -> `(240,209)`. `mosaic_xy(2,true,1,1)==(0,1)`, `mosaic_xy(2,true,1,2)==(0,1)`, `mosaic_xy(2,true,1,3)==(0,3)`.
- `e05_07_mosaic_xy_v0` : `mosaic_xy(4,true,0,0)==(0,0)` (v = 0 : pas de panique).
- `e05_07_bg_pixel_mosaic_x` : Scene A de E05-05 + `write(0x06,0x11)` (taille 2, BG1) : `bg_pixel(0,1,0)` = `Some(Pix{rgb:0x1234,..})` (xm = 0 -> pixel 0 de la tuile) alors que sans mosaique `bg_pixel(0,1,0)==None`.
- `e05_07_bg_pixel_mosaic_v` : Scene A + `write(0x06,0x11)` : `bg_pixel(0,0,2)` rgb 0x2345 (vm = 2 - (1 % 2) = 1 -> rangee 1 : indice 2) alors que sans mosaique `bg_pixel(0,0,2)==None` (rangee 2) ; `bg_pixel(0,1,1)` rgb 0x2345 (xm = 0, vm = 1).
- `e05_07_mosaic_per_bg` : Scene A + `write(0x06,0x12)` (taille 2, active pour BG2 seulement, bit 1) : `bg_pixel(0,1,0)==None` (BG1 non concerne).
- `e05_07_mosaic_size1_noop` : `write(0x06,0x01)` (taille 1, BG1 actif) : identique a l'absence de mosaique.
