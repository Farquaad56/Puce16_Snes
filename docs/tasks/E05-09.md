`layer_group` : BG1 = `win_sel[0] & 15`, BG2 = `win_sel[0] >> 4`, BG3 = `win_sel[1] & 15`, BG4 = `win_sel[1] >> 4`, OBJ = `win_sel[2] & 15`, couleur (layer 5) = `win_sel[2] >> 4`. `layer_logic` : BG1 `win_log_bg & 3`, BG2 `(win_log_bg >> 2) & 3`, BG3 `(>> 4) & 3`, BG4 `(>> 6) & 3`, OBJ `win_log_obj`, couleur `win_log_col`. Couche > 5 : groupe 0, logique 0.
`window_out(g, logic, x, wh)` : `w1 = (x >= wh[0] && x <= wh[1]) ^ (g & 1 != 0)` ; `w2 = (x >= wh[2] && x <= wh[3]) ^ (g & 4 != 0)` ; `en1 = g & 2 != 0` ; `en2 = g & 8 != 0` ; (false,false) -> false ; (true,false) -> w1 ; (false,true) -> w2 ; (true,true) -> logique 0 `w1 | w2`, 1 `w1 & w2`, 2 `w1 ^ w2`, 3 `!(w1 ^ w2)`.

## 10. Fenetres (fonctions pures)
Un groupe de 4 bits `g` par couche: bit0 = inversion fenetre 1, bit1 = activation fenetre 1, bit2 = inversion fenetre 2, bit3 = activation fenetre 2.
Sources: BG1 = `win_sel[0] & 15`, BG2 = `win_sel[0] >> 4`, BG3 = `win_sel[1] & 15`, BG4 = `win_sel[1] >> 4`, OBJ = `win_sel[2] & 15`, couleur = `win_sel[2] >> 4`. Logiques: BG1 `win_log_bg & 3`, BG2 `(>>2) & 3`, BG3 `(>>4) & 3`, BG4 `(>>6) & 3`, OBJ `win_log_obj`, couleur `win_log_col`.
```
fn window_out(g: u8, logic: u8, x: u8, wh: [u8; 4]) -> bool:
    w1 = (x >= wh[0] && x <= wh[1]) ^ (g & 1 != 0)
    w2 = (x >= wh[2] && x <= wh[3]) ^ (g & 4 != 0)
    en1 = g & 2 != 0 ; en2 = g & 8 != 0
    match (en1, en2):
        (false, false) -> false                 // fenetres inactives: inversion sans effet
        (true, false)  -> w1
        (false, true)  -> w2
        (true, true)   -> match logic { 0 => w1 | w2, 1 => w1 & w2, 2 => w1 ^ w2, _ => !(w1 ^ w2) }
```
`true` = la couche est CACHEE a ce pixel (si le bit TMW/TSW de la couche est actif pour l'ecran concerne). Si gauche > droite, la fenetre non inversee est vide.

## Tests
Tous les tests sont prefixes par `e05_09_`.

- `e05_09_window1_only` : wh = [10,20,15,25], g = 2 : `window_out(2,0,x,wh)` vrai pour x = 10, 15, 20 ; faux pour x = 9, 21, 0, 255.
- `e05_09_window1_inverted` : g = 3 (fenetre 1 active + inversee) : faux pour x = 10, 15, 20 ; vrai pour x = 9, 21, 0, 255.
- `e05_09_window2_only` : g = 8 : vrai pour x = 15, 25 ; faux pour x = 14, 26. g = 12 (fenetre 2 active + inversee) : faux pour 15..=25, vrai pour 14.
- `e05_09_left_greater_than_right` : wh = [20,10,0,0], g = 2 : faux pour tout x (fenetre vide) ; g = 3 : vrai pour tout x (0, 10, 15, 20, 255).
- `e05_09_inactive_inversion_no_effect` : g = 1 (inversion seule, aucune fenetre active) -> faux pour tout x ; g = 5 -> faux ; g = 0 -> faux.
- `e05_09_logic_combinations` : wh = [10,20,15,25], g = 0xA (les deux actives, sans inversion). x = 12 (w1 vrai, w2 faux) : OR vrai, AND faux, XOR vrai, XNOR faux. x = 17 (vrai, vrai) : OR vrai, AND vrai, XOR faux, XNOR vrai. x = 22 (faux, vrai) : OR vrai, AND faux, XOR vrai, XNOR faux. x = 30 (faux, faux) : OR faux, AND faux, XOR faux, XNOR vrai. (logique 0 = OR, 1 = AND, 2 = XOR, 3 = XNOR).
- `e05_09_logic_with_inversion` : wh = [10,20,15,25], g = 0xB (fenetre 1 inversee + les deux actives), logique 0 (OR) : x = 12 -> w1 = faux (inverse), w2 = faux -> faux ; x = 30 -> w1 vrai (inverse) -> vrai.
- `e05_09_layer_group_extraction` : `Regs` avec `win_sel = [0xA5,0x3C,0x71]` (ecrire par `regs.write(0x23,0xA5)`, `0x24`, `0x25`) : `layer_group(&r,0)==5`, `(1)==0xA`, `(2)==0xC`, `(3)==3`, `(4)==1`, `(5)==7` ; `layer_group(&r,6)==0`.
- `e05_09_layer_logic_extraction` : `regs.write(0x2A,0xE4)` : `layer_logic(&r,0)==0`, `(1)==1`, `(2)==2`, `(3)==3` ; `regs.write(0x2B,0xFE)` : `layer_logic(&r,4)==2`, `layer_logic(&r,5)==3`.
- `e05_09_ppu_window_hides` : `Ppu::new`: `write(0x23,0x02)` (BG1 fenetre 1 active), `write(0x26,10)`, `write(0x27,20)` : `window_hides(0,15)==true`, `window_hides(0,9)==false`, `window_hides(1,15)==false` (BG2 : groupe 0) ; `write(0x2C,0)` ne change rien (TMW n'est pas consulte ici).
