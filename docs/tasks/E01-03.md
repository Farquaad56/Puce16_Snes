## Specification

- `pub const PPU_WRITE_PHASE: u32 = 0; // UNKNOWN - to confirm` (voir 05_PPU.md section 0)

Dans `region.rs` (garde l'enum existant) ajoute des methodes: `impl Region { pub const fn master_hz(self) -> u64` (NTSC -> `MASTER_HZ_NTSC`, PAL -> `MASTER_HZ_PAL`) ; `pub const fn last_line(self) -> u32` (NTSC 261, PAL 311) ; `pub const fn is_pal(self) -> bool` }.
Les constantes `LINES_NTSC`/`LINES_PAL` valent 262 / 312 (corrige le commentaire "263 en entrelace": le nombre de lignes en entrelace est gere par le PPU, 05_PPU.md section 5.2).

## Tests
Tous les tests sont prefixes par `e01_03_`.

- `e01_03_master_hz` : `Region::Ntsc.master_hz() == 21_477_272`, `Region::Pal.master_hz() == 21_281_370`.
- `e01_03_last_line` : `Region::Ntsc.last_line() == 261`, `Region::Pal.last_line() == 311`, `is_pal` faux/vrai.
- `e01_03_line_sums` : `CLOCKS_SHORT_LINE == 1360`, `CLOCKS_PER_LINE == 1364`, `CLOCKS_LONG_LINE == 1368`, `LINES_NTSC * CLOCKS_PER_LINE == 357_368` (u64), `LINES_PAL * CLOCKS_PER_LINE == 425_568`.
- `e01_03_visible` : `VISIBLE_CLOCK_FIRST == 88`, `VISIBLE_DOT_FIRST * 4 == VISIBLE_CLOCK_FIRST`, `VISIBLE_CLOCK_END - VISIBLE_CLOCK_FIRST == 1024`.
