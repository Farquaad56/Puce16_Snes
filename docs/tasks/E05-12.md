## Specification
Ajoute a `ppu/mode7.rs` (garde `M7Regs` de E04-05; ses champs `a b c d cx cy hofs vofs flip_x flip_y fill outside` sont `pub`):
```rust
pub fn clip13(n: i32) -> i32;                        // si n & 0x2000 != 0 { n | !0x3FF } sinon { n & 0x3FF }
pub fn m7_sample(r: &M7Regs, x: i32, v: i32) -> (i32, i32);     // (px, py) dans la carte 1024x1024
```
`m7_sample` : `sx = if r.flip_x { 255 - x } else { x }` ; `sy = if r.flip_y { 255 - v } else { v }` ; `a,b,c,d = r.a as i32, ...` ; `dh = clip13(r.hofs as i32 - r.cx as i32)` ; `dv = clip13(r.vofs as i32 - r.cy as i32)` ;
`ox = ((a * dh) & !63) + ((b * dv) & !63) + ((b * sy) & !63) + ((r.cx as i32) << 8)` ;
`oy = ((c * dh) & !63) + ((d * dv) & !63) + ((d * sy) & !63) + ((r.cy as i32) << 8)` ;
`px = (ox + a * sx) >> 8` ; `py = (oy + c * sx) >> 8` (decalage arithmetique) ; retourne `(px, py)`.

## 8. Mode 7 (fonction pure + pixel)
Registres: `m7a, m7b, m7c, m7d: i16`; `m7_cx, m7_cy, m7_hofs, m7_vofs: i32` (13 bits signes). M7SEL: `flip_x` (bit0), `flip_y` (bit1), `outside` (bit7), `fill` (bit6).
```
fn clip(n: i32) -> i32 { if n & 0x2000 != 0 { n | !0x3FF } else { n & 0x3FF } }
fn m7_sample(x, v) -> (i32 px, i32 py):
    sx = if flip_x { 255 - x } else { x }
    sy = if flip_y { 255 - v } else { v }
    a, b, c, d as i32
    ox = ((a * clip(m7_hofs - m7_cx)) & !63) + ((b * clip(m7_vofs - m7_cy)) & !63) + ((b * sy) & !63) + (m7_cx << 8)
    oy = ((c * clip(m7_hofs - m7_cx)) & !63) + ((d * clip(m7_vofs - m7_cy)) & !63) + ((d * sy) & !63) + (m7_cy << 8)
    px = (ox + a * sx) >> 8        // decalage arithmetique
    py = (oy + c * sx) >> 8
```
Pixel mode 7 (avec mosaique appliquee a `x` et `v` avant): 
```
si (px | py) & !0x3FF != 0 (hors 0..1023):
    si !outside:      px &= 0x3FF ; py &= 0x3FF            // repetition
    sinon si !fill:   transparent
    sinon:            tuile = 0 ; fx = px & 7 ; fy = py & 7  // remplissage avec la tuile 0
sinon tuile = (vram[((py >> 3) << 7) + (px >> 3)] & 0xFF)  // carte 128x128 en octets BAS
indice = (vram[tuile * 64 + (fy * 8 + fx)] >> 8) & 0xFF     // pixels en octets HAUTS
```
(avec `fx = px & 7`, `fy = py & 7`). Indice 0 = transparent. BG1: `rgb = cgram[indice]` (ou couleur directe section 3). EXTBG (SETINI bit6): BG2 utilise le MEME echantillon: `prio = indice >> 7`, `idx7 = indice & 0x7F` (0 = transparent), `rgb = cgram[idx7]`. Priorite BG1 en mode 7: niveau unique (traite comme prio 0 dans la table; voir section 2).
`UNKNOWN - to confirm`: bits de remplacement de flip_y avec `v` (deja decale d'une ligne) et alignement horizontal en overscan; validation par ROM de test mode 7.

## Tests
Tous les tests sont prefixes par `e05_12_`.

- `e05_12_clip13_cases` : `clip13(5)==5` ; `clip13(0x3FF)==1023` ; `clip13(0x400)==0` ; `clip13(0x1FFF)==1023` ; `clip13(-1)==-1` ; `clip13(-1024)==-1024` ; `clip13(0x2005)==-1019`.
- `e05_12_identity` : a=d=0x100, b=c=0, cx=cy=hofs=vofs=0 : `m7_sample(&r,7,9)==(7,9)` ; `(0,0)->(0,0)` ; `(255,223)->(255,223)`.
- `e05_12_scroll` : identite + `hofs=10`, `vofs=5` : `m7_sample(&r,7,9)==(17,14)`.
- `e05_12_flips` : identite + `flip_x` : `m7_sample(&r,7,9)==(248,9)` ; identite + `flip_y` : `(7,246)` ; les deux : `(248,246)`.
- `e05_12_zoom_x2` : a=d=0x80 : `m7_sample(&r,7,9)==(3,4)` ((896)>>8 = 3 ; oy = (128*9=1152)&!63 = 1152 -> 1152>>8 = 4) ; `m7_sample(&r,8,9)==(4,4)`.
- `e05_12_rotation_90` : a=0, b=0x100, c=-256, d=0 (cx=cy=hofs=vofs=0) : `m7_sample(&r,7,9)==(9,-7)`.
- `e05_12_center_offset` : identite + `cx=100, cy=50, hofs=100, vofs=50` : `m7_sample(&r,7,9)==(107,59)`.
- `e05_12_mask_63_matters` : a=63, d=0x100, b=c=0, hofs=1, vofs=0, cx=cy=0 : ox = (63*1)&!63 = 0 -> `m7_sample(&r,4,0)==(0,0)` (sans le masquage on obtiendrait (63 + 252) >> 8 = 1).
- `e05_12_negative_shift_is_arithmetic` : a=0, b=0, c=-256, d=0x100, reste a 0 : `m7_sample(&r,3,0)==(0,-3)`.
- `e05_12_hofs_minus_cx_clipped` : identite, cx=0, hofs=0x1005 (bit 12 a 1, bit 13 a 0) : dh = clip13(0x1005) = 0x005 -> `m7_sample(&r,0,0)==(5,0)`. hofs=-1 (0xFFFF as i16 = -1) : dh = clip13(-1) = -1 -> `m7_sample(&r,0,0)==(-1,0)`.
