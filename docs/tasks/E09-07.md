## Specification
1. `header.rs`: `pub fn has_sdd1(chipset: u8) -> bool { chipset >> 4 == 4 && chipset & 0xF >= 3 }`; `chipset_info` ne renvoie plus de nom de coprocesseur pour ce cas (`has_sdd1`), la pile (`has_battery`) reste `low in {2,5,6}` (donc `$45` = pile, `$43` = pas de pile). Les autres chipsets (GSU, SA-1, DSP...) gardent leur refus.
2. `Cart`: nouveau champ `sdd1: Option<Box<Sdd1>>` (`Sdd1` doit etre `Clone`); `from_bytes_forced` le cree quand `has_sdd1`. Accesseurs: `pub fn has_sdd1(&self) -> bool`, `pub fn io_read(&self, reg: u16) -> Option<u8>`, `pub fn io_write(&mut self, reg: u16, v: u8)`, `pub fn dma_write(&mut self, reg: u16, v: u8)` (sans S-DD1: `None` / sans effet).
3. Mappage avec S-DD1 (a la place de `mapper::rom_offset`): banques 00-3F et 80-BF offsets $8000-$FFFF -> `sdd1.lorom_offset(addr)`; banques C0-FF -> `sdd1.mmc_offset(addr)`; les deux masquees par `rom_mask`; banques 40-7D -> `None`. SRAM: nouvelles fonctions dans `mapper.rs` (ou dans `cart/mod.rs`) selon la section 4: banques 00-3F/80-BF offsets $6000-$7FFF -> `(offset & 0x1FFF) % sram_len`; banques 70-73 offsets $0000-$FFFF -> `(((bank & 3) << 16) | offset) % sram_len`; `sram_len == 0` -> pas de SRAM.
4. `Cart::read(&self, bank, addr)` (sans effet de bord, utilise aussi par les outils de debug): sans decompression, la fenetre C0-FF renvoie la ROM normale via `mmc_offset`. NOUVELLE methode `pub fn read_bus(&mut self, bank: u8, addr: u16) -> Option<u8>` pour le bus: identique a `read`, sauf que les lectures C0-FF passent par `sdd1.mcu_read(addr24, &self.rom)`. Sans S-DD1, `read_bus` == `read`. `write` utilise le mappage SRAM du S-DD1 quand il est present.
5. Les ROM sans S-DD1 se comportent EXACTEMENT comme avant (aucun test existant ne doit changer).
6. Mettre a jour `sdd1/mod.rs` si necessaire (re-exports).

## 2. Detection et perimetre
- Active si le chipset `$FFD6` a le quartet haut = 4 et le quartet bas >= 3 (`$43` = S-DD1, `$45` = S-DD1 + SRAM sur pile). Le mappage du S-DD1 remplace alors le mappage LoROM/HiROM normal; l'octet de mode `$FFD5` n'est PAS utilise pour decider (les jeux ont `$32`, mais les ROM de test des taches utilisent `$20`).
- L'en-tete est lu a la position LoROM (`$7FC0`); `pick_header` reste inchange.
- Hors perimetre: HDMA depuis la zone decompressee, timing du decompresseur (instantane), autres puces.

## 4. Mappage de la ROM et de la SRAM
Toutes les adresses sont sur 24 bits (`addr = bank << 16 | offset`). `rom[x]` = `rom[x & rom_mask]` (la ROM est deja normalisee en puissance de 2 par `normalize`).

**Banques 00-3F et 80-BF, offsets $8000-$FFFF** (fenetre "LoROM"):
```
a = addr
if bank in 20..=3F  and (r4805 & 0x80) != 0 { a = a with bit 21 cleared }      // bit 21 = banque & 0x20
if bank in A0..=BF  and (r4807 & 0x80) != 0 { a = a with bit 21 cleared }
offset_rom = ((a >> 1) & 0x1F8000) | (a & 0x7FFF)
```
**Banques C0-FF, tous offsets** (fenetre MMC, blocs de 1 Mio):
```
block = (addr >> 20) & 3           // C0-CF -> 0, D0-DF -> 1, E0-EF -> 2, F0-FF -> 3
offset_rom = ((reg[4804 + block] & 0x0F) << 20) | (addr & 0xFFFFF)
```
**Banques 40-7D**: pas de ROM (bus ouvert). Banques 7E-7F: WRAM (inchange).

**SRAM** (cartes avec SRAM, ex. Star Ocean 8 Kio), carte `SHVC-LN3B-01`: banques 00-3F et 80-BF offsets $6000-$7FFF: `index = (offset & $1FFF) % sram_len`; banques 70-73 offsets $0000-$FFFF: `index = (((bank & 3) << 16) | offset) % sram_len`. (Le miroir 70-73 vient de la carte d'ares; `UNKNOWN - to confirm` si un jeu l'utilise.)

## Tests
Tous les tests sont prefixes par `e09_07_`.

- `e09_07_chipset_43_loads_without_battery` : make_rom_with(.., chipset 0x43): Cart::from_bytes OK, has_sdd1() = true, has_battery() = false
- `e09_07_chipset_45_has_battery_and_sram` : chipset 0x45, sram_log2 = 3 (8 Kio): OK, has_battery() = true, sram().len() = 8192
- `e09_07_other_coprocessors_still_refused` : chipset 0x13 -> Err(UnsupportedCoprocessor("GSU")), 0x34 -> Err(UnsupportedCoprocessor("SA-1")), 0x00 -> OK sans S-DD1 (has_sdd1() = false)
- `e09_07_lorom_window_reads_rom` : ROM 32 Kio avec rom[4] = 0xAB: read(0x00, 0x8004) = Some(0xAB), read(0x80, 0x8004) = Some(0xAB); read(0x40, 0x8004) = None; read(0x00, 0x2000) = None
- `e09_07_mmc_window_reads_rom` : meme ROM: read(0xC0, 0x0004) = Some(0xAB); apres io_write($4804, 0x01) la fenetre C0 pointe sur le bloc 1 (ROM 32 Kio: l'offset 0x100004 est masque en 0x0004, donc toujours 0xAB)
- `e09_07_sram_windows_mirror` : chipset 0x45 + 8 Kio: write(0x00, 0x6000, 0x5A) -> read(0x70, 0x0000) = Some(0x5A), read(0x80, 0x7FFF) apres write(0x00, 0x7FFF, 0x33) = Some(0x33); read(0x00, 0x8000) n'est pas la SRAM
- `e09_07_read_bus_without_sdd1_equals_read` : chipset 0x00: pour 20 couples (bank, addr) variees read_bus == read
