## Specification
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum CycleKind { Read, Write, Idle }
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub struct Cycle { pub addr: u16, pub val: u8, pub kind: CycleKind }
pub struct FlatSmpBus { mem: Vec<u8> /* 65536 */, touched: Vec<u16>, pub log: Vec<Cycle> }
impl FlatSmpBus {
    pub fn new() -> FlatSmpBus;                         // memoire a zero, journal vide
    pub fn poke(&mut self, addr: u16, bytes: &[u8]);    // ecrit bytes[i] en addr+i (wrap 16 bits), SANS journal; memorise les adresses touchees
    pub fn peek(&self, addr: u16) -> u8;                // lecture sans journal
    pub fn clear_log(&mut self);
    pub fn reset_mem(&mut self);                        // remet a zero les adresses touchees, vide le journal
}
impl Default for FlatSmpBus { ... }
impl SmpBus for FlatSmpBus { ... }
```
- `read(addr)` journalise `Cycle { addr, val, kind: Read }`; `write(addr, v)` ecrit, memorise l'adresse, journalise `Write`; `idle()` journalise `Cycle { addr: 0, val: 0, kind: Idle }`. Memoire allouee en une fois.
- Le bus est PLAT: aucun registre mappe, pas d'IPL (comme l'oracle).

## 5. Tests unitaires (tous les fichiers de test `tests/e06_NN_*.rs`)
`testbus.rs` fournit `FlatSmpBus` (64 Kio, `poke`, `peek`, journal `log`). Aide de test:
```rust
fn run(setup: impl FnOnce(&mut Spc700, &mut FlatSmpBus), prog: &[u8]) -> (Spc700, FlatSmpBus, u32) {
    let mut cpu = Spc700::new(); let mut bus = FlatSmpBus::new();
    cpu.pc = 0x0200; bus.poke(0x0200, prog); setup(&mut cpu, &mut bus);
    let cyc = cpu.step(&mut bus); (cpu, bus, cyc)
}
```
Un test = un programme d'UNE instruction a `0x0200`, un `step`, verification des registres, de la memoire et du nombre de cycles renvoye (colonne `cycles` du TSV, +2 si branche prise). Valeurs calculees a la main dans l'enonce.

## Tests
Tous les tests sont prefixes par `e06_06_`.

- `e06_06_read_write_log` : write(0x1234,0x5A) puis read(0x1234)==0x5A ; log == [Write{0x1234,0x5A}, Read{0x1234,0x5A}].
- `e06_06_idle_log` : idle() ajoute Cycle{addr:0,val:0,kind:Idle}.
- `e06_06_poke_peek` : poke(0x0010,&[1,2,3]) -> peek(0x0011)==2 ; le journal reste vide.
- `e06_06_poke_wrap` : poke(0xFFFF,&[7,8]) -> peek(0xFFFF)==7 et peek(0)==8.
- `e06_06_reset_mem` : poke(0x10,&[5]) ; reset_mem() -> peek(0x10)==0 et journal vide.
- `e06_06_flat_registers` : write(0x00F4,0x99) puis read(0x00F4)==0x99 (aucun registre mappe) ; read(0xFFC0) lit la RAM (0 apres new).
