# E05-08 - ppu/bg.rs: offset-per-tile (modes 2 et 4)
Epopee: E05 | Type: code | Dependances: E05-07 | Taille estimee: ~130 lignes

## Contexte
Offset-per-tile: BG3 fournit des offsets de defilement par colonne de 8 pixels pour BG1/BG2 (spec 05b 7.1). Cette tache gere les modes 2 et 4 (fonds non hi-res). Le mode 6 (hi-res) est traite en E05-17.
La fonction renvoie `(hofs_use, vofs_use)` utilises par `bg_pixel` a la place de `scroll.hofs(n)` / `scroll.vofs(n)`. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'. Aides de test (a recopier dans le fichier de test): `fn put_vram(p: &mut Ppu, addr: u16, w: u16) { p.write(0x15,0x80); p.write(0x16,(addr & 0xFF) as u8); p.write(0x17,(addr >> 8) as u8); p.write(0x18,(w & 0xFF) as u8); p.write(0x19,(w >> 8) as u8); }` ; `fn put_cgram(p: &mut Ppu, i: u8, w: u16) { p.write(0x21,i); p.write(0x22,(w & 0xFF) as u8); p.write(0x22,(w >> 8) as u8); }` ; `fn set_scroll(p: &mut Ppu, reg: u8, v: u16) { p.write(reg,(v & 0xFF) as u8); p.write(reg,(v >> 8) as u8); }` (reg = 0x0D HOFS BG1, 0x0E VOFS BG1, 0x0F/0x10 BG2, 0x11/0x12 BG3, 0x13/0x14 BG4). Un `Ppu::new(Region::Ntsc)` neuf est en forced blank: toutes ces ecritures sont autorisees. Chaque test construit SA scene sur un `Ppu` neuf.

## Specification
Ajoute a `ppu/bg.rs`:
```rust
impl Ppu { fn opt_offsets(&self, n: usize, xm: usize) -> (u16, u16); }     // prive
```
`hofs_use = scroll.hofs(n)` et `vofs_use = scroll.vofs(n)` par defaut. Si `mode` est 2 ou 4 et `n <= 1` :
```
n_col = (xm + (hofs(n) & 7)) >> 3                    // 0 = tuile partielle de gauche, jamais modifiee
si n_col >= 1:
    ex = (n_col - 1) + (hofs(2) >> 3) ; ey = vofs(2) >> 3        // coordonnees dans la carte de BG3 (tuiles 8x8)
    e(tx,ty) = vram_word(map_entry_addr(map_base[2], map_x2[2], map_y2[2], tx, ty))     // mot BRUT
    mode 2 : eh = e(ex, ey) ; ev = e(ex, ey + 1)
    mode 4 : e0 = e(ex, ey) ; si e0 & 0x8000 == 0 { eh = e0 ; ev = 0 } sinon { eh = 0 ; ev = e0 }
    bit = 0x2000 si n == 0 (BG1), 0x4000 si n == 1 (BG2)
    si eh & bit != 0 : hofs_use = (eh & 0x3F8) | (hofs(n) & 7)
    si ev & bit != 0 : vofs_use = ev & 0x3FF
```
Dans `bg_pixel`, apres la mosaique : `(hofs_use, vofs_use) = opt_offsets(n, xm)` et `px = (xm + hofs_use) & 0x3FF`, `py = (vm + vofs_use) & 0x3FF`. Hors modes 2/4, `opt_offsets` renvoie les scrolls normaux.

### 7.1 Offset-per-tile (modes 2, 4, 6; couche BG1 ou BG2)
```
n_col = (xm + (hofs[n] & 7)) >> 3          // colonne de 8 px depuis la gauche; 0 = tuile partielle de gauche, jamais modifiee
si n_col >= 1:
    ex = ((n_col - 1) + (hofs[2] >> 3))      // colonne dans la carte de BG3 (hofs/vofs de BG3)
    ey = vofs[2] >> 3
    mode 2: eh = entree_BG3(ex, ey)  ;  ev = entree_BG3(ex, ey + 1)     // ev = "comme si 8 etait ajoute a VOFS"
    mode 4: e = entree_BG3(ex, ey) ; si e.bit15 == 0 { eh = e ; ev = 0 } sinon { eh = 0 ; ev = e }
    mode 6: hi-res: voir UNKNOWN (colonnes de 16 px hi-res)
    bit_enable = 13 pour BG1 (n = 0), 14 pour BG2 (n = 1)
    si eh.bit(bit_enable): hofs_use = (eh & 0x3F8) | (hofs[n] & 7)
    si ev.bit(bit_enable): vofs_use = ev & 0x3FF
```
`entree_BG3` utilise la carte de BG3 (`map_base[2]`, tailles de BG3) via `map_entry_addr` (tuiles 8x8, tx/ty modulo la taille de la carte). En mode 4 et mode 6, eh ou ev vaut 0 quand l'autre est utilise.

## Tests
Tous les tests sont prefixes par `e05_08_`.

- `e05_08_mode2_both_offsets` : Scene E (mode 2, BG1 4 bpp) : `write(0x05,0x02)` ; `write(0x07,0x04)` ; `write(0x0B,0x01)` ; `write(0x09,0x08)` (carte BG3 a 0x800) ; tuile 2 (0x1020) rangee 0 : `put_vram(0x1020,0x0080)` ; entree BG1 (3,1) a 0x423 : `put_vram(0x423,0x0402)` ; `put_cgram(p,17,0x1234)` ; entrees BG3 : `put_vram(0x800,0x2010)` (horizontal : bit 13 + 0x10) et `put_vram(0x820,0x2005)` (vertical : rangee suivante de la carte BG3, valeur 5). Attendu : `bg_pixel(0,8,3)==Some(Pix{rgb:0x1234,prio:0,obj_pal:0})` (colonne 1 : hofs_use = 16, vofs_use = 5 -> px = 24, py = 8 -> tuile (3,1)).
- `e05_08_mode2_first_column_unmodified` : Scene E : `bg_pixel(0,0,3)==None` (n_col = 0 : pas d'offset ; entree (0,0) de BG1 vide) ; `bg_pixel(0,7,3)==None`.
- `e05_08_mode2_horizontal_only` : Scene E avec `put_vram(0x800,0x0010)` (pas de bit 13 : horizontal ignore) : `bg_pixel(0,8,3)==None` (px = 8, py = 3 + 5 = 8 -> entree (1,1) vide).
- `e05_08_mode2_wrong_enable_bit` : Scene E avec entrees BG3 `0x4010` et `0x4005` (bit 14 = BG2 seulement) : BG1 inchange -> `bg_pixel(0,8,3)==None`.
- `e05_08_mode2_fine_hofs_kept` : Scene E + `set_scroll(&mut p,0x0D,3)` : `bg_pixel(0,5,3)==Some(Pix{rgb:0x1234,..})` (n_col = (5+3)>>3 = 1 ; hofs_use = 0x10 | 3 = 19 ; px = 5 + 19 = 24).
- `e05_08_mode2_bg3_hofs_shifts_column` : Scene E mais les entrees BG3 en colonne 1 : `put_vram(0x800,0x0000)`, `put_vram(0x801,0x2010)`, `put_vram(0x821,0x2005)` ; `set_scroll(&mut p,0x11,8)` (HOFS BG3 = 8 -> ex = 0 + 1) : `bg_pixel(0,8,3)==Some(Pix{rgb:0x1234,..})`. Sans le scroll de BG3, `bg_pixel(0,8,3)==None`.
- `e05_08_mode4_horizontal` : Scene F (mode 4, BG2 2 bpp) : `write(0x05,0x04)` ; `write(0x08,0x0C)` (carte BG2 a 0xC00) ; `write(0x0B,0x20)` (chr BG2 a 0x2000) ; `write(0x09,0x08)` ; `put_vram(0x2008,0x0080)` (tuile 1 rangee 0) ; `put_cgram(p,1,0x0AAA)` ; `put_vram(0xC23,0x0001)` (entree BG2 (3,1)) ; `put_vram(0x800,0x4010)` (bit 15 = 0 -> horizontal, bit 14 = BG2, valeur 0x10) : `bg_pixel(1,8,8)==Some(Pix{rgb:0x0AAA,prio:0,obj_pal:0})` (px = 24, py = 8).
- `e05_08_mode4_vertical` : Scene F' = Scene F mais SANS l'entree (3,1) et avec `put_vram(0xC21,0x0001)` (entree (1,1)) et `put_vram(0x800,0xC005)` (bit 15 = 1 -> vertical, bit 14 = BG2, valeur 5) : `bg_pixel(1,8,3)==Some(Pix{rgb:0x0AAA,..})` (py = 3 + 5 = 8 -> ligne de tuiles 1, px = 8 inchange). Sans l'entree BG3 (`put_vram(0x800,0)`), `bg_pixel(1,8,3)==None`.
- `e05_08_non_opt_modes` : En mode 1, avec la meme VRAM BG3 que Scene E, `bg_pixel(0,8,3)` n'est pas modifie (les scrolls normaux sont utilises) : `None` si la carte BG1 n'a rien en (1,0).
