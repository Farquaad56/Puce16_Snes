## Specification
`PROG_JOY` (auto-read active, copie JOY1L, JOY1H, JOY2H en WRAM $0120-$0122 en boucle):
```
78 18 FB
A9 01 8D 00 42     NMITIMEN = 1 (auto-read, pas de NMI)
AD 18 42 8D 20 01  L: $0120 = JOY1L          (L = offset 0x08)
AD 19 42 8D 21 01  $0121 = JOY1H
AD 1B 42 8D 22 01  $0122 = JOY2H
80 EC              BRA L
```
`PROG_JOY_OFF` = `PROG_JOY` avec les 5 octets `A9 01 8D 00 42` remplaces par `EA EA EA EA EA`. Boutons: `BTN_A=0x0080`, `BTN_START=0x1000`, `BTN_B=0x8000` (constantes de `puce16_core::joypad`). Chaque fichier de test commence par `mod common; #[path = "common/prog.rs"] mod prog;` (et `#[path = "common/fake_dma_bus.rs"]` n'est pas utile ici), puis `use puce16_core::snes::Snes; use prog::build_rom;`. Helper de test: `fn snes(rom: Vec<u8>) -> Snes { Snes::new(&rom, None).ok().unwrap() }`. Les programmes sont du code machine 65816 assemble A LA MAIN (octets donnes); l'adresse CPU de l'octet i du programme est 0x8000 + i. `settle(&mut s)` = `for _ in 0..12 { s.step_instruction(); }` (laisse le temps au CPU de prendre une interruption apres `run_frame`).

### 6.4 Auto-read joypad
- Si NMITIMEN.0 = 1: au debut du VBlank (V = vblank_start), a partir de `H >= 32.5 dots` (defaut: clock 130 = ligne V, hclock 130; `UNKNOWN - to confirm` entre H=32.5 et 95.5), l'auto-read dure **4224 master clocks**; pendant ce temps HVBJOY.0 = 1.
- Au debut: equivalent a JOYOUT=1 puis 0 (latch). Puis 16 lectures de $4016 et $4017: JOY1 (bits D0 du port 1) , JOY2 (bits D0 du port 2), JOY3 (bits D1 port 1), JOY4 (bits D1 port 2); le 1er bit lu = bit 15.
- Defaut v1: les registres JOYn sont mis a jour **a la fin** des 4224 clocks (pendant l'operation, ils conservent l'ancienne valeur). `UNKNOWN - to confirm`.
- Les manettes standard (voir joypad ci-dessous) renvoient apres 16 bits: 1.

### 6.5 JOYOUT / JOYSER0 / JOYSER1 ($4016/$4017)
- `$4016` ecriture: bit0 = OUT0 (latch). Quand OUT0 passe de 1 a 0, chaque manette charge son registre a decalage (16 bits: B Y Select Start Up Down Left Right A X L R 0 0 0 0, 1 = appuye; ordre de lecture: B d'abord). Tant que OUT0 = 1, le registre est relu continuellement (chaque lecture retourne le bit B).
- `$4016` lecture: bits1-0 = (D1, D0) du port 1 (D1 = 0 pour manette standard); bits 7-2 = mdr. Chaque lecture decale d'un bit (apres 16 lectures: retourne 1).
- `$4017` lecture: bits1-0 = port 2 (D1, D0); bits 4-2 = 1; bits 7-5 = mdr.
- Etat clavier -> bits: format de `set_joypad(port, u16)`: bit15 = B, 14 = Y, 13 = Select, 12 = Start, 11 = Up, 10 = Down, 9 = Left, 8 = Right, 7 = A, 6 = X, 5 = L, 4 = R, 3-0 = 0 (identique a JOY1H:JOY1L apres auto-read).

## Tests
Tous les tests sont prefixes par `e03_41_`.

- `e03_41_zero_before_vblank` : `set_joypad(0, BTN_A|BTN_START)` apres `new` ; `run_master(100_000)` : `peek_wram(0x120)==0`, `0x121==0`, `0x122==0` (l'auto-read n'a pas encore eu lieu ; le programme a deja copie des zeros).
- `e03_41_values_after_autoread` : `set_joypad(0, BTN_A|BTN_START)`, `set_joypad(1, BTN_B)` ; `run_frame()` puis `run_master(20_000)` : `peek_wram(0x120)==0x80` (octet bas de 0x1080), `0x121==0x10`, `0x122==0x80` (JOY2H = octet haut de 0x8000).
- `e03_41_old_value_during_autoread` : meme config ; `run_frame()` (retour juste apres le debut du VBlank, avant la fin des 4224 clocks) puis `run_master(1000)` : `peek_wram(0x120)==0` (JOY1L garde l'ancienne valeur pendant la lecture).
- `e03_41_next_frame_updates` : apres le test precedent complet: `set_joypad(0, 0x0001)` ; `run_frame()` (frame suivante) ; `run_master(20_000)` : `peek_wram(0x120)==0x01` et `0x121==0x00`. Avant ce `run_frame()` (juste apres `set_joypad`) `peek_wram(0x120)` valait encore 0x80.
- `e03_41_autoread_off` : `PROG_JOY_OFF`, `set_joypad(0,0xFFF0)` : 2 frames + `run_master(20_000)` : `peek_wram(0x120)==0`.
- `e03_41_opposite_dirs_not_filtered_by_core` : `set_joypad(0, BTN_LEFT|BTN_RIGHT)` (le filtrage est cote desktop) : apres auto-read `peek_wram(0x121)==0x03` (LEFT=0x0200, RIGHT=0x0100 -> octet haut 0x03).
