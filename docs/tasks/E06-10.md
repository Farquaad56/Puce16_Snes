## 4. Recettes d'adressage (`addr.rs`, ordre des acces utiles)
Ces fonctions consomment les octets d'operande et retournent l'adresse effective; le cycle supplementaire (index) est un `idle`. `P` = `dp()`.
| Fonction | Octets lus | Adresse |
|---|---|---|
| `ea_dp(cpu,bus)` | `b = fetch8` | `P \| b` |
| `ea_dpx(cpu,bus)` / `ea_dpy` | `b = fetch8`; idle | `P \| ((b + X) & 0xFF)` / avec Y |
| `ea_abs(cpu,bus)` | `fetch16` | valeur |
| `ea_absx` / `ea_absy` | `fetch16`; idle | `(abs + idx) & 0xFFFF` |
| `ea_x(cpu,bus)` / `ea_y` | idle | `P \| X` / `P \| Y` |
| `ea_dpx_ind(cpu,bus)` | `b = fetch8`; idle; pointeur: bas en `P\|((b+X)&0xFF)`, haut en `P\|((b+X+1)&0xFF)` | pointeur |
| `ea_dp_ind_y(cpu,bus)` | `b = fetch8`; pointeur: bas en `P\|b`, haut en `P\|((b+1)&0xFF)`; idle | `(pointeur + Y) & 0xFFFF` |
Motifs communs des 6 familles ALU (OR=0x00, AND=0x20, EOR=0x40, CMP=0x60, ADC=0x80, SBC=0xA0), `kind = op & 0xE0`, `form = op & 0x1F`:
`0x04` A,dp ; `0x05` A,!abs ; `0x06` A,(X) ; `0x07` A,[dp+X] ; `0x08` A,#imm ; `0x09` dp,dp ; `0x14` A,dp+X ; `0x15` A,!abs+X ; `0x16` A,!abs+Y ; `0x17` A,[dp]+Y ; `0x18` dp,#imm ; `0x19` (X),(Y).
Formes memoire: `dp,dp` = `src = fetch8` puis `dst = fetch8` (ordre des octets: source d'abord), lit source, lit destination, ecrit destination (rien d'ecrit pour CMP); `dp,#imm` = `imm = fetch8`, `dp = fetch8`, lit dp, ecrit dp; `(X),(Y)` = lit `(Y)`, lit `(X)`, ecrit `(X)`. (Pour CMP aucune ecriture.)

## 5. Modes d'adressage (notation du TSV)
`P` = base de page directe. Toute addition d'index dans la page directe se fait **modulo 256 dans la page** (`(dp + X) & 0xFF`), les adresses absolues modulo 65536.
- `#imm`: octet suivant.
- `dp`: `P | b`. `dp+X`, `dp+Y`: `P | ((b + idx) & 0xFF)`.
- `!abs`: 16 bits LE. `!abs+X`, `!abs+Y`: `(abs + idx) & 0xFFFF`.
- `(X)`: `P | X`. `(Y)`: `P | Y`. `(X)+`: `P | X` puis `X += 1`.
- `[dp+X]`: pointeur 16 bits lu en `P | ((b+X)&0xFF)` (octet bas) et `P | ((b+X+1)&0xFF)` (octet haut); adresse = pointeur.
- `[dp]+Y`: pointeur lu en `P|b` et `P|((b+1)&0xFF)`; adresse = `(pointeur + Y) & 0xFFFF`.
- `abs.bit` (OR1, AND1, EOR1, MOV1, NOT1): operande 16 bits `v`; adresse = `v & 0x1FFF` (adresse **absolue**, pas de page directe), numero de bit = `v >> 13`. `/abs.bit` = bit inverse.
- `rel`: octet signe ajoute au PC apres lecture de l'operande.
- `up` (PCALL): adresse `$FF00 | imm`.
- Octets d'operandes: `dp,#imm` = `op imm dp`; `dp,dp` = `op src dst`; `dp,rel` / `dp.bit,rel` = `op dp rel`.

## Tests
Tous les tests sont prefixes par `e06_10_`.

- `e06_10_ea_dp` : pc=0x0200, octets [0x34] : `ea_dp`==0x0034, pc==0x0201, journal = 1 lecture ; avec psw=F_P : 0x0134.
- `e06_10_ea_dpx_wrap` : octets [0xFE], x=3 : `ea_dpx`==0x0001 (wrap page) ; journal = [Read, Idle] ; avec F_P : 0x0101.
- `e06_10_ea_dpy_wrap` : octets [0xF8], y=0x10 : `ea_dpy`==0x0008.
- `e06_10_ea_abs` : octets [0x34,0x12] : `ea_abs`==0x1234, pc==0x0202, journal = 2 lectures.
- `e06_10_ea_absx_wrap` : octets [0xFF,0xFF], x=2 : `ea_absx`==0x0001 ; journal = [Read, Read, Idle].
- `e06_10_ea_absy` : octets [0x00,0x20], y=5 : `ea_absy`==0x2005.
- `e06_10_ea_x_y` : x=7 : `ea_x`==0x0007, pc inchange, journal = [Idle] ; avec F_P : 0x0107 ; y=9 : `ea_y`==0x0009.
- `e06_10_ea_dpx_ind` : octets [0x10], x=2, poke(0x12,&[0x00,0x30]) : `ea_dpx_ind`==0x3000 ; journal = [Read, Idle, Read 0x0012, Read 0x0013].
- `e06_10_ea_dpx_ind_wrap` : octets [0xFE], x=1, poke(0x00FF,&[0x34]), poke(0x0000,&[0x12]) : `ea_dpx_ind`==0x1234 (haut lu en 0x0000 par wrap de page).
- `e06_10_ea_dp_ind_y` : octets [0x20], y=0x20, poke(0x20,&[0xF0,0x10]) : `ea_dp_ind_y`==0x1110 ; journal = [Read, Read 0x0020, Read 0x0021, Idle].
- `e06_10_ea_dp_ind_y_wrap` : octets [0xFF], y=2, poke(0x00FF,&[0xFF]), poke(0x0000,&[0x12]) : pointeur 0x12FF + 2 -> 0x1301.
