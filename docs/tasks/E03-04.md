## Specification
Ajoute a `cart/mod.rs` (sans modifier ce qui existe):
```rust
pub fn strip_copier_header(data: &[u8]) -> &[u8];     // si data.len() % 1024 == 512: &data[512..], sinon data
pub fn normalize(data: &[u8]) -> Vec<u8>;             // precondition data.len() >= 1
```
`normalize`: `big` = plus grande puissance de 2 <= len. Si `len == big`: copie telle quelle. Sinon `rest = &data[big..]`, `small` = plus petite puissance de 2 >= `rest.len()`; construire `part` = `rest` completee de zeros jusqu'a `small` octets; resultat = `data[..big]` suivi de `part` repetee `big / small` fois (taille finale `2 * big`).

## 1. Chargement d'un fichier ROM

1. Si `len % 1024 == 512`: ignorer les 512 premiers octets (en-tete de copieur). Sinon utiliser tel quel.
2. Si `len < 0x8000`: erreur `CartError::TooSmall`.
3. Normalisation en puissance de 2 (algorithme du wiki):
   - `big` = plus grande puissance de 2 <= len. Si `len == big`: rien a faire.
   - Sinon `rest = len - big`; `small` = plus petite puissance de 2 >= rest; completer la partie restante avec des 0 jusqu'a `small`, puis la repeter jusqu'a ce qu'elle fasse `big` octets. Taille finale = 2 * big.
   - `rom_mask = rom.len() - 1`. Tout acces ROM fait `offset & rom_mask`.

## Tests
Tous les tests sont prefixes par `e03_04_`.

- `e03_04_strip_512` : `data` de 0x8000+512 octets avec data[i]=(i%251) as u8: `strip_copier_header(&data)` a 0x8000 octets et son premier octet == data[512]. Pour 0x8000 octets: renvoie le meme slice (meme longueur).
- `e03_04_strip_edge` : une entree de exactement 512 octets: renvoie un slice vide ; une entree de 1000 octets: inchangee.
- `e03_04_pow2_noop` : `normalize` d'un tableau de 0x8000 octets == ce tableau ; de 0x10000 aussi.
- `e03_04_pow2_96k` : len 0x18000 (data[i]=(i%251) as u8): resultat de longueur 0x20000 ; `r[..0x18000]==data` ; `r[0x18000..0x20000]==data[0x10000..0x18000]`.
- `e03_04_pow2_80k` : len 0x14000: resultat 0x20000 ; `r[0x10000..0x14000]==data[0x10000..]` ; `r[0x14000..0x18000]`, `r[0x18000..0x1C000]`, `r[0x1C000..0x20000]` sont tous egaux a `data[0x10000..0x14000]`.
- `e03_04_pow2_non_pow_rest` : len 0x16000 (rest=0x6000, small=0x8000): resultat 0x20000 ; `r[0x10000..0x16000]==data[0x10000..]` ; `r[0x16000..0x18000]` tous a 0 ; `r[0x18000..0x1E000]==data[0x10000..0x16000]` ; `r[0x1E000..0x20000]` tous a 0.
- `e03_04_pow2_3mib` : len 3*1024*1024 (data[i]=(i%251) as u8): resultat 4 Mio ; `r[3 Mio..4 Mio]==data[2 Mio..3 Mio]`.
