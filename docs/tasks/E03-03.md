## Specification
Ajoute a `cart/header.rs` (sans toucher aux fonctions existantes):
```rust
pub fn score_header(rom: &[u8], map: MapMode) -> Option<i32>;   // rom = ROM NORMALISEE (longueur puissance de 2). None si pos + 0x40 > rom.len()
pub fn pick_from_scores(s: [Option<i32>; 3]) -> Option<MapMode>;  // s = [LoRom, HiRom, ExHiRom]; le plus grand score gagne; egalite: premier dans cet ordre
pub fn pick_header(rom: &[u8]) -> Result<MapMode, CartError>;      // NoHeader si aucun candidat
```
`score_header`: `pos = header_pos(map)`, `h = parse_header(rom,pos)?`, puis somme (voir tableau de la spec):
+4 si `checksum as u32 + complement as u32 == 0xFFFF` ; +2 si `compute_checksum(rom,pos) == h.checksum` ;
+2 si `(h.map_byte & 0xE0) == 0x20` ET `mmmm = h.map_byte & 0x0F` coherent (LoRom: 0,2,3,0xA ; HiRom: 1 ; ExHiRom: 5) ;
+1 si `h.rom_log2 < 32` ET `(1u64 << h.rom_log2) * 1024 >= rom.len() as u64 / 2` (`h.rom_log2` = octet `$FFD7` tel quel, taille declaree `1 << N` Kio) ;
RESET = u16 LE a `pos + 0x3C`: +2 si `>= 0x8000`, sinon -4 ;
1er octet du code: `off = mapper::rom_offset(map, 0x00, reset)` ; si `Some(o)` lire `b = rom[o & (rom.len()-1)]`: +1 si b dans {0x78,0x18,0x38,0x9C,0x64,0x74,0x9E,0x4C,0x5C,0xDC,0xA9,0xC2,0xE2}, -2 si b dans {0x00,0x02,0xDB,0x42,0xFF} ; si `None`: 0 ;
+1 si le titre brut (21 octets) est entierement dans 0x20..=0x7E ;
+1 si `h.rom_log2` dans 7..=14 ET `h.ram_log2` dans 0..=8.
NB: pour une `make_rom` de 32 Kio, N = 5 ; de 64 Kio, N = 6 ; de 8 Mio, N = 13.

## 3. Choix de l'en-tete (heuristique `score_header`)
Candidats: les trois positions ci-dessus dont `pos + 0x40 <= rom.len()`. Pour chacun, `score` entier:

| Critere | Points |
|---|---|
| checksum + complement == $FFFF | +4 |
| checksum calcule == checksum en-tete | +2 |
| bits 7-5 de $FFD5 == `001` et mapper (mmmm) coherent avec la position (LoROM: 0,2,3,A?; HiROM: 1; ExHiROM: 5) | +2 |
| `1<<N_rom` Kio >= taille normalisee / 2 (taille declaree plausible) | +1 |
| vecteur RESET ($FFFC) >= $8000 | +2, sinon -4 |
| 1er octet a l'adresse RESET (lu via le mapper candidat) dans {$78 SEI, $18 CLC, $38 SEC, $9C/$64/$74/$9E STZ, $4C JMP, $5C JML, $DC JMP[], $A9 LDA#, $C2 REP, $E2 SEP} | +1 |
| 1er octet dans {$00 BRK, $02 COP, $DB STP, $42 WDM, $FF} | -2 |
| titre entierement ASCII $20-$7E | +1 |
| N_rom dans 7..=14 et N_ram dans 0..=8 | +1 |

Le candidat de score maximal gagne; egalite: ordre LoROM, HiROM, ExHiROM. Si aucun candidat n'existe -> `CartError::NoHeader`. `UNKNOWN - to confirm`: ces poids sont un point de depart (inspires de bsnes/snes9x); ils sont ajustes par la suite si une ROM de la suite de test est mal detectee. Option CLI `--mapper lorom|hirom|exhirom` pour forcer.

## Tests
Tous les tests sont prefixes par `e03_03_`.

- `e03_03_lorom_score` : ROM = `common::make_rom(&[0x78], Map::LoRom)` (32 Kio, N=5): `score_header(&rom, LoRom)==Some(13)` (4+2+2+1+2+1+1) ; avec code `[0x00]` -> Some(10) ; avec `[0xEA]` -> Some(12). `score_header(&rom, HiRom)==None` et `ExHiRom -> None`.
- `e03_03_hirom_picks` : ROM = `make_rom(&[0x78], Map::HiRom)` (64 Kio, N=6): `score_header(&rom,HiRom)==Some(13)` ; `score_header(&rom,LoRom)==Some(-4)` (en-tete a 0x7FC0 vide: seul RESET=0 < 0x8000 compte -4) ; `pick_header(&rom)==Ok(HiRom)`.
- `e03_03_exhirom_picks` : ROM = `make_rom(&[0x78], Map::ExHiRom)` (8 Mio, N=13): `score_header(&rom,ExHiRom)==Some(14)` ; LoRom et HiRom -> Some(-4) ; `pick_header(&rom)==Ok(ExHiRom)`.
- `e03_03_pick_scores` : `pick_from_scores([Some(5),Some(5),None])==Some(LoRom)` ; `[Some(3),Some(5),Some(5)]==Some(HiRom)` ; `[None,None,None]==None` ; `[Some(-4),Some(-4),Some(-4)]==Some(LoRom)` ; `[None,Some(-1),Some(-2)]==Some(HiRom)`.
- `e03_03_no_header` : `pick_header(&vec![0u8; 0x4000])` == `Err(CartError::NoHeader)` (aucun candidat).
