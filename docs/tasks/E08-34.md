```rust
pub fn bgr555_to_rgba(c: u16) -> [u8; 4];   // r5 = c & 31, g5 = (c >> 5) & 31, b5 = (c >> 10) & 31 ; c8 = (c5 << 3) | (c5 >> 2) (D-010) ; alpha 255
/// decode une tuile 8x8 de `bpp` (2, 4 ou 8) bits dont le premier mot est a `word_addr`; adresses modulo 0x8000. Sortie: 64 indices de couleur, ligne par ligne, pixel de gauche = bit 7.
pub fn decode_tile(vram: &[u16], word_addr: usize, bpp: u8, out: &mut [u8; 64]);
pub fn tile_words(bpp: u8) -> usize;       // 2 -> 8, 4 -> 16, 8 -> 32 ; autre -> 8
/// grille cols x rows de tuiles consecutives a partir de `base_word`, couleurs lues dans `cgram[(palette * (1 << bpp) + idx) & 0xFF]` (8 bpp: palette ignoree). Renvoie (largeur, hauteur, RGBA). Un `vram` vide donne une image noire opaque de la bonne taille.
pub fn render_tiles(vram: &[u16], cgram: &[u16], base_word: usize, bpp: u8, palette: u8, cols: usize, rows: usize) -> (usize, usize, Vec<u8>);
pub fn palette_rgba(cgram: &[u16]) -> Vec<[u8; 4]>;     // 256 couleurs (cgram plus court: complete par noir opaque)
pub fn hex_rows(data: &[u8], base: u32) -> Vec<String>;  // 16 octets par ligne: format!("{:06X}: ", adresse) puis les octets "XX" separes par un espace, puis deux espaces, puis l'ASCII (0x20..=0x7E sinon '.'); derniere ligne eventuellement plus courte, sans remplissage
pub fn flags_string(p: u8, e: bool) -> String;           // "NVMXDIZC": lettre MAJUSCULE si le bit (7..0) est 1 sinon minuscule, puis " e=1" ou " e=0"
```
Planaire SNES (spec 05 section tuiles): 2 bpp = 8 mots, mot `r` = (plan 0 = octet bas, plan 1 = octet haut) de la ligne `r` ; 4 bpp = 16 mots (mots 0-7 plans 0/1, mots 8-15 plans 2/3) ; 8 bpp = 32 mots (plans 0/1, 2/3, 4/5, 6/7 par blocs de 8 mots). Indice = OU des bits de plan, plan 0 = poids faible.

## 8. Debugger (fenetre egui separee, ouverte par F10)

Envoie `RequestDebug(true)` ; le thread d'emulation joint a chaque frame un `DebugData` = `{ snapshot: DebugSnapshot, vram: Vec<u16> (32768), cgram: Vec<u16> (256), oam: Vec<u8> (544), wram_page: Vec<u8> (256 octets de la page choisie), ppu_regs: Option<PpuRegsSnapshot>, smp: Option<SmpSnapshot>, dma: Option<[DmaChanSnapshot; 8]> }` (les `Vec` sont vides et les `Option` sont `None` pour le motif de test).
Panneaux (v1):
1. **Registres**: CPU (A, X, Y, S, D, DB, PB, PC, P avec drapeaux N V M X D I Z C et e), SMP (A, X, Y, SP, PC, PSW), position (frame, V, H, master), registres PPU principaux (INIDISP, BGMODE, TM, TS, CGWSEL, CGADSUB, SETINI), registres DMA actifs.
2. **VRAM - tuiles**: grille de tuiles 8x8, choix profondeur 2/4/8 bpp, palette (0..15 ou 0..7), adresse de base en mots (curseur par pas de 0x400), zoom 1-4.
3. **VRAM - cartes**: rendu de la carte d'un BG (1..4) avec ses reglages courants (taille de carte, tuile 8/16) ; mode 7 : carte 128x128 en 1024x1024.
4. **Palettes**: 256 pastilles CGRAM, survol = indice + valeur.
5. **OAM**: tableau des 128 sprites (x, y, tuile, palette, priorite, taille, flips).
6. **Memoire**: vue hexadecimale de WRAM (page de 256 octets, navigation par 256).
Commandes d'execution: Pause, Reprendre, Avancer une frame, Avancer une instruction CPU (via commande `StepInstruction`), Executer jusqu'a un PC (un seul point d'arret `PC`, saisi en hexadecimal). Pas de desassembleur en v1 (hors perimetre).

## Tests
Tous les tests sont prefixes par `e08_34_`.

- `e08_34_color_conversion` : `bgr555_to_rgba(0x0000)==[0,0,0,255]` ; `0x7FFF -> [255,255,255,255]` ; `0x001F -> [255,0,0,255]` ; `0x03E0 -> [0,255,0,255]` ; `0x7C00 -> [0,0,255,255]` ; `0x0010 -> [132,0,0,255]` (16<<3 | 16>>2 = 128+4).
- `e08_34_tile_words` : `tile_words(2)==8`, `4 -> 16`, `8 -> 32`, `3 -> 8`.
- `e08_34_decode_2bpp` : vram[0]=0x00FF (plan0=0xFF, plan1=0x00) et vram[1]=0xFF00 (plan0=0x00, plan1=0xFF), le reste 0 ; `decode_tile(.., 0, 2)`: ligne 0 = huit fois 1 ; ligne 1 = huit fois 2 ; lignes 2..8 = 0.
- `e08_34_decode_2bpp_bits` : vram[0]=0x0180 (plan0=0x80, plan1=0x01) : ligne 0 = `[1,0,0,0,0,0,0,2]`.
- `e08_34_decode_4bpp_planes` : vram[8]=0x00FF a l'adresse 0 + 8 (plan 2 = 0xFF, plan 3 = 0x00), vram[0]=0x0000 : ligne 0 = huit fois 4 ; avec en plus vram[0]=0xFF00 (plan 1 = 0xFF) : ligne 0 = huit fois 6.
- `e08_34_decode_8bpp_planes` : vram[24]=0x0001 (plan 6 = 0x01) : ligne 0, pixel 7 = 64 ; vram[16+1]=0x0080 (plan 4 = 0x80, ligne 1) : ligne 1, pixel 0 = 16.
- `e08_34_decode_wraps` : tuile 2 bpp a `word_addr = 0x7FFF` : la ligne 0 vient de `vram[0x7FFF]` et la ligne 1 de `vram[0]` (modulo 0x8000), sans panique.
- `e08_34_render_tiles_layout` : `render_tiles(.., base 0, bpp 2, palette 0, cols 2, rows 1)` : taille (16, 8), longueur 16*8*4 ; tuile 1 (a `base + 8`) rendue a partir de x=8 ; couleur lue dans cgram: `cgram[1]=0x001F` -> pixel d'indice 1 = `[255,0,0,255]`.
- `e08_34_render_tiles_palette` : bpp 4, palette 2, indice 3 : couleur `cgram[2*16+3]` ; bpp 8: `cgram[idx]` quel que soit `palette`.
- `e08_34_render_tiles_empty_vram` : `render_tiles(&[], &[], 0, 4, 0, 4, 4)` : taille (32, 32), tout noir opaque `[0,0,0,255]`, pas de panique.
- `e08_34_palette_rgba` : cgram de 256 mots avec `cgram[5]=0x03E0` : `palette_rgba(..)[5]==[0,255,0,255]`, longueur 256 ; `palette_rgba(&[])` : 256 noirs.
- `e08_34_hex_rows_format` : `hex_rows(&[0x48,0x69,0x00,0xFF], 0x7E0000)==["7E0000: 48 69 00 FF  Hi.."]`.
- `e08_34_hex_rows_multi` : 20 octets 0..20 de base 0x10 : 2 lignes ; la 2eme commence par `"000020: "` et contient 4 octets.
- `e08_34_flags_string` : `flags_string(0x34,true)=="nvMXdIzc e=1"` ; `flags_string(0xFF,false)=="NVMXDIZC e=0"` ; `flags_string(0x00,false)=="nvmxdizc e=0"`.
