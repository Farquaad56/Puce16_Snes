# E04-11 - ppu/mod.rs: INIDISP/SETINI complets, rechargement OAM et drapeaux au debut de frame
Epopee: E04 | Type: code | Dependances: E04-10 | Taille estimee: ~110 lignes

## Contexte
Derniers morceaux du `Ppu` sans rendu: les bits restants de SETINI ($2133), le rechargement de l'adresse OAM au debut du VBlank (spec 05 section 2.1) et la remise a zero de `range_over` / `time_over` au debut de la frame (section 5.3).
Ces comportements vivent dans `step_dot` (sur la position COURANTE, avant d'avancer, dans l'ordre de la section 5.3). Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'. Dans les tests, utilise l'aide locale `fn at(p: &mut Ppu, v: u32, dot: u32) { for _ in 0..(v * 340 + dot) { p.step_dot(); } }` (valide pour NTSC, frame 0, sans entrelace: toutes les lignes ont 340 dots; position atteinte = (v, dot) apres ces steps).

## Specification
Dans `ppu/mod.rs`:
- Champs `obj_interlace: bool`, `pseudo_hires: bool`, `extbg: bool` (false) et accesseurs `obj_interlace()`, `pseudo_hires()`, `extbg()`. `write(0x33, v)`: `interlace = bit0`, `obj_interlace = bit1`, `overscan = bit2`, `pseudo_hires = bit3`, `extbg = bit6` ; le bit 7 est ignore.
- Accesseur `pub fn oam_internal_addr(&self) -> u16` (= `oam.internal()`).
- `step_dot`, a `dot == 0`: si `v == 0`: `time_over = false ; range_over = false` (en plus de l'evenement VBLANK_END) ; si `v == vblank_start()` et `!forced_blank`: `oam.reload()` (en plus de l'evenement VBLANK_START). Rien d'autre ne change.
`hash_into`: AJOUTE a la fin: `obj_interlace`, `pseudo_hires`, `extbg` (u8 chacun).

### 5.3 Evenements par (v, dot), dans CET ordre dans `step_dot`
1. `dot == 0`:
   - `v == 0`: debut de frame: `time_over = range_over = false`; evenement VBLANK_END.
   - `1 <= v <= vis_last`: **evaluation des sprites** pour la ligne (05b section 6) -> remplit `line_obj[256]`.
   - `v == vblank_start`: evenement VBLANK_START; rechargement OAM (2.1) si `!forced_blank`.
   - evenement LINE_START (toujours).
2. `dot == 274`: evenement HBLANK_START. `dot == 1`: HBLANK_END. (bornes `UNKNOWN - to confirm`, spec 02 3.1: 1096 clocks / 4.)
3. Si `1 <= v <= vis_last` et `22 <= dot <= 277`: `x = dot - 22`; **composer le pixel x** (05b section 11) et l'ecrire dans le framebuffer (section 6).
4. Avancer `dot += 1`; si `dot == line_dots(v)`: `dot = 0; v += 1; si v > last_line {v = 0; field ^= 1; FRAME_START}`.

`step_dot` retourne un petit ensemble de drapeaux (`DotEvents`: LINE_START, HBLANK_START, HBLANK_END, VBLANK_START, VBLANK_END) et `scheduler` gere NMI/IRQ/HDMA/auto-joypad a partir de la position (spec 02/03). Le PPU ne connait ni DMA ni NMI.

### 2.1 OAMDATA ($2104) et lecture OAMDATAREAD ($2138)
```
a = internal_oamadd                                  // 10 bits
if a & 0x200 != 0:                                   // table haute (32 octets, miroir tous les 32)
    oam[0x200 + (a & 0x1F)] = v                      // ecriture immediate (si acces autorise, voir 3)
else:
    if a & 1 == 0: oam_latch = v                     // octet pair: memorise
    else: oam[a-1] = oam_latch; oam[a] = v           // octet impair: ecrit le mot
internal_oamadd = (a + 1) & 0x3FF
```
Lecture $2138: `a = internal_oamadd`; octet = `oam[ if a&0x200 {0x200 + (a&0x1F)} else {a} ]`; puis `internal_oamadd = (a+1) & 0x3FF`.
Rechargement: a chaque debut de VBlank (V = vblank_start, dot 0), si `!forced_blank`: `internal_oamadd = (oamadd_reg & 0x1FF) << 1`. (`UNKNOWN - to confirm`: rechargement aussi quand forced_blank retombe a 0; defaut: non.)

## Tests
Tous les tests sont prefixes par `e04_11_`.

- `e04_11_setini_bits` : `write(0x33,0x4A)`: obj_interlace()==true, pseudo_hires()==true, extbg()==true, interlace()==false, overscan()==false. `write(0x33,0x87)`: interlace, obj_interlace, overscan vrais ; pseudo_hires et extbg faux (bit 7 ignore). `write(0x33,0x00)`: tout faux.
- `e04_11_oam_reload_at_vblank` : forced blank : `write(0x02,0x07); write(0x03,0x00)` (internal 14) ; 3 x `write(0x04,1)` (internal 17) ; `write(0x00,0x0F)` (display on) ; `at(p,225,0)` : `oam_internal_addr()==17` (l'evenement n'a pas encore eu lieu : il se produit pendant le step execute A (225,0)) ; un `step_dot` de plus -> `oam_internal_addr()==14`.
- `e04_11_oam_reload_skipped_in_forced_blank` : forced blank (par defaut) : `write(0x02,0x07)`, 3 x `write(0x04,1)` (internal 17) ; `at(p,225,1)` : `oam_internal_addr()==17` (pas de rechargement en forced blank).
- `e04_11_oam_write_in_vblank` : display on, `at(p,226,0)` : `write(0x02,0); write(0x04,0xAA); write(0x04,0xBB)` -> `oam()[0]==0xAA`, `oam()[1]==0xBB` (acces autorise en VBlank).
- `e04_11_oam_reload_overscan` : `write(0x33,0x04)`, `write(0x02,0x07)` en forced blank, 3 x `write(0x04,1)`, `write(0x00,0x0F)` ; `at(p,225,1)` : internal reste 17 (pas encore VBlank) ; puis 15*340 steps supplementaires (position (240,1)) : `oam_internal_addr()==14`.
- `e04_11_flags_cleared_at_frame_start` : `set_range_over(true); set_time_over(true)` sur un `Ppu::new` (v=0,dot=0) ; un `step_dot` : `read(0x3E,0,false)==0x01`.
- `e04_11_flags_persist_mid_frame` : `at(p,5,0)`, puis `set_range_over(true); set_time_over(true)` ; 256*340 steps supplementaires (position (261,0)) : `read(0x3E,0,false)==0xC1` ; encore 340 steps (position (0,0) de la frame suivante, l'evenement du dot 0 n'est pas encore execute) : `read(0x3E,0,false)==0xC1` ; UN step de plus : `read(0x3E,0,false)==0x01`.
- `e04_11_hash` : hash differe apres `write(0x33,0x02)`, `write(0x33,0x08)`, `write(0x33,0x40)` (chacun sur un Ppu neuf).
