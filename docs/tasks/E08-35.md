/// Carte d'un BG (mode 0-6). map_size: 0 = 32x32, 1 = 64x32, 2 = 32x64, 3 = 64x64 ecrans-tuiles (chaque ecran = 0x400 mots; disposition 64x32: ecrans a base et base+0x400 cote a cote; 32x64: base et base+0x400 l'un sous l'autre; 64x64: base, base+0x400 (droite), base+0x800 (bas gauche), base+0xC00 (bas droite)).
/// Entree de carte: bits 0-9 numero de caractere, 10-12 palette, 13 priorite (ignoree ici), 14 flip H, 15 flip V.
/// Tuile de caractere c: premier mot = (chr_base_word + c * tile_words(bpp)) & 0x7FFF. tile16 = vrai: la tuile affichee fait 16x16 et est composee des caracteres c, c+1 (ligne du haut) et c+16, c+17 (ligne du bas) ; flip H echange gauche/droite ET retourne chaque 8x8 ; flip V idem pour haut/bas.
/// Couleur: cgram[((palette << bpp) + idx) & 0xFF] (8 bpp: cgram[idx]). Simplification v1 documentee: pas de decalage de palette du mode 0, pas de transparence (l'indice 0 est dessine).
/// Renvoie (largeur, hauteur, RGBA) en pixels: largeur = ecrans_horizontaux * 32 * (8 ou 16).
pub fn render_bg_map(vram: &[u16], cgram: &[u16], map_base_word: usize, chr_base_word: usize, map_size: u8, tile16: bool, bpp: u8) -> (usize, usize, Vec<u8>);
/// Mode 7: carte 128x128 (octet BAS du mot `y * 128 + x` = numero de tuile), tuile n = 8x8 pixels 8 bpp dont le pixel (px, py) est l'octet HAUT du mot `n * 64 + py * 8 + px`. Image 1024x1024 RGBA, couleur cgram[indice] directe.
pub fn render_mode7_map(vram: &[u16], cgram: &[u16]) -> (usize, usize, Vec<u8>);
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct SpriteInfo { pub index: u8, pub x: i16, pub y: u8, pub tile: u16, pub palette: u8, pub priority: u8, pub hflip: bool, pub vflip: bool, pub large: bool }
/// OAM de 544 octets: sprite i = octets 4i..4i+3 (x bas, y, tuile, attributs vhoopppN) ; table haute (octets 512..543): sprite i = 2 bits a l'octet 512 + i/4, decalage 2 * (i % 4): bit 0 = bit 8 de x, bit 1 = grande taille. x = 9 bits en complement a 2 (-256..255). tile = octet de tuile | (N << 8) ; palette = bits 1-3 ; priority = bits 4-5 ; flips bits 6 (H) et 7 (V). `oam` plus court que 544: sprites manquants a zero.
pub fn decode_oam(oam: &[u8]) -> Vec<SpriteInfo>;      // 128 elements
pub fn sprite_dims(obj_size: u8, large: bool) -> (u8, u8);   // largeur, hauteur: table de spec 05b section sprites (tailles 0..7)

## 8. Debugger (fenetre egui separee, ouverte par F10)

Envoie `RequestDebug(true)` ; le thread d'emulation joint a chaque frame un `DebugData` = `{ snapshot: DebugSnapshot, vram: Vec<u16> (32768), cgram: Vec<u16> (256), oam: Vec<u8> (544), wram_page: Vec<u8> (256 octets de la page choisie), ppu_regs: Option<PpuRegsSnapshot>, smp: Option<SmpSnapshot>, dma: Option<[DmaChanSnapshot; 8]> }` (les `Vec` sont vides et les `Option` sont `None` pour le motif de test).
Panneaux (v1):
1. **Registres**: CPU (A, X, Y, S, D, DB, PB, PC, P avec drapeaux N V M X D I Z C et e), SMP (A, X, Y, SP, PC, PSW), position (frame, V, H, master), registres PPU principaux (INIDISP, BGMODE, TM, TS, CGWSEL, CGADSUB, SETINI), registres DMA actifs.
2. **VRAM - tuiles**: grille de tuiles 8x8, choix profondeur 2/4/8 bpp, palette (0..15 ou 0..7), adresse de base en mots (curseur par pas de 0x400), zoom 1-4.
3. **VRAM - cartes**: rendu de la carte d'un BG (1..4) avec ses reglages courants (taille de carte, tuile 8/16) ; mode 7 : carte 128x128 en 1024x1024.
4. **Palettes**: 256 pastilles CGRAM, survol = indice + valeur.
5. **OAM**: tableau des 128 sprites (x, y, tuile, palette, priorite, taille, flips).
6. **Memoire**: vue hexadecimale de WRAM (page de 256 octets, navigation par 256).
Commandes d'execution: Pause, Reprendre, Avancer une frame, Avancer une instruction CPU (via commande `StepInstruction`), Executer jusqu'a un PC (un seul point d'arret `PC`, saisi en hexadecimal). Pas de desassembleur en v1 (hors perimetre).

## Tests
Tous les tests sont prefixes par `e08_35_`.

- `e08_35_bg_map_size` : `render_bg_map(.., map_size 0, tile16 false, bpp 2)` -> (256, 256) ; `map_size 1` -> (512, 256) ; `2` -> (256, 512) ; `3` -> (512, 512) ; `tile16 true`, map_size 0 -> (512, 512).
- `e08_35_bg_map_tile_lookup` : vram[0x100 + 0] = entree (caractere 1, palette 0) ; tuile 1 a `chr_base 0`: vram[8] = 0x00FF (ligne 0 = indice 1) ; cgram[1] = 0x001F : `render_bg_map(.., map_base 0x100, chr_base 0, 0, false, 2)` : pixels (0..8, 0) = `[255,0,0,255]`.
- `e08_35_bg_map_hflip` : meme tuile mais plan0 = 0x80 sur la ligne 0 (pixel de gauche seul) et entree avec flip H (bit 14) : le pixel colore est a x = 7.
- `e08_35_bg_map_vflip` : tuile dont seule la ligne 0 est non nulle, entree avec flip V (bit 15) : la ligne coloree est y = 7.
- `e08_35_bg_map_palette_bits` : entree avec palette 3, bpp 2, indice 1 -> couleur `cgram[(3 << 2) + 1]`.
- `e08_35_bg_map_screens_64x32` : map_size 1 : l'entree de l'ecran 2 (mot `map_base + 0x400`) est dessinee a x = 256..263, y = 0.
- `e08_35_bg_map_tile16_layout` : tile16 vrai, entree caractere 0 sans flip : le sous-bloc du haut-droit (x 8..16, y 0..8) vient du caractere 1 et le bas-gauche (x 0..8, y 8..16) du caractere 16 ; avec flip H le haut-gauche vient du caractere 1 (retourne).
- `e08_35_bg_map_empty_vram` : `render_bg_map(&[], &[], 0, 0, 0, false, 2)` : taille (256,256), tout noir opaque, pas de panique.
- `e08_35_mode7_map` : vram[0] = 0x0005 (tuile 5 en (0,0)) ; vram[5*64 + 0] = 0x0900 (octet haut 9 : pixel (0,0) de la tuile) ; cgram[9] = 0x7C00 : pixel (0,0) de l'image = `[0,0,255,255]` ; taille (1024, 1024).
- `e08_35_oam_decode_basic` : octets du sprite 0 = `[0x10,0x20,0x05,0x31]`, table haute 0 : `index 0, x 16, y 0x20, tile 0x105, palette 0, priority 3, hflip false, vflip false, large false`.
- `e08_35_oam_decode_high_table` : sprite 1 avec x bas 0xFF et table haute octet 512, bits 2-3 = `0b11` (bit8=1, large=1) : `x == -1`, `large == true` ; sprite 0 du meme octet inchange.
- `e08_35_oam_decode_flips_palette` : attributs 0xE6 (v=1,h=1,oo=2,ppp=3,N=0): `vflip`, `hflip`, `priority 2`, `palette 3`, `tile` sans bit 8.
- `e08_35_oam_short_input` : `decode_oam(&[])` : 128 elements a zero (x 0, y 0, tile 0) ; `decode_oam(&[0;544]).len()==128`.
- `e08_35_sprite_dims` : `sprite_dims(0,false)==(8,8)` ; `(0,true)==(16,16)` ; `(3,true)==(32,32)` ; `(5,false)==(32,32)` ; `(5,true)==(64,64)` ; `(6,false)==(16,32)` ; `(6,true)==(32,64)` ; `(7,false)==(16,32)` ; `(7,true)==(32,32)`.
