## Specification
Cree `apu/timer.rs` et declare `pub mod timer;` dans `apu/mod.rs` (sans rien changer d'autre dans `mod.rs`).
```rust
#[derive(Clone, Debug)]
pub struct Timer { divider: u16, enable: bool, target: u8, stage0: u16, stage1: u8, out: u8 }
impl Timer {
    pub fn new(divider: u16) -> Timer;           // tout a 0, enable faux
    pub fn tick(&mut self);                      // algorithme de 07 section 3.1 (un appel = un cycle SMP)
    pub fn set_enable(&mut self, on: bool);      // transition faux -> vrai : stage1 = 0 et out = 0 (stage0 est conserve) ; vrai -> faux ou inchange : seulement enable = on
    pub fn set_target(&mut self, t: u8);
    pub fn read_out(&mut self) -> u8;            // renvoie out & 0x0F puis out = 0
    pub fn out(&self) -> u8;  pub fn stage1(&self) -> u8;  pub fn stage0(&self) -> u16;  pub fn enabled(&self) -> bool;
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);   // divider (u16), enable (u8), target (u8), stage0 (u16), stage1 (u8), out (u8)
}
```

### 3.1 Timers
Timer 0 et 1: diviseur `128` cycles SMP (8 kHz). Timer 2: diviseur `16` cycles SMP (64 kHz).
Etat par timer: `stage0: u16` (diviseur interne, tourne en permanence, jamais remis a 0 par CONTROL), `stage1: u8`, `out: u8` (4 bits), `enable: bool`, `target: u8`.
A chaque cycle SMP:
```
stage0 += 1
if stage0 == divider { stage0 = 0; if enable { stage1 = stage1.wrapping_add(1); if stage1 == target { stage1 = 0; out = (out + 1) & 0x0F } } }
```
(`target == 0` equivaut donc a 256, grace au `u8` qui deborde.) Lecture de `$FD+n`: retourne `out`, puis `out = 0`.

## Tests
Tous les tests sont prefixes par `e06_32_`.

- `e06_32_period_timer2` : `Timer::new(16)`, `set_target(3)`, `set_enable(true)` : apres 47 `tick` `out()==0` ; apres 48 `out()==1` ; apres 96 `out()==2` ; `stage1()` revient a 0 a chaque sortie.
- `e06_32_read_clears` : meme timer apres 48 ticks : `read_out()==1` puis `read_out()==0`.
- `e06_32_target_zero_is_256` : `Timer::new(16)`, cible 0, enable : apres 16*255 ticks `out()==0` ; apres 16*256 ticks `out()==1`.
- `e06_32_disabled_runs_stage0_only` : timer desactive, 20 ticks : `stage0()==4`, `stage1()==0`, `out()==0`.
- `e06_32_enable_midway` : `Timer::new(16)`, cible 1 ; 8 ticks desactive ; `set_enable(true)` ; 8 ticks de plus (16 au total) : `out()==1` (stage0 n'a pas ete remis a zero).
- `e06_32_enable_transition_resets` : cible 1, enable, 16 ticks : out==1 ; `set_enable(false)` ; `set_enable(true)` : `out()==0` et `stage1()==0`. Sans transition (`set_enable(true)` deux fois de suite) : out conserve.
- `e06_32_out_wraps_4_bits` : `Timer::new(1)`, cible 1, enable : apres 15 ticks `out()==15` ; apres 16 ticks `out()==0`.
- `e06_32_divider_128` : `Timer::new(128)`, cible 1, enable : 127 ticks -> out 0 ; 128 ticks -> out 1.
- `e06_32_hash` : deux timers neufs de meme diviseur ont le meme hash ; apres `tick()` il differe.
