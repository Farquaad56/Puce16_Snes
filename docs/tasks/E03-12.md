    pub fn new() -> Apu;  pub fn reset(&mut self);             // les 8 octets a 0

### 3.3 Apu (squelette, `apu/mod.rs`; sera complete en E06)

pub struct Apu { to_apu: [u8; 4], from_apu: [u8; 4] /* valeurs vues par le CPU */ }

    pub fn port_read(&self, i: usize) -> u8 { self.from_apu[i & 3] }     // $2140-$2143 (miroir tous les 4)

## Tests
Tous les tests sont prefixes par `e03_12_`.

- `e03_12_power_on` : `Apu::new()`: `port_read(i)==0` pour i in 0..4, `cpu_to_apu(i)==0`.
- `e03_12_write_goes_to_apu` : `port_write(1,0x55)`: `cpu_to_apu(1)==0x55` ET `port_read(1)==0` (les deux sens sont separes).
- `e03_12_mirror` : `port_write(5,0x77)` -> `cpu_to_apu(1)==0x77` ; `debug_set_from_apu(2,0x99)` -> `port_read(6)==0x99` et `port_read(2)==0x99`.
- `e03_12_reset` : apres ecritures, `reset()` remet tout a 0.
- `e03_12_step_to_noop` : `step_to(1_000_000)` ne panique pas et ne change pas le hash.
- `e03_12_hash` : hash differe apres `port_write(0,1)` et apres `debug_set_from_apu(0,1)`.
