## 5. Bruit
A chaque echantillon: `if poll(FLG & 0x1F) { let fb = (noise << 13) ^ (noise << 14); noise = (fb & 0x4000) ^ (noise >> 1) }` (u16, 15 bits utiles; bit 14 neuf = bit0 ^ bit1). Depart 0x4000: suite 0x2000, 0x1000, 0x0800.

## Tests
Tous les tests sont prefixes par `e06_44_`.

- `e06_44_counter_wraps` : `Dsp::new()`: apres 1 `debug_step_counter_noise` `counter()==0x77FF` ; apres 2: `0x77FE` ; `debug_set_counter(1)` puis un pas -> 0 ; un autre pas -> `0x77FF`.
- `e06_44_counter_cycle_length` : `debug_set_counter(0x77FF)` : apres 0x77FF pas `counter()==0` ; apres 0x7800 pas `counter()==0x77FF` (periode 0x7800 = 30720).
- `e06_44_noise_rate0_frozen` : `write(FLG, 0x20)` (taux 0), 100 pas : `noise()==0x4000`.
- `e06_44_noise_rate31_sequence` : `write(FLG, 0x3F)` (taux 31 = chaque echantillon) : apres 1, 2, 3, 4 pas `noise()` vaut `0x2000`, `0x1000`, `0x0800`, `0x0400`.
- `e06_44_noise_feedback` : `write(FLG,0x3F)`, `debug_set_noise(0x4000)` : apres 13 pas `noise()==0x0002` ; 14eme pas -> `0x4001` ; 15eme -> `0x6000` ; 16eme -> `0x3000`.
- `e06_44_noise_rate5_cadence` : `write(FLG, 0x25)` (taux 5: periode 768), `debug_set_counter(0)`, `debug_set_noise(0x4000)` : apres 30720 pas `noise()==0x0014` (40 mises a jour) et `counter()` est revenu a 0.
- `e06_44_noise_ignores_other_flg_bits` : `write(FLG,0xFF)` fonctionne comme `0x1F` pour le taux : `debug_set_noise(0x4000)`, un pas -> `0x2000`.
- `e06_44_noise_accessors` : `Dsp::new().noise()==0x4000` ; `debug_set_noise(7)` puis `noise()==7`.
