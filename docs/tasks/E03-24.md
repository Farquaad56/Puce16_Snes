## Specification
Ajoute a `on_dot`, APRES le point 3: `mode = (mmio.nmitimen >> 4) & 3`. Si `mode != 0`:
- `htime_ok = mmio.htime <= 339` ; `vtime_ok = mmio.vtime <= ppu.last_line()` ;
- mode 1: `hit = htime_ok && dot == htime + IRQ_H_OFFSET_DOTS` ;
- mode 2: `hit = vtime_ok && v == vtime && dot == IRQ_H_OFFSET_DOTS` ;
- mode 3: `hit = htime_ok && vtime_ok && v == vtime && dot == htime + IRQ_H_OFFSET_DOTS`.
Si `hit`: `mmio.timeup_flag = true; mmio.irq_line = true`. (Les types de `htime`/`vtime`: `u16`; `dot`, `v`: `u16`.)

### 6.3 IRQ timer (H/V)
- Condition evaluee **a chaque dot** (en pratique: a chaque avance de H):
  - mode 1 (V=0,H=1): vrai quand `H == HTIME` (a chaque ligne);
  - mode 2 (V=1,H=0): vrai quand `V == VTIME` et `H == 0`;
  - mode 3: `V == VTIME` et `H == HTIME`.
- Quand la condition passe de faux a vrai: TIMEUP.7 = 1 (flag) et la ligne IRQ du CPU = 1 (maintenue jusqu'a lecture de $4211 ou jusqu'a ce que NMITIMEN V/H = 00; ecrire NMITIMEN avec V/H=00 efface le flag et la ligne).
- Decalage H reel (IRQ declenche ~ quelques dots apres H==HTIME): `IRQ_H_DELAY` defaut 4 clocks? `UNKNOWN - to confirm`.
- HTIME > 339 ou VTIME > derniere ligne: ne se declenche jamais.
- V=0 H=0 (modes 2,3): decale d'un dot sur certaines revisions: ignorer en v1.

## 8. Algorithme de `Timing::on_dot` (position = (ppu.v(), ppu.dot()) APRES le step, `t` = debut de ce dot)
Dans cet ordre:
1. `dot == 0`: `line_start = t`; `refreshed_this_line = false`. Si de plus `v == 0`: `out.frame_end = true`; `mmio.rdnmi_flag = false` (fin du VBlank).
2. `v == ppu.vblank_start() && dot == NMI_FLAG_DOT`: `mmio.rdnmi_flag = true`; `out.vblank_start = true`.
3. Ligne NMI: `line = mmio.rdnmi_flag && (mmio.nmitimen & 0x80 != 0)`; si `line && !nmi_line_prev`: `nmi_edge = true`; `nmi_line_prev = line`.
4. IRQ H/V: `mode = (mmio.nmitimen >> 4) & 3`; si `mode != 0`: mode 1: `dot == htime + IRQ_H_OFFSET_DOTS`; mode 2: `v == vtime && dot == IRQ_H_OFFSET_DOTS`; mode 3: `v == vtime && dot == htime + IRQ_H_OFFSET_DOTS` ; `htime > 339` ou `vtime > derniere ligne` : jamais. Si vrai: `mmio.timeup_flag = true; mmio.irq_line = true`.
5. Auto-read: si `nmitimen & 1 != 0 && v == vblank_start && dot == AUTOREAD_START_DOT`: `autoread_end = Some(t + AUTOREAD_CLOCKS)`. Puis, si `autoread_end == Some(e)` et `t >= e`: `mmio.joy = joy.autoread_values()`; `autoread_end = None`.
6. HDMA: `mmio.hdmaen != 0`: `v == 0 && dot == HDMA_INIT_DOT` -> `out.hdma_init`; `v <= vis_last && dot == HDMA_RUN_DOT` -> `out.hdma_run`.
`mmio.read` de `$4210` efface `rdnmi_flag` ; de `$4211` efface `timeup_flag` ET `irq_line` ; `mmio.write(NMITIMEN)` avec bits V/H = 00 efface `timeup_flag` et `irq_line`.

## Tests
Tous les tests sont prefixes par `e03_24_`.

- `e03_24_mode1` : `Rig::new(Ntsc)`; `mmio.nmitimen=0x10; mmio.htime=100`: `run_until(0,101)`: avant ce step `timeup_flag==false`, apres: true et `irq_line==true`. Position exacte: le step qui ARRIVE en (0,101).
- `e03_24_mode1_every_line` : apres avoir efface (`mmio.timeup_flag=false; mmio.irq_line=false`), `run_until(1,100)`: toujours faux ; `run_until(1,101)`: vrai (a chaque ligne).
- `e03_24_mode2` : `nmitimen=0x20; vtime=10`: aucun drapeau avant (10,1) (verifier en parcourant tous les steps jusqu'a (10,0)) ; `run_until(10,1)`: vrai ; pas de nouveau declenchement a (11,1) apres effacement.
- `e03_24_mode3` : `nmitimen=0x30; htime=50; vtime=10`: faux jusqu'a (10,50) ; `run_until(10,51)`: vrai. Ligne 11 (11,51): rien.
- `e03_24_mode0_never` : nmitimen=0x00 avec htime=100: sur 2 lignes entieres jamais de drapeau.
- `e03_24_htime_too_big` : mode 1, `htime=340`: sur une frame entiere (262*340 steps): jamais de drapeau ; `htime=339` (dot 340 n'existe pas sur ligne normale) : jamais non plus ; `htime=338`: declenche en dot 339.
- `e03_24_vtime_too_big` : NTSC mode 2, `vtime=262` (> last_line 261): jamais sur une frame. PAL mode 2, `vtime=262`: declenche en (262,1).
- `e03_24_clear_by_4211` : apres declenchement, `mmio.read(0x4211,0,rig.t,Default::default())` renvoie un octet avec bit 7 a 1 puis `timeup_flag==false`, `irq_line==false`.
- `e03_24_clear_by_nmitimen` : apres declenchement, `mmio.write(0x4200,0x00,t)` efface les deux ; `mmio.write(0x4200,0x10,t)` ne les efface pas.
- `e03_24_vtime_zero_mode3` : mode 3, `vtime=0`, `htime=0`: declenche en (0,1) de la 1re frame.
