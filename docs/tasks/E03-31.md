## Contexte
Le moteur DMA acces au bus via `DmaBus`: l'A-bus ne peut pas viser les registres systeme (zones ignorees, lecture = open bus), le B-bus vise `$2100 + reg`.

## Specification
Dans `bus/mod.rs` (ou un sous-module): `impl crate::dma::DmaBus for SysBus`:
- `a_read(addr)`: `bank = (addr >> 16) as u8; a = addr as u16`. Si `bank & 0x7F <= 0x3F` ET `a` dans `0x2100..=0x21FF | 0x4000..=0x41FF | 0x4200..=0x421F | 0x4300..=0x437F`: renvoie `self.mdr` (sans modifier rien). Sinon `v = self.read_inner(addr); self.mdr = v; v`.
- `a_write(addr, v)`: meme zone interdite -> ne fait rien ; sinon `self.mdr = v; self.write_inner(addr, v)`.
- `b_read(reg)`: `v = self.read_inner(0x00_2100 | reg as u32); self.mdr = v; v`. `b_write(reg, v)`: `self.mdr = v; self.write_inner(0x00_2100 | reg as u32, v)`.
- `elapse(clocks)`: `self.advance(clocks)`. `master()`: `self.master`. Dans les tests: `mod common; use common::*;` puis `fn mk(code: &[u8]) -> SysBus { SysBus::new(Cart::from_bytes(&make_rom(code, Map::LoRom)).unwrap(), Region::Ntsc) }` (imports: `puce16_core::bus::SysBus`, `puce16_core::cart::Cart`, `puce16_core::Region`).

## 3. DMA general (MDMAEN $420B)

Ecriture non nulle: les canaux dont le bit est a 1 s'executent dans l'ordre 0..7. Le CPU est arrete pendant toute la duree.

Pour chaque canal actif, tant que le compteur n'est pas 0:
1. Lire un octet (source selon direction), ecrire a destination.
   - Direction A->B: lire A-bus `(A1Bn:A1Tn)`, ecrire B-bus `$2100 + ...`.
   - Direction B->A: lire B-bus, ecrire A-bus.
2. Passer a l'octet suivant du pattern (offset B suivant, cyclique sur la longueur du pattern).
3. Ajuster A1Tn (16 bits, la banque ne change jamais): mode 0: +1; mode 2: -1; modes 1 et 3: inchange.
4. Decrementer DASn (16 bits). A 0 -> fin du canal. Le transfert s'arrete meme au milieu d'un pattern.

Apres le canal: DASn = 0, A1Tn = adresse apres l'avance (wrap 16 bits dans la banque). Compteur initial 0 = 65536 octets.

Restrictions:
- L'adresse A-bus ne peut pas viser $2100-$21FF, $4000-$41FF, $4200-$421F, $4300-$437F (banques 00-3F/80-BF): ces acces sont ignores (lecture = open bus; ecriture = rien). `UNKNOWN - to confirm` le detail: defaut = lecture open bus (`mdr`), ecriture ignoree.
- DMA WRAM->$2180 : la lecture A-bus en WRAM n'a pas d'effet utile (rien n'est ecrit, adresse WMADD non incrementee). DMA $2180->WRAM: ecrit open bus; WMADD non incremente. (wiki)
- BBADn = $00 sur certaines revisions de CPU: ne pas emuler la panne; documenter seulement.
- DMA ne peut pas copier WRAM -> WRAM.

### 3.1 Timing DMA (cycle-accurate, valeurs par defaut)
- L'ecriture de MDMAEN fixe un drapeau "DMA en attente". Le DMA demarre **apres la lecture de l'opcode de l'instruction suivante** (le CPU ne se fait pas interrompre au milieu d'un cycle).
- Au demarrage: temps maitre aligne sur le multiple de 8 clocks suivant (`master_phase`; `UNKNOWN - to confirm` l'origine: defaut = origine de la ligne 0 de la frame), puis **8 clocks de surcout**.
- Par canal actif: **8 clocks** de surcout de canal.
- Par octet transfere: **8 clocks**.
- A la fin: **le CPU reprend apres un alignement sur son prochain cycle** (6/8/12 clocks selon l'adresse du cycle suivant): `UNKNOWN - to confirm`; defaut: pas de realignement supplementaire.
- HDMA peut interrompre un DMA general: le DMA est mis en pause pendant l'execution de HDMA (voir 4).
- Les composants PPU/APU/timers avancent normalement pendant le DMA (via `catch_up`). Le CPU ne s'execute pas.

### 3.7 Dma (`dma/mod.rs`, `dma/hdma.rs`)
```rust
pub trait DmaBus {
    fn a_read(&mut self, addr: u32) -> u8;      // lecture A-bus SANS avancer le temps (le moteur DMA gere le temps)
    fn a_write(&mut self, addr: u32, v: u8);
    fn b_read(&mut self, reg: u8) -> u8;        // $2100 + reg
    fn b_write(&mut self, reg: u8, v: u8);
    fn elapse(&mut self, clocks: u32);          // avance master et appelle catch_up
    fn master(&self) -> u64;
}
#[derive(Default)] pub struct Channel { pub dmap: u8, pub bbad: u8, pub a1t: u16, pub a1b: u8, pub das: u16, pub dasb: u8, pub a2a: u16, pub nltr: u8, pub unused: u8,
                                         /* etat HDMA prive */ do_transfer: bool, done: bool, line_counter: u8 }
#[derive(Default)] pub struct Dma { pub ch: [Channel; 8] }
impl Dma { pub fn new() -> Dma;                                   // valeurs de power-on de la spec 03
    pub fn read(&self, reg: u16) -> Option<u8>; pub fn write(&mut self, reg: u16, v: u8);    // $4300-$437F ; None = open bus
    pub fn run_general<B: DmaBus>(&mut self, bus: &mut B, mask: u8);
    pub fn hdma_init<B: DmaBus>(&mut self, bus: &mut B, mask: u8);
    pub fn hdma_run_line<B: DmaBus>(&mut self, bus: &mut B, mask: u8);
    pub fn hash_into(&self, h: &mut Fnv64); }
```
`SysBus` appelle `let mut d = std::mem::take(&mut self.dma); d.run_general(self, mask); self.dma = d;` (evite l'emprunt double). `SysBus` implemente `DmaBus`.

## Tests
Tous les tests sont prefixes par `e03_31_`.

- `e03_31_a_read_ok_zones` : `bus.wram.write(0x30,0x9A)`: `a_read(0x7E0030)==0x9A`, `a_read(0x000030)==0x9A` ; ROM `mk(&[0xA9])`: `a_read(0x008000)==0xA9` ; `bus.mdr` vaut alors 0xA9.
- `e03_31_a_read_forbidden` : mdr=0x77: `a_read` de 0x002100, 0x0021FF, 0x004000, 0x0041FF, 0x004200, 0x00421F, 0x004300, 0x00437F, 0x802100 vaut 0x77 ; `a_read(0x004016)` aussi (zone 4000-41FF) ; `a_read(0x002000)` (hors liste, 'open bus' via read_inner) == mdr.
- `e03_31_a_write` : `a_write(0x7E0040,9)` -> `wram.read(0x40)==9` ; `a_write(0x002100,0x00)` ignore (`ppu.forced_blank()` reste true) ; `a_write(0x00420B,0x01)` ignore (`pending_dma()==0`) ; `a_write(0x004300,5)` ignore (`dma.ch[0].dmap==0xFF`).
- `e03_31_b_bus` : `b_write(0x80,0xAB)`: `wram.read(0)==0xAB`, `wram.addr==1` ; `b_read(0x80)` lit l'octet a l'adresse 1 et incremente ; `b_write(0x00,0x00)` -> `ppu.forced_blank()==false` ; `b_write(0x42,7)` -> `apu.cpu_to_apu(2)==7` ; `b_write(0xFF,1)` ne panique pas.
- `e03_31_b_read_updates_mdr` : `bus.apu.debug_set_from_apu(3,0x5E)`: `b_read(0x43)==0x5E` et `bus.mdr==0x5E`.
- `e03_31_no_time_except_elapse` : apres `a_read`, `a_write`, `b_read`, `b_write`: `bus.master==0` ; `elapse(10)` -> `master()==10` ; `elapse(1364)` fait avancer le PPU (`ppu.v()==1`).
- `e03_31_dma_through_trait` : utilise `Dma::new()` + `run_general(&mut bus_ref, 1)` en retirant le DMA du bus (`let mut d = std::mem::take(&mut bus.dma); ...`): ROM `mk` avec donnees [1,2,3] a 0x8000 (code = ces 3 octets), canal 0: dmap=0, bbad=0x80, a1b=0, a1t=0x8000, das=3, `wram.addr=0x100`: apres, `wram.read(0x100..0x103)==[1,2,3]` et `bus.master==8+8+24==40`.
