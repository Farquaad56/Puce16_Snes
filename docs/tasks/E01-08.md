## Specification
Dans `tests/common/mod.rs` (module partage `mod common;` par les autres fichiers de test):
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Map { LoRom, HiRom, ExHiRom }
/// Build a valid ROM. `code` is placed at the file offset that CPU address $00:8000 maps to:
/// LoRom file offset 0x0000 ; HiRom file offset 0x8000 ; ExHiRom file offset 0x408000.
pub fn make_rom(code: &[u8], map: Map) -> Vec<u8>;
pub fn make_rom_with(code: &[u8], map: Map, rom_log2: u8 /* 15=32 KiB .. */, sram_log2: u8, chipset: u8, country: u8) -> Vec<u8>;
```
Regles de `make_rom_with`:
- taille ROM = `1 << rom_log2` octets (panique si trop petit pour contenir l'en-tete: LoRom >= 32 Kio, HiRom >= 64 Kio, ExHiRom >= 8 Mio = `rom_log2 >= 23`), remplie d'octets 0x00 sauf code et en-tete.
- en-tete a: LoRom `0x7FC0`, HiRom `0xFFC0`, ExHiRom `0x40FFC0`. Titre = 21 octets ASCII `"PUCE16 TEST ROM      "`. Octet map: LoRom `0x20`, HiRom `0x21`, ExHiRom `0x25`. Chipset = param. Taille ROM = `rom_log2 - 10`. Taille RAM = `sram_log2` (0 = aucune; la valeur est l'exposant N de `1024 << N`, donc 3 = 8 Kio). Pays = param. Dev = 0x00. Version = 0.
- vecteurs (zone header_offset + 0x20 .. +0x3F): TOUS les mots a `0x8000` (little-endian). `pub fn set_vector(rom: &mut Vec<u8>, map: Map, name: &str, addr: u16)` ecrase un vecteur puis RECALCULE le checksum. Table (offsets relatifs au debut de l'en-tete): `cop` -> +0x24 (natif) et +0x34 (emulation); `brk` -> +0x26 (natif) et +0x3E (emulation); `nmi` -> +0x2A et +0x3A; `irq` -> +0x2E et +0x3E; `reset` -> +0x3C seulement. Nom inconnu: panique.
- code copie au debut du code reset (voir plus haut); checksum: complement et checksum mis a 0xFFFF / 0x0000 pendant le calcul, somme de tous les octets (u16 wrapping), puis `checksum` en header+0x1E (LE) et `!checksum` en header+0x1C (LE).
- `make_rom(code, map)` = `make_rom_with(code, map, 15 (LoRom) / 16 (HiRom) / 23 (ExHiRom, = 8 Mio), 0, 0x00, 0x01)`.

## 2. En-tete interne (adresses CPU $00FFC0-$00FFDF, offset dans le fichier selon le mapper)

| Offset | Taille | Champ |
|---|---|---|
| $FFC0 | 21 | titre ASCII ($20-$7E) |
| $FFD5 | 1 | `001s mmmm`: s=vitesse (0 lent, 1 rapide), mmmm = mapper ($0 LoROM, $1 HiROM, $5 ExHiROM; $2 S-DD1, $3 SA-1, $A SPC7110 = non supportes v1) |
| $FFD6 | 1 | chipset |
| $FFD7 | 1 | taille ROM: `1 << N` Kio |
| $FFD8 | 1 | taille RAM: `1 << N` Kio (0 = aucune) |
| $FFD9 | 1 | code pays |
| $FFDA | 1 | developpeur (si $33: en-tete etendu) |
| $FFDB | 1 | version |
| $FFDC | 2 | complement du checksum (LE) |
| $FFDE | 2 | checksum (LE) |
| $FFE0-$FFFF | 32 | vecteurs |

Position de l'en-tete dans le fichier normalise: LoROM `0x7FC0`, HiROM `0xFFC0`, ExHiROM `0x40FFC0`.

### 2.1 Vecteurs (adresses CPU, banque 00)
Natif: COP $FFE4, BRK $FFE6, ABORT $FFE8, NMI $FFEA, IRQ $FFEE. Emulation: COP $FFF4, ABORT $FFF8, NMI $FFFA, RESET $FFFC, IRQ/BRK $FFFE. Lus par le CPU via le bus (pas par `cart/`).

### 2.2 Chipset ($FFD6)
- Quartet bas: `0` ROM; `1` ROM+RAM; `2` ROM+RAM+batterie; `3` ROM+coproc; `4` ROM+coproc+RAM; `5` ROM+coproc+RAM+batterie; `6` ROM+coproc+batterie.
- Quartet haut (si bas >= 3): `0` DSP-n, `1` GSU, `2` OBC1, `3` SA-1, `4` S-DD1, `5` S-RTC, `E` autre, `F` custom (voir $FFBF).
- v1 (D-005): si bas >= 3 -> `CartError::UnsupportedCoprocessor(nom)` (`UNKNOWN - to confirm`: defaut = refuser plutot que lancer sans coprocesseur).
- `has_battery` = quartet bas dans {2, 5, 6}.
- Taille SRAM = `0` si $FFD8 == 0, sinon `1024 << N` octets si 1 <= N <= 8; N > 8 -> traiter comme 0 (avertissement). Contenu initial SRAM: `0x00` (`UNKNOWN - to confirm`).

### 2.3 Region ($FFD9)
NTSC si code dans {`$00`, `$01`, `$0D`, `$0F`, `$10`}; PAL sinon (`UNKNOWN - to confirm` pour $0D/$0F/$10: les codes $00 et $01 sont surs). L'utilisateur peut forcer (`--region ntsc|pal`). `enum Region { Ntsc, Pal }` (decision D-003).

### 2.4 Checksum
- Calcul sur la ROM normalisee (puissance de 2): mettre temporairement complement=$FFFF et checksum=$0000 dans l'en-tete, additionner tous les octets sur 16 bits (debordement ignore).
- Valide si `checksum_calcule == checksum_en_tete` et `checksum ^ complement == $FFFF`.
- Le checksum n'est PAS bloquant: c'est un critere de score (ROM homebrew sans checksum valides).

## 7. Tests internes sans ROM externe (a faire des que le composant existe)

| Test | Verifie |
|---|---|
| Handshake IPL | apres reset, ~100 000 clocks maitres (l'IPL efface d'abord $00-$EF, ~50 000 clocks): lecture CPU de $2140 = $AA et $2141 = $BB (le SPC700 execute la ROM IPL, spec 07) |
| Transfert IPL | un programme CPU synthetique (mis dans une ROM LoROM fabriquee en code) envoie un petit programme SPC700 par le protocole IPL et le lance; la reponse sur les ports prouve l'execution |
| DMA WRAM | ROM synthetique: DMA general 256 octets ROM -> $2180; relecture par le CPU |
| NMI/IRQ | ROM synthetique: NMI incremente un compteur en WRAM une fois par frame; apres 60 frames compteur = 60 (ou 59/60 selon alignement, tolerance +-1 documentee) |
| Auto-joypad | `set_joypad` -> lecture de $4218/$4219 apres 2 frames = valeur injectee |
| Determinisme | meme ROM + memes entrees, deux executions -> `state_hash` egal a chaque frame |
| Save state | `save_state` puis `load_state` puis N frames == N frames sans passer par le save state (hash identique) |

Une ROM synthetique est fabriquee par une fonction de test `make_rom(code: &[u8], mode: MapMode) -> Vec<u8>` (en-tete valide, vecteur RESET = $8000, checksum correct) : fournie par la tache `E01-xx` dans `crates/puce16-core/tests/common/mod.rs`.

## Tests
Tous les tests sont prefixes par `e01_08_`.

- `e01_08_lorom_layout` : `make_rom(&[0xEA], Map::LoRom)`: len==32768 ; rom[0]==0xEA ; rom[0x7FFC..0x7FFE]==[0x00,0x80] ; rom[0x7FD5]==0x20 ; rom[0x7FC0..0x7FC6]==b"PUCE16".
- `e01_08_hirom_layout` : `make_rom(&[0xEA], Map::HiRom)`: len==65536 ; rom[0x8000]==0xEA ; rom[0xFFFC..0xFFFE]==[0x00,0x80] ; rom[0xFFD5]==0x21.
- `e01_08_checksum_valid` : pour LoRom et HiRom: somme u16 (wrapping) de tous les octets == checksum lu en header+0x1E ; checksum ^ complement == 0xFFFF.
- `e01_08_set_vector` : `set_vector(&mut rom, Map::LoRom, "nmi", 0x8123)`: rom[0x7FEA..0x7FEC]==[0x23,0x81] et rom[0x7FFA..0x7FFC]==[0x23,0x81] ; le checksum reste valide (set_vector recalcule).
- `e01_08_chipset_sram` : `make_rom_with(&[], Map::LoRom, 15, 3, 0x02, 1)`: rom[0x7FD6]==0x02 ; rom[0x7FD8]==3 ; rom[0x7FD9]==1.
