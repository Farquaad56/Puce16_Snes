# E08-03 - State pour Joypads, Cart (SRAM) et Wram
Epopee: E08 | Type: code | Dependances: E08-02 | Taille estimee: ~120 lignes

## Contexte
Trois petits composants dans trois fichiers. Cart ne sauve QUE la SRAM (la ROM n'est jamais sauvee). Regle commune des sauvegardes d'etat (spec 08 section 9, spec 09 section 9): `impl State for X` sauve, DANS L'ORDRE DE DECLARATION, tous les champs de X qui (a) sont couverts par `hash_into`, ou (b) influencent le comportement futur. Ne sauve PAS les constantes derivees de la region ou de la ROM (reconstruites par le constructeur): les lister dans un commentaire `// not saved: <champ> (<raison>)`.
Les tableaux de taille fixe s'ecrivent sans prefixe de longueur (`bytes`, `slice_u16`), les `Vec` de taille variable avec prefixe (`vec_u8`, `vec_u16`). Un enum est sauve par un `u8` d'indice explicite; une valeur inconnue au chargement donne `StateError::Mismatch("<champ>")`. `load` ecrase les champs en place.
Les tests sont des tests unitaires DANS le fichier (`#[cfg(test)] mod tests`, noms `e08_NN_...`): ils peuvent donc ecrire les champs prives. Forme des tests: (1) `roundtrip_all_fields`: mettre CHAQUE champ sauve a une valeur non nulle et distincte, `save`, `load` dans une instance neuve (constructeur habituel du type), puis re-`save` de la copie = memes octets ET `hash_into` identique (si le type en a un); (2) `truncated`: pour n dans {0, len/2, len-1}, `load` sur `data[..n]` renvoie `Err(StateError::Truncated)`; (3) un test comportemental propre au type (indique ci-dessous). Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## 9. Save states (core, `savestate.rs`)

- Format binaire maison: octets little-endian, `u32` version du blob (1 au debut). Aucun serde, aucune dependance.
- Ecriture/lecture par un trait: `trait State { fn save(&self, w: &mut StateWriter); fn load(&mut self, r: &mut StateReader) -> Result<(), StateError>; }` implemente par chaque composant, dans CET ordre: `master` (+ phase APU `apu_acc: i64`), Cpu, Bus (WRAM 128 Kio, registres $4200-$421F, mdr), DMA (8 canaux + etat HDMA), timing, Ppu (registres, VRAM, CGRAM, OAM, latchs, position, `line_obj`, framebuffer 512x478), Apu (RAM 64 Kio, SMP, timers, ports, DSP: registres, voix, echo, tampons), joypads, Cart (SRAM seulement ; la ROM n'est PAS sauvee).
- `StateWriter`: `u8/u16/u32/u64/i64/bool/bytes(&[u8])/slice_u16`; `StateReader` symetrique avec verification de fin de donnees (erreur `StateError::Truncated`/`Version`/`Mismatch`).
- Aller-retour: `load_state(save_state())` laisse `state_hash` inchange, et executer N frames apres un `load_state` donne le meme `state_hash` que sans passer par le save state.
- Taille attendue: ~1.3 Mio ; pas de compression en v1.
