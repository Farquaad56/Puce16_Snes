## Specification
Dans `ppu/vram.rs`:
```rust
pub fn remap(mode: u8, a: u16) -> u16;            // mode 0..=3 (VMAIN bits 3-2), formules de la section 2.3 ; mode > 3: comme 0
pub struct Vram { mem: Vec<u16> /* 0x8000 mots a 0 */, vmain: u8, vmadd: u16, latch: u16 }
impl Vram {
    pub fn new() -> Vram;                          // tout a 0
    pub fn reset_regs(&mut self);                  // vmain = 0, vmadd = 0, latch = 0 ; la memoire est CONSERVEE
    pub fn set_vmain(&mut self, v: u8);  pub fn vmain(&self) -> u8;  pub fn vmadd(&self) -> u16;
    pub fn step(&self) -> u16;                     // vmain bits 1-0: 0 -> 1, 1 -> 32, 2 ou 3 -> 128
    pub fn inc_on_high(&self) -> bool;             // vmain bit 7
    pub fn set_addr_l(&mut self, v: u8);           // (vmadd & 0xFF00) | v, puis prefetch
    pub fn set_addr_h(&mut self, v: u8);           // (vmadd & 0x00FF) | ((v & 0x7F) << 8), puis prefetch
    pub fn write_low(&mut self, v: u8, ok: bool);  pub fn write_high(&mut self, v: u8, ok: bool);
    pub fn read_low(&mut self, ok: bool) -> u8;    pub fn read_high(&mut self, ok: bool) -> u8;
    pub fn word(&self, a: u16) -> u16;             // mem[a & 0x7FFF]
    pub fn set_word(&mut self, a: u16, w: u16);    // debug/test: mem[a & 0x7FFF] = w
    pub fn mem(&self) -> &[u16];
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);   // toute la memoire (write_u16_slice), puis vmain (u8), vmadd (u16), latch (u16)
}
```
Regles (section 2.3, a suivre EXACTEMENT):
- Adresse d'acces: `ra = remap((vmain >> 2) & 3, vmadd) & 0x7FFF`. `vmadd` lui-meme n'est jamais remappe.
- prefetch: `latch = mem[ra]`.
- `write_low(v, ok)`: si `ok`, octet bas de `mem[ra]` = v. Puis, si `!inc_on_high()`: `vmadd = (vmadd + step()) & 0x7FFF` (meme si `!ok`). `write_high`: idem sur l'octet haut, increment si `inc_on_high()`.
- `read_low(ok)`: `byte = if ok { latch & 0xFF } else { 0 }`; puis si `!inc_on_high()`: `latch = mem[ra]` (adresse AVANT increment) et `vmadd += step` (masque 0x7FFF) -- le rechargement et l'increment ont lieu MEME si `!ok`. `read_high(ok)`: `byte = latch >> 8` (ou 0), rechargement et increment si `inc_on_high()`.

### 2.3 VRAM
```
fn remap(a: u16) -> u16:           // VMAIN bits 3-2
    0: a
    1: (a & 0xFF00) | ((a & 0x00E0) >> 5) | ((a & 0x001F) << 3)
    2: (a & 0xFE00) | ((a & 0x01C0) >> 6) | ((a & 0x003F) << 3)
    3: (a & 0xFC00) | ((a & 0x0380) >> 7) | ((a & 0x007F) << 3)
```
Toute lecture/ecriture de VRAM via les registres utilise `ra = remap(vmadd) & 0x7FFF`.
- Prefetch (ecriture de VMADDL ou VMADDH): `vram_latch = vram[remap(vmadd) & 0x7FFF]` (toujours, meme hors blank).
- VMDATAL ecriture: si `vram_ok()` alors `vram[ra].low = v`. Si `!vram_inc_on_high`: `vmadd = (vmadd + step) & 0x7FFF` (l'increment a lieu MEME si l'ecriture est bloquee).
- VMDATAH ecriture: idem sur l'octet haut; increment si `vram_inc_on_high`.
- Lecture $2139 (low): retourne `vram_latch & 0xFF`; si `!vram_inc_on_high`: `vram_latch = vram[ra]; vmadd += step`. Lecture $213A (high): retourne `vram_latch >> 8`; si `vram_inc_on_high`: meme rechargement et increment. (Le rechargement lit a l'adresse AVANT l'increment.)
- Lecture hors blank: `vram_latch` reste utilisable (valeur du dernier prefetch); `UNKNOWN - to confirm`: sur le vrai materiel lire pendant l'affichage actif donne 0. Defaut v1: si `!vram_ok()` la lecture retourne `0`.

## Tests
Tous les tests sont prefixes par `e04_01_`.

- `e04_01_remap_modes` : `remap(0,0x1234)==0x1234` ; `remap(1,0x1234)==0x12A1` ; `remap(2,0x1234)==0x13A0` ; `remap(3,0x1234)==0x11A4` ; `remap(1,0x0001)==0x0008` ; `remap(1,0x0020)==0x0001` ; `remap(2,0x0040)==0x0001` ; `remap(3,0x0080)==0x0001` ; `remap(2,0x0001)==0x0008` ; `remap(3,0x0001)==0x0008` ; `remap(1,0x00FF)==0x00FF` ; `remap(2,0x01FF)==0x01FF`.
- `e04_01_power_on` : `Vram::new()`: `vmain()==0`, `vmadd()==0`, `word(0)==0`, `word(0x7FFF)==0`, `mem().len()==0x8000`.
- `e04_01_step_values` : `set_vmain(0x00)`: step()==1, inc_on_high()==false ; `0x01`: 32 ; `0x02`: 128 ; `0x03`: 128 ; `0x80`: step 1 et inc_on_high()==true ; `0x8D`: step 32 et inc_on_high()==true.
- `e04_01_write_low_inc1` : vmain 0x00, adresse 0 (`set_addr_l(0); set_addr_h(0)`) : `write_low(0x11,true)`, `write_low(0x22,true)` -> `word(0)==0x0011`, `word(1)==0x0022`, `vmadd()==2` ; ensuite `write_high(0x33,true)` -> `word(2)==0x3300` et `vmadd()` reste 2 (increment sur l'octet bas seulement).
- `e04_01_write_word_inc_high` : vmain 0x80, adresse 0x0100 (`set_addr_l(0); set_addr_h(1)`) : `write_low(0xCD,true)` (vmadd reste 0x100), `write_high(0xAB,true)` -> `word(0x100)==0xABCD`, `vmadd()==0x101` ; puis `write_low(0x01,true); write_high(0x02,true)` -> `word(0x101)==0x0201`, `vmadd()==0x102`.
- `e04_01_step32_step128` : vmain 0x81, adresse 0 : `write_low(1,true); write_high(2,true)` -> `word(0)==0x0201`, `vmadd()==32` ; `write_low(3,true); write_high(4,true)` -> `word(32)==0x0403`, `vmadd()==64`. Puis vmain 0x82, adresse 0 : trois paires d'ecritures -> `vmadd()==384`, `word(128)!=0` et `word(256)!=0` (ecrites avec des valeurs non nulles).
- `e04_01_addr_wrap_mask` : vmain 0x00, `set_addr_l(0xFF); set_addr_h(0x7F)` -> `vmadd()==0x7FFF` ; `write_low(0x5A,true)` -> `word(0x7FFF)==0x005A` et `vmadd()==0` (masque 0x7FFF). `set_addr_l(0); set_addr_h(0xFF)` -> `vmadd()==0x7F00` (bit 7 de VMADDH ignore).
- `e04_01_blocked_write` : vmain 0x00, adresse 5 : `write_low(0x77,false)` -> `word(5)==0` et `vmadd()==6`. vmain 0x80, adresse 9 : `write_high(0x88,false)` -> `word(9)==0` et `vmadd()==10` ; `write_low(0x99,false)` ne change pas vmadd (reste 10).
- `e04_01_remap_applied` : vmain 0x04 (remap mode 1, increment 1, sur octet bas), adresse 1 : `write_low(0x99,true)` -> `word(8)==0x0099`, `word(1)==0`, `vmadd()==2` (vmadd n'est pas remappe).
- `e04_01_prefetch_on_addr` : `set_word(0x0100,0xCAFE)` ; vmain 0 ; `set_addr_l(0); set_addr_h(1)` -> `read_low(true)==0xFE`. Avec vmain 0x04 : `set_word(8,0xABCD)`, `set_addr_l(1); set_addr_h(0)` -> `read_low(true)==0xCD` (le prefetch utilise le remap).
- `e04_01_read_low_sequence` : `set_word(5,0xBEEF); set_word(6,0x1234); set_word(7,0x5678)`, vmain 0, `set_addr_l(5); set_addr_h(0)` : quatre `read_low(true)` renvoient 0xEF, 0xEF, 0x34, 0x78 (les deux premieres lectures renvoient le meme mot) et `vmadd()==9`.
- `e04_01_read_high_sequence` : `set_word(10,0xA1B2); set_word(11,0xC3D4)`, vmain 0x80, adresse 10 : `read_high(true)==0xA1` (vmadd 11) ; `read_low(true)==0xB2` (ne change ni le latch ni vmadd) ; `read_high(true)==0xA1` (vmadd 12) ; `read_high(true)==0xC3` (vmadd 13).
- `e04_01_read_blocked` : `set_word(20,0x1111)`, vmain 0, adresse 20 : `read_low(false)==0` et `vmadd()==21` ; ensuite `read_low(true)==0x11` (le latch a ete recharge par la lecture bloquee).
- `e04_01_hash` : hash identique pour deux `Vram::new()` ; differe apres `set_word(3,1)` ; differe apres `set_vmain(0x80)` ; differe apres `set_addr_l(1)` ; `reset_regs()` ne modifie pas la memoire (`word(3)` conserve).
