## Specification
`exec` traite `Mn::Sta`, `Mn::Stx`, `Mn::Sty`, `Mn::Stz`:
- valeur: STA -> `cpu.a`; STX -> `cpu.x`; STY -> `cpu.y`; STZ -> 0.
- largeur: STA et STZ `wide = !cpu.m8()`; STX et STY `wide = !cpu.x8()`.
- `let e = addr::ea(cpu, bus, am, true); addr::write_data(cpu, bus, &e, v, wide);` Aucun flag modifie. Retourne `true`.

### 3.2 Acces donnee

- Lecture: apres le calcul d'adresse, `R(addr)` octet bas, puis `R(addr+1)` octet haut si 16 bits.
- Ecriture: `W(addr, lo)` puis `W(addr+1, hi)` si 16 bits.
- L'adresse +1 d'une donnee 16 bits traverse les banques (24 bits) pour les modes a/al/a,x/al,x/a,y/(d)/[d]/(d),y ...;
  pour les modes direct page (d, d,x, d,y) l'octet haut est a (D + offset + 1) avec les regles de wrap de la section 4.
  `UNKNOWN - to confirm` cas par cas: laisser les tests JSON trancher.

## 6. Tests d'unite des familles (convention)

Les tests utilisent `FlatBus` (`cpu/testbus.rs`): `FlatBus::new()` ; `bus.poke(addr, &[octets])` ecrit sans journal ; `bus.peek(addr) -> u8` ;
`bus.log: Vec<Cycle>` avec `Cycle { addr: u32, val: u8, kind: CycleKind }`, `CycleKind::{Read, Write, Idle}` (un cycle `Idle` a `addr = 0` et `val = 0`) ;
`bus.clear_log()`. Un test pose le programme en `00:8000` (`cpu.pb = 0; cpu.pc = 0x8000`), fixe les registres a la main, fait `cpu.step(&mut bus)`, puis verifie
registres, memoire et `bus.log.len()` (= nombre de cycles de l'instruction, opcode compris) et, quand c'est precise, la suite exacte des cycles.
Un test peut ecrire `let cycles: Vec<(char, u32, u8)>` ou 'R'/'W'/'I' est le type: a lui de choisir une forme lisible, tant que adresse, valeur, ordre sont verifies.

## Tests
Tous les tests sont prefixes par `e02_16_`.

- `e02_16_sta_abs_8` : e=false, p=0x20, a=0x125A, `8D 00 20`: peek(0x2000)==0x5A ; cycles = 4 ; dernier cycle = Write 0x002000=0x5A ; P inchange.
- `e02_16_sta_abs_16` : p=0x00, a=0x1234, `8D 00 20`: peek(0x2000)==0x34, peek(0x2001)==0x12 ; cycles = 5 ; ecritures dans l'ordre 0x2000 puis 0x2001.
- `e02_16_sta_abs_x_8` : p=0x30, x=1, a=0x07, `9D 00 20`: peek(0x2001)==0x07 ; cycles = 5 (Idle force).
- `e02_16_sta_ind_y` : p=0x30, d=0, poke(0x30,&[0x00,0x20]), y=0x10, a=0x09, `91 30`: peek(0x2010)==0x09 ; cycles = 6.
- `e02_16_sta_dp` : p=0x20, d=0, `85 10`, a=0x33: peek(0x10)==0x33 ; cycles = 3.
- `e02_16_sta_long` : `8F 56 34 12`, a=0x44, p=0x20: peek(0x123456)==0x44 ; cycles = 5.
- `e02_16_stx_abs_16` : p=0x00, x=0xABCD, `8E 00 20`: peek(0x2000)==0xCD, peek(0x2001)==0xAB ; cycles = 5.
- `e02_16_sty_dp_8` : p=0x30, y=0x12, `84 10`: peek(0x10)==0x12 ; cycles = 3.
- `e02_16_stz_dp_16` : p=0x00, poke(0x10,&[0xFF,0xFF]), `64 10`: peek(0x10)==0 et peek(0x11)==0 ; cycles = 4.
- `e02_16_stz_abs_x` : p=0x20, x=0x0001 (X=0), poke(0x2001,&[0x55]), `9E 00 20`: peek(0x2001)==0 ; cycles = 5.
- `e02_16_flags_untouched` : p=0xE3 -> apres STA/STX/STZ p inchange (e=false).
