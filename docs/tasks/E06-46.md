## Specification
1. `dsp/mod.rs`: remplace le corps de `run_sample` (qui ne faisait rien):
```rust
pub fn run_sample(&mut self, ram: &mut [u8; 65536]) {
    self.step_counter_noise();
    self.scan_kon_koff();
    let (mut sum_l, mut sum_r, mut echo_l, mut echo_r, mut prev_out) = (0i32, 0i32, 0i32, 0i32, 0i32);
    for x in 0..8 {
        let (l, r) = self.voice_step(x, &*ram, prev_out);
        prev_out = self.voices[x].out;
        sum_l = clamp16(sum_l + l); sum_r = clamp16(sum_r + r);
        if self.regs[reg::EON as usize] >> x & 1 != 0 { echo_l = clamp16(echo_l + l); echo_r = clamp16(echo_r + r); }
    }
    let (ml, mr) = self.run_echo(ram, sum_l, sum_r, echo_l, echo_r);
    self.audio.push(ml as i16); self.audio.push(mr as i16);
    self.regs[reg::ENDX as usize] = self.endx;
}
fn scan_kon_koff(&mut self);   // 07b section 6 : every_other = !every_other ; si vrai : kon = new_kon ; new_kon = 0 ; koff = regs[KOFF] ; pour x in 0..8 : bit kon -> kon_delay = 5 et mode = Attack ; puis bit koff -> mode = Release. Ensuite (a CHAQUE echantillon) si regs[FLG] & 0x80 : pour chaque voix mode = Release et env = 0
```
(`clamp16` de `brr`.) La scrutation a lieu une fois par echantillon avant les voix.
2. `dsp/echo.rs`: squelette (remplace le commentaire), signature definitive:
```rust
impl Dsp {
    pub(super) fn run_echo(&mut self, ram: &mut [u8; 65536], sum_l: i32, sum_r: i32, echo_l: i32, echo_r: i32) -> (i32, i32);
}
```
Version provisoire: `ml = clamp16((sum_l * MVOLL as i8) >> 7)`, `mr` idem avec MVOLR ; si `regs[FLG] & 0x40` -> `(0, 0)` ; ne touche ni `ram` ni l'echo (parametres `echo_*` et `ram` non utilises: prefixer par `_` dans le corps).

## 3. Ordre d'un echantillon (`Dsp::run_sample(&mut self, ram: &mut [u8; 65536])`)
1. `counter = if counter == 0 { 0x77FF } else { counter - 1 }`.
2. Bruit: `if poll(counter, FLG & 0x1F) { fb = (noise << 13) ^ (noise << 14); noise = (fb & 0x4000) ^ (noise >> 1) }`.
3. Scrutation KON/KOFF et soft reset (07b section 6).
4. Les 8 voix dans l'ordre 0..7 (07b section 4); `sum_l/sum_r/echo_l/echo_r` remis a 0 avant.
5. Echo, sortie, ecriture echo (07b section 7); `audio.push(L); audio.push(R)`.
6. Mise a jour de `regs[ENDX] = endx`.

## 6. KON / KOFF / FLG
```
every_other = !every_other
if every_other {                     // un echantillon sur deux
    kon = new_kon; new_kon = 0; koff = regs[KOFF]
    for each voice x: if kon bit { kon_delay = 5; mode = Attack } ; then: if koff bit { mode = Release }
}
if FLG & 0x80 (soft reset): pour chaque voix { mode = Release; env = 0 } (a chaque echantillon)
```
(Si KON et KOFF sont a 1 pour la meme voix, la note est declenchee puis coupee: voix silencieuse.) `FLG bit 6` (mute): la sortie finale est 0 (le calcul continue). `FLG bit 5`: coupe l'ECRITURE de l'echo seulement.
