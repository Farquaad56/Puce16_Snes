impl Filter {
    pub fn from_name(s: &str) -> Filter;      // "nearest" | "linear" | "scanlines" ; tout autre texte -> Nearest
    pub fn name(self) -> &'static str;        // les memes trois noms
    pub fn next(self) -> Filter;              // Nearest -> Linear -> Scanlines -> Nearest

## 4. Fenetre, video, filtres, plein ecran

- Fenetre egui (`eframe`), titre `Puce16 - <nom de la ROM>`. Zone de jeu = `FrameView` (256x224 .. 512x478, spec 05 section 6) affichee dans une texture RGBA (conversion XRGB8888 -> `Color32`).
- Echelle: entier `1..=8` (defaut 3) ou "ajuster a la fenetre" ; ratio: pixels carres (defaut) ou 8:7 (largeur multipliee par 8/7).
- Filtres (option `filter`): `nearest` (defaut, `TextureOptions::NEAREST`), `linear` (`TextureOptions::LINEAR`), `scanlines` (nearest + une ligne sur deux assombrie a 75 % par pre-traitement CPU, uniquement en echelle >= 2).
- Plein ecran: `ViewportCommand::Fullscreen(true)` (sans bordure), memes regles d'echelle, curseur masque apres 2 s.
- Cadence: PAL 50.0070 Hz, NTSC 60.0988 Hz (valeurs de reference, flottants autorises ici). Synchronisation principale = audio (section 5) ; sans audio: minuteur monotone. Pause automatique quand la fenetre perd le focus (option, defaut: non).
- Menu minimal (barre egui): Fichier (Ouvrir, ROM recentes, Quitter), Emulation (Pause, Reset, Save/Load state, slot), Video (echelle, ratio, filtre, plein ecran), Audio (volume 0-100, muet), Entrees (liste des touches, lecture seule en v1), Debug (ouvrir le debugger).

## Tests
Tous les tests sont prefixes par `e08_25_`.

- `e08_25_filter_names` : `Filter::from_name("linear")==Linear` ; `"scanlines"` -> Scanlines ; `"nearest"`, `""`, `"weird"` -> Nearest ; `Linear.name()=="linear"`.
- `e08_25_filter_cycle` : `Nearest.next()==Linear`, `Linear.next()==Scanlines`, `Scanlines.next()==Nearest`.
- `e08_25_ratio_names` : `ratio_from_name("par87")==Par87` ; `"square"`, `"x"` -> Square ; `ratio_name(Par87)=="par87"`.
- `e08_25_scanlines_active` : `(Scanlines,1)` faux ; `(Scanlines,2)` vrai ; `(Scanlines,3)` vrai ; `(Nearest,3)` faux ; `(Linear,5)` faux.
- `e08_25_apply_scanlines_values` : image 2x4 pixels (width 2) toute a `[200,100,40,255]` : lignes 0 et 2 inchangees ; lignes 1 et 3: `[150,75,30,255]` (200*3/4=150, 100*3/4=75, 40*3/4=30).
- `e08_25_apply_scanlines_alpha` : alpha reste 255 sur toutes les lignes, et 7 si alpha vaut 7 au depart.
- `e08_25_apply_scanlines_odd_height` : image de 3 lignes : seule la ligne 1 est modifiee, pas de panique.
- `e08_25_apply_scanlines_empty` : `apply_scanlines(&mut [], 256)` ne panique pas ; `width == 0` ne panique pas.
