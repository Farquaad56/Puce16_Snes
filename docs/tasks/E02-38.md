## Specification
- CLC/SEC/CLI/SEI/CLD/SED/CLV: `bus.idle()`; `set_flag(..)`. 2 cycles.
- REP: `m = fetch8`; `bus.idle()`; `cpu.set_p(cpu.p & !m)`. SEP: idem avec `cpu.p | m`. 3 cycles. (set_p gere l'emulation et la mise a zero des octets hauts.)
- XCE: `bus.idle()`; `old_e = cpu.e`; `cpu.e = cpu.flag(FLAG_C)`; `set_flag(C, old_e)`; si `cpu.e`: `set_p(cpu.p)` (force M=X=1 et efface les octets hauts de X/Y) et `s = 0x0100 | (s & 0xFF)`. 2 cycles.
- XBA: `bus.idle(); bus.idle()`; `a = a.rotate_left(8)` (echange des octets); `set_nz8(a & 0xFF)`. 3 cycles.
- NOP: `bus.idle()`. 2 cycles.

### 5.2 Flags
- N/Z: mis par LDA/LDX/LDY, ADC SBC AND ORA EOR CMP CPX CPY, INC DEC (y compris INX INY DEX DEY), ASL LSR ROL ROR, PLA PLX PLY PLB PLD, transferts (TAX TAY TXA TYA TSX TXY TYX TCD TDC TCS? **TCS ne modifie aucun flag**; TSC et TDC mettent N/Z), XBA (N/Z sur l'octet bas de A apres echange).
- STA STX STY STZ, PHx, TXS, TCS, TSB/TRB (seul Z), BIT: BIT `#` ne modifie que Z; BIT mem modifie N=bit7 (ou bit15), V=bit6 (ou bit14), Z=(A & m)==0.
- TSB: Z=(A & m)==0; m = m | A. TRB: Z=(A & m)==0; m = m & ~A.
- CMP/CPX/CPY: calcul a - m en binaire: C = (a >= m), Z, N sur le resultat; V inchange.
- Flags de decalage: ASL C=bit sorti (7 ou 15); LSR C=bit0; ROL/ROR passent par C.
- CLC SEC CLI SEI CLD SED CLV: mettent/effacent le flag. REP: P &= ~imm; SEP: P |= imm (en E=1, M et X restent a 1; si X devient 1: X.h=Y.h=0).
- XCE: echange C et E. Apres: si E=1: M=X=1, X.h=Y.h=0, S.h=$01.
- PLP: si E=1, M=X=1 forces; si X devient 1: X.h=Y.h=0.
- TAX/TAY/etc: copie 16 bits si X=0 (ou M=0 pour TXA/TYA...) ; regle: la taille copiee = taille de la **destination**: TAX/TAY (dest X/Y) selon X; TXA/TYA (dest A) selon M; TSX selon X; TXS: en E=1 seulement octet bas (S.h=$01), en E=0 16 bits; TCS 16 bits (E=1: S.h=$01); TSC 16 bits; TCD/TDC 16 bits toujours; TXY/TYX selon X.
- XBA: echange octets de A (16 bits toujours), 3 cycles.
- Arithmetique decimale: voir 6.

## 5. Cycles des instructions implicites et de pile (complement de 01 section 7)

Apres le cycle opcode. `IO` = `bus.idle()`.
| Instruction | Cycles |
|---|---|
| PHA PHX PHY (8 bits) | `IO`; push (total 3). 16 bits: `IO`; push octet haut; push octet bas (total 4) |
| PHP PHB PHK | `IO`; push (total 3) |
| PHD | `IO`; push octet haut de D; push octet bas (total 4, pile "nouvelle") |
| PLA PLX PLY (8 bits) | `IO`; `IO`; pull (total 4). 16 bits: pull octet bas puis octet haut (total 5) |
| PLP PLB | `IO`; `IO`; pull (total 4) |
| PLD | `IO`; `IO`; pull bas; pull haut (total 5, pile "nouvelle") |
| PEA | `R(pc++)`=lo; `R(pc++)`=hi; push hi; push lo (total 5, pile "nouvelle") |
| PEI | `R(pc++)`=dp; [`IO` si DL != 0]; lit le mot en D+dp (lo puis hi, wrap bank 0); push hi; push lo (total 6, +1 si DL != 0; pile "nouvelle") |
| PER | `R(pc++)`=lo; `R(pc++)`=hi; `IO`; push de `(pc_apres_operande + off16)` octet haut puis bas (total 6; pile "nouvelle") |
| Transferts (TAX ...), CLC SEC CLI SEI CLD SED CLV, NOP, INX DEX INY DEY, formes accumulateur (INC A ...) | `IO` (total 2) |
| REP SEP | `R(pc++)`=masque; `IO` (total 3) |
| XBA | `IO`; `IO` (total 3) |
| XCE | `IO` (total 2) |
Les instructions "nouvelles" appellent `cpu.fix_stack_e()` en fin d'instruction.
PHP pousse P tel quel (en emulation: bits 5 et 4 = 1 car M=X=1: B=1 pour PHP). PLP appelle `set_p(valeur)`.

## 6. Tests d'unite des familles (convention)

Les tests utilisent `FlatBus` (`cpu/testbus.rs`): `FlatBus::new()` ; `bus.poke(addr, &[octets])` ecrit sans journal ; `bus.peek(addr) -> u8` ;
`bus.log: Vec<Cycle>` avec `Cycle { addr: u32, val: u8, kind: CycleKind }`, `CycleKind::{Read, Write, Idle}` (un cycle `Idle` a `addr = 0` et `val = 0`) ;
`bus.clear_log()`. Un test pose le programme en `00:8000` (`cpu.pb = 0; cpu.pc = 0x8000`), fixe les registres a la main, fait `cpu.step(&mut bus)`, puis verifie
registres, memoire et `bus.log.len()` (= nombre de cycles de l'instruction, opcode compris) et, quand c'est precise, la suite exacte des cycles.
Un test peut ecrire `let cycles: Vec<(char, u32, u8)>` ou 'R'/'W'/'I' est le type: a lui de choisir une forme lisible, tant que adresse, valeur, ordre sont verifies.

## Tests
Tous les tests sont prefixes par `e02_38_`.

- `e02_38_flag_ops` : pour chacun de CLC SEC CLI SEI CLD SED CLV (18 38 58 78 D8 F8 B8): depart p=0xFF (e=false) pour les Clx, p=0x00 pour les Sxx: le bit correspondant (C,C,I,I,D,D,V) vaut la valeur attendue, les autres bits inchanges ; cycles=2.
- `e02_38_rep_native` : e=false, p=0xFF, `C2 30`: p==0xCF ; cycles=3.
- `e02_38_rep_keeps_emulation` : e=true, p=0x30, `C2 30`: p==0x30.
- `e02_38_sep_clears_index_high` : e=false, p=0x00, x=0x1234, y=0x5678, `E2 10`: p==0x10, x==0x0034, y==0x0078 ; cycles=3.
- `e02_38_xce_to_native` : e=true, p=0x30 (C=0), `FB`: e==false, C=1, p==0x31 ; cycles=2.
- `e02_38_xce_to_emulation` : e=false, p=0x01 (M=0,X=0,C=1), x=0x1234, y=0x5678, s=0x1234, `FB`: e==true, C=0, p==0x30, x==0x0034, y==0x0078, s==0x0134.
- `e02_38_xba` : a=0x1280, `EB`: a==0x8012, N=0 (octet bas 0x12), Z=0 ; cycles=3.
- `e02_38_xba_zero` : a=0x0012, `EB`: a==0x1200, Z=1.
- `e02_38_nop` : `EA`: pc==0x8001, cycles=2, registres inchanges.
