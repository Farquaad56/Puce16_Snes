### 4.1 Interpolation gaussienne (table `GAUSS[512]`, voir section 8)
```
let (a, b, c, d) = window;                // a = le plus ancien, i16 echelle 16 bits
let mut o = (GAUSS[255 - f] * a) >> 11;
o += (GAUSS[511 - f] * b) >> 11;
o += (GAUSS[256 + f] * c) >> 11;
o = o as i16 as i32;                       // repliement 16 bits: BUG materiel (3 valeurs max-negatives -> bruit fort), a conserver
o += (GAUSS[f] * d) >> 11;
sample = clamp16(o) & !1
```

## Tests
Tous les tests sont prefixes par `e06_42_`.

- `e06_42_zero_window` : `gauss_interp(0,0,0,0,f)==0` pour f in {0,1,100,255}.
- `e06_42_newest_has_zero_weight_at_f0` : `gauss_interp(0,0,0,12345,0)==0` (car `GAUSS[0]==0`).
- `e06_42_constant_positive` : pour f in {0,1,64,127,128,200,255} : `r = gauss_interp(10000,10000,10000,10000,f)` verifie `9980 <= r && r <= 10020` et `r % 2 == 0`.
- `e06_42_constant_negative` : meme chose avec -10000 : `-10020 <= r && r <= -9980` et `r & 1 == 0`.
- `e06_42_matches_reference_formula` : pour f in 0..256 et les fenetres `(1000,-2000,3000,-4000)`, `(32767,32767,32767,32767)`, `(-32768,-32768,-32768,0)`, `(-32768,-32768,-32768,-32768)` : le resultat egale une implementation de reference ecrite DANS LE TEST avec `i64` et `as i16` explicites, sur `puce16_core::apu::dsp::gauss::GAUSS`.
- `e06_42_clamps_to_16_bits` : `gauss_interp(32767,32767,32767,32767,f)` est dans `-32768..=32767` pour tout f (aucune panique de debordement en mode debug).
- `e06_42_frac_masked` : `gauss_interp(100,200,300,400,256)==gauss_interp(100,200,300,400,0)`.
