Dans `snes.rs`:

```rust
#[derive(Clone, Debug, PartialEq, Eq)] pub struct SmpSnapshot { pub a: u8, pub x: u8, pub y: u8, pub sp: u8, pub pc: u16, pub psw: u8 }
#[derive(Clone, Debug, PartialEq, Eq)] pub struct DmaChanSnapshot { pub dmap: u8, pub bbad: u8, pub a1t: u16, pub a1b: u8, pub das: u16, pub dasb: u8 }
impl Snes {
    pub fn debug_vram(&self) -> &[u16];           // 32768 mots (Motif: &[])
    pub fn debug_cgram(&self) -> &[u16];          // 256 mots
    pub fn debug_oam(&self) -> &[u8];             // 544 octets
    pub fn debug_ppu_regs(&self) -> Option<crate::ppu::PpuRegsSnapshot>;   // Ppu::regs_snapshot() ; Motif: None
    pub fn debug_smp(&self) -> Option<SmpSnapshot>;
    pub fn debug_dma(&self) -> Option<[DmaChanSnapshot; 8]>;
    pub fn debug_wram_page(&self, page: u16) -> Vec<u8>;       // 256 octets de la WRAM, page 0..=511 (page & 0x1FF), via peek_wram ; Motif: 256 zeros
    /// execute des instructions (step_instruction) jusqu'a ce que PB:PC == (pb, pc) AVANT d'executer l'instruction a cette adresse ; au plus `max_instructions`. Renvoie vrai si l'adresse est atteinte. Si PB:PC vaut deja l'adresse au depart: renvoie vrai SANS rien executer.
    pub fn debug_run_until_pc(&mut self, pb: u8, pc: u16, max_instructions: u32) -> bool;
}
```

## 8. Debugger (fenetre egui separee, ouverte par F10)

Envoie `RequestDebug(true)` ; le thread d'emulation joint a chaque frame un `DebugData` = `{ snapshot: DebugSnapshot, vram: Vec<u16> (32768), cgram: Vec<u16> (256), oam: Vec<u8> (544), wram_page: Vec<u8> (256 octets de la page choisie), ppu_regs: Option<PpuRegsSnapshot>, smp: Option<SmpSnapshot>, dma: Option<[DmaChanSnapshot; 8]> }` (les `Vec` sont vides et les `Option` sont `None` pour le motif de test).
Panneaux (v1):
1. **Registres**: CPU (A, X, Y, S, D, DB, PB, PC, P avec drapeaux N V M X D I Z C et e), SMP (A, X, Y, SP, PC, PSW), position (frame, V, H, master), registres PPU principaux (INIDISP, BGMODE, TM, TS, CGWSEL, CGADSUB, SETINI), registres DMA actifs.
2. **VRAM - tuiles**: grille de tuiles 8x8, choix profondeur 2/4/8 bpp, palette (0..15 ou 0..7), adresse de base en mots (curseur par pas de 0x400), zoom 1-4.
3. **VRAM - cartes**: rendu de la carte d'un BG (1..4) avec ses reglages courants (taille de carte, tuile 8/16) ; mode 7 : carte 128x128 en 1024x1024.
4. **Palettes**: 256 pastilles CGRAM, survol = indice + valeur.
5. **OAM**: tableau des 128 sprites (x, y, tuile, palette, priorite, taille, flips).
6. **Memoire**: vue hexadecimale de WRAM (page de 256 octets, navigation par 256).
Commandes d'execution: Pause, Reprendre, Avancer une frame, Avancer une instruction CPU (via commande `StepInstruction`), Executer jusqu'a un PC (un seul point d'arret `PC`, saisi en hexadecimal). Pas de desassembleur en v1 (hors perimetre).

## Tests
Tous les tests sont prefixes par `e08_32_`.

- `e08_32_pattern_variant_empty` : `Snes::new_test_pattern(Ntsc)`: `debug_vram().is_empty()`, `debug_cgram().is_empty()`, `debug_oam().is_empty()`, `debug_ppu_regs().is_none()`, `debug_smp().is_none()`, `debug_dma().is_none()`, `debug_wram_page(0)==vec![0u8;256]`.
- `e08_32_real_sizes` : ROM `make_rom(&[0x80,0xFE], LoRom)` : `debug_vram().len()==32768`, `debug_cgram().len()==256`, `debug_oam().len()==544`, `debug_ppu_regs().is_some()`, `debug_smp().is_some()`, `debug_dma().is_some()`.
- `e08_32_wram_page_content` : programme `78 18 FB A9 42 8D 10 00 80 FE` (SEI CLC XCE LDA #$42 STA $0010 BRA -2), apres `run_frame()` : `debug_wram_page(0)[0x10]==0x42` ; `debug_wram_page(1)[0x10]==0` ; la page renvoyee a 256 octets ; `debug_wram_page(512)` == `debug_wram_page(0)` (masque 0x1FF).
- `e08_32_run_until_pc_reaches` : meme programme, au reset: `debug_run_until_pc(0, 0x8008, 100)==true`, `debug().pc==0x8008`, `debug().pb==0`, `peek_wram(0x10)==0x42`.
- `e08_32_run_until_pc_already_there` : au reset (PC 0x8000): `debug_run_until_pc(0, 0x8000, 100)==true` et `debug().pc==0x8000` (rien execute).
- `e08_32_run_until_pc_limit` : adresse jamais atteinte `debug_run_until_pc(0, 0x9000, 50)==false` ; le CPU a avance (`debug().pc` est dans `0x8000..=0x8009`) sans panique.
- `e08_32_smp_snapshot_after_boot` : apres 2 `run_frame()` de la ROM `make_rom(&[0x80,0xFE], LoRom)`: `debug_smp()` est `Some` et sa lecture ne panique pas (aucune valeur precise: l'etat exact du SMP est couvert par E06).
