## Specification
Programme (a placer en tete du code, adresse CPU $00:8000 = decalage 0 de la ROM LoROM; `build_rom_with(&[(0, &PROG), (0x100, &stream)], &[("reset", 0x8000)], 0, 0x43)`):
```
78 18 FB                 SEI ; CLC ; XCE
A9 01  8D 00 48          LDA #$01 ; STA $4800        (activation hard canal 0)
       8D 01 48          STA $4801                   (activation soft canal 0)
A9 08  8D 00 43          LDA #$08 ; STA $4300        (DMAP: A->B, adresse A FIXE, mode 0)
A9 80  8D 01 43          LDA #$80 ; STA $4301        (B-bus $2180 = WRAM data)
A9 00  8D 02 43          LDA #$00 ; STA $4302        (adresse source $C0:0100)
A9 01  8D 03 43          LDA #$01 ; STA $4303
A9 C0  8D 04 43          LDA #$C0 ; STA $4304
A9 40  8D 05 43          LDA #$40 ; STA $4305        (taille $0040 = 64 octets)
A9 00  8D 06 43          LDA #$00 ; STA $4306
       8D 81 21          STA $2181                   (adresse WRAM = $7E:0000)
       8D 82 21          STA $2182
       8D 83 21          STA $2183
A9 01  8D 0B 42          LDA #$01 ; STA $420B        (MDMAEN: canal 0)
80 FE                    BRA -2
```
`stream` = `lcg_bytes(0x1000 + k, 4096)` avec `data[0] = (data[0] & 0x0F) | (k << 4)`. Le programme occupe les octets 0..0x50 de la ROM, le flux commence a 0x100: aucun recouvrement. Apres `Snes::new(&rom, None)` puis 2 appels de `run_frame()`, comparer `peek_wram(i)` pour i dans 0..64 avec les 64 octets attendus (colonne `output_hex_first64` de `docs/specs/data/sdd1_vectors.tsv`, ligne dont `header` = `k << 4`).
Controle sans S-DD1: meme programme avec chipset `0x00`: la DMA a adresse fixe copie 64 fois le meme octet, donc `peek_wram(i) == rom[0x100]` pour tout i.
Generateur de flux de test (identique a `docs/tools/sdd1_ref.py`): `fn lcg_bytes(seed: u32, n: usize) -> Vec<u8> { let mut x = seed; (0..n).map(|_| { x = x.wrapping_mul(1664525).wrapping_add(1013904223); (x >> 24) as u8 }).collect() }`. Fermeture de ROM des tests: `let rom = |a: u32| data[(a as usize) % data.len()];` (lecture cyclique).

## 5. Interception DMA
Le S-DD1 espionne les ecritures du S-CPU aux registres DMA `$43x2-$43x6` (x = canal 0..7) et garde pour chaque canal une copie:
```
$43x2 -> addr bits 0-7     $43x3 -> addr bits 8-15     $43x4 -> addr bits 16-23
$43x5 -> size bits 0-7     $43x6 -> size bits 8-15      (size: u16; la valeur 0 reste 0, voir ci-dessous)
```
L'ecriture est quand meme transmise au DMA normal. Les jeux programment un DMA en mode **adresse A fixe** (bit 3 de `$43x0`): chaque lecture de l'octet suivant se fait donc a la meme adresse source, et c'est le S-DD1 qui renvoie un octet decompresse different a chaque lecture.

Lecture a une adresse `addr` dans les banques C0-FF (`mcu_read`):
```
si (r4800 & r4801) != 0:
    pour n = 0..7:
        si (r4800 bit n) et (r4801 bit n) et addr == dma[n].addr:
            si !dma_ready: decompressor.init(addr); dma_ready = true
            octet = decompressor.read()
            dma[n].size = dma[n].size.wrapping_sub(1)
            si dma[n].size == 0: dma_ready = false; r4801 &= !(1 << n)
            retourner octet
retourner rom[mmc_offset(addr)]          // pas de decompression: ROM normale
```
Le decompresseur lit les octets compresses par la fenetre MMC (`rom[mmc_offset(a)]` pour une adresse 24 bits `a` qui commence a `addr` et s'incremente). Une taille initiale 0 signifie 65536 octets (le decompte `0 -> 0xFFFF` fait le tour).

## 9. Plan de test
1. Tables: `RUNCOUNT` et `EVOLUTION` egales aux lignes de `sdd1_tables.tsv`.
2. Etages: valeurs concretes des taches E09-02..04 (IM, GCD, BG, PEM, CM).
3. Vecteurs d'or: 16 en-tetes `$00,$10,...,$F0`, flux = 4096 octets d'un generateur congruentiel (`x = x * 1664525 + 1013904223 mod 2^32`, octet = `x >> 24`, graine `0x1000 + n`, premier octet `(b & 0x0F) | (n << 4)`), lecture cyclique (`rom(a) = data[a % 4096]`): les 64 premiers octets decompresses et les FNV-64 (offset `0xcbf29ce484222325`, premier `0x100000001b3`) des 256 puis 8192 premiers octets doivent egaler `sdd1_vectors.tsv`.
4. Registres et mappage: valeurs de la section 3 et 4.
5. DMA: espionnage, decompte, effacement de `r4801`.
6. Bout en bout: ROM synthetique avec chipset `$43`, DMA d'une zone decompressee vers la WRAM (E09-10).
7. Gate: Street Fighter Alpha 2 et Star Ocean fournis par l'utilisateur (E09-11).

## Tests
Tous les tests sont prefixes par `e09_10_`.

- `e09_10_wram_gets_decompressed_header_00` : k = 0: WRAM[0..64] == 64 octets de la ligne header 00 du TSV (commencent par 75 12 24 91)
- `e09_10_wram_gets_decompressed_header_30` : k = 3: WRAM[0..64] == ligne header 30 (commencent par 45 56 11 a4)
- `e09_10_wram_gets_decompressed_mode7_c0` : k = 12 (en-tete 0xC0): WRAM[0..64] == ligne header c0 (commencent par 3a 66 c6 48)
- `e09_10_without_sdd1_same_byte_repeated` : chipset 0x00: tous les octets WRAM[0..64] egalent rom[0x100]
