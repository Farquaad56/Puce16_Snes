## Specification
1. `dsp/mod.rs`: `pub mod reg { ... }` avec, toutes de type `u8`: `MVOLL=0x0C MVOLR=0x1C EVOLL=0x2C EVOLR=0x3C KON=0x4C KOFF=0x5C FLG=0x6C ENDX=0x7C EFB=0x0D PMON=0x2D NON=0x3D EON=0x4D DIR=0x5D ESA=0x6D EDL=0x7D` et les decalages de voix `VOLL=0 VOLR=1 PITCHL=2 PITCHH=3 SRCN=4 ADSR1=5 ADSR2=6 GAIN=7 ENVX=8 OUTX=9`, plus deux fonctions `pub fn fir(i: usize) -> u8 { 0x0F + 0x10 * i as u8 }` et `pub fn vreg(x: usize, off: u8) -> usize { x * 16 + off as usize }` (indice dans `regs` du registre `off` de la voix `x`). Dans le code, on indexe `regs` par `reg::X as usize`. `pub mod tables; pub mod brr; pub mod voice; pub mod envelope; pub mod echo;`, la struct `Dsp` de 07d section 2 (champs prives) et:

## 1. Registres (acces via $F2/$F3, 128 octets, `regs[0x80]`)
Voix `x` (0..7), base `x*0x10`: `+0 VOLL(i8) +1 VOLR(i8) +2 PITCHL +3 PITCHH(6 bits) +4 SRCN +5 ADSR1 +6 ADSR2 +7 GAIN +8 ENVX +9 OUTX`.
Globaux: `$0C MVOLL $1C MVOLR $2C EVOLL $3C EVOLR $4C KON $5C KOFF $6C FLG $7C ENDX $0D EFB $2D PMON $3D NON $4D EON $5D DIR $6D ESA $7D EDL`, FIR: `$0F,$1F,...,$7F` = FIR0..FIR7 (i8). `$1D`, `$xA`, `$xB`, `$xE`: stockes sans effet.
- Ecriture: `regs[a] = v`, sauf: `$4C` -> `new_kon = v` (et `regs[$4C] = v`); `$7C` (ENDX): toute ecriture met `endx = 0` (`UNKNOWN - to confirm`). ENVX/OUTX/ENDX sont mis a jour par le DSP a chaque echantillon (`regs[x8] = env >> 4`, `regs[x9] = out >> 8`, `regs[$7C] = endx`).
- Lecture: `regs[a]`.
- Power-on: tous les registres 0 sauf `FLG = $E0`; `counter = 0`, `noise = 0x4000`, `every_other = true`, echo offset/length 0, historiques FIR 0. Reset DSP: `FLG = $E0` (les autres registres sont conserves, `UNKNOWN`).

## Tests
Tous les tests sont prefixes par `e06_31_`.

- `e06_31_power_on` : `Dsp::new()`: `read(0x6C)==0xE0` ; `read(a)==0` pour a in 0..0x80 sauf 0x6C ; `new_kon()==0` ; `endx()==0` ; `take_audio()` vide.
- `e06_31_write_read` : `write(0x00,0x55)`: `read(0x00)==0x55` ; `write(0x0F,0x7F)` (FIR0): `read(0x0F)==0x7F` ; registres sans effet stockes tels quels : `write(0x1D,0x9A)`: `read(0x1D)==0x9A`.
- `e06_31_address_mask` : `write(0x81,0x07)`: `read(0x01)==0x07` et `read(0x81)==0x07` (adresse masquee a 7 bits).
- `e06_31_kon_write` : `write(0x4C,0x03)`: `read(0x4C)==0x03` et `new_kon()==0x03`.
- `e06_31_endx_write_clears` : `debug_set_endx(0xFF)` : `endx()==0xFF` ; `write(0x7C,0x12)`: `endx()==0` et `read(0x7C)==0`.
- `e06_31_reset_keeps_registers` : `write(0x00,1)`, `write(0x6C,0x20)`, `write(0x4C,1)` ; `reset()` : `read(0x6C)==0xE0`, `read(0x00)==1` (conserve), `new_kon()==0`.
- `e06_31_reg_constants` : `reg::MVOLL==0x0C`, `reg::FLG==0x6C`, `reg::EDL==0x7D`, `reg::fir(0)==0x0F`, `reg::fir(7)==0x7F`, `reg::vreg(3, reg::GAIN)==0x37`, `reg::vreg(7, reg::OUTX)==0x79`.
- `e06_31_voice_new` : `Voice::new()`: kon_delay==0, mode==Mode::Release, env==0, hidden_env==0, buf==[0;12], interp_pos==0, p1==0, p2==0.
- `e06_31_hash_changes` : deux `Dsp::new()` ont le meme hash (Fnv64) ; apres `write(0x00,1)` il differe ; apres `debug_set_endx(1)` il differe aussi.
- `e06_31_take_audio_drains` : `take_audio()` deux fois de suite : les deux vides (rien n'est produit encore).
