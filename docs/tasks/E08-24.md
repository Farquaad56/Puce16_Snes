## Specification
Dans `config.rs` (serde + serde_json deja en dependances):
```rust
#[derive(Clone, PartialEq, Debug, serde::Serialize, serde::Deserialize)]
#[serde(default)]
pub struct Config {
    pub scale: u8,                         // 1..=8, defaut 3
    pub fit_window: bool,                  // defaut false
    pub ratio: String,                     // "square" (defaut) | "par87"
    pub filter: String,                    // "nearest" (defaut) | "linear" | "scanlines"
    pub volume: u8,                        // 0..=100, defaut 100
    pub muted: bool,                       // defaut false
    pub fullscreen: bool,                  // defaut false
    pub block_opposite_dirs: bool,         // defaut true
    pub pause_on_focus_loss: bool,         // defaut false
    pub recent_roms: Vec<String>,          // max 8, le plus recent en premier
    pub last_dir: String,                  // defaut ""
    pub keymap: std::collections::BTreeMap<String, Vec<String>>,   // bouton SNES -> noms de touches ; vide = defauts du code
    pub pad_map: std::collections::BTreeMap<String, String>,       // bouton SNES -> nom de bouton manette ; vide = defauts
}
impl Default for Config { ... }
impl Config {
    pub fn sanitize(&mut self);                         // scale -> 1..=8 ; volume -> <= 100 ; ratio/filter inconnus -> defaut ; recent_roms tronquee a 8 sans doublons
    pub fn add_recent(&mut self, path: &str);           // met `path` en tete, retire l'ancien doublon, tronque a 8
    pub fn to_json(&self) -> String;                    // serde_json::to_string_pretty + "\n"
    pub fn from_json(text: &str) -> Config;             // jamais d'erreur : JSON invalide -> Config::default() ; puis sanitize
}
pub fn config_dir_from(appdata: Option<&str>, home: Option<&str>) -> Option<std::path::PathBuf>;
pub fn config_path() -> Option<std::path::PathBuf>;     // lit les variables d'environnement APPDATA et HOME puis config_dir_from(..).map(|d| d.join("config.json"))
pub fn load() -> Config;                                // lit config_path ; absent/illisible -> defaut
pub fn save(cfg: &Config) -> Result<(), String>;        // cree le dossier, write_atomic de to_json
```
`config_dir_from`: si `appdata` est `Some(non vide)` -> `<appdata>/Puce16` ; sinon si `home` est `Some(non vide)` -> `<home>/.config/puce16` ; sinon `None`.

## 6. Fichiers

- Ouverture: `rfd` (filtres `.sfc`, `.smc`, `.swc`, `.fig`, `.zip`). Un `.zip` (crate `zip`) : prendre la premiere entree dont l'extension est une des quatre precedentes.
- **SRAM**: `<dossier de la ROM>/<nom sans extension>.srm`, octets bruts de `Snes::sram()`. Chargee a l'ouverture de la ROM (`load_sram`) ; sauvee toutes les 5 s si le contenu a change, a la fermeture de la ROM et a la sortie ; ecriture atomique (ecrire `.srm.tmp` puis renommer). Pas de SRAM (`None`) -> aucun fichier.
- **Save states**: `<dossier de la ROM>/<nom>.<slot>.p16s`, slot 0..9. Contenu: en-tete `b"P16S"` + `u16` version du conteneur (1) + `u64` hash FNV-64 des octets de la ROM tels que charges (apres extraction d'un `.zip`, avant toute normalisation du core) + `u8` region, puis le blob `Snes::save_state()`. Au chargement: refuser (message) si magie, version ou hash ROM different.
- **Config**: `config.json` dans `%APPDATA%\Puce16\` (Windows) ; a defaut `$HOME/.config/puce16/`. JSON: `scale, ratio, filter, volume, muted, fullscreen, keymap, pad_map, recent_roms (max 8), last_dir, block_opposite_dirs`. Fichier absent ou invalide -> valeurs par defaut (jamais de plantage).
- Capture d'ecran F2: `<nom>_<n>.ppm` dans le dossier de la ROM (n = premier numero libre).

## 4. Fenetre, video, filtres, plein ecran

- Fenetre egui (`eframe`), titre `Puce16 - <nom de la ROM>`. Zone de jeu = `FrameView` (256x224 .. 512x478, spec 05 section 6) affichee dans une texture RGBA (conversion XRGB8888 -> `Color32`).
- Echelle: entier `1..=8` (defaut 3) ou "ajuster a la fenetre" ; ratio: pixels carres (defaut) ou 8:7 (largeur multipliee par 8/7).
- Filtres (option `filter`): `nearest` (defaut, `TextureOptions::NEAREST`), `linear` (`TextureOptions::LINEAR`), `scanlines` (nearest + une ligne sur deux assombrie a 75 % par pre-traitement CPU, uniquement en echelle >= 2).
- Plein ecran: `ViewportCommand::Fullscreen(true)` (sans bordure), memes regles d'echelle, curseur masque apres 2 s.
- Cadence: PAL 50.0070 Hz, NTSC 60.0988 Hz (valeurs de reference, flottants autorises ici). Synchronisation principale = audio (section 5) ; sans audio: minuteur monotone. Pause automatique quand la fenetre perd le focus (option, defaut: non).
- Menu minimal (barre egui): Fichier (Ouvrir, ROM recentes, Quitter), Emulation (Pause, Reset, Save/Load state, slot), Video (echelle, ratio, filtre, plein ecran), Audio (volume 0-100, muet), Entrees (liste des touches, lecture seule en v1), Debug (ouvrir le debugger).

## Tests
Tous les tests sont prefixes par `e08_24_`.

- `e08_24_defaults` : `Config::default()`: scale 3, ratio `square`, filter `nearest`, volume 100, `muted==false`, `block_opposite_dirs==true`, `recent_roms` vide.
- `e08_24_roundtrip` : config modifiee (scale 5, filter `scanlines`, volume 40, 2 ROM recentes, une entree dans `keymap`) -> `to_json` -> `from_json` == original.
- `e08_24_invalid_json_gives_defaults` : `from_json("not json")==Config::default()` ; `from_json("")==Config::default()`.
- `e08_24_partial_json` : `from_json("{\"scale\": 6}")`: scale 6, tous les autres champs par defaut.
- `e08_24_sanitize` : `scale 0` -> 1 ; `scale 99` -> 8 ; `volume 250` -> 100 ; `ratio "weird"` -> `square` ; `filter "x"` -> `nearest` ; 12 ROM recentes -> 8.
- `e08_24_add_recent` : ajouter `a`, `b`, `a` -> `["a","b"]` (le doublon remonte en tete) ; 10 ajouts distincts -> longueur 8 et le dernier ajoute en tete.
- `e08_24_config_dir` : `config_dir_from(Some("C:/Users/x/AppData/Roaming"), None)` -> `C:/Users/x/AppData/Roaming/Puce16` ; `(None, Some("/home/x"))` -> `/home/x/.config/puce16` ; `(Some(""), Some("/home/x"))` -> la branche HOME ; `(None, None)` -> `None`.
- `e08_24_save_load_in_temp` : `save` n'est pas teste sur le vrai dossier utilisateur : tester `to_json`/`from_json` + `files::write_atomic` dans un dossier temporaire (fichier relu == `to_json`).
