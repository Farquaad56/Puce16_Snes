# E03-21 - dma/hdma.rs: hdma_init (debut de frame)
Epopee: E03 | Type: code | Dependances: E03-20 | Taille estimee: ~130 lignes

## Contexte
Initialisation HDMA a chaque debut de frame (spec 03 section 4.1). Le PREMIER transfert n'a pas lieu ici: il est execute par `hdma_run_line` a la ligne 0 (E03-22).
Temps: `elapse(18)` une fois (si `mask != 0`), puis `elapse(8)` par canal actif. La lecture des octets de table ne coute rien (`UNKNOWN - to confirm`). Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## Specification
Dans `dma/hdma.rs`: `impl Dma { pub fn hdma_init<B: DmaBus>(&mut self, bus: &mut B, mask: u8); pub fn hdma_state(&self, n: usize) -> (u16, u8, bool, bool); }`
`hdma_state(n)` renvoie `(a2a, line_counter, do_transfer, done)` du canal `n`.
Algorithme de `hdma_init`: si `mask == 0` retourner sans rien faire. `bus.elapse(18)`. Pour chaque canal `n` dont le bit est dans `mask` (ordre 0..7): `bus.elapse(8)` ; `a2a = a1t` ; lire `b = bus.a_read((a1b << 16) | a2a)` ; `a2a = a2a.wrapping_add(1)` ; `nltr = b` ;
- si `b == 0`: `done = true; do_transfer = false; line_counter = 0` ; fin pour ce canal ;
- sinon: `done = false; do_transfer = true; line_counter = if b & 0x7F == 0 { 128 } else { b & 0x7F }` ; si le mode est indirect (`dmap & 0x40 != 0`): lire `lo` puis `hi` aux adresses `(a1b << 16) | a2a` (a2a +1 apres chaque lecture, wrap 16 bits), `das = (hi << 8) | lo`.
Les canaux hors `mask` ne sont pas modifies. Une lecture A-bus passe par `bus.a_read` (aucun `elapse`).

### 4.1 Initialisation (debut de chaque frame)
A V=0, H ~ debut de ligne (`HDMA_INIT_HCLOCK` defaut 12 clocks, `UNKNOWN - to confirm`), pour chaque canal actif:
1. `A2An = A1Tn` (16 bits bas).
2. Lire l'octet de ligne `NLTRn` depuis `(A1Bn:A2An)`, `A2An++`.
3. Si NLTRn == $00: le canal est termine pour la frame (flag `done`).
4. Mode indirect (DMAPn bit6): lire 2 octets suivants `(A1Bn:A2An)` -> `DASn` (lo, hi), `A2An += 2`; banque indirecte = DASBn.
5. Premier transfert (voir 4.2) avec le meme flag "do transfer".

## 5. HDMA: declenchement
- `pending_hdma_init`: `Timing` renvoie `hdma_init` a (v == 0, dot == HDMA_INIT_DOT) si `mmio.hdmaen != 0` (valeur au moment du declenchement).
- `pending_hdma_run`: `hdma_run` a (v in 0..=vis_last, dot == HDMA_RUN_DOT) si `mmio.hdmaen != 0`.
- Execution dans `begin_cycle`: init: `dma.hdma_init(self, mmio.hdmaen)`; run: `dma.hdma_run_line(self, mmio.hdmaen)`. Surcout: `bus.elapse(18)` (une fois par appel) + 8 par canal actif + 8 par octet (spec 03 4.3), appliques par le moteur HDMA.
- Un canal HDMA actif est un canal dont le bit est dans `hdmaen` et dont `done == false`.

## Tests

- `e03_21_direct_basic` : FakeBus; ch0: dmap=0x00, bbad=0x26, a1b=0x7E, a1t=0x2000 ; `poke(0x7E2000, 0x03)`. `hdma_init(&mut bus, 1)`: `hdma_state(0)==(0x2001, 3, true, false)` ; `ch[0].nltr==3` ; `bus.master==26` (18+8) ; `b_writes()` vide.
- `e03_21_event_order` : meme test: `bus.ev==[Elapse(18), Elapse(8), ARead(0x7E2000)]`.
- `e03_21_zero_first_byte` : table `0x00`: `hdma_state(0)==(0x2001, 0, false, true)`.
- `e03_21_repeat_flag_count` : octet 0x85: `line_counter==5`, `ch.nltr==0x85`. Octet 0x80: `line_counter==128`. Octet 0x01: 1. Octet 0x7F: 127. Octet 0xFF: 127.
- `e03_21_indirect` : dmap=0x40, a1t=0x3000, table `[0x02, 0x00, 0x40]`: `hdma_state(0)==(0x3003, 2, true, false)` et `ch[0].das==0x4000`.
- `e03_21_indirect_zero_line` : dmap=0x40, table `[0x00, 0x11, 0x22]`: done=true, a2a==0x3001 (pas de lecture des 2 octets indirects).
- `e03_21_mask_selects` : ch0 et ch2 actifs, ch1 pas: ch1 inchange (`hdma_state(1)==(0xFFFF, 0, false, true)` au power-on) ; `bus.master==18+8+8==34` ; les ARead arrivent dans l'ordre ch0 puis ch2.
- `e03_21_empty_mask` : `hdma_init(&mut bus, 0)`: aucun evenement, `bus.master==0`.
- `e03_21_a2a_wrap` : a1t=0xFFFF, table octet a 7E:FFFF = 0x02 : apres init `a2a==0x0000` (wrap dans la banque).
- `e03_21_reinit_resets_done` : un canal `done=true` (octet 0) re-initialise avec un octet non nul repasse a `done=false, do_transfer=true`.
