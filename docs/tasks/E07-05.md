## Specification
Dans `suite/baseline.rs` (tests unitaires dans le fichier, noms `e07_05_...`):
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub struct Entry { pub frames: u32, pub frame_hash: u64, pub state_hash: u64, pub audio_hash: u64 }
#[derive(Clone, PartialEq, Eq, Debug, Default)] pub struct Baseline { pub roms: std::collections::BTreeMap<String, Entry> }
pub fn hex64(v: u64) -> String;                 // "0x" + 16 chiffres hexa minuscules
pub fn parse_hex64(s: &str) -> Option<u64>;     // exactement "0x" + 16 hexa (majuscules ou minuscules acceptees)
impl Baseline {
    pub fn parse(text: &str) -> Result<Baseline, String>;
    pub fn to_json(&self) -> String;
    pub fn load(path: &std::path::Path) -> Result<Baseline, String>;          // fichier absent -> Ok(Baseline::default())
    pub fn save(&self, path: &std::path::Path) -> Result<(), String>;         // ecrit path.tmp puis renomme (atomique)
}
```
`parse`: JSON `{ "version": 1, "roms": { "<name>": { "frames": N, "frame_hash": "0x..", "state_hash": "0x..", "audio_hash": "0x.." } } }` via `serde_json`; `version` different de 1 -> Err contenant `unsupported baseline version`; hash mal forme -> Err contenant le nom de la ROM ; JSON invalide -> Err contenant `invalid baseline`.
`to_json`: `serde_json::to_string_pretty` d'une structure ayant `version` en premier puis `roms` (BTreeMap: cles triees), champs d'une entree dans l'ordre `frames, frame_hash, state_hash, audio_hash`, suivi d'un `\n` final.

## 5. Manifeste `tests/manifest.toml`

```toml
[[rom]]
name = "peterlemon_gfx_mode1"          # unique, [a-z0-9_]
path = "tests/roms/homebrew/peterlemon/GFX/Mode1/Mode1.sfc"   # chemin relatif a la racine du repo
region = "auto"                        # auto | ntsc | pal
frames = 120                           # nombre de frames a executer
optional = false                       # true: ignore si le fichier manque
epic = "E04"                           # plus petite epopee ou la ROM doit passer
check = "hash"                         # hash | ram | ports | none
# check = "ram"  -> expect_ram = [ { addr = 0x7E0010, value = 0x01 } ]
# check = "ports" -> expect_ports = [0xAA, 0xBB, 0x00, 0x00]   (valeurs vues par le CPU sur $2140-$2143)
```
`baseline.json`: `{ "version": 1, "roms": { "<name>": { "frames": 120, "frame_hash": "0x...", "state_hash": "0x...", "audio_hash": "0x..." } } }` (`audio_hash`: FNV-1a 64 de toutes les paires `[i16; 2]` produites par `Snes::take_audio` pendant les `frames` frames, chaque `i16` en little-endian, L puis R. Pour `check = "hash"` les TROIS hash sont calcules et compares.).

## Tests
Tous les tests sont prefixes par `e07_05_`.

- `e07_05_hex64` : `hex64(0)=="0x0000000000000000"` ; `hex64(0xDEADBEEF)=="0x00000000deadbeef"` ; `parse_hex64("0x00000000DEADBEEF")==Some(0xDEADBEEF)` ; `parse_hex64("0xDEADBEEF")==None` (16 chiffres exiges) ; `parse_hex64("deadbeef")==None`.
- `e07_05_roundtrip` : un `Baseline` de 2 entrees -> `to_json` -> `parse` == original.
- `e07_05_json_exact` : `Baseline` vide -> `to_json()=="{\n  \"version\": 1,\n  \"roms\": {}\n}\n"`.
- `e07_05_keys_sorted` : entrees inserees `b` puis `a` : dans `to_json`, `"a"` apparait avant `"b"`.
- `e07_05_entry_field_order` : le JSON d'une entree contient `frames` < `frame_hash` < `state_hash` < `audio_hash` (positions croissantes dans le texte).
- `e07_05_bad_version` : `{"version":2,"roms":{}}` -> Err contenant `unsupported baseline version`.
- `e07_05_bad_hash` : entree `x` avec `"frame_hash":"0x12"` -> Err contenant `x`.
- `e07_05_bad_json` : `not json` -> Err contenant `invalid baseline`.
- `e07_05_load_missing_is_empty` : chemin inexistant dans un dossier temporaire -> `Ok(Baseline::default())`.
- `e07_05_save_load_atomic` : `save` dans un dossier temporaire puis `load` == original ; le fichier `.tmp` n'existe plus apres `save`.
