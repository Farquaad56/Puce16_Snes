# E08-33 - emu_thread: commandes de debug (RequestDebug, SetWramPage, StepInstruction, RunToPc) et Event::Debug

## Contexte
Le thread d'emulation joint un `DebugData` a chaque frame quand le debugger est ouvert, et sait avancer d'une instruction ou jusqu'a un PC. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## Specification
Dans `emu_thread.rs`:
```rust
pub struct DebugData { pub snapshot: puce16_core::snes::DebugSnapshot, pub vram: Vec<u16>, pub cgram: Vec<u16>, pub oam: Vec<u8>, pub wram_page: Vec<u8>,
    pub ppu_regs: Option<puce16_core::ppu::PpuRegsSnapshot>, pub smp: Option<puce16_core::snes::SmpSnapshot>, pub dma: Option<[puce16_core::snes::DmaChanSnapshot; 8]> }
// Command gagne: RequestDebug(bool), SetWramPage(u16), StepInstruction, RunToPc(u32)   // RunToPc: (pb << 16) | pc
// Event gagne: Debug(Box<DebugData>)
```
- `RequestDebug(true)` active, `(false)` desactive (defaut: desactive). Actif: apres CHAQUE `Event::Frame` publiee, envoyer aussi un `Event::Debug` construit depuis les accesseurs `debug_*` (E08-32) ; `wram_page` = `debug_wram_page(page courante)` (page courante `SetWramPage`, defaut 0). `SetWramPage` alors actif renvoie aussitot un `Event::Debug`.
- `StepInstruction`: ignore si le thread n'est pas en pause (`Event::Status("pause first")`) ; en pause: `snes.step_instruction()` puis `Event::Debug` si actif (PAS de nouvelle `Event::Frame`).
- `RunToPc(addr)`: ignore hors pause (meme statut). En pause: boucle de blocs de `debug_run_until_pc(pb, pc, RUN_TO_PC_BLOCK)` (constantes `pub const RUN_TO_PC_BLOCK: u32 = 100_000;` et `pub const RUN_TO_PC_MAX_BLOCKS: u32 = 100;`), entre deux blocs traiter les commandes en attente: `Quit` termine le thread ; `Pause(false)` ANNULE la recherche (`Event::Status("Breakpoint cancelled")`) et reprend l'execution normale. Atteint -> reste en pause, `Event::Status(format!("Breakpoint {:02X}:{:04X}", pb, pc))`, une `Event::Frame` (image courante) puis `Event::Debug` si actif. Blocs epuises -> `Event::Status("Breakpoint not reached")`, reste en pause.
- Les autres comportements sont inchanges ; le motif de test envoie un `DebugData` a vecteurs vides. ROM minimale pour les tests (LoROM, 32 Kio, boucle infinie): `fn tiny_rom() -> Vec<u8> { let mut r = vec![0u8; 0x8000]; r[0] = 0x80; r[1] = 0xFE; r[0x7FFC] = 0x00; r[0x7FFD] = 0x80; r }` (BRA -2 a 0x8000, vecteur RESET 0x8000; l'unique candidat d'en-tete est LoROM). Elle reste en mode emulation.

## 8. Debugger (fenetre egui separee, ouverte par F10)

Envoie `RequestDebug(true)` ; le thread d'emulation joint a chaque frame un `DebugData` = `{ snapshot: DebugSnapshot, vram: Vec<u16> (32768), cgram: Vec<u16> (256), oam: Vec<u8> (544), wram_page: Vec<u8> (256 octets de la page choisie), ppu_regs: Option<PpuRegsSnapshot>, smp: Option<SmpSnapshot>, dma: Option<[DmaChanSnapshot; 8]> }` (les `Vec` sont vides et les `Option` sont `None` pour le motif de test).
Panneaux (v1):
1. **Registres**: CPU (A, X, Y, S, D, DB, PB, PC, P avec drapeaux N V M X D I Z C et e), SMP (A, X, Y, SP, PC, PSW), position (frame, V, H, master), registres PPU principaux (INIDISP, BGMODE, TM, TS, CGWSEL, CGADSUB, SETINI), registres DMA actifs.
2. **VRAM - tuiles**: grille de tuiles 8x8, choix profondeur 2/4/8 bpp, palette (0..15 ou 0..7), adresse de base en mots (curseur par pas de 0x400), zoom 1-4.
3. **VRAM - cartes**: rendu de la carte d'un BG (1..4) avec ses reglages courants (taille de carte, tuile 8/16) ; mode 7 : carte 128x128 en 1024x1024.
4. **Palettes**: 256 pastilles CGRAM, survol = indice + valeur.
5. **OAM**: tableau des 128 sprites (x, y, tuile, palette, priorite, taille, flips).
6. **Memoire**: vue hexadecimale de WRAM (page de 256 octets, navigation par 256).
Commandes d'execution: Pause, Reprendre, Avancer une frame, Avancer une instruction CPU (via commande `StepInstruction`), Executer jusqu'a un PC (un seul point d'arret `PC`, saisi en hexadecimal). Pas de desassembleur en v1 (hors perimetre).

## 7. Architecture desktop

- Thread d'emulation (`emu_thread.rs`) possede `Snes` ; thread UI (egui) envoie des `Command` (`std::sync::mpsc`): `LoadRom(Vec<u8>, path)`, `Reset`, `Pause(bool)`, `FrameAdvance`, `SetJoypad(port, u16)`, `SaveState(slot)`, `LoadState(slot)`, `SetFastForward(bool)`, `RequestDebug(bool)`, `Quit`.
- Le thread d'emulation publie `Event` : `Frame(Arc<FrameData>)` (largeur, hauteur, pixels), `Status(String)`, `Debug(Box<DebugData>)` (seulement si demande), `SramDirty`, `Error(String)`.
- Boucle: tant que non en pause: `run_frame()` ; pousser l'audio ; publier la frame ; attendre selon la synchro. Une frame est publiee par frame emulee (la UI affiche la plus recente).
- Aucun etat d'emulation n'est partage par verrou avec la UI: tout passe par canaux.

## Tests
Tous les tests sont prefixes par `e08_33_`.

- `e08_33_no_debug_by_default` : `spawn_with_audio(Ntsc,true,None)` + `LoadRom(tiny_rom(),"t")` + `FrameAdvance` : on recoit `Event::Frame` et aucun `Event::Debug` (attendre 200 ms).
- `e08_33_debug_after_frame` : `RequestDebug(true)` puis `FrameAdvance` : un `Event::Debug` arrive apres la `Event::Frame` ; `vram.len()==32768`, `cgram.len()==256`, `oam.len()==544`, `wram_page.len()==256`, `ppu_regs.is_some()`.
- `e08_33_debug_off_again` : `RequestDebug(true)`, `RequestDebug(false)`, `FrameAdvance` : aucun `Event::Debug`.
- `e08_33_pattern_debug_empty` : sans ROM (motif de test), `RequestDebug(true)` + `FrameAdvance` : `Event::Debug` avec `vram.is_empty()` et `ppu_regs.is_none()`.
- `e08_33_step_instruction` : ROM `78 18 FB A9 42 8D 10 00 80 FE` = `tiny_rom()` dont les 10 premiers octets sont remplaces par `78 18 FB A9 42 8D 10 00 80 FE` (SEI CLC XCE LDA #$42 STA $0010 BRA -2), en pause, `RequestDebug(true)`, 3 x `StepInstruction` : le dernier `Event::Debug` a `snapshot.pc==0x8003` ; aucun `Event::Frame` recu pendant ces pas.
- `e08_33_step_requires_pause` : thread NON en pause : `StepInstruction` -> `Event::Status` contenant `pause first`.
- `e08_33_run_to_pc` : meme programme, en pause : `RunToPc(0x008008)` -> `Event::Status` contenant `Breakpoint 00:8008` ; `SetWramPage(0)` -> `Event::Debug` avec `wram_page[0x10]==0x42`.
- `e08_33_run_to_pc_cancel` : ROM `tiny_rom()`, en pause : `RunToPc(0x009000)` (jamais atteinte) puis aussitot `Pause(false)` -> `Event::Status` contenant `cancelled` (timeout 10 s) ; ensuite des `Event::Frame` arrivent (l'emulation tourne).
- `e08_33_set_wram_page` : `SetWramPage(1)` actif -> `Event::Debug` avec `wram_page.len()==256`.
