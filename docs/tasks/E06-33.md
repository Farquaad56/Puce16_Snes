# E06-33 - apu/ipl.rs: la ROM IPL de 64 octets
Epopee: E06 | Type: data | Dependances: E06-32 | Taille estimee: ~50 lignes

## Contexte
Les 64 octets de la ROM de demarrage du SMP, a recopier depuis le fichier de donnees (pas de memoire). Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## Lire d'abord
- specs/data/ipl_rom.hex (64 octets en hexa, 16 par ligne)
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_SNES.md` (a consulter avant toute question)

## Write only in
- `crates/puce16-core/src/apu/ipl.rs`
- `crates/puce16-core/src/apu/mod.rs`
- `crates/puce16-core/tests/e06_33_ipl.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Cree `apu/ipl.rs` avec `pub const IPL_ROM: [u8; 64] = [ ... ];` (les 64 octets du fichier `specs/data/ipl_rom.hex`, dans l'ordre, ecrits `0xCD, 0xEF, ...`) et declare `pub mod ipl;` dans `apu/mod.rs` (sans rien changer d'autre). Ajoute un commentaire d'en-tete: `// IPL ROM of the S-SMP, copied from docs/specs/data/ipl_rom.hex`.


### Notes
Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## Tests
Tous les tests sont prefixes par `e06_33_`.

- `e06_33_length_and_sum` : `IPL_ROM.len()==64` ; la somme des 64 octets (en u32) vaut 10936.
- `e06_33_known_bytes` : `IPL_ROM[0]==0xCD`, `IPL_ROM[1]==0xEF` (MOV X,#$EF) ; `IPL_ROM[9..12]==[0x8F,0xAA,0xF4]` (MOV $F4,#$AA) ; `IPL_ROM[47]==0xBA` (MOVW YA,$F6 a $FFEF) ; `IPL_ROM[59]==0x1F` (JMP [$0000+X]).
- `e06_33_reset_vector` : `IPL_ROM[62]==0xC0` et `IPL_ROM[63]==0xFF` : le vecteur de reset ($FFFE/$FFFF) pointe sur $FFC0.
