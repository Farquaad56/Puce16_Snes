## Specification
Dans `cart/mod.rs` (garde `pub mod header; pub mod mapper;`) ajoute:
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum MapMode { LoRom, HiRom, ExHiRom }
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum CartError { TooSmall, NoHeader, UnsupportedCoprocessor(&'static str) }
pub use header::Header;
```
(`Region` reste dans `crate::region`.) Dans `cart/header.rs`:
```rust
#[derive(Clone, PartialEq, Eq, Debug)]
pub struct Header { pub title: String, pub map_byte: u8, pub chipset: u8, pub rom_log2: u8, pub ram_log2: u8,
                    pub country: u8, pub dev_id: u8, pub version: u8, pub checksum: u16, pub complement: u16 }
pub fn header_pos(map: MapMode) -> usize;                  // LoRom 0x7FC0, HiRom 0xFFC0, ExHiRom 0x40FFC0
pub fn parse_header(rom: &[u8], pos: usize) -> Option<Header>;   // None si pos + 0x40 > rom.len()
pub fn compute_checksum(rom: &[u8], pos: usize) -> u16;    // somme u16 (wrapping) de tous les octets, avec complement=0xFFFF et checksum=0x0000 dans l'en-tete
pub fn region_from_country(c: u8) -> Region;               // Ntsc si c dans {0x00,0x01,0x0D,0x0F,0x10}, sinon Pal
pub fn sram_bytes(ram_log2: u8) -> usize;                  // 0 si ram_log2 == 0 ou > 8 ; sinon 1024 << ram_log2
pub fn chipset_info(chipset: u8) -> (bool, Option<&'static str>);   // (has_battery, coprocessor name)
```
- `parse_header`: octets relatifs a `pos`: titre `+0x00..0x15` (chaque octet 0x20..=0x7E -> le caractere, sinon `'?'`, puis supprimer les espaces de fin), `map_byte +0x15`, `chipset +0x16`, `rom_log2 +0x17`, `ram_log2 +0x18`, `country +0x19`, `dev_id +0x1A`, `version +0x1B`, `complement +0x1C` (u16 LE), `checksum +0x1E` (u16 LE).
- `compute_checksum`: somme de tous les octets de `rom`, MOINS les 4 octets reels `pos+0x1C..pos+0x20`, PLUS `0xFF+0xFF` (ceux du complement force a 0xFFFF; le checksum force a 0 ajoute 0).
- `chipset_info`: `low = chipset & 0xF`; `has_battery = low in {2,5,6}`; coprocesseur `Some(nom)` si `low >= 3`, nom selon `chipset >> 4`: 0 `"DSP"`, 1 `"GSU"`, 2 `"OBC1"`, 3 `"SA-1"`, 4 `"S-DD1"`, 5 `"S-RTC"`, 0xE `"other"`, 0xF `"custom"`, autres `"unknown"`.

## 2. En-tete interne (adresses CPU $00FFC0-$00FFDF, offset dans le fichier selon le mapper)

| Offset | Taille | Champ |
|---|---|---|
| $FFC0 | 21 | titre ASCII ($20-$7E) |
| $FFD5 | 1 | `001s mmmm`: s=vitesse (0 lent, 1 rapide), mmmm = mapper ($0 LoROM, $1 HiROM, $5 ExHiROM; $2 S-DD1, $3 SA-1, $A SPC7110 = non supportes v1) |
| $FFD6 | 1 | chipset |
| $FFD7 | 1 | taille ROM: `1 << N` Kio |
| $FFD8 | 1 | taille RAM: `1 << N` Kio (0 = aucune) |
| $FFD9 | 1 | code pays |
| $FFDA | 1 | developpeur (si $33: en-tete etendu) |
| $FFDB | 1 | version |
| $FFDC | 2 | complement du checksum (LE) |
| $FFDE | 2 | checksum (LE) |
| $FFE0-$FFFF | 32 | vecteurs |

Position de l'en-tete dans le fichier normalise: LoROM `0x7FC0`, HiROM `0xFFC0`, ExHiROM `0x40FFC0`.

### 2.1 Vecteurs (adresses CPU, banque 00)
Natif: COP $FFE4, BRK $FFE6, ABORT $FFE8, NMI $FFEA, IRQ $FFEE. Emulation: COP $FFF4, ABORT $FFF8, NMI $FFFA, RESET $FFFC, IRQ/BRK $FFFE. Lus par le CPU via le bus (pas par `cart/`).

### 2.2 Chipset ($FFD6)
- Quartet bas: `0` ROM; `1` ROM+RAM; `2` ROM+RAM+batterie; `3` ROM+coproc; `4` ROM+coproc+RAM; `5` ROM+coproc+RAM+batterie; `6` ROM+coproc+batterie.
- Quartet haut (si bas >= 3): `0` DSP-n, `1` GSU, `2` OBC1, `3` SA-1, `4` S-DD1, `5` S-RTC, `E` autre, `F` custom (voir $FFBF).
- v1 (D-005): si bas >= 3 -> `CartError::UnsupportedCoprocessor(nom)` (`UNKNOWN - to confirm`: defaut = refuser plutot que lancer sans coprocesseur).
- `has_battery` = quartet bas dans {2, 5, 6}.
- Taille SRAM = `0` si $FFD8 == 0, sinon `1024 << N` octets si 1 <= N <= 8; N > 8 -> traiter comme 0 (avertissement). Contenu initial SRAM: `0x00` (`UNKNOWN - to confirm`).

### 2.3 Region ($FFD9)
NTSC si code dans {`$00`, `$01`, `$0D`, `$0F`, `$10`}; PAL sinon (`UNKNOWN - to confirm` pour $0D/$0F/$10: les codes $00 et $01 sont surs). L'utilisateur peut forcer (`--region ntsc|pal`). `enum Region { Ntsc, Pal }` (decision D-003).

### 2.4 Checksum
- Calcul sur la ROM normalisee (puissance de 2): mettre temporairement complement=$FFFF et checksum=$0000 dans l'en-tete, additionner tous les octets sur 16 bits (debordement ignore).
- Valide si `checksum_calcule == checksum_en_tete` et `checksum ^ complement == $FFFF`.
- Le checksum n'est PAS bloquant: c'est un critere de score (ROM homebrew sans checksum valides).

## Tests
Tous les tests sont prefixes par `e03_01_`.

- `e03_01_pos` : `header_pos(LoRom)==0x7FC0`, `header_pos(HiRom)==0xFFC0`, `header_pos(ExHiRom)==0x40FFC0`.
- `e03_01_parse_fields` : tampon de 0x8000 octets a zero; a 0x7FC0 ecris `b"HELLO WORLD          "` (21 octets, espaces de fin); octets: [0x7FD5]=0x20, [0x7FD6]=0x02, [0x7FD7]=0x0A, [0x7FD8]=0x03, [0x7FD9]=0x01, [0x7FDA]=0x33, [0x7FDB]=0x02, [0x7FDC..0x7FDE]=[0x34,0x12], [0x7FDE..0x7FE0]=[0xCB,0xED]. `parse_header(&buf,0x7FC0)` == Header{title:"HELLO WORLD", map_byte:0x20, chipset:2, rom_log2:10, ram_log2:3, country:1, dev_id:0x33, version:2, checksum:0xEDCB, complement:0x1234}.
- `e03_01_parse_none` : `parse_header(&buf[..0x7FFF], 0x7FC0)==None` ; `parse_header(&buf, 0x7FC1)==None` (0x7FC1+0x40 > 0x8000).
- `e03_01_title_nonascii` : octet de titre 0x00 ou 0xFF -> `'?'` ; un titre tout a zero (21 octets) donne 21 fois `'?'`.
- `e03_01_checksum_zero` : tampon de 0x8000 zeros: `compute_checksum(&buf,0x7FC0)==0x01FE`.
- `e03_01_checksum_ignores_field` : meme tampon avec buf[0]=1, buf[1]=2 et les 4 octets 0x7FDC..0x7FE0 = [0x12,0x34,0x56,0x78]: `compute_checksum==0x0201` (3 + 0x01FE).
- `e03_01_region` : `region_from_country`: 0x00 et 0x01 -> Ntsc ; 0x0D, 0x0F, 0x10 -> Ntsc ; 0x02, 0x11, 0xFF -> Pal.
- `e03_01_sram` : `sram_bytes`: 0->0 ; 1->2048 ; 3->8192 ; 8->262144 ; 9->0 ; 255->0.
- `e03_01_chipset` : `chipset_info(0x00)==(false,None)` ; `(0x01)==(false,None)` ; `(0x02)==(true,None)` ; `(0x13)==(false,Some("GSU"))` ; `(0x34)==(false,Some("SA-1"))` ; `(0x25)==(true,Some("OBC1"))` ; `(0x03)==(false,Some("DSP"))` ; `(0x56)==(true,Some("unknown"))`.
