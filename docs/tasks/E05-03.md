## Specification
Ajoute a `ppu/bg.rs`:
```rust
pub fn decode_row(vram: &[u16], row_word_addr: u16, bpp: u8) -> [u8; 8];
```
`a = row_word_addr`. `m0 = vram[a & 0x7FFF]` (octet bas = plan 0, octet haut = plan 1). Si `bpp >= 4`: `m1 = vram[(a + 8) & 0x7FFF]` (plans 2 et 3). Si `bpp == 8`: `m2 = vram[(a + 16) & 0x7FFF]` (plans 4 et 5) et `m3 = vram[(a + 24) & 0x7FFF]` (plans 6 et 7). Pixel `px` (0 = gauche): bit `7 - px` de chaque plan ; indice = plan0 | plan1 << 1 | plan2 << 2 | ... Les plans non lus valent 0. `bpp` autre que 2/4/8: panic avec un message.

## 4. Format des tuiles (fonction pure `decode_row`)
Une tuile 8x8 = 8 rangees. Adresse en mots: `tile_word = chr_base[n] + tile_number * words_per_tile` (masque 0x7FFF), `words_per_tile` = 8 (2 bpp), 16 (4 bpp), 32 (8 bpp).
Rangee `fy` (0..7): mot `m0 = vram[tile_word + fy]` : octet bas = plan 0, octet haut = plan 1. Si 4 bpp: `m1 = vram[tile_word + 8 + fy]` : plans 2 et 3. Si 8 bpp: plans 4,5 en `+16 + fy`, plans 6,7 en `+24 + fy`.
Pixel `px` (0 = gauche): bit `7 - px` de chaque plan; `indice = plan0 | plan1 << 1 | plan2 << 2 | ...`.
`fn decode_row(vram: &[u16], row_word_addr: u16, bpp: u8) -> [u8; 8]` (prend l'adresse du premier mot de la rangee, relit `+8/+16/+24` selon bpp).

## Tests
Tous les tests sont prefixes par `e05_03_`.

- `e05_03_bpp2_pattern` : `vram[0] = 0xCCAA` (plan0 = 0xAA, plan1 = 0xCC) : `decode_row(&vram,0,2)==[3,2,1,0,3,2,1,0]`.
- `e05_03_bpp2_zero_and_full` : `vram[0]=0x0000` -> [0;8] ; `vram[0]=0xFFFF` -> [3;8] ; `vram[0]=0x0080` -> [1,0,0,0,0,0,0,0] ; `vram[0]=0x0001` -> [0,0,0,0,0,0,0,1] ; `vram[0]=0x8000` -> [2,0,0,0,0,0,0,0].
- `e05_03_bpp4_planes` : `vram[0]=0xCCAA`, `vram[8]=0x00F0` (plan2 = 0xF0, plan3 = 0) : `decode_row(&vram,0,4)==[7,6,5,4,3,2,1,0]` ; avec `vram[8]=0xFFF0` : `[15,14,13,12,11,10,9,8]`.
- `e05_03_bpp8_planes` : `vram` entierement a 0 sauf `vram[0]=0x0000`, `vram[16]=0x0180` (plan4 = 0x80, plan5 = 0x01), `vram[24]=0x0040` (plan6 = 0x40, plan7 = 0) : `decode_row(&vram,0,8)==[16,64,0,0,0,0,0,32]`.
- `e05_03_row_offset` : `vram[0x0100]=0x0080` : `decode_row(&vram,0x0100,2)[0]==1` ; `decode_row(&vram,0x0101,2)==[0;8]`. En 4 bpp, les plans 2/3 sont lus a `row + 8` : `vram[0x0108]=0x0080` -> `decode_row(&vram,0x0100,4)[0]==4`.
- `e05_03_wrap_at_end` : `vram` de 0x8000 mots : `vram[0x0007]=0x0080` et `a=0x7FFF` en 4 bpp -> les plans 2/3 viennent de `(0x7FFF+8)&0x7FFF == 7` : `decode_row(&vram,0x7FFF,4)[0]==4`.
- `e05_03_bad_bpp` : `#[should_panic]` : `decode_row(&vram,0,3)`.
