## Specification
```rust
pub fn poll<B: Bus>(cpu: &mut Cpu, bus: &mut B) -> bool;      // algorithme de 01b section 4
pub fn service<B: Bus>(cpu: &mut Cpu, bus: &mut B, nmi: bool);   // sequence materielle
pub fn reset<B: Bus>(cpu: &mut Cpu, bus: &mut B);
```
- `service`: `bus.read(cpu.pc24())` (opcode fantome, resultat ignore); `bus.idle()`; si `!cpu.e`: `push8(pb)`; `push8(pc >> 8)`; `push8(pc & 0xFF)` (pc = adresse de la PROCHAINE instruction, non incrementee); P pousse: en natif `cpu.p`; en emulation `(cpu.p | 0x20) & !0x10` (B=0); vecteur: NMI natif 0xFFEA / emulation 0xFFFA ; IRQ natif 0xFFEE / emulation 0xFFFE; `lo = read(vec)`, `hi = read(vec+1)`; `I=1`, `D=0`, `pb=0`, `pc = hi<<8|lo`. 8 cycles natif, 7 emulation.
- `poll`: exactement l'algorithme de 01b section 4 (ordre: halted; waiting; NMI avant IRQ).
- `reset`: `e = true`; `p = 0x34` (M, X, I; D=0 et le reste 0); `s = 0x01FF`; `db = pb = 0`; `d = 0`; `x &= 0xFF; y &= 0xFF`; `halted = waiting = false`; 5 appels `bus.idle()` (placeholder: UNKNOWN - to confirm) puis `lo = read(0xFFFC)`, `hi = read(0xFFFD)`; `pc = hi<<8|lo`.

## 4. Interruptions dans `step`

`interrupts::poll(cpu, bus) -> bool` (appele au debut de chaque `step`, c'est-a-dire a la frontiere d'instruction):
1. si `cpu.halted` (STP): `bus.idle()`; retourne vrai.
2. `let nmi = bus.nmi_pending(); let irq = bus.irq_asserted() && !cpu.flag(FLAG_I);`
3. si `cpu.waiting` (WAI): si `nmi` ou `bus.irq_asserted()` (meme si I=1): `waiting = false`; sinon `bus.idle()` et retourne vrai (le CPU reste a l'arret).
4. si `nmi`: sequence d'interruption NMI (vecteur natif $FFEA / emulation $FFFA), retourne vrai.
5. sinon si `irq`: sequence IRQ (natif $FFEE / emulation $FFFE), retourne vrai.
6. sinon retourne faux.
(Quand WAI est reveille par une IRQ avec I=1: `waiting=false`, puis le pas continue normalement vers l'instruction suivante: le fetch de l'opcode se fait dans le meme `step`: etape 3 ne retourne pas vrai dans ce cas.)
Un NMI consomme est perdu s'il n'est pas pris: l'appel `nmi_pending()` n'a lieu qu'a l'etape 2 et son resultat est toujours utilise (4).

## 8. Interruptions (NMI, IRQ, RESET)

Sequence materielle (hors BRK/COP): `R(pc)` (opcode fantome, ignore); `IO`; [push PB si E=0]; push PCH; push PCL; push P (B=0 en E=1); `R(vec)`lo; `R(vec+1)`hi (7 cycles E=1, 8 cycles E=0). Puis I=1, D=0, PB=0.
- IRQ est ignore si I=1. NMI jamais masquable.
- Echantillonnage: les lignes NMI/IRQ sont examinees a la **fin de l'instruction** (avant le fetch du prochain opcode, au dernier cycle de l'instruction courante). `UNKNOWN - to confirm` le decalage exact en master clocks entre l'evenement (VBlank, H/V match) et la prise en compte: tests ROM (specs/06_TEST_ROMS.md) trancheront. Valeur de depart: l'IRQ/NMI declenchee pendant le dernier cycle n'est prise qu'apres l'instruction suivante.
- NMI: detection de front montant de la ligne (RDNMI flag AND NMITIMEN bit7). Une ecriture qui active NMITIMEN.7 pendant que le flag RDNMI est deja a 1 genere un NMI (front).
- WAI: le CPU attend; si IRQ (I=1) se produit: reprend a l'instruction suivante sans prendre l'interruption; si I=0 ou NMI: prend l'interruption.
- RESET: lit $FFFC (E=1). Duree/alignement des premiers cycles: `UNKNOWN - to confirm` (voir 02_BUS_TIMING.md).
- ABORT: non utilise sur SNES (ligne non cablee); ne pas implementer.

## 6. Tests d'unite des familles (convention)

Les tests utilisent `FlatBus` (`cpu/testbus.rs`): `FlatBus::new()` ; `bus.poke(addr, &[octets])` ecrit sans journal ; `bus.peek(addr) -> u8` ;
`bus.log: Vec<Cycle>` avec `Cycle { addr: u32, val: u8, kind: CycleKind }`, `CycleKind::{Read, Write, Idle}` (un cycle `Idle` a `addr = 0` et `val = 0`) ;
`bus.clear_log()`. Un test pose le programme en `00:8000` (`cpu.pb = 0; cpu.pc = 0x8000`), fixe les registres a la main, fait `cpu.step(&mut bus)`, puis verifie
registres, memoire et `bus.log.len()` (= nombre de cycles de l'instruction, opcode compris) et, quand c'est precise, la suite exacte des cycles.
Un test peut ecrire `let cycles: Vec<(char, u32, u8)>` ou 'R'/'W'/'I' est le type: a lui de choisir une forme lisible, tant que adresse, valeur, ordre sont verifies.

## Tests
Tous les tests sont prefixes par `e02_40_`.

- `e02_40_nmi_native` : e=false, p=0x00, pb=0x02, pc=0x8123, s=0x01FF, poke(0xFFEA,&[0x00,0x90]), bus.nmi=true; `poll` renvoie true: pc==0x9000, pb==0, I=1, s==0x01FB, peek(0x01FF)==0x02, peek(0x01FE)==0x81, peek(0x01FD)==0x23, peek(0x01FC)==0x00 ; cycles=8 ; log = [R 0x028123, Idle, W, W, W, W, R 0xFFEA, R 0xFFEB] ; bus.nmi == false ensuite.
- `e02_40_irq_emulation` : e=true, p=0x30 (I=0), pc=0x8123, s=0x01FF, poke(0xFFFE,&[0x00,0x88]), bus.irq=true: poll -> true ; pc==0x8800 ; peek(0x01FF)==0x81, peek(0x01FE)==0x23, peek(0x01FD)==0x20 (B=0) ; cycles=7 ; I=1.
- `e02_40_irq_masked` : p avec I=1, bus.irq=true: poll -> false, journal vide, pc inchange.
- `e02_40_nmi_priority_over_irq` : bus.nmi et bus.irq tous deux vrais, I=0: le vecteur pris est celui de NMI.
- `e02_40_wai_waits` : waiting=true, rien en attente: poll -> true avec exactement 1 cycle Idle ; waiting reste true.
- `e02_40_wai_wakes_on_masked_irq` : waiting=true, I=1, bus.irq=true: poll -> false, waiting==false, aucun cycle.
- `e02_40_wai_nmi` : waiting=true, bus.nmi=true: poll -> true (sequence NMI), waiting==false.
- `e02_40_stp` : halted=true: poll -> true avec 1 Idle ; halted reste true ; irq/nmi ignores.
- `e02_40_reset` : poke(0xFFFC,&[0x00,0x80]); cpu avec e=false, p=0x00, x=0x1234, y=0x5678, s=0x0000, d=0x1111, db=5, pb=6: `reset`: e, p==0x34, pc==0x8000, pb==0, db==0, d==0, s==0x01FF, x==0x34, y==0x78 ; cycles=7.
- `e02_40_step_takes_interrupt` : bus.nmi=true: `cpu.step(&mut bus)` execute la sequence NMI (pas d'instruction) -> pc == vecteur.
