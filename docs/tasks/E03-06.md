## Specification
Ajoute a `impl Cart`:
```rust
pub fn read(&self, bank: u8, addr: u16) -> Option<u8>;      // None = open bus
pub fn write(&mut self, bank: u8, addr: u16, v: u8) -> bool;   // true si la SRAM a ete ecrite
pub fn load_sram(&mut self, data: &[u8]);                    // copie min(len) octets, le reste de la SRAM est mis a 0 ; la taille ne change pas
pub fn hash_into(&self, h: &mut crate::hash::Fnv64);         // ecrit sram (si non vide)
```
`read`: si `!sram.is_empty()` et `mapper::sram_offset(map,bank,addr,sram.len())` donne `Some(o)` -> `Some(sram[o])`. Sinon `mapper::rom_offset(map,bank,addr)` -> `Some(rom[o & rom_mask])`, ou `None`.
`write`: si `sram_offset` donne `Some(o)`: `sram[o] = v; true`. Sinon `false` (ecritures ROM ignorees).
`load_sram`: `for i in 0..sram.len() { sram[i] = data.get(i).copied().unwrap_or(0) }`.
`hash_into`: `h.write(&self.sram)` (rien d'autre: la ROM est immuable).

## Tests
Tous les tests sont prefixes par `e03_06_`.

- `e03_06_lorom_read` : ROM `make_rom(&[0xA9,0x01],LoRom)`: `read(0x00,0x8000)==Some(0xA9)` ; `read(0x00,0x8001)==Some(0x01)` ; `read(0x80,0x8000)==Some(0xA9)` ; `read(0x00,0xFFFC)==Some(0x00)` ; `read(0x00,0xFFFD)==Some(0x80)` ; `read(0x00,0x7FFF)==None` ; `read(0x7E,0x8000)==None`.
- `e03_06_hirom_read` : ROM HiRom: `read(0xC0,0x8000)==Some(0xA9)` ; `read(0x00,0x8000)==Some(0xA9)` ; `read(0x80,0x8000)==Some(0xA9)` ; `read(0xC0,0xFFFD)==Some(0x80)` ; `read(0x40,0xFFFD)==Some(0x80)` ; `read(0x00,0x7FFF)==None`.
- `e03_06_exhirom_read` : ROM ExHiRom: `read(0x00,0x8000)==Some(0xA9)` ; `read(0x00,0xFFFD)==Some(0x80)` ; `read(0x40,0xFFFD)==Some(0x80)` ; `read(0xC0,0x8000)==Some(0x00)` (premiere moitie, zeros).
- `e03_06_rom_write_ignored` : `write(0x00,0x8000,0x55)==false` ; `read(0x00,0x8000)` inchange.
- `e03_06_lorom_sram` : ROM `make_rom_with(&[],LoRom,15,3,0x02,1)` (SRAM 8 Kio): `write(0x70,0x0000,0x5A)==true` ; `read(0x70,0x0000)==Some(0x5A)` ; `read(0x70,0x2000)==Some(0x5A)` (miroir modulo 0x2000) ; `read(0xF0,0x0000)==Some(0x5A)` ; `write(0x00,0x8000,1)==false`. `sram()[0]==0x5A`.
- `e03_06_hirom_sram` : ROM `make_rom_with(&[],HiRom,16,3,0x02,1)`: `write(0x20,0x6000,0x77)==true` ; `read(0x20,0x6000)==Some(0x77)` ; `read(0xA0,0x6000)==Some(0x77)` ; `read(0x30,0x6000)==Some(0x77)` (bank&0x1F=0x10 -> 0x20000 % 0x2000 = 0) ; `read(0x20,0x7FFF)==Some(0x00)`.
- `e03_06_load_sram` : SRAM 8 Kio: `load_sram(&[1,2,3])` -> sram()[0..4]==[1,2,3,0], len 8192 ; apres `load_sram(&vec![9;10000])`: len 8192 et sram()[8191]==9 ; apres `load_sram(&[])` tout a 0.
- `e03_06_hash_sram` : deux Cart identiques ont le meme hash (`Fnv64`) ; apres `write(0x70,0,1)` le hash differe.
