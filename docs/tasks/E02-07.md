## Specification
Dans `cpu/addr.rs` (declare `mod absolute; mod direct; mod indirect;`):
```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Ea { pub lo: u32, pub hi: u32 }       // adresses 24 bits de l'octet bas et de l'octet haut
pub fn ea<B: Bus>(cpu: &mut Cpu, bus: &mut B, am: Am, store: bool) -> Ea;
pub fn read_data<B: Bus>(cpu: &mut Cpu, bus: &mut B, ea: &Ea, wide: bool) -> u16;
pub fn write_data<B: Bus>(cpu: &mut Cpu, bus: &mut B, ea: &Ea, v: u16, wide: bool);
pub fn read_operand<B: Bus>(cpu: &mut Cpu, bus: &mut B, am: Am, wide: bool) -> u16;
pub fn rmw<B: Bus, F: FnOnce(&mut Cpu, u16, bool) -> u16>(cpu: &mut Cpu, bus: &mut B, am: Am, f: F);
```
- `ea`: `store` = vrai si l'instruction ecrit (STA STX STY STZ et tous les RMW): force le cycle `IO` supplementaire des modes indexes. Dispatch: `Abs AbsX AbsY Long LongX` -> `absolute::ea(cpu,bus,am,store)` ; `Dp DpX DpY Sr` -> `direct::ea(..)` ; `DpInd DpIndLong DpXInd DpIndY DpIndLongY SrIndY` -> `indirect::ea(..)` ; tout autre mode -> `panic!("ea: mode {:?} has no memory operand", am)`.
- Sous-fichiers `addr/absolute.rs`, `addr/direct.rs`, `addr/indirect.rs`: chacun contient `pub(super) fn ea<B: Bus>(cpu: &mut Cpu, bus: &mut B, am: Am, store: bool) -> Ea { unimplemented!("E02-xx") }` (remplis plus tard).
- `read_data`: `bus.read(ea.lo)` puis, si `wide`, `bus.read(ea.hi)` -> valeur `lo | hi << 8`. `write_data`: ecrit `lo` puis (si `wide`) `hi`.
- `read_operand`: si `am == Am::Imm`: `fetch16` si `wide` sinon `fetch8` (zero-etendu); sinon `let e = ea(cpu,bus,am,false); read_data(cpu,bus,&e,wide)`.
- `rmw` (lecture-modification-ecriture, 01 section 3.3): `wide = !cpu.m8()`.
  * `Am::Acc`: `bus.idle()`; `old` = A (16 bits si wide, sinon octet bas); `new = f(cpu, old, wide)`; ecrire: wide -> `a = new`; sinon `a = (a & 0xFF00) | (new & 0xFF)` (l'octet haut B est conserve).
  * Sinon: `let e = ea(cpu,bus,am,true)`; lire `lo` (puis `hi` si wide); `bus.idle()`; `new = f(cpu, old, wide)`; si wide: ecrire d'abord l'octet HAUT (`ea.hi`), puis l'octet bas (`ea.lo`).
  * `f` recoit `wide` pour savoir s'il traite 8 ou 16 bits (et met les flags lui-meme).

### 3.2 Acces donnee

- Lecture: apres le calcul d'adresse, `R(addr)` octet bas, puis `R(addr+1)` octet haut si 16 bits.
- Ecriture: `W(addr, lo)` puis `W(addr+1, hi)` si 16 bits.
- L'adresse +1 d'une donnee 16 bits traverse les banques (24 bits) pour les modes a/al/a,x/al,x/a,y/(d)/[d]/(d),y ...;
  pour les modes direct page (d, d,x, d,y) l'octet haut est a (D + offset + 1) avec les regles de wrap de la section 4.
  `UNKNOWN - to confirm` cas par cas: laisser les tests JSON trancher.

### 3.3 Instructions lecture-modification-ecriture (ASL LSR ROL ROR INC DEC TSB TRB sur memoire)

`R(addr)`=lo; [`R(addr+1)`=hi si 16 bits]; `IO` (cycle de modification); [`W(addr+1)`=hi' si 16 bits]; `W(addr)`=lo'.
**En 16 bits l'ecriture se fait octet HAUT d'abord, puis octet bas.** (Les JSON le confirment: a verifier au premier test.)
Les formes accumulateur (ASL A ...) sont implied: `IO` seul.

Totaux utiles (8 bits): `LDA #`=2, `LDA d`=3(+DL), `LDA a`=4, `LDA al`=5, `LDA d,x`=4(+DL), `LDA a,x`=4(+1 si page), `LDA (d)`=5(+DL),
`LDA (d),y`=5(+DL,+1 page), `LDA [d]`=6(+DL), `LDA (d,x)`=6(+DL), `LDA d,s`=4, `LDA (d,s),y`=7, `STA a,x`=5, `STA (d),y`=6, `ASL a`=6, `ASL a,x`=7, `ASL d`=5(+DL). +1 par octet supplementaire en 16 bits (+2 pour les RMW).

## 6. Tests d'unite des familles (convention)

Les tests utilisent `FlatBus` (`cpu/testbus.rs`): `FlatBus::new()` ; `bus.poke(addr, &[octets])` ecrit sans journal ; `bus.peek(addr) -> u8` ;
`bus.log: Vec<Cycle>` avec `Cycle { addr: u32, val: u8, kind: CycleKind }`, `CycleKind::{Read, Write, Idle}` (un cycle `Idle` a `addr = 0` et `val = 0`) ;
`bus.clear_log()`. Un test pose le programme en `00:8000` (`cpu.pb = 0; cpu.pc = 0x8000`), fixe les registres a la main, fait `cpu.step(&mut bus)`, puis verifie
registres, memoire et `bus.log.len()` (= nombre de cycles de l'instruction, opcode compris) et, quand c'est precise, la suite exacte des cycles.
Un test peut ecrire `let cycles: Vec<(char, u32, u8)>` ou 'R'/'W'/'I' est le type: a lui de choisir une forme lisible, tant que adresse, valeur, ordre sont verifies.

## Tests
Tous les tests sont prefixes par `e02_07_`.

- `e02_07_read_data_8` : FlatBus: poke(0x1000,&[0x34,0x12]); Ea{lo:0x1000,hi:0x1001}; read_data(wide=false)==0x34 ; log = 1 lecture.
- `e02_07_read_data_16` : meme Ea, wide=true -> 0x1234 ; log = [Read 0x1000, Read 0x1001] dans cet ordre.
- `e02_07_write_data_16` : write_data(Ea{lo:0x2000,hi:0x2001}, 0xABCD, wide=true): peek(0x2000)==0xCD, peek(0x2001)==0xAB ; log = [Write 0x2000=0xCD, Write 0x2001=0xAB].
- `e02_07_read_operand_imm_8` : pb=0, pc=0x8000, poke(0x8000,&[0x7F,0x11]); read_operand(Imm, wide=false)==0x7F, pc==0x8001, log = 1 lecture en 0x008000.
- `e02_07_read_operand_imm_16` : idem avec wide=true -> 0x117F, pc==0x8002, log = lectures 0x008000 puis 0x008001.
- `e02_07_rmw_acc_8bit` : e=false, p=0x20 (M=1), a=0x12FF; rmw(Acc, |_c,v,_w| (v+1)&0xFF) -> a==0x1200 ; log = [Idle] seulement.
- `e02_07_rmw_acc_16bit` : e=false, p=0x00, a=0x00FF; rmw(Acc, |_c,v,w| { assert!(w); v+1 }) -> a==0x0100 ; log = [Idle].
