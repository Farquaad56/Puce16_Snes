## Specification
Reecris `run_echo` (meme signature qu'en E06-46) dans `dsp/echo.rs` en suivant le pseudo-code de 07b section 7, dans cet ordre:
1. `if echo_offset == 0 { echo_length = ((regs[EDL] & 15) as u16) << 11 }`.
2. `ptr = ((regs[ESA] as u16) << 8).wrapping_add(echo_offset)`.
3. Lire `l = (i16::from_le_bytes([ram[ptr], ram[ptr+1]]) as i32) >> 1` et `r` pareil en `ptr+2`, `ptr+3` (indices `wrapping_add` modulo 65536).
4. Historique: decaler `hist_l`/`hist_r` d'un cran vers l'indice bas (`hist[i] = hist[i+1]` pour i = 0..7) puis `hist[7] = l` (resp. `r`). `hist[0]` est le PLUS ANCIEN (coefficient FIR0), `hist[7]` le plus recent (FIR7).
5. `fir_l = sum_{i=0..6} (hist_l[i] * FIR_i as i8 as i32) >> 6` (chaque terme decale separement) ; `fir_l = fir_l as i16 as i32` ; `fir_l += (hist_l[7] * FIR_7 as i8 as i32) >> 6` ; `fir_l = clamp16(fir_l) & !1`. Meme chose pour `r`. `FIR_i = regs[reg::fir(i)]`.
6. `main_l = clamp16(((sum_l * MVOLL as i8) >> 7) + ((fir_l * EVOLL as i8) >> 7))` ; idem `main_r`. Si `regs[FLG] & 0x40` : `(main_l, main_r) = (0, 0)`.
7. Feedback: `wl = clamp16(echo_l + ((fir_l * EFB as i8) >> 7)) & !1` ; `wr` idem. Si `regs[FLG] & 0x20 == 0` : ecrire `wl` puis `wr` (little endian, 2 octets chacun) a `ptr`, `ptr+2`.
8. `echo_offset += 4` ; `if echo_offset >= echo_length { echo_offset = 0 }`.
9. Renvoyer `(main_l, main_r)`.

## 7. Echo, sortie
Ordre dans un echantillon, apres les 8 voix:
```
if echo_offset == 0 { echo_length = (regs[EDL] & 15) << 11 }
ptr = ((ESA as u16) << 8).wrapping_add(echo_offset)
l = i16(ram[ptr] | ram[ptr+1] << 8) >> 1 ; r = i16(ram[ptr+2] | ram[ptr+3] << 8) >> 1     // octets mod 65536
push (l, r) dans hist (anneau de 8; FIR0 = le plus ANCIEN, FIR7 = le plus RECENT; UNKNOWN - to confirm)
fir_l = sum_{i=0..6} (hist_l[i] * FIR_i as i8) >> 6 ; fir_l = fir_l as i16 as i32 ; fir_l += (hist_l[7] * FIR_7) >> 6 ; fir_l = clamp16(fir_l) & !1   // meme chose pour r
main_l = clamp16( ((sum_l * MVOLL as i8) >> 7) + ((fir_l * EVOLL as i8) >> 7) )        // idem r
if FLG & 0x40 { main_l = 0; main_r = 0 }
audio.push(main_l as i16); audio.push(main_r as i16)
// feedback / ecriture echo
wl = clamp16(echo_l + ((fir_l * EFB as i8) >> 7)) & !1 ; wr idem
if FLG & 0x20 == 0 { ram[ptr..ptr+4] = wl LE, wr LE }
echo_offset += 4; if echo_offset >= echo_length { echo_offset = 0 }
```
(EDL = 0 => longueur 0 => ecrit toujours 4 octets en `ESA*256`, comme le wiki.) `echo_l/r` = somme clampee des voix EON de l'echantillon, remise a 0 au debut de l'echantillon, de meme que `sum_l/r`.
