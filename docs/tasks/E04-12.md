```rust
impl Ppu { pub fn regs_snapshot(&self) -> PpuRegsSnapshot;  /* copie des valeurs courantes */ }
```
`Ppu::reset()` (remplace celle de E03-08): conserve `region` ET les contenus de `vram`, `cgram`, `oam` (`mem`); appelle `reset_regs()` sur `vram`, `cgram`, `oam`; remplace `scroll`, `m7`, `regs` par `new()`; remet `v = 0, dot = 0, field = false, interlace = false, obj_interlace = false, overscan = false, pseudo_hires = false, extbg = false, forced_blank = true, brightness = 0, ppu1_mdr = ppu2_mdr = 0, latch_h = latch_v = 0, counter_latched = ophct_byte = opvct_byte = range_over = time_over = false`.
Le `Ppu::new(region)` equivaut a un power-on (toutes memoires a 0).

## 7. Reset et power-on
- Power-on: tous les registres 0 sauf `forced_blank = true`; memoires a 0; `v = 0, dot = 0, field = false`; latchs a 0; `internal_oamadd = 0`.
- Reset bouton: memes registres PPU qu'au power-on (INIDISP force blank); VRAM/CGRAM/OAM CONSERVEES (`UNKNOWN - to confirm`).

## Tests
Tous les tests sont prefixes par `e04_12_`.

- `e04_12_snapshot_power_on` : `Ppu::new(Ntsc).regs_snapshot()`: v==0, dot==0, field==false, forced_blank==true, brightness==0, bg_mode==0, tm==0, vmadd==0, oam_internal==0, m7==[0;6], fixed==[0;3].
- `e04_12_snapshot_values` : apres `write(0x00,0x0F)`, `write(0x05,0x07)`, `write(0x2C,0x13)`, `write(0x32,0x2A)`, `write(0x07,0x7B)`, `write(0x16,0x34)`, `write(0x17,0x12)`, `write(0x1B,0x00)`, `write(0x1B,0x01)` : brightness==15, forced_blank==false, bg_mode==7, tm==0x13, fixed==[10,0,0], map_base[0]==0x7800, vmadd==0x1234, m7[0]==256.
- `e04_12_reset_keeps_memories` : forced blank : `write(0x16,0x05); write(0x17,0x00); write(0x18,0x7B)` (VRAM mot 5 bas = 0x7B), CGRAM mot 2 = 0x0155 (`write(0x21,2); write(0x22,0x55); write(0x22,0x01)`), OAM octets 0,1 = 0x11,0x22 ; `reset()` : `vram()[5]==0x007B`, `cgram()[2]==0x0155`, `oam()[0]==0x11`, `oam()[1]==0x22`.
- `e04_12_reset_clears_registers` : apres de nombreuses ecritures (0x00 0x0F, 0x05 0x07, 0x15 0x80, 0x16 0x34, 0x2C 0x1F, 0x33 0x4F, 0x0D 0x12) et 12345 `step_dot`: `reset()` -> `regs_snapshot()` egal a celui d'un `Ppu::new` de meme region (memoires exclues du snapshot), `ppu1_mdr()==0`, `ppu2_mdr()==0`, `counter_latched()==false`, `v()==0`, `dot()==0`.
- `e04_12_reset_keeps_region` : `Ppu::new(Pal)` puis `reset()` : `read(0x3F,0,false)==0x13` (toujours PAL) ; `last_line()==311`.
- `e04_12_hash_covers_everything` : a partir d'un `Ppu::new(Ntsc)`, chacune des actions suivantes (sur une copie fraiche) change `hash_into`: `write(0x21,1)` ; `write(0x16,1)` ; `write(0x22,5)` seul ; `read(0x37,0,true)` ; `set_range_over(true)` ; `write(0x33,0x40)` ; `write(0x0D,3)` ; `write(0x1F,3)` ; `write(0x2C,1)` ; `write(0x01,0x20)` ; `write(0x00,0x01)` ; un `step_dot` ; `write(0x02,5)`.
- `e04_12_hash_after_reset_equals_new_except_memories` : sur des `Ppu` ou seules des REGISTRES (pas de memoire) ont ete ecrits (ex.: 0x05, 0x2C, 0x33), `reset()` redonne exactement le hash de `Ppu::new` (meme region).
- `e04_12_reset_idempotent` : `reset()` deux fois de suite donne le meme hash qu'une seule fois.
