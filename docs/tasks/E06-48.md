## 9. Interface Rust
```rust
pub struct Dsp { /* regs[128], voix[8], counter, noise, every_other, new_kon, kon, endx, echo_offset, echo_length, hist, audio */ }
impl Dsp {
    pub fn new() -> Self;
    pub fn reset(&mut self);
    pub fn read(&mut self, addr: u8) -> u8;                  // addr & 0x7F
    pub fn write(&mut self, addr: u8, v: u8);                // addr & 0x7F
    pub fn run_sample(&mut self, ram: &mut [u8; 65536]);     // 1 echantillon stereo -> audio
    pub fn take_audio(&mut self) -> Vec<i16>;                // L,R,L,R...
}
```
L'`Apu` appelle `run_sample` tous les 32 cycles SMP. Debit: `APU_RESONATOR_HZ / 768` = 32 040 echantillons/s (D-004).

## Tests
Tous les tests sont prefixes par `e06_48_`.

- `e06_48_sample_rate_constant` : `AUDIO_SAMPLE_RATE==32_040`.
- `e06_48_samples_per_run` : apres 3 `run_frame()` : `take_audio(&mut v)` ajoute `v.len()` paires avec `1450 <= v.len() && v.len() <= 1650`.
- `e06_48_silent_by_default` : dans `samples_per_run` toutes les paires sont `[0,0]` (FLG au power-on = 0xE0, mute).
- `e06_48_take_appends_and_drains` : `v = vec![[7,7]]` : apres `take_audio(&mut v)`, `v[0]==[7,7]` et `v.len() >= 2` ; un 2eme appel immediat n'ajoute rien.
- `e06_48_determinism` : deux `Snes` identiques, 2 frames : memes vecteurs audio et meme `state_hash()`.
- `e06_48_per_frame_count_stable` : pour les frames 4 a 8: chaque `run_frame` ajoute entre 530 et 537 paires (357k clocks / 670 clocks par echantillon).
