Le CLI peut charger des triches: `run <rom> --cheat fichier.cht --cheat-code 7E0DBF99`. Une fonction pure collecte les codes; la commande les passe a `Snes::set_cheats` avant la premiere image. ## Specification
1. `cheats.rs` (module declare dans `main.rs`): `pub fn collect_cheats(file_text: Option<&str>, codes: &[String]) -> Result<Vec<ParCode>, String>`. Le texte du fichier passe par `parse_cheat_file`; seules les entrees `enabled` contribuent, dans l'ordre, tous leurs codes; puis chaque element de `codes` passe par `parse_par` dans l'ordre. Erreurs de fichier: `format!("fichier .cht ligne {}: {:?}", e.line, e.kind)`; erreurs de code: `format!("code invalide '{}': {:?}", texte, erreur)`.
2. Options de `run`: `--cheat <FICHIER>` (une fois) et `--cheat-code <CODE>` (repetable), dans la meme structure d'arguments que `--input`. Dans la commande: lire le fichier (erreur de lecture -> message), appeler `collect_cheats`; en cas d'erreur afficher `erreur cheat: <message>` sur stderr et sortir avec un code non nul sans lancer la console. Sinon `snes.set_cheats(&codes)` avant la premiere image.
3. Sans option, le comportement de `run` est exactement celui d'avant (aucun test existant ne change).
4. Les tests de `collect_cheats` sont dans `cheats.rs` (`#[cfg(test)] mod tests`, noms prefixes `e10_04_`); les tests du binaire sont dans `tests/e10_04_*.rs` (copier le style de `e03_44_run_rom.rs`: ROM synthetique ecrite dans un dossier temporaire, appel du binaire compile).

## 6. Ligne de commande

`puce16-cli run <rom> --cheat <fichier.cht> --cheat-code <AAAAAAVV>` (`--cheat-code` repetable). Les codes des entrees `+` du fichier, puis les `--cheat-code`, sont passes a `set_cheats` avant la premiere image. Une erreur de fichier ou de code arrete la commande avec un message clair (`erreur cheat: ...`) et un code de sortie non nul.

## Tests
Tous les tests sont prefixes par `e10_04_`.

- `e10_04_collect_only_enabled_in_order` : fichier "+ A = 7E0001AA\n- B = 7E0002BB\n+ C = 7E0003CC 7E0004DD" + codes ["7E0005EE"] -> [0x7E0001/AA, 0x7E0003/CC, 0x7E0004/DD, 0x7E0005/EE]
- `e10_04_collect_without_file` : None + ["7E0010FF"] -> [0x7E0010/FF]; None + [] -> []
- `e10_04_collect_bad_code_message` : ["7E0010F"] -> Err contenant "code invalide '7E0010F'" et "Length(7)"
- `e10_04_collect_bad_file_message` : fichier "oops" -> Err contenant "ligne 1" et "MissingSign"
- `e10_04_binary_applies_cheat_code` : ROM synthetique (programme E6 00 80 FC, vecteur reset 0x8000), `run <rom> --frames 3 --cheat-code 7E000042 --state-hash` comparee a la meme commande sans option: les sorties different; code de sortie 0
- `e10_04_binary_rejects_bad_code` : `run <rom> --frames 1 --cheat-code ZZ` -> code de sortie non nul et stderr contient "erreur cheat"
