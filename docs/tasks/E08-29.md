## Specification
Ajoute dans `input.rs` (sans modifier `Key`, `default_buttons`, `Hotkey` de E01-13):
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum PadButton { South, East, West, North, LeftTrigger, RightTrigger, Start, Select, DPadUp, DPadDown, DPadLeft, DPadRight, Other }
pub fn pad_buttons(pressed: &[PadButton]) -> u16;            // tableau section 3: South->B, East->A, West->Y, North->X, LeftTrigger->L, RightTrigger->R, Start->START, Select->SELECT, DPad*->directions, Other->0
/// stick gauche: x positif = droite, y positif = HAUT (convention gilrs). Seuil strict: abs(axe) > 0.5.
pub fn stick_buttons(x: f32, y: f32) -> u16;
pub fn snes_button_bit(name: &str) -> Option<u16>;           // "B","A","Y","X","L","R","Start","Select","Up","Down","Left","Right" (casse exacte) ; autre -> None
pub fn pad_button_name(b: PadButton) -> &'static str;        // "South","East","West","North","LeftTrigger","RightTrigger","Start","Select","DPadUp","DPadDown","DPadLeft","DPadRight","Other"
/// `map`: bouton SNES -> nom de bouton manette (config.pad_map). Map vide = defauts. Pour chaque entree valide de `map`, ce bouton SNES est active si le bouton manette nomme est dans `pressed` ; un bouton SNES present dans `map` NE suit PLUS le defaut. Noms inconnus ignores.
pub fn pad_buttons_mapped(pressed: &[PadButton], map: &std::collections::BTreeMap<String, String>) -> u16;
pub fn key_name(k: Key) -> &'static str;                     // "ArrowUp","ArrowDown","ArrowLeft","ArrowRight","Z","S","Q","D","X","K","C","L","W","J","V","I","A","U","E","O","Enter","Backspace","ShiftRight","Other"
/// `map`: bouton SNES -> liste de noms de touches (config.keymap). Meme regle: map vide = defauts ; un bouton SNES present dans `map` ne suit plus le defaut.
pub fn keyboard_buttons_mapped(pressed: &[Key], map: &std::collections::BTreeMap<String, Vec<String>>) -> u16;
```
Algorithme mapped (commun): `bits = defaut(pressed) & !(OU des bits des boutons SNES presents dans map)` puis OU des bits des entrees de `map` dont une touche / un bouton nomme est presse.

## 3. Manette physique (`gilrs`, dependance autorisee par D-019)

Mapping par defaut (disposition "Xbox", noms `gilrs::Button`):
| Bouton SNES | Bouton manette |
|---|---|
| B | South (A) |
| A | East (B) |
| Y | West (X) |
| X | North (Y) |
| L / R | LeftTrigger / RightTrigger (bumpers) |
| Start / Select | Start / Select (Back) |
| Directions | DPad ; stick gauche avec zone morte 0.5 (seuil `abs(axis) > 0.5`) |
Premiere manette connectee = port 0 (joueur 1) ; deuxieme = port 1. Le clavier alimente toujours le port 0 (OU logique avec la manette 0). Deconnexion: le port retombe a 0 sans erreur. Mapping modifiable dans `config.json` (`pad_map`).

## Tests
Tous les tests sont prefixes par `e08_29_`.

- `e08_29_pad_defaults` : `pad_buttons(&[South])==BTN_B` ; `[East]==BTN_A` ; `[West]==BTN_Y` ; `[North]==BTN_X` ; `[LeftTrigger]==BTN_L` ; `[RightTrigger]==BTN_R` ; `[Start]==BTN_START` ; `[Select]==BTN_SELECT` ; `[DPadUp,DPadLeft]==BTN_UP|BTN_LEFT` ; `[Other]==0` ; `[]==0`.
- `e08_29_stick_threshold` : `stick_buttons(0.5,0.0)==0` (seuil strict) ; `(0.51,0.0)==BTN_RIGHT` ; `(-0.9,0.0)==BTN_LEFT` ; `(0.0,0.9)==BTN_UP` ; `(0.0,-0.9)==BTN_DOWN` ; `(0.7,0.7)==BTN_RIGHT|BTN_UP` ; `(0.1,-0.2)==0`.
- `e08_29_snes_names` : `snes_button_bit("B")==Some(BTN_B)` ; `"Select"` -> `Some(BTN_SELECT)` ; `"Up"` -> `Some(BTN_UP)` ; `"b"` -> `None` ; `""` -> `None`.
- `e08_29_pad_names` : `pad_button_name(South)=="South"` ; `pad_button_name(DPadRight)=="DPadRight"` ; `pad_button_name(Other)=="Other"`.
- `e08_29_pad_mapped_empty_is_default` : map vide : `pad_buttons_mapped(&[South,Start], &map)==pad_buttons(&[South,Start])`.
- `e08_29_pad_mapped_override` : map `{"B": "West"}` : `[West]` -> `BTN_B` (B est active par la map) et aussi `BTN_Y` (par le defaut, car Y n'est pas dans la map): resultat `BTN_B|BTN_Y` ; `[South]` -> `0` (B ne suit plus le defaut South).
- `e08_29_pad_mapped_unknown_ignored` : map `{"B": "Nope", "Zed": "South"}` : `[South]` -> `0` (B est dans la map donc ne suit plus South, mais `Nope` n'existe pas) ; aucune panique.
- `e08_29_key_names` : `key_name(Key::Up)=="ArrowUp"` ; `key_name(Key::Enter)=="Enter"` ; `key_name(Key::ShiftRight)=="ShiftRight"` ; `key_name(Key::Z)=="Z"`.
- `e08_29_keyboard_mapped_empty` : map vide : `keyboard_buttons_mapped(&[Key::X,Key::Enter], &map)==default_buttons(&[Key::X,Key::Enter])`.
- `e08_29_keyboard_mapped_override` : map `{"A": ["Q", "Enter"]}` : `[Key::Q]` -> `BTN_A|BTN_LEFT` (Q reste Gauche par le defaut, et active A) ; `[Key::C]` -> `0` (A ne suit plus C) ; `[Key::Enter]` -> `BTN_START|BTN_A`.
