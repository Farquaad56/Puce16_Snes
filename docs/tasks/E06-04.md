## Specification
1. `docs/tools/gen_spc_tables.py` (Python 3, stdlib seulement): lit `docs/specs/data/opcodes_spc700.tsv` (256 lignes de donnees apres l'en-tete), ecrit `crates/puce16-core/src/apu/spc700/table.rs` avec en tete `// GENERATED by docs/tools/gen_spc_tables.py - do not edit`.
2. Contenu genere: `pub static BYTES: [u8; 256]`, `pub static CYCLES: [u8; 256]`, `pub static BRANCH_EXTRA: [u8; 256]`, `pub static NAME: [&str; 256]` (indices = opcode; NAME = texte exact de la colonne `mnemonic`).
3. Option `--check`: ne rien ecrire; code de sortie 1 si `table.rs` differe de la sortie generee (sinon 0). Le script doit echouer (exit 1, message clair) si le TSV n'a pas 256 lignes ou si un opcode manque/est duplique.
4. Lancer le script une fois pour produire `table.rs`.
5. Le fichier `spc700/mod.rs` existe peut-etre deja sans `pub mod table;`: ajoute cette seule declaration si elle manque (E06-05 la reprendra).

## Tests
Tous les tests sont prefixes par `e06_04_`.

- `e06_04_known_rows` : NAME[0x00]=="NOP" ; NAME[0xE4]=="MOV A,dp" ; NAME[0xC7]=="MOV [dp+X],A" ; NAME[0xFF]=="STOP" ; NAME[0x3F]=="CALL !abs" ; NAME[0xFE]=="DBNZ Y,rel".
- `e06_04_cycles_bytes` : CYCLES[0x00]==2 ; CYCLES[0x01]==8 ; CYCLES[0x0F]==8 (BRK) ; CYCLES[0x9E]==12 (DIV) ; CYCLES[0xCF]==9 (MUL) ; CYCLES[0xE4]==3 ; CYCLES[0xC7]==7 ; BYTES[0x00]==1 ; BYTES[0x03]==3 ; BYTES[0x05]==3 ; BYTES[0x08]==2 ; BYTES[0x3F]==3.
- `e06_04_branch_extra` : BRANCH_EXTRA[0x03]==2 (BBS) ; BRANCH_EXTRA[0x10]==2 (BPL) ; BRANCH_EXTRA[0x2E]==2 (CBNE) ; BRANCH_EXTRA[0xFE]==2 (DBNZ Y) ; BRANCH_EXTRA[0x2F]==0 (BRA, 4 cycles fixes) ; BRANCH_EXTRA[0x00]==0.
- `e06_04_all_rows_sane` : pour les 256 opcodes: BYTES entre 1 et 3, CYCLES entre 2 et 12, NAME non vide; exactement 28 opcodes ont BRANCH_EXTRA == 2 (8 branches conditionnelles + 16 BBS/BBC + 2 CBNE + 2 DBNZ), tous les autres 0.
