## Specification
Dans `bus/route.rs`: `impl SysBus { pub fn read_inner(&mut self, addr: u32) -> u8 { ... } }` (declare `mod route;` dans `bus/mod.rs`).
`bank = (addr >> 16) as u8`, `a = (addr & 0xFFFF) as u16`.
- Si `bank & 0x7F <= 0x3F` (banques 00-3F et 80-BF), selon `a`:
  `0x0000..=0x1FFF` -> `wram.read(a as u32)` ;
  `0x2100..=0x213F` -> `ppu.read((a - 0x2100) as u8, self.mdr, self.mmio.wrio & 0x80 != 0)` ;
  `0x2140..=0x217F` -> `apu.port_read((a & 3) as usize)` ;
  `0x2180` -> `wram.data_read()` ;
  `0x4016` -> `(self.mdr & 0xFC) | joy.read_port(0)` ; `0x4017` -> `(self.mdr & 0xE0) | 0x1C | joy.read_port(1)` ;
  `0x4210..=0x421F` -> `mmio.read(a, self.mdr, self.master, HvState { vblank: ppu.in_vblank(), hblank: ppu.in_hblank(), autoread_busy: timing.autoread_busy(self.master) })` ;
  `0x4300..=0x437F` -> `dma.read(a).unwrap_or(self.mdr)` ;
  `0x6000..=0xFFFF` -> `cart.read(bank, a).unwrap_or(self.mdr)` ;
  tout autre `a` -> `self.mdr`.
- Sinon si `bank == 0x7E || bank == 0x7F`: `wram.read((((bank & 1) as u32) << 16) | a as u32)`.
- Sinon: `cart.read(bank, a).unwrap_or(self.mdr)`.
Dans les tests: `mod common; use common::*;` puis `fn mk(code: &[u8]) -> SysBus { SysBus::new(Cart::from_bytes(&make_rom(code, Map::LoRom)).unwrap(), Region::Ntsc) }` (imports: `puce16_core::bus::SysBus`, `puce16_core::cart::Cart`, `puce16_core::Region`).

## 6. Open bus et routage (`read_inner` / `write_inner`)
Banque `b = addr >> 16`, `a = addr & 0xFFFF`. Zones systeme pour `(b & 0x7F) <= 0x3F` (banques 00-3F et 80-BF):
| a | read | write |
|---|---|---|
| 0000-1FFF | `wram.read(a)` | `wram.write(a, v)` |
| 2100-213F | `ppu.read(a-0x2100, mdr, wrio bit7)` (E03: renvoie mdr) ; met a jour `mdr` | `ppu.write(a-0x2100, v)` |
| 2140-217F | `apu.port_read(a & 3)` | `apu.port_write(a & 3, v)` |
| 2180 | `wram.data_read()` | `wram.data_write(v)` |
| 2181-2183 | open bus (mdr) | `wram.set_addr_l/m/h(v)` |
| 4016 | `(mdr & 0xFC) \| joy.read_port(0)` | `joy.write_out(v & 1 != 0)` |
| 4017 | `(mdr & 0xE0) \| 0x1C \| joy.read_port(1)` | ignoree |
| 4200-420D | open bus | `mmio.write(..)` puis appliquer l'effet (Mdmaen -> `pending_dma = v`; Hdmaen -> `mmio.hdmaen = v` ; Memsel -> `self.memsel`; Wrio -> `ppu.wrio_write(old,new)`) |
| 4210-421F | `mmio.read(..)` | ignoree |
| 4300-437F | `dma.read(a)` (None -> mdr) | `dma.write(a, v)` |
| 6000-FFFF | `cart.read(b, a)` (None -> mdr) | `cart.write(b, a, v)` |
| autre | open bus (mdr) | ignoree |
Banques 40-7D / C0-FF: `7E-7F` = `wram.read(((b & 1) << 16) | a)` ; autres: `cart.read(b, a)` (None -> mdr). Les ecritures cartouche passent par `cart.write`.
Les lectures ne mettent `mdr` a jour que quand la valeur renvoyee provient du bus de donnees externe: en v1, `mdr = valeur lue` pour TOUTE lecture CPU.

## 4. Open bus
- `mdr: u8` = derniere valeur vue sur le bus de donnees (mise a jour a chaque lecture ET ecriture CPU, et a chaque octet DMA lu cote A-bus... voir 03_DMA.md).
- Lecture d'une adresse non mappee: retourne `mdr`. Lecture d'un registre partiellement defini (ex: RDNMI bits 6-4, HVBJOY bits 5-1, TIMEUP bits 6-0, JOYSER bits 7-2): les bits non definis valent les bits correspondants de `mdr`.
- JOYSER1 ($4017): bits 4-2 = 1 toujours; bits 7-5 = mdr.
- PPU: les lectures PPU1 ($2134-$2137? voir 05_PPU.md) utilisent un open bus PPU separe (ppu1_mdr / ppu2_mdr). Defaut v1: ppu1_mdr = derniere valeur lue d'un registre PPU1 ($2134-$2136, $2138-$213A, $213E), ppu2_mdr = derniere valeur lue de PPU2 ($213B-$213D, $213F). `UNKNOWN - to confirm` si necessaire pour les ROM de test.

## Tests
Tous les tests sont prefixes par `e03_27_`.

- `e03_27_wram_mirror` : `bus.wram.write(0x10,0xAB)`: `read_inner(0x000010)`, `read_inner(0x3F0010)`, `read_inner(0x800010)`, `read_inner(0xBF0010)`, `read_inner(0x7E0010)` valent tous 0xAB. `bus.wram.write(0x10010,0x77)`: `read_inner(0x7F0010)==0x77`. `read_inner(0x001FFF)==0x55`. `read_inner(0x7E2000)==0x55`.
- `e03_27_rom_banks` : `mk(&[0xA9,0x01])`: `read_inner(0x008000)==0xA9`, `0x808000 -> 0xA9`, `0x008001 -> 0x01`, `0x00FFFC -> 0x00`, `0x00FFFD -> 0x80`, `0x400000 -> 0xA9`, `0xC00000 -> 0xA9`.
- `e03_27_wmdata_port` : `bus.wram.write(0x200,0x11); write(0x201,0x22); wram.set_addr_l(0); wram.set_addr_m(2)`: `read_inner(0x002180)==0x11`, puis `0x22`, et `wram.addr==0x202`.
- `e03_27_joyser` : mdr=0xFF (champ pub): `read_inner(0x004016)==0xFD` ; `read_inner(0x004017)==0xFD` (0xE0|0x1C|1). mdr=0x00: `0x004016 -> 0x01`, `0x004017 -> 0x1D`.
- `e03_27_joyser_serial` : `bus.joy.set_buttons(0,0x8000)`; `bus.joy.write_out(true); write_out(false)`; mdr=0: 16 lectures de 0x004016 donnent 1,0,0,...(15 zeros) ; la 17eme donne 1.
- `e03_27_rdnmi_hvbjoy` : `bus.mmio.rdnmi_flag=true`, mdr=0: `read_inner(0x004210)==0x82`, puis `0x02`. Au power-on, mdr=0: `read_inner(0x004212)==0x40` (HBlank car dot 0, pas de VBlank, pas d'auto-read).
