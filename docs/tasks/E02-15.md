## Specification
Dans `mem/load.rs`, `exec` traite `Mn::Lda`, `Mn::Ldx`, `Mn::Ldy` (sinon `return false`):
- LDA: `wide = !cpu.m8()`; `v = addr::read_operand(cpu, bus, am, wide)`; si `wide` `cpu.a = v` sinon `cpu.a = (cpu.a & 0xFF00) | v` ; `cpu.set_nz(v, wide)`.
- LDX / LDY: `wide = !cpu.x8()`; meme lecture; `cpu.x = v` (resp. `y`) (en 8 bits la valeur est `v` zero-etendue, l'octet haut est 0); `set_nz(v, wide)`.
- Retourne `true`. Les cycles viennent des modes (aucun cycle a ajouter).

### 5.1 Taille des operandes
- `#` immediat: 1 octet si M=1 (ou X=1 pour LDX LDY CPX CPY), 2 octets sinon.
- `imm8` (REP, SEP) et `wdm`, `brk`, `cop` (octet de signature): toujours 1 octet.
- Instructions utilisant M: ORA AND EOR ADC SBC CMP BIT LDA STA STZ + RMW memoire + PHA PLA + transferts vers A.
- Instructions utilisant X: LDX LDY STX STY CPX CPY INX INY DEX DEY PHX PHY PLX PLY.
<!-- end -->

<!-- begin docs/specs/01_CPU_65816.md#5.2 Flags -->
### 5.2 Flags
- N/Z: mis par LDA/LDX/LDY, ADC SBC AND ORA EOR CMP CPX CPY, INC DEC (y compris INX INY DEX DEY), ASL LSR ROL ROR, PLA PLX PLY PLB PLD, transferts (TAX TAY TXA TYA TSX TXY TYX TCD TDC TCS? **TCS ne modifie aucun flag**; TSC et TDC mettent N/Z), XBA (N/Z sur l'octet bas de A apres echange).
- STA STX STY STZ, PHx, TXS, TCS, TSB/TRB (seul Z), BIT: BIT `#` ne modifie que Z; BIT mem modifie N=bit7 (ou bit15), V=bit6 (ou bit14), Z=(A & m)==0.
- TSB: Z=(A & m)==0; m = m | A. TRB: Z=(A & m)==0; m = m & ~A.
- CMP/CPX/CPY: calcul a - m en binaire: C = (a >= m), Z, N sur le resultat; V inchange.
- Flags de decalage: ASL C=bit sorti (7 ou 15); LSR C=bit0; ROL/ROR passent par C.
- CLC SEC CLI SEI CLD SED CLV: mettent/effacent le flag. REP: P &= ~imm; SEP: P |= imm (en E=1, M et X restent a 1; si X devient 1: X.h=Y.h=0).
- XCE: echange C et E. Apres: si E=1: M=X=1, X.h=Y.h=0, S.h=$01.
- PLP: si E=1, M=X=1 forces; si X devient 1: X.h=Y.h=0.
- TAX/TAY/etc: copie 16 bits si X=0 (ou M=0 pour TXA/TYA...) ; regle: la taille copiee = taille de la **destination**: TAX/TAY (dest X/Y) selon X; TXA/TYA (dest A) selon M; TSX selon X; TXS: en E=1 seulement octet bas (S.h=$01), en E=0 16 bits; TCS 16 bits (E=1: S.h=$01); TSC 16 bits; TCD/TDC 16 bits toujours; TXY/TYX selon X.
- XBA: echange octets de A (16 bits toujours), 3 cycles.
- Arithmetique decimale: voir 6.

## 6. Tests d'unite des familles (convention)

Les tests utilisent `FlatBus` (`cpu/testbus.rs`): `FlatBus::new()` ; `bus.poke(addr, &[octets])` ecrit sans journal ; `bus.peek(addr) -> u8` ;
`bus.log: Vec<Cycle>` avec `Cycle { addr: u32, val: u8, kind: CycleKind }`, `CycleKind::{Read, Write, Idle}` (un cycle `Idle` a `addr = 0` et `val = 0`) ;
`bus.clear_log()`. Un test pose le programme en `00:8000` (`cpu.pb = 0; cpu.pc = 0x8000`), fixe les registres a la main, fait `cpu.step(&mut bus)`, puis verifie
registres, memoire et `bus.log.len()` (= nombre de cycles de l'instruction, opcode compris) et, quand c'est precise, la suite exacte des cycles.
Un test peut ecrire `let cycles: Vec<(char, u32, u8)>` ou 'R'/'W'/'I' est le type: a lui de choisir une forme lisible, tant que adresse, valeur, ordre sont verifies.

## Tests
Tous les tests sont prefixes par `e02_15_`.

- `e02_15_lda_imm_8_keeps_high_byte` : e=false, p=0x20, a=0x1234, `A9 80`: a==0x1280, N=1,Z=0 ; cycles = 2.
- `e02_15_lda_imm_16_zero` : p=0x00, a=0x5555, `A9 00 00`: a==0x0000, Z=1,N=0 ; cycles = 3.
- `e02_15_lda_abs` : p=0x20, db=0, poke(0x2000,&[0x42]), `AD 00 20`: A.l==0x42 ; cycles = 4 ; dernier cycle = Read 0x002000.
- `e02_15_lda_long` : p=0x20, poke(0x123456,&[0x99]), `AF 56 34 12`: A.l==0x99, N=1 ; cycles = 5.
- `e02_15_lda_dp_16` : p=0x00, d=0, poke(0x10,&[0x34,0x12]), `A5 10`: a==0x1234 ; cycles = 4.
- `e02_15_lda_ind_y` : p=0x30 (M=1,X=1), poke(0x30,&[0x00,0x20]), db=0, poke(0x2010,&[0x77]), y=0x10, `B1 30`: A.l==0x77 ; cycles = 5.
- `e02_15_lda_sr_ind_y` : p=0x20, s=0x01F0, poke(0x01F4,&[0x00,0x30]), poke(0x3002,&[0x5A]), y=0x0002 (p X=0 -> p=0x20), `B3 04`: A.l==0x5A ; cycles = 7.
- `e02_15_ldx_imm_8` : p=0x30, x=0x0034, `A2 FF`: x==0x00FF, N=1 ; cycles = 2.
- `e02_15_ldx_imm_16` : p=0x00, `A2 34 12`: x==0x1234 ; cycles = 3.
- `e02_15_ldy_dpx` : p=0x30, d=0, x=2, poke(0x12,&[0x77]), `B4 10`: y==0x77 ; cycles = 4.
- `e02_15_lda_emulation` : e=true, p=0x30, `A9 80`: A.l==0x80, N=1, cycles = 2.
