## Specification
Dans `misc.rs::exec`:
- PUSH: `2D` A ; `4D` X ; `6D` Y ; `0D` PSW (`push8`). POP: `AE` A ; `CE` X ; `EE` Y ; `8E` PSW (`pull8`, aucun effet de flag sauf POP PSW qui charge tout `psw`).
- `60` CLRC (C=0) ; `80` SETC ; `ED` NOTC ; `A0` EI (I=1) ; `C0` DI (I=0) ; `E0` CLRV (V=0 ET H=0) ; `20` CLRP (P=0) ; `40` SETP (P=1) ; `00` NOP.
- `EF` SLEEP et `FF` STOP: `halted = true` (`pc` reste a l'adresse suivante); les `step` suivants renvoient 1 (E06-05).

### 6.5 Flags et pile
`CLRC`, `SETC`, `NOTC` (C), `EI`/`DI` (I), `CLRV` (V=0 **et** H=0), `CLRP`/`SETP` (P). `PUSH A|X|Y|PSW`: ecrit `[$100|SP]`, `SP -= 1`. `POP`: `SP += 1`, lit `[$100|SP]` (`POP PSW` charge tous les flags, sans effet de flag pour les autres POP).

### 6.6 Controle de flux (cycles dans le TSV; `branch_taken_extra` s'ajoute si la branche est prise)
- `BPL BMI BVC BVS BCC BCS BNE BEQ rel`: saut conditionnel. `BRA rel`: toujours (4 cycles).
- `CBNE dp,rel` / `CBNE dp+X,rel`: saute si `A != M` (aucun flag). `DBNZ Y,rel` / `DBNZ dp,rel`: decremente puis saute si non nul (aucun flag).
- `JMP !abs`; `JMP [!abs+X]`: pointeur 16 bits lu en `(abs+X) & 0xFFFF` (+1 modulo 65536).
- `CALL !abs`: empile `PCH` puis `PCL` (adresse de l'instruction suivante), `PC = abs`. `PCALL up`: pareil vers `$FF00|imm`. `TCALL n` (n = 0..15, opcode `n*0x10 + 0x01`): empile PC suivant, `PC = lecture16($FFDE - 2*n)`.
- `BRK`: empile `PCH`, `PCL` (PC apres BRK), puis `PSW`; `B = 1; I = 0`; `PC = lecture16($FFDE)`.
- `RET`: depile `PCL` puis `PCH`. `RETI`: depile `PSW`, puis `PCL`, `PCH`.
- `NOP`. `SLEEP` / `STOP`: le coeur reste arrete (le PC ne change plus; chaque `step` consomme 1 cycle factice) tandis que timers et DSP continuent (`UNKNOWN - to confirm`).

## Tests
Tous les tests sont prefixes par `e06_28_`.

- `e06_28_push_a` : sp=0xEF, a=0x5A, `2D`: peek(0x01EF)==0x5A, sp==0xEE, cycles 4.
- `e06_28_push_x_y_psw` : x=0x11 `4D`: peek(0x01EF)==0x11 ; y=0x22 `6D`: peek(0x01EF)==0x22 ; psw=0x86 `0D`: peek(0x01EF)==0x86 ; sp==0xEE ; psw inchange.
- `e06_28_pop_a_no_flags` : sp=0xEE, poke(0x01EF,&[0x9C]), psw=0x00, `AE`: a==0x9C, sp==0xEF, psw==0x00 (pas de N/Z), cycles 4.
- `e06_28_pop_x_y` : `CE` et `EE` avec poke(0x01EF,&[0x33]): x==0x33 resp. y==0x33.
- `e06_28_pop_psw` : sp=0xEE, poke(0x01EF,&[0xA5]), `8E`: psw==0xA5.
- `e06_28_carry_ops` : psw=0 `80`: psw==0x01 ; psw=1 `60`: psw==0 ; psw=0 `ED`: psw==1 ; psw=1 `ED`: psw==0 ; cycles: SETC 2, CLRC 2, NOTC 3.
- `e06_28_i_flag` : psw=0 `A0`: psw==0x04, cycles 3 ; psw=0x04 `C0`: psw==0, cycles 3.
- `e06_28_clrv_clears_h` : psw=0x48 (V,H) `E0`: psw==0x00, cycles 2 ; psw=0xC9 `E0`: psw==0x81.
- `e06_28_p_flag` : psw=0 `40`: psw==0x20 ; `20`: psw==0 ; cycles 2.
- `e06_28_nop` : psw=0x5A, `00`: tous les registres inchanges, pc==0x0201, cycles 2.
- `e06_28_sleep_halts` : `EF`: halted==true, cycles 7, pc==0x0201 ; un `step` de plus renvoie 1 et pc==0x0201 ; idem `FF`.
- `e06_28_all_opcodes_implemented` : Pour chacun des 256 opcodes: bus plat avec l'opcode en 0x0200 et des octets d'operande 0x00; `catch_unwind` autour d'un `step`: AUCUN ne doit paniquer avec le message `unimplemented opcode` (d'autres paniques ne sont pas attendues non plus ; la valeur de retour est ignoree).
