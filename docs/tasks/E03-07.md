# E03-07 - ppu/dot.rs: tables de dots et types de ligne
Epopee: E03 | Type: code | Dependances: E03-06 | Taille estimee: ~100 lignes

## Contexte
Le PPU avance dot par dot. Cette tache ne contient que des fonctions pures sur les durees (en clocks maitres) des dots d'une ligne.
Decision D-008 (provisoire): 4 dots de 5 clocks aux H = 323, 324, 327, 328. Execution strictement sequentielle (D-020): cette tache suppose que toutes les precedentes sont terminees. Ne modifie QUE les fichiers de 'Write only in'.

## Specification
Dans `ppu/dot.rs` (module deja declare par `ppu/mod.rs`):
```rust
#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum LineType { Normal, Short, Long }
pub fn line_type(region: Region, interlace: bool, field: bool, v: u16) -> LineType;
pub fn line_dots(lt: LineType) -> u16;                 // Long: 341 ; sinon 340
pub fn line_clocks(lt: LineType) -> u32;               // Normal 1364 ; Short 1360 ; Long 1368
pub fn dot_clocks(lt: LineType, dot: u16) -> u32;      // 5 si dot dans {323,324,327,328} et lt != Short ; sinon 4 (dot >= line_dots: panic)
pub fn dot_start_clock(lt: LineType, dot: u16) -> u32; // somme des dot_clocks de 0..dot ; accepte dot == line_dots(lt) (= fin de ligne)
```
`line_type`: `Short` si Ntsc ET `!interlace` ET `field` ET `v == 240` ; `Long` si Pal ET `interlace` ET `field` ET `v == 311` ; sinon `Normal`.
`dot_start_clock` peut se calculer en boucle (pas de table necessaire). Utilise les constantes de `crate::consts` (CLOCKS_PER_LINE, CLOCKS_SHORT_LINE, CLOCKS_LONG_LINE).

### 5.1 Longueur des lignes et des dots
```
fn line_clocks(v) -> u32:   // 1364 par defaut
    NTSC && !interlace && field && v == 240  -> 1360   // ligne courte
    PAL  &&  interlace && field && v == 311  -> 1368   // ligne longue
fn line_dots(v) -> u16:  340 (ligne courte aussi: 340 dots de 4 clocks); ligne longue: 341
fn dot_clocks(dot, line) -> u32:  5 si dot in {323, 324, 327, 328} et ligne non courte; sinon 4   // D-008 provisoire
```
`DOT_START_CLOCK[line_type][dot]` est precalcule (3 tables de 341+1 entrees); somme = `line_clocks`.

### 3.1 Position dans la ligne
- `hclock` (0..1363) = master clocks depuis le debut de la ligne. `dot` = H counter (0..339).
- Conversion clock -> dot: 340 dots; les 4 dots de 5 clocks sont aux H = 323, 324, 327, 328 (D-008, provisoire), tous les autres 4 clocks. Table precalculee `DOT_START_CLOCK[0..=340]`.
- Ligne longue (PAL entrelace field=1 V=311): 1368 clocks, 341 dots (337 de 4 + 4 de 5): dot supplementaire a la fin. Ligne courte: 1360 clocks, 340 dots tous a 4 clocks.
- Debut du picture: pixel x=0 a clock 88 (dot 22). 256 pixels: clocks 88..1111.
- HBlank: flag HVBJOY.6 = 1 pour dot >= 274 (clock >= 1096) ou dot < 1 (clock < 4). `UNKNOWN - to confirm` bornes exactes; defaut: H=1 si hclock >= 1096 ou hclock < 4... (valeurs de depart, ROM de test timing trancheront).

## Tests
Tous les tests sont prefixes par `e03_07_`.

- `e03_07_line_type` : `line_type(Ntsc,false,true,240)==Short` ; `(Ntsc,false,false,240)==Normal` ; `(Ntsc,true,true,240)==Normal` ; `(Ntsc,false,true,239)==Normal` ; `(Pal,true,true,311)==Long` ; `(Pal,true,false,311)==Normal` ; `(Pal,false,true,311)==Normal` ; `(Pal,false,true,240)==Normal`.
- `e03_07_dots_clocks_sums` : `line_dots`: Normal 340, Short 340, Long 341. `line_clocks`: 1364, 1360, 1368. Pour chaque type, la somme des `dot_clocks(lt,d)` pour d in 0..line_dots(lt) == `line_clocks(lt)`.
- `e03_07_five_clock_dots` : Normal: `dot_clocks` vaut 5 pour d in {323,324,327,328} et 4 pour d in {0,1,322,325,326,329,339}. Short: 4 partout. Long: 5 aux memes dots, `dot_clocks(Long,340)==4`.
- `e03_07_start_clock_normal` : Normal: `dot_start_clock` de 0->0, 1->4, 22->88, 274->1096, 323->1292, 324->1297, 325->1302, 326->1306, 327->1310, 328->1315, 329->1320, 340->1364.
- `e03_07_start_clock_short_long` : Short: 323->1292, 324->1296, 340->1360. Long: 323->1292, 329->1320, 340->1364, 341->1368.
- `e03_07_visible_window` : `dot_start_clock(Normal,22)==88` (consts::VISIBLE_CLOCK_FIRST) et `dot_start_clock(Normal,278)==1112` (consts::VISIBLE_CLOCK_END).
- `e03_07_panic_oob` : `#[should_panic]`: `dot_clocks(Normal, 340)`.
