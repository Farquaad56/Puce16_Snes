## Specification
Ajoute a `mov.rs::exec` (`ea` = adresse effective par `addr::ea_*`; puis `let _ = cpu.rd(bus, ea); cpu.wr(bus, ea, v);`):
- depuis A: `C4` dp ; `C5` !abs ; `C6` (X) ; `C7` [dp+X] ; `D4` dp+X ; `D5` !abs+X ; `D6` !abs+Y ; `D7` [dp]+Y.
- depuis X: `C9` !abs ; `D8` dp ; `D9` dp+Y.
- depuis Y: `CB` dp ; `CC` !abs ; `DB` dp+X.
Retourne `true`; aucun flag modifie.

### 6.1 MOV (41 opcodes) - aucun flag sauf indication
- Chargements `MOV A|X|Y, src`: `N,Z` selon la valeur. Idem `MOV A,X`, `MOV A,Y`, `MOV X,A`, `MOV Y,A`, `MOV X,SP`. `MOV SP,X`: pas de flag. `MOV A,(X)+`: lit `(X)` puis `X+=1`.
- Stockages (`MOV dst, A|X|Y`, `MOV dp,#imm`, `MOV dp,dp`, `MOV (X)+,A`, `MOV [dp+X],A`, ...): pas de flag. Chaque stockage fait une **lecture factice** de la destination avant l'ecriture (sauf `MOV dp,dp` qui lit la source puis ecrit la destination) (`UNKNOWN - to confirm` via les cycles des tests). Important pour `$FD-$FF` (lecture efface le compteur).
- `MOVW YA,dp`: lit octet bas puis haut (haut en `P|((b+1)&0xFF)`), `YA = mot`, `N` = bit 15, `Z` = (YA==0). `MOVW dp,YA`: lecture factice de l'octet bas, puis ecrit bas (A) puis haut (Y); pas de flag.
