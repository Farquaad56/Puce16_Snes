## Specification
Dans `bus/mod.rs` (garde `access_clocks`, `pub mod wram; pub mod mmio;`) ajoute:
```rust
pub struct SysBus {
    pub master: u64, pub region: Region,
    pub cart: Cart, pub wram: Wram, pub mmio: Mmio, pub dma: Dma, pub ppu: Ppu, pub apu: Apu, pub joy: Joypads, pub timing: Timing,
    pub mdr: u8, pub memsel: bool,
    ppu_t: u64, pending_dma: u8, dma_wait: bool, pending_hdma_init: bool, pending_hdma_run: bool, vblank_flag: bool, vblank_count: u64,
}
impl SysBus {
    pub fn new(cart: Cart, region: Region) -> SysBus;     // tout a l'etat de power-on; master 0; ppu_t 0; mdr 0; memsel false; flags faux; vblank_count 0
    pub fn reset(&mut self);                              // reset bouton: mmio.reset(), ppu.reset(), apu.reset(), wram.reset_addr(), timing = Timing::new(), pending_* = faux, master = 0, ppu_t = 0, mdr = 0, memsel = false, vblank_flag = false, vblank_count = 0 ; WRAM, cart (SRAM), dma, joy conserves
    pub fn take_vblank_flag(&mut self) -> bool;           // renvoie vblank_flag puis le met a false
    pub fn vblank_count(&self) -> u64;  pub fn pending_dma(&self) -> u8;
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);  // master (u64), mdr, memsel (u8), ppu_t (u64), pending_dma, dma_wait, pending_hdma_init, pending_hdma_run, vblank_flag (u8), vblank_count (u64), puis cart, wram, mmio, dma, ppu, apu, joy, timing
}
```
Imports: `crate::cart::Cart`, `crate::dma::Dma`, `crate::ppu::Ppu`, `crate::apu::Apu`, `crate::joypad::Joypads`, `crate::timing::Timing`, `crate::region::Region`, `wram::Wram`, `mmio::Mmio`.

## 7. Reset et power-on
- Power-on: WRAM = 0x55 (D-011), registres 5A22 comme ci-dessus, PPU voir 05_PPU.md, APU voir 07_SPC700.md.
- Reset (bouton): registres NMITIMEN, HDMAEN, MDMAEN = 0, flags RDNMI/TIMEUP effaces; RAM conservee. CPU: voir 01_CPU_65816.md.
- Premiere instruction apres reset: le temps initial `master` (offset de phase) est `UNKNOWN - to confirm`; defaut: H = 0 de la ligne V = 0, master = 0, puis 7 cycles de reset a 6 clocks... Les ROM ne dependent normalement pas de la phase (sauf tests de timing).

## Tests
Tous les tests sont prefixes par `e03_26_`.

- `e03_26_power_on` : Dans les tests: `mod common; use common::*;` puis `fn mk(code: &[u8]) -> SysBus { SysBus::new(Cart::from_bytes(&make_rom(code, Map::LoRom)).unwrap(), Region::Ntsc) }` (imports: `puce16_core::bus::SysBus`, `puce16_core::cart::Cart`, `puce16_core::Region`). `mk(&[0xEA])`: master==0, mdr==0, memsel==false, `wram.read(0)==0x55`, `ppu.v()==0`, `ppu.dot()==0`, `vblank_count()==0`, `take_vblank_flag()==false`, `pending_dma()==0`, `region==Ntsc`.
- `e03_26_reset_keeps_wram` : `bus.wram.write(5,1); bus.mmio.nmitimen=0x80; bus.master=1000; bus.mdr=7; bus.reset()`: master==0, mdr==0, nmitimen==0, `wram.read(5)==1`, `wram.addr==0`, ppu position (0,0).
- `e03_26_reset_keeps_cart_sram` : ROM avec SRAM (`make_rom_with(&[],LoRom,15,3,0x02,1)`): `bus.cart.write(0x70,0,0x5A)` puis `reset()`: `bus.cart.read(0x70,0)==Some(0x5A)`.
- `e03_26_take_vblank_initial` : `bus.vblank_count()==0` et `take_vblank_flag()==false` deux fois de suite (le flag n'est leve que par le temps: voir E03-29).
- `e03_26_hash_equal` : deux `mk(&[0xEA])` ont le meme hash (`Fnv64::new()` puis `hash_into`) ; apres `bus.wram.write(0,1)` le hash differe ; apres `bus.master = 5` il differe.
- `e03_26_pal_region` : `SysBus::new(cart, Region::Pal)`: `ppu.last_line()==311`.
