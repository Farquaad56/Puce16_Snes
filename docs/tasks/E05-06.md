## Specification
Dans `Ppu::bg_pixel` :
- Tuile 8x8 (`!regs.tile16[n]`) : `tx = px >> 3`, `ty = py >> 3` ; `fx = (px & 7) ^ (if hflip { 7 } else { 0 })` ; `fy = (py & 7) ^ (if vflip { 7 } else { 0 })` ; numero de tuile = `entry.tile`.
- Tuile 16x16 (`regs.tile16[n]`) : `tx = px >> 4`, `ty = py >> 4` ; `xs = (((px >> 3) & 1) as u16) ^ (hflip as u16)` ; `ys = (((py >> 3) & 1) as u16) ^ (vflip as u16)` ; numero = `(entry.tile + xs + ys * 16) & 0x3FF` ; `fx`, `fy` comme pour 8x8 (a partir de `px & 7`, `py & 7`).
Le reste (palette, priorite, direct color) est inchange. L'entree est lue a `map_entry_addr(.., tx, ty)`.

## 5. Tilemap (fonction pure `map_entry_addr`)
Entree de 16 bits: `VHPC CCTT TTTT TTTT`: bit15 V (flip vertical), bit14 H (flip horizontal), bit13 P (priorite), bits12-10 palette, bits9-0 numero de tuile.
Position d'entree `(tx, ty)` en unites de tuile de la carte (apres division par 8 ou 16 selon la taille):
```
scr = ((tx >> 5) & map_x2) + ((ty >> 5) & map_y2) * (if map_x2 {2} else {1})
addr = (map_base + scr * 0x400 + (ty & 31) * 32 + (tx & 31)) & 0x7FFF
```
`tx` est masque par la largeur: `tx & (if map_x2 {63} else {31})`, `ty & (if map_y2 {63} else {31})` avant le calcul ci-dessus.
Tuile 8x8: `tx = px >> 3`, `ty = py >> 3`. Tuile 16x16 (BGMODE bit pour ce BG): `tx = px >> 4`, `ty = py >> 4`; sous-tuile: `xs = ((px >> 3) & 1) ^ H`, `ys = ((py >> 3) & 1) ^ V`; `tuile = T + xs + ys * 16` (`& 0x3FF`). Flip dans la tuile 8x8: `fx = (px & 7) ^ (if H {7} else {0})`, `fy = (py & 7) ^ (if V {7} else {0})`.

## Tests
Tous les tests sont prefixes par `e05_06_`.

- `e05_06_scene_16x16` : Scene D (mode 1, BG1 16x16, 4 bpp) : `write(0x05,0x11)` ; `write(0x07,0x04)` ; `write(0x0B,0x01)` ; `put_vram(0x400,0x0402)` (entree (0,0) : tuile 2, pal 1) ; tuile 2 (0x1020) rangee 0 : `put_vram(0x1020,0x0080)` (indice 1 pixel 0) ; tuile 3 (0x1030) : `put_vram(0x1030,0x8000)` (indice 2) ; tuile 18 (0x1120) : `put_vram(0x1120,0x8080)` (indice 3) ; `put_cgram(p,17,0x0011)`, `(p,18,0x0022)`, `(p,19,0x0033)`. Attendu (v=0 -> py=0) : `bg_pixel(0,0,0)` rgb 0x0011 (tuile 2) ; `bg_pixel(0,8,0)` rgb 0x0022 (sous-tuile droite = tuile 3) ; `bg_pixel(0,0,8)` rgb 0x0033 (sous-tuile basse = tuile 18) ; `bg_pixel(0,1,0)==None`.
- `e05_06_hflip_16x16` : Scene D avec entree 0x4402 (H flip) : `bg_pixel(0,15,0)` rgb 0x0011 (xs = 1^1 = 0 -> tuile 2, fx = 7^7 = 0) ; `bg_pixel(0,7,0)` rgb 0x0022 (xs = 0^1 = 1 -> tuile 3, fx = 0) ; `bg_pixel(0,0,0)==None` (tuile 3, fx = 7).
- `e05_06_vflip_16x16` : Scene D avec entree 0x8402 (V flip) : `bg_pixel(0,0,15)` rgb 0x0011 (ys = 1^1 = 0 -> tuile 2, fy = 7^7 = 0 mais la rangee 0 : py=15 -> fy = (15&7)^7 = 0) ; `bg_pixel(0,0,7)` rgb 0x0033 (ys = 0^1 = 1 -> tuile 18, fy = 7^7 = 0).
- `e05_06_flips_8x8` : Scene A de E05-05 avec entree (0,0) = 0x4402 (H flip, 8x8) : `bg_pixel(0,7,0)` rgb 0x1234 et `bg_pixel(0,0,0)==None`. Avec 0x8402 (V flip) : `bg_pixel(0,0,7)` rgb 0x1234 (fy = 7^7 = 0) et `bg_pixel(0,0,0)==None` (fy = 7).
- `e05_06_both_flips_8x8` : entree 0xC402 (H et V) : `bg_pixel(0,7,7)` rgb 0x1234 ; `bg_pixel(0,0,0)==None`.
- `e05_06_tile_number_wrap_16x16` : entree avec tuile 0x3F0 (16x16, ys=1 -> + 16) : le numero utilise est `(0x3F0 + 16) & 0x3FF == 0` (tuile 0) : avec des donnees de tuile 0 non nulles a 0x1000 (`put_vram(0x1000,0x0080)`), `bg_pixel(0,0,8)` renvoie Some (indice 1).
- `e05_06_tile16_per_bg` : Scene D + BG2 en 8x8 : `write(0x08,0x08)` (carte BG2 a 0x800) ; `write(0x0B,0x11)` (chr BG1 et BG2 a 0x1000) ; `put_vram(0x801,0x0402)` (entree BG2 (1,0) : tuile 2, pal 1). `bg_pixel(1,8,0)` rgb 0x0011 (BG2 8x8 : px = 8 -> tuile 2 pixel 0) alors que `bg_pixel(0,8,0)` rgb 0x0022 (BG1 16x16 : sous-tuile droite = tuile 3).
