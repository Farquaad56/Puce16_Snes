## Specification
Programmes (offsets relatifs a 0x8000). Vecteur NMI -> 0x8100 pour les programmes A, B et G; handler `HANDLER_INC0100` a l'offset 0x100: `EE 00 01  40` = INC $0100 ; RTI.
- `PROG_A` (NMI active): `78 18 FB  9C 00 01  A9 80  8D 00 42  80 FE` = SEI ; CLC ; XCE ; STZ $0100 ; LDA #$80 ; STA $4200 ; BRA -2.
- `PROG_B` (NMI inactive): `78 18 FB  9C 00 01  80 FE`.
- `PROG_C` (comptage par RDNMI, sans NMI): `78 18 FB  9C 02 01  AD 10 42  10 FB  EE 02 01  80 F6` = ... STZ $0102 ; L: LDA $4210 ; BPL L ; INC $0102 ; BRA L. (L = offset 0x06.)
- `PROG_G` (active NMI en plein VBlank): `78 18 FB  9C 00 01  AD 12 42  10 FB  A9 80  8D 00 42  80 FE` = ... STZ $0100 ; L: LDA $4212 ; BPL L ; LDA #$80 ; STA $4200 ; BRA -2. Chaque fichier de test commence par `mod common; #[path = "common/prog.rs"] mod prog;` (et `#[path = "common/fake_dma_bus.rs"]` n'est pas utile ici), puis `use puce16_core::snes::Snes; use prog::build_rom;`. Helper de test: `fn snes(rom: Vec<u8>) -> Snes { Snes::new(&rom, None).ok().unwrap() }`. Les programmes sont du code machine 65816 assemble A LA MAIN (octets donnes); l'adresse CPU de l'octet i du programme est 0x8000 + i. `settle(&mut s)` = `for _ in 0..12 { s.step_instruction(); }` (laisse le temps au CPU de prendre une interruption apres `run_frame`).

### 6.2 NMI
- Flag NMI (RDNMI.7) mis au debut du VBlank (V = vblank_start, H = 0 + `NMI_FLAG_DELAY` clocks; defaut 2 dots = ~8 clocks; `UNKNOWN - to confirm`), efface par lecture de $4210 ou a la fin du VBlank (V=0 debut).
- Ligne NMI vers CPU = `flag AND nmitimen.7`. Front montant => NMI. Voir 01_CPU_65816.md section 8.
- Power-on/reset: flag = 0 (RDNMI & $7F).

## 8. Algorithme de `Timing::on_dot` (position = (ppu.v(), ppu.dot()) APRES le step, `t` = debut de ce dot)
Dans cet ordre:
1. `dot == 0`: `line_start = t`; `refreshed_this_line = false`. Si de plus `v == 0`: `out.frame_end = true`; `mmio.rdnmi_flag = false` (fin du VBlank).
2. `v == ppu.vblank_start() && dot == NMI_FLAG_DOT`: `mmio.rdnmi_flag = true`; `out.vblank_start = true`.
3. Ligne NMI: `line = mmio.rdnmi_flag && (mmio.nmitimen & 0x80 != 0)`; si `line && !nmi_line_prev`: `nmi_edge = true`; `nmi_line_prev = line`.
4. IRQ H/V: `mode = (mmio.nmitimen >> 4) & 3`; si `mode != 0`: mode 1: `dot == htime + IRQ_H_OFFSET_DOTS`; mode 2: `v == vtime && dot == IRQ_H_OFFSET_DOTS`; mode 3: `v == vtime && dot == htime + IRQ_H_OFFSET_DOTS` ; `htime > 339` ou `vtime > derniere ligne` : jamais. Si vrai: `mmio.timeup_flag = true; mmio.irq_line = true`.
5. Auto-read: si `nmitimen & 1 != 0 && v == vblank_start && dot == AUTOREAD_START_DOT`: `autoread_end = Some(t + AUTOREAD_CLOCKS)`. Puis, si `autoread_end == Some(e)` et `t >= e`: `mmio.joy = joy.autoread_values()`; `autoread_end = None`.
6. HDMA: `mmio.hdmaen != 0`: `v == 0 && dot == HDMA_INIT_DOT` -> `out.hdma_init`; `v <= vis_last && dot == HDMA_RUN_DOT` -> `out.hdma_run`.
`mmio.read` de `$4210` efface `rdnmi_flag` ; de `$4211` efface `timeup_flag` ET `irq_line` ; `mmio.write(NMITIMEN)` avec bits V/H = 00 efface `timeup_flag` et `irq_line`.

## Tests
Tous les tests sont prefixes par `e03_37_`.

- `e03_37_nmi_counts_frames` : PROG_A + handler + vecteur nmi: pour k = 1..=5: `run_frame(); settle();` puis `peek_wram(0x100)==k` (un NMI par frame).
- `e03_37_nmi_not_before_vblank` : PROG_A: `run_master(100_000)` (avant le VBlank, ~306 900 clocks): `peek_wram(0x100)==0` et `frame_count()==0`.
- `e03_37_nmi_disabled` : PROG_B (meme handler/vecteur): 3 frames avec settle : `peek_wram(0x100)==0` (jamais de NMI).
- `e03_37_rdnmi_polling` : PROG_C (sans handler): pour k = 1..=4: `run_frame(); settle();` puis `peek_wram(0x102)==k` (le bit 7 de $4210 est vu une seule fois par frame, la lecture l'efface).
- `e03_37_enable_in_vblank_fires` : PROG_G + handler + vecteur nmi: apres le 1er `run_frame(); settle();` : `peek_wram(0x100)==1` (activer NMITIMEN.7 alors que RDNMI est deja a 1 declenche un NMI) ; apres le 2eme : 2.
- `e03_37_nmi_handler_returns` : PROG_A: apres `run_frame(); settle();` le CPU est revenu dans la boucle principale: `debug().pc` vaut l'offset de la boucle `BRA` + 0x8000 (0x800B pour PROG_A) et `debug().e==false`.
- `e03_37_nmi_native_vs_emulation` : `PROG_A` modifie pour NE PAS passer en mode natif (sans `CLC ; XCE`: `78  9C 00 01  A9 80  8D 00 42  80 FE`) : le NMI utilise le vecteur d'EMULATION ($FFFA), qui est aussi 0x8100 grace a `set_vector` : le compteur vaut 1 apres la 1re frame (verifie `debug().e==true` apres le handler).
