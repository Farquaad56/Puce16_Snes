## Specification
Ajoute dans `files.rs` (sans toucher aux fonctions de E03-45):
```rust
use std::path::{Path, PathBuf};
pub fn srm_path(rom: &Path) -> PathBuf;                 // meme dossier, nom sans extension + ".srm"
pub fn state_path(rom: &Path, slot: u8) -> PathBuf;     // "<nom>.<slot>.p16s" (slot 0..=9, sinon slot % 10)
pub fn screenshot_path(rom: &Path, exists: &dyn Fn(&Path) -> bool) -> PathBuf;   // "<nom>_<n>.ppm", n = premier entier >= 1 tel que !exists(chemin)
pub fn write_atomic(path: &Path, bytes: &[u8]) -> Result<(), String>;            // ecrit "<chemin>.tmp" puis rename ; Err("cannot write <chemin>: <err>")
pub fn rom_hash(bytes: &[u8]) -> u64;                   // FNV-1a 64 (puce16_core::hash::Fnv64) des octets
pub const STATE_MAGIC: [u8; 4] = *b"P16S";
pub const STATE_CONTAINER_VERSION: u16 = 1;
pub fn encode_state(rom_hash: u64, region: u8, blob: &[u8]) -> Vec<u8>;   // magic, u16 version LE, u64 hash LE, u8 region, puis blob
pub fn decode_state(data: &[u8], expect_rom_hash: u64) -> Result<(u8, &[u8]), String>;
```
`decode_state` renvoie `(region, blob)` ou `Err`: `"not a Puce16 state"` (fichier < 15 octets ou magie fausse), `"unsupported state container version <v>"`, `"state belongs to another ROM"` (hash different). L'en-tete fait 4 + 2 + 8 + 1 = 15 octets. "Nom" = nom de fichier sans extension (`file_stem`) ; dossier = parent de la ROM (`.` si absent).

## 6. Fichiers

- Ouverture: `rfd` (filtres `.sfc`, `.smc`, `.swc`, `.fig`, `.zip`). Un `.zip` (crate `zip`) : prendre la premiere entree dont l'extension est une des quatre precedentes.
- **SRAM**: `<dossier de la ROM>/<nom sans extension>.srm`, octets bruts de `Snes::sram()`. Chargee a l'ouverture de la ROM (`load_sram`) ; sauvee toutes les 5 s si le contenu a change, a la fermeture de la ROM et a la sortie ; ecriture atomique (ecrire `.srm.tmp` puis renommer). Pas de SRAM (`None`) -> aucun fichier.
- **Save states**: `<dossier de la ROM>/<nom>.<slot>.p16s`, slot 0..9. Contenu: en-tete `b"P16S"` + `u16` version du conteneur (1) + `u64` hash FNV-64 des octets de la ROM tels que charges (apres extraction d'un `.zip`, avant toute normalisation du core) + `u8` region, puis le blob `Snes::save_state()`. Au chargement: refuser (message) si magie, version ou hash ROM different.
- **Config**: `config.json` dans `%APPDATA%\Puce16\` (Windows) ; a defaut `$HOME/.config/puce16/`. JSON: `scale, ratio, filter, volume, muted, fullscreen, keymap, pad_map, recent_roms (max 8), last_dir, block_opposite_dirs`. Fichier absent ou invalide -> valeurs par defaut (jamais de plantage).
- Capture d'ecran F2: `<nom>_<n>.ppm` dans le dossier de la ROM (n = premier numero libre).

## Tests
Tous les tests sont prefixes par `e08_20_`.

- `e08_20_srm_path` : `srm_path("/g/Super Mario World.sfc")=="/g/Super Mario World.srm"` ; `srm_path("rom.smc")=="rom.srm"` ; un nom sans extension `"game"` -> `"game.srm"`.
- `e08_20_state_path` : `state_path("/g/a.sfc", 3)=="/g/a.3.p16s"` ; slot 12 -> `a.2.p16s`.
- `e08_20_screenshot_path` : `exists` toujours faux -> `"/g/a_1.ppm"` ; `exists` vrai pour `a_1.ppm` et `a_2.ppm` seulement -> `a_3.ppm`.
- `e08_20_write_atomic` : dans un dossier temporaire: ecrit [1,2,3] ; relu == [1,2,3] ; le fichier `.tmp` n'existe plus ; une seconde ecriture remplace le contenu ; dossier inexistant -> `Err` contenant `cannot write`.
- `e08_20_rom_hash` : `rom_hash(&[])==0xcbf29ce484222325` ; `rom_hash(&[1,2,3])` == valeur calculee dans le test avec `Fnv64` ; deux ROM differentes -> hash differents.
- `e08_20_encode_header_layout` : `encode_state(0x0102030405060708, 1, &[9,9])` == `b"P16S"` + `[1,0]` + `[8,7,6,5,4,3,2,1]` + `[1]` + `[9,9]` (longueur 17).
- `e08_20_decode_roundtrip` : `decode_state(&encode_state(h, 1, blob), h) == Ok((1, blob))`.
- `e08_20_decode_errors` : magie `XXXX...` -> `Err("not a Puce16 state")` ; 10 octets -> idem ; version 2 -> `unsupported state container version 2` ; autre hash -> `state belongs to another ROM`.
