## Specification
Dans `ppu/mod.rs`: ajoute au `Ppu` les champs `latch_h: u16`, `latch_v: u16`, `counter_latched: bool`, `ophct_byte: bool`, `opvct_byte: bool`, `range_over: bool`, `time_over: bool` (tous a 0 / false) et:
```rust
pub fn latch_counters(&mut self);                  // latch_h = (self.dot as u32 + crate::consts::HV_LATCH_DOT_OFFSET) as u16 ; latch_v = self.v ; counter_latched = true
pub fn counter_latched(&self) -> bool;
pub fn set_range_over(&mut self, b: bool);  pub fn set_time_over(&mut self, b: bool);
pub fn range_over(&self) -> bool;  pub fn time_over(&self) -> bool;
```
`wrio_write(old, new)`: si `old & 0x80 != 0 && new & 0x80 == 0` (front descendant du bit 7) -> `latch_counters()`.
`read` (complete E04-09):
- `0x37` SLHV: si `wrio7` -> `latch_counters()` ; renvoie `cpu_mdr` (pas de mise a jour d'open bus).
- `0x3C` OPHCT: `val = if !ophct_byte { (latch_h & 0xFF) as u8 } else { (((latch_h >> 8) & 1) as u8) | (ppu2_mdr & 0xFE) }` ; `ophct_byte = !ophct_byte` ; `ppu2_mdr = val`. `0x3D` OPVCT: idem avec `latch_v` et `opvct_byte`.
- `0x3E` STAT77: `val = (range_over as u8) << 7 | (time_over as u8) << 6 | (ppu1_mdr & 0x10) | 0x01` ; `ppu1_mdr = val`.
- `0x3F` STAT78: `val = (field as u8) << 7 | (counter_latched as u8) << 6 | (ppu2_mdr & 0x20) | (is_pal as u8) << 4 | 0x03` ; puis `counter_latched = false ; ophct_byte = false ; opvct_byte = false` ; `ppu2_mdr = val`.
`hash_into`: AJOUTE a la fin: `latch_h` (u16), `latch_v` (u16), `counter_latched`, `ophct_byte`, `opvct_byte`, `range_over`, `time_over` (u8 chacun).

## 4. Registres PPU en lecture ($2134-$213F)

`Ppu::read(reg, cpu_mdr, wrio7) -> u8`. `ppu1_mdr` et `ppu2_mdr` = derniere valeur retournee par un registre PPU1 / PPU2 respectivement.

| Reg | Nom | Valeur retournee | Mise a jour open bus |
|---|---|---|---|
| $2134 | MPYL | `mpy & 0xFF` | `ppu1_mdr = valeur` |
| $2135 | MPYM | `(mpy >> 8) & 0xFF` | `ppu1_mdr` |
| $2136 | MPYH | `(mpy >> 16) & 0xFF` | `ppu1_mdr` |
| $2137 | SLHV | si `wrio7`: verrouille les compteurs (4.1). Retourne `cpu_mdr`. | aucune |
| $2138 | OAMDATAREAD | voir 2.1 | `ppu1_mdr` |
| $2139 | VMDATALREAD | voir 2.3 | `ppu1_mdr` |
| $213A | VMDATAHREAD | voir 2.3 | `ppu1_mdr` |
| $213B | CGDATAREAD | voir 2.4 | `ppu2_mdr` |
| $213C | OPHCT | voir 4.1 | `ppu2_mdr` |
| $213D | OPVCT | voir 4.1 | `ppu2_mdr` |
| $213E | STAT77 | `(range_over<<7) | (time_over<<6) | (ppu1_mdr & 0x10) | 0x01` (bit7 = T: plus de 32 sprites sur une ligne = `range_over`; bit6 = R: plus de 34 tranches = `time_over`; bit5 master/slave = 0; version PPU1 = 1) | `ppu1_mdr` |
| $213F | STAT78 | `(field<<7) | (counter_latched<<6) | (ppu2_mdr & 0x20) | (is_pal<<4) | 0x03` ; puis `counter_latched = false; ophct_byte = 0; opvct_byte = 0` | `ppu2_mdr` |

`mpy = (m7a as i16 as i32) * ((m7b_last_byte as i8) as i32)` (24 bits signe, calcule a la lecture).
Lecture de $2100-$2133 et de $2137: retourne `cpu_mdr` (open bus CPU).

### 4.1 Verrou des compteurs H/V
- Verrouillage (`latch_counters`): `latch_h = dot_counter_now()`, `latch_v = v`, `counter_latched = true`. `dot_counter_now()` = `self.dot` (0..339, ou 0..340 sur ligne longue); decalage `HV_LATCH_DOT_OFFSET` dans consts.rs, defaut 0 (`UNKNOWN - to confirm`).
- Declencheurs: lecture de $2137 si `wrio7`; `wrio_write(old, new)` quand le bit 7 passe de 1 a 0 (front descendant) [spec 02: WRIO.7 = /EXTLATCH].
- OPHCT ($213C): `ophct_byte == 0` -> retourne `latch_h & 0xFF`; sinon retourne `(latch_h >> 8) & 1 | (ppu2_mdr & 0xFE)`. Puis `ophct_byte ^= 1`.
- OPVCT ($213D): idem avec `latch_v` et `opvct_byte`.
- Avant tout verrouillage, `latch_h = latch_v = 0`.

## Tests
Tous les tests sont prefixes par `e04_10_`.

- `e04_10_before_latch` : `Ppu::new(Ntsc)` : `read(0x3C,0,false)==0` et `read(0x3D,0,false)==0` ; `counter_latched()==false`.
- `e04_10_latch_via_slhv` : a (3,100): `read(0x37,0xEE,true)==0xEE` ; `counter_latched()==true` ; `read(0x3C,0,false)==100` ; `read(0x3D,0,false)==3` (ppu2_mdr valait 100, mais le 1er octet ne depend pas de l'open bus).
- `e04_10_slhv_needs_wrio7` : a (3,100): `read(0x37,0,false)` ne verrouille pas : `counter_latched()==false`.
- `e04_10_ophct_two_bytes` : a (1,300): `read(0x37,0,true)` ; `read(0x3C,0,false)==0x2C` (300 = 0x12C, ppu2_mdr=0x2C) ; `read(0x3C,0,false)==0x2D` (bit 8 = 1 | (0x2C & 0xFE)) ; `read(0x3C,0,false)==0x2C` (le toggle est revenu au 1er octet).
- `e04_10_opvct_two_bytes` : a (261,5): `read(0x37,0,true)` ; `read(0x3D,0,false)==0x05` (261 = 0x105) ; `read(0x3D,0,false)==0x05` (bit 8 = 1 | (0x05 & 0xFE = 0x04) = 0x05) ; `read(0x3D,0,false)==0x05`.
- `e04_10_latch_value_frozen` : a (2,10): `read(0x37,0,true)` ; puis 5 `step_dot` supplementaires : `read(0x3C,0,false)==10` (la valeur verrouillee ne bouge pas).
- `e04_10_stat78_ntsc` : `Ppu::new(Ntsc)`: `read(0x3F,0,false)==0x03`. Apres 262*340 steps (frame 0 terminee): `read(0x3F,0,false)==0x83` (field=1).
- `e04_10_stat78_pal` : `Ppu::new(Pal)`: `read(0x3F,0,false)==0x13`.
- `e04_10_stat78_clears_latch` : a (3,100): `read(0x37,0,true)` ; `read(0x3F,0,false)==0x43` ; `counter_latched()==false` ; `read(0x3F,0,false)==0x03`.
- `e04_10_stat78_resets_toggles` : a (1,300): latch ; `read(0x3C,0,false)==0x2C` (toggle vrai) ; `read(0x3F,0,false)==0x63` (0x40 latched | 0x20 (ppu2_mdr=0x2C) | 0x03) ; `read(0x3C,0,false)==0x2C` (toggle remis au 1er octet, latch_h conserve).
- `e04_10_stat77` : `Ppu::new(Ntsc)`: `read(0x3E,0,false)==0x01`. `set_range_over(true)`: 0x81. `set_time_over(true)` aussi: 0xC1. Open bus bit 4: a=16 (`write(0x1B,0x10); write(0x1B,0x00)`), `write(0x1C,0x01)` -> `read(0x34,..)==0x10` (ppu1_mdr=0x10) puis `read(0x3E,..)==0x11`.
- `e04_10_wrio_falling_edge` : a (2,10): `wrio_write(0x80,0x00)` verrouille (`counter_latched()==true`) ; nouveau `Ppu` a (2,10): `wrio_write(0x00,0x80)`, `wrio_write(0x80,0x80)`, `wrio_write(0x00,0x00)` ne verrouillent pas ; `wrio_write(0xFF,0x7F)` verrouille.
- `e04_10_hash` : hash differe apres `read(0x37,0,true)` (verrou) ; apres `set_range_over(true)` ; apres `set_time_over(true)`.
