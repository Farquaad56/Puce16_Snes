## Specification
Dans `ppu/cgram.rs`:
```rust
pub struct Cgram { mem: [u16; 256], addr: u8, toggle: bool, latch: u8 }
impl Cgram {
    pub fn new() -> Cgram;                         // tout a 0 / false
    pub fn reset_regs(&mut self);                  // addr = 0, toggle = false, latch = 0 ; memoire CONSERVEE
    pub fn set_addr(&mut self, v: u8);             // CGADD: addr = v ; toggle = false
    pub fn write(&mut self, v: u8);                // CGDATA, section 2.4
    pub fn read(&mut self, ppu2_mdr: u8) -> u8;    // CGDATAREAD, section 2.4 ; renvoie l'octet (l'appelant le memorise comme ppu2_mdr)
    pub fn addr(&self) -> u8;  pub fn toggle(&self) -> bool;
    pub fn word(&self, i: u8) -> u16;              // mem[i]
    pub fn set_word(&mut self, i: u8, w: u16);     // debug/test: mem[i] = w & 0x7FFF
    pub fn mem(&self) -> &[u16; 256];
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);   // mem (write_u16_slice), addr (u8), toggle (u8), latch (u8)
}
```
`write` : si `!toggle` { `latch = v` } sinon { `mem[addr] = ((v & 0x7F) as u16) << 8 | latch as u16 ; addr = addr.wrapping_add(1)` } ; puis `toggle = !toggle`.
`read(m)` : `w = mem[addr]` ; si `!toggle` -> `byte = (w & 0xFF) as u8` ; sinon `byte = ((w >> 8) as u8 & 0x7F) | (m & 0x80)` et `addr = addr.wrapping_add(1)` ; puis `toggle = !toggle` ; renvoie `byte`.

### 2.4 CGRAM
```
CGDATA write v:  if cgram_byte_toggle == 0 { cgram_latch = v }
                 else { cgram[cgram_addr] = (((v & 0x7F) as u16) << 8) | cgram_latch as u16; cgram_addr = (cgram_addr + 1) & 0xFF }
                 cgram_byte_toggle ^= 1
CGDATAREAD ($213B): w = cgram[cgram_addr]
                 toggle == 0 -> byte = w & 0xFF
                 toggle == 1 -> byte = ((w >> 8) as u8 & 0x7F) | (ppu2_mdr & 0x80); cgram_addr = (cgram_addr + 1) & 0xFF
                 cgram_byte_toggle ^= 1 ; ppu2_mdr = byte
```
Les acces CGRAM sont toujours autorises dans v1 (les jeux ecrivent la CGRAM en HBlank par HDMA). `UNKNOWN - to confirm`: ecritures pendant l'affichage actif sur le vrai materiel.

## Tests
Tous les tests sont prefixes par `e04_02_`.

- `e04_02_set_addr_resets_toggle` : `write(0x12)` -> toggle()==true ; `set_addr(5)` -> addr()==5, toggle()==false.
- `e04_02_pair_write` : `set_addr(0)`; `write(0x1F); write(0x03)` -> `word(0)==0x031F`, `addr()==1`, `toggle()==false` ; `write(0xFF); write(0xFF)` -> `word(1)==0x7FFF` (bit 15 efface), `addr()==2`.
- `e04_02_latch_not_committed` : `set_addr(3); write(0xAA)` : `word(3)==0`, `toggle()==true`, `addr()==3`. Le 2eme octet `write(0x01)` -> `word(3)==0x01AA`, `addr()==4`.
- `e04_02_addr_wrap` : `set_addr(255); write(0x01); write(0x02)` -> `word(255)==0x0201`, `addr()==0`.
- `e04_02_read_pair` : `set_word(2,0x7ABC)` ; `set_addr(2)` ; `read(0x00)==0xBC` (toggle vrai, addr reste 2) ; `read(0x00)==0x7A` (addr 3, toggle faux). Meme sequence avec `m=0x80` sur le 2eme octet : `read(0x80)==0xFA`.
- `e04_02_set_word_masks_bit15` : `set_word(0,0xFFFF)` -> `word(0)==0x7FFF`.
- `e04_02_shared_toggle` : `set_addr(0)`; `write(0x11)` (toggle vrai) ; `read(0x00)==0` (traite comme octet haut de `word(0)==0`), `addr()==1`, `toggle()==false`.
- `e04_02_hash` : hash identique pour deux `Cgram::new()` ; differe apres `set_word(0,1)` ; differe apres `set_addr(1)` ; differe apres un `write(5)` seul (latch/toggle).
