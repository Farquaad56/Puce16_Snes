## Specification
Ecris dans `dsp/brr.rs` (remplace le commentaire):
```rust
pub fn clamp16(v: i32) -> i32;     // v.max(-32768).min(32767)
/// b0 = octet haut (nibbles 1-2), b1 = octet bas (nibbles 3-4). Renvoie (4 echantillons a l'echelle 16 bits, nouveau p1, nouveau p2).
pub fn decode_group(b0: u8, b1: u8, shift: u8, filter: u8, p1: i32, p2: i32) -> ([i32; 4], i32, i32);
```
`decode_group` suit EXACTEMENT la boucle de la section 3 (`nyb` est un `i16` construit par `((b0 as u16) << 8 | b1 as u16) as i16`; `nyb >>= 12` arithmetique pour le nibble signe; `nyb <<= 4` apres chaque echantillon; `shift` est un `u8` 0..15 avec `shift > 12` -> branche `(s >> 4) << 11`; `filter` est 0..3 (utiliser `filter & 3`); toutes les operations sur des `i32`; le repliement final est `((s * 2) as i16) as i32`). A chaque echantillon: `p2 = p1 >> 1; p1 = s_replie`. Les valeurs renvoyees sont les derniers `p1` et `p2`.

## 3. BRR
Bloc de 9 octets: en-tete `SSSS FFLE` (shift = bits 7-4, filtre F = bits 3-2, boucle L = bit 1, fin E = bit 0) + 8 octets = 16 nibbles (nibble haut d'abord).
Repertoire: `dir = (DIR as u16) << 8`; entree de la voix = `dir + SRCN*4` (mod 65536): `start = ram16(entry)`, `loop = ram16(entry+2)`.
Decodage par **groupes de 4 echantillons** (octets `addr+1+2*j` et `+2` du groupe j = 0..3 du bloc):
```
nyb = (ram[a] << 8 | ram[a+1]) as i16                 // 16 bits = 4 nibbles
for _ in 0..4 {
    let mut s = (nyb >> 12) as i32;  nyb <<= 4;         // nibble signe -8..7
    s = if shift > 12 { (s >> 4) << 11 } else { (s << shift) >> 1 };
    // p1 = dernier echantillon decode (echelle 16 bits), p2 = avant-dernier >> 1
    if filter == 2 { s += p1; s -= p2; s += p2 >> 4; s += (p1 * -3) >> 6 }
    else if filter == 3 { s += p1; s -= p2; s += (p1 * -13) >> 7; s += (p2 * 3) >> 4 }
    else if filter == 1 { s += p1 >> 1; s += (-p1) >> 5 }
    s = clamp16(s); s = (s * 2) as i16 as i32;          // stocke a l'echelle 16 bits (repliement)
    p2 = p1 >> 1; p1 = s; push dans le tampon annulaire
}
```
(Coefficients du wiki: F1 = 15/16*p1; F2 = 61/32*p1 - 15/16*p2; F3 = 115/64*p1 - 13/16*p2.) Les `p1,p2` continuent d'un bloc au suivant; ils ne sont PAS remis a zero au key-on (`UNKNOWN`, comportement materiel: l'historique residuel influe, d'ou le conseil "commencer par un bloc filtre 0").
Tampon annulaire: 12 echantillons (3 groupes), index d'ecriture `buf_pos` (multiple de 4): le groupe decode est ecrit a `buf_pos`, puis `buf_pos = (buf_pos + 4) % 12` (=> `buf_pos` pointe toujours le plus ancien groupe).
Fin de bloc (apres le groupe 3 d'un bloc dont l'en-tete est H): `if H & 1 { endx |= bit; addr = loop; if H & 2 == 0 { mode = Release; env = 0; hidden_env = 0 } } else { addr += 9 }` (comme le materiel: l'adresse saute a `loop` des que le drapeau E est present, que L soit mis ou non; sans L la voix est coupee mais le decodeur continue de lire a `loop`, sans effet audible car env = 0.). (`UNKNOWN - to confirm`: le materiel traite la fin quelques echantillons avant la fin audible a cause de l'avance du decodeur (8 echantillons); ce modele reproduit cette avance. Isoler dans `voice.rs::advance_block`.)
`ENDX`: mis a la fin d'un bloc a drapeau E (meme avec L); remis a 0 pour la voix au key-on.

## Tests
Tous les tests sont prefixes par `e06_40_`.

- `e06_40_clamp16` : `clamp16(40000)==32767`, `clamp16(-40000)==-32768`, `clamp16(123)==123`, `clamp16(-32768)==-32768`.
- `e06_40_filter0_shift4` : `decode_group(0x12,0x34,4,0,0,0)` == `([16,32,48,64], 64, 24)`.
- `e06_40_filter0_shift2_shift0` : `decode_group(0x12,0x34,2,0,0,0)` == `([4,8,12,16], 16, 6)` ; `decode_group(0x12,0x34,0,0,0,0)` == `([0,2,2,4], 4, 1)`.
- `e06_40_negative_nibbles` : `decode_group(0x8F,0x01,0,0,0,0)` == `([-8,-2,0,0], 0, 0)` (nibbles 8,F,0,1 : -8,-1,0,1).
- `e06_40_shift12_full_scale` : `decode_group(0x77,0x77,12,0,0,0)` == `([28672,28672,28672,28672], 28672, 14336)` ; `decode_group(0x80,0x00,12,0,0,0).0[0] == -32768`.
- `e06_40_shift13_to_15` : `decode_group(0x7F,0x80,13,0,0,0)` == `([0,-4096,-4096,0], 0, -2048)` ; le meme resultat pour shift 14 et 15.
- `e06_40_filter1` : `decode_group(0,0,0,1,16000,0)` == `([15000,14062,13182,12358], 12358, 6591)` ; `decode_group(0x12,0x34,1,1,0,0)` == `([2,4,8,14], 14, 4)`.
- `e06_40_filter2` : `decode_group(0,0,0,2,1000,500)` == `([968,906,818,708], 708, 409)`.
- `e06_40_filter3` : `decode_group(0,0,0,3,1000,500)` == `([982,950,908,858], 858, 454)`.
- `e06_40_clamp_then_wrap` : `decode_group(0x70,0x00,12,2,30000,0)` == `([-2,-28130,11912,-16460], -16460, 5956)` : le premier echantillon depasse +32767, est clampe puis `*2` se replie en -2 (comportement materiel voulu).
- `e06_40_history_continues` : `let (a,p1,p2) = decode_group(0x12,0x34,4,0,0,0); decode_group(0,0,0,1,p1,p2)` renvoie `([60,56,52,48], 48, 26)` ; `a == [16,32,48,64]`.
- `e06_40_filter_bits_masked` : `decode_group(0,0,0,5,1000,500)` == `decode_group(0,0,0,1,1000,500)` (filter & 3).
