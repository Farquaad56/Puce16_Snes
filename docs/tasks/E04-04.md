## Specification
Dans `ppu/regs.rs`:
```rust
pub struct Scroll { hofs: [u16; 4], vofs: [u16; 4], bgofs_latch: u8, bghofs_latch: u8 }
impl Scroll {
    pub fn new() -> Scroll;                        // tout a 0
    pub fn write_hofs(&mut self, n: usize, v: u8); // n = 0..=3 (BG1..BG4) ; n > 3: ignore
    pub fn write_vofs(&mut self, n: usize, v: u8);
    pub fn hofs(&self, n: usize) -> u16;  pub fn vofs(&self, n: usize) -> u16;    // 0 si n > 3
    pub fn hash_into(&self, h: &mut crate::hash::Fnv64);   // hofs[0..4], vofs[0..4] (u16), bgofs_latch, bghofs_latch (u8)
}
```
`write_hofs(n, v)` : `hofs[n] = (((v as u16) << 8) | (bgofs_latch & 0xF8) as u16 | (bghofs_latch & 7) as u16) & 0x3FF` ; puis `bgofs_latch = v ; bghofs_latch = v`.
`write_vofs(n, v)` : `vofs[n] = (((v as u16) << 8) | bgofs_latch as u16) & 0x3FF` ; puis `bgofs_latch = v`.
Les 4 fonds partagent les MEMES deux latchs.

### 2.2 Registres de scroll
Latchs partages: `bgofs_latch: u8` (tous les BGnHOFS/VOFS), `bghofs_latch: u8` (BGnHOFS seulement), `mode7_latch: u8` (M7*).
```
BGnHOFS write v:  hofs[n] = ((v << 8) | (bgofs_latch & !7) | (bghofs_latch & 7)) & 0x3FF
                  bgofs_latch = v ; bghofs_latch = v
BGnVOFS write v:  vofs[n] = ((v << 8) | bgofs_latch) & 0x3FF
                  bgofs_latch = v
```
$210D en plus: `m7_hofs = sign_extend_13((v << 8) | mode7_latch)`; `mode7_latch = v`. $210E: `m7_vofs` idem. (Les deux ecritures - BG1 et mode 7 - ont lieu a chaque ecriture de $210D / $210E.)

## Tests
Tous les tests sont prefixes par `e04_04_`.

- `e04_04_power_on` : `Scroll::new()`: hofs(n)==0 et vofs(n)==0 pour n in 0..4 ; `hofs(4)==0`.
- `e04_04_hofs_two_writes` : `write_hofs(0,0x34); write_hofs(0,0x01)` -> `hofs(0)==0x134`.
- `e04_04_hofs_mask_10bits` : `write_hofs(0,0xFF); write_hofs(0,0xFF)` -> `hofs(0)==0x3FF`.
- `e04_04_hofs_latch_shared_between_bg` : `write_hofs(0,0x34); write_hofs(1,0x01)` -> `hofs(1)==0x134`, et `hofs(0)==0` (la 1ere ecriture donne (0x34<<8)&0x3FF = 0).
- `e04_04_vofs_two_writes` : `write_vofs(0,0x34); write_vofs(0,0x02)` -> `vofs(0)==0x234`.
- `e04_04_vofs_other_bg` : `write_vofs(3,0xFF); write_vofs(3,0x03)` -> `vofs(3)==0x3FF` ; `vofs(0)==0`.
- `e04_04_hofs_uses_both_latches` : `write_vofs(0,0x35)` (bgofs_latch=0x35, bghofs_latch=0) puis `write_hofs(0,0x01)` -> `hofs(0)==0x130` (bits 2-0 viennent du latch H, ici 0).
- `e04_04_latch_leftovers` : `write_hofs(0,0x07)`; `write_vofs(0,0x01)` -> `vofs(0)==0x107` ; puis `write_hofs(0,0x00)` -> `hofs(0)==0x007` (bgofs_latch=1 -> (1&0xF8)=0, bghofs_latch=7 -> 7).
- `e04_04_bad_index` : `write_hofs(4,1)` et `write_vofs(9,1)` ne paniquent pas et ne modifient pas les latchs (hash identique avant/apres).
- `e04_04_hash` : hash identique pour deux `Scroll::new()` ; differe apres `write_hofs(0,1)` ; differe apres `write_vofs(2,1)`.
