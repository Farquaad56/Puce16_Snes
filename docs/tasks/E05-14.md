## Specification
Dans `ppu/bg.rs` :
```rust
pub fn pick_layers(order: &[(u8, u8)], layers: &[Option<Pix>; 5], en: u8, hidden: [bool; 5], backdrop: u16) -> Pick;
impl Ppu {
    pub fn sample_layers(&self, x: usize, v: usize) -> [Option<Pix>; 5];
    pub fn pick_screen(&self, main: bool, x: usize, v: usize) -> Pick;
}
```
`pick_layers` : pour `(layer, level)` dans `order` (avant -> arriere) : ignorer si `en >> layer & 1 == 0` ; ignorer si `hidden[layer]` ; si `layers[layer] == Some(p)` et `p.prio == level` : retourner `Pick { rgb: p.rgb, layer, obj_pal: p.obj_pal }`. Sinon `Pick { rgb: backdrop, layer: LAYER_BACKDROP, obj_pal: 0 }`. (Pour les BG le niveau est la priorite de tuile 0/1 ; pour OBJ la priorite 0..3 ; en mode 7 le BG1 a toujours `prio 0`.)
`sample_layers(x, v)` : `mask = regs.tm | regs.ts` ; mode 7 : couche 0 = `m7_pixel(0,x,v)`, couche 1 = `m7_pixel(1,x,v)` (None sans EXTBG), couches 2-3 None ; modes 0-6 : couche n = `bg_pixel(n,x,v)` pour n in 0..4 ; dans tous les modes : couche 4 = `obj_pixel(x)`. Une couche dont le bit n'est pas dans `mask` vaut None.
`pick_screen(main, x, v)` : `layers = sample_layers(x,v)` ; `order = priority_order(regs.bg_mode, regs.bg3_priority, extbg)` ; `en = if main { tm } else { ts }` ; `hidden[l] = layer_hidden(main, l, x)` ; `backdrop = if main { cgram[0] } else { fixed_color }` ou `fixed_color = fixed_r | fixed_g << 5 | fixed_b << 10`.
Dans `ppu/window.rs` ajoute : `impl Ppu { pub fn layer_hidden(&self, main: bool, layer: u8, x: usize) -> bool }` = `((if main { regs.tmw } else { regs.tsw }) >> layer) & 1 != 0 && window_hides(layer, x)` (couches 0..=4).

### 11.1 Echantillons de couches (une fois par x)
Pour chaque couche activee dans `tm | ts` : `layer_pix[n] = bg_pixel(n, x, v)` (BG), `layer_pix[4] = line_obj[x]`. Mode 7: BG1 via section 8, BG2 si EXTBG. Les BG sans bpp (BPP = 0) restent `None`.

### 11.2 Choix d'un ecran
```
fn pick(screen, x) -> Pick:
    en = if main { tm } else { ts } ; wm = if main { tmw } else { tsw }
    pour (couche, niveau) dans PRIORITE[mode] (avant -> arriere):
        si en.bit(couche) == 0 : continuer
        si wm.bit(couche) && window_out(couche, x) : continuer
        si layer_pix[couche] = Some(p) avec p.prio == niveau : retourner Pick { rgb: p.rgb, layer: couche, obj_pal: p.obj_pal }
    si main : Pick { rgb: cgram[0], layer: BACKDROP }
    sinon   : Pick { rgb: fixed_color, layer: BACKDROP }      // le fond du sous-ecran est la couleur fixe (COLDATA)
```
Pour OBJ, `niveau` compare a `p.prio` (0..3). Pour BG, `niveau` 0/1 compare au bit de priorite de tuile.

## Tests
Tous les tests sont prefixes par `e05_14_`.

- `e05_14_pick_priority_order_mode1` : ordre mode 1 = `priority_order(1,false,false)` (S3 1H 2H S2 1L 2L S1 3H S0 3L), `en = 0x1F`, `hidden = [false;5]`, backdrop 0x0BAD. (a) BG1 prio 1 (rgb 1) + BG2 prio 1 (rgb 2) + OBJ prio 2 (rgb 3) : 1H est avant S2 -> `Pick{rgb:1,layer:0,obj_pal:0}`. (b) BG1 prio 0 (rgb 1) + OBJ prio 2 (rgb 3) : S2 est avant 1L -> `Pick{rgb:3,layer:4,..}`. (c) OBJ prio 0 (rgb 3) + BG3 prio 0 (rgb 4) : S0 est avant 3L -> rgb 3. (d) OBJ prio 0 (rgb 3) + BG3 prio 1 (rgb 4) : 3H est avant S0 -> `Pick{rgb:4,layer:2,..}`. (e) BG3 prio 1 (rgb 4) + OBJ prio 1 (rgb 3) : S1 est avant 3H -> `Pick{rgb:3,layer:4,..}`.
- `e05_14_pick_none_is_backdrop` : aucune couche : `Pick{rgb:0x0BAD,layer:5,obj_pal:0}`. Toutes les couches presentes mais `en = 0` : backdrop.
- `e05_14_pick_level_must_match` : BG1 avec `prio: 1` seul, mode 1 : trouve a l'entree (0,1) ; si le `Pix` a `prio: 5` (valeur invalide) il n'est jamais choisi -> backdrop.
