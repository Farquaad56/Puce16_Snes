# SPEC 07 - SPC700 (S-SMP), registres $F0-$FF, timers, IPL, ports

Source: wiki SNESdev (S_SMP, SPC_700_instruction_set) + references higan/bsnes. Fichiers: `puce16-core/src/apu/{mod.rs,spc700/*,smp_io.rs}`.
Donnees: `docs/specs/data/opcodes_spc700.tsv` (op, mnemonic, bytes, cycles, branch_taken_extra) et `docs/specs/data/ipl_rom.hex` (64 octets, verifie: il se desassemble en l'algorithme IPL du wiki).
Oracle de verite: SingleStepTests/spc700 (voir `06_TEST_ROMS.md`). Quand cette spec dit `UNKNOWN - to confirm`, le defaut indique est suivi puis corrige par les tests.

## 1. Registres du coeur
`A, X, Y: u8`, `SP: u8` (pile en page 1: adresse `$0100 | SP`), `PC: u16`, `YA` = `(Y<<8)|A` (16 bits).
`PSW` = `N V P B H I Z C` (bits 7..0). Le flag `P` choisit la page directe: `dp_base = if P {0x0100} else {0x0000}`. `I` n'a aucun effet (pas d'interruption sur le SPC700 de la SNES). `B` est mis par BRK.
Reset: `PC = lecture 16 bits de $FFFE/$FFFF` (= `$FFC0` via l'IPL), `A=X=Y=0`, `SP=0`, `PSW=$02` (`UNKNOWN - to confirm`: l'IPL fixe SP=$EF lui-meme).

## 2. Memoire 64 Kio
| Plage | Contenu |
|---|---|
| $0000-$00EF | RAM (page directe, P=0) |
| $00F0-$00FF | registres (section 3) |
| $0100-$01FF | RAM (pile) |
| $0200-$FFBF | RAM |
| $FFC0-$FFFF | IPL ROM si `CONTROL bit7 = 1`, sinon RAM. Les ecritures vont TOUJOURS dans la RAM. |

RAM au power-on: `0x00` (`UNKNOWN - to confirm`). Les acces du DSP a la RAM (BRR, echo) lisent/ecrivent la RAM directement (pas l'IPL).

## 3. Registres $F0-$FF
| Addr | Nom | Lecture | Ecriture |
|---|---|---|---|
| $F0 | TEST | `$00` | ignore en v1 (power-on $0A). `UNKNOWN`: ne PAS emuler les etats d'attente |
| $F1 | CONTROL | `$00` | bit0/1/2: active timer 0/1/2 (transition 0->1: remet a 0 les compteurs internes `stage1` et la sortie `out` du timer); bit4: efface les ports d'entree 0 et 1 ($F4,$F5); bit5: efface les ports d'entree 2 et 3; bit7: IPL ROM visible. Power-on/reset: `$B0` |
| $F2 | DSPADDR | valeur ecrite (bit7 lu a 0, selon le wiki) | octet complet stocke |
| $F3 | DSPDATA | `dsp.read(DSPADDR & 0x7F)` | si `DSPADDR` bit7 = 0: `dsp.write(DSPADDR & 0x7F, v)`; sinon ignore |
| $F4-$F7 | CPUIO0-3 | octet ecrit par le S-CPU dans `$2140-$2143` (`port_in[n]`) | stocke dans `port_out[n]` (lu par le S-CPU) |
| $F8,$F9 | - | RAM normale | RAM normale |
| $FA-$FC | T0-T2 TARGET | `$00` | cible du timer |
| $FD-$FF | T0-T2 OUT | compteur 4 bits (`out & 0x0F`), **remis a 0 par la lecture** | ignore |

Les ecritures dans $F0-$FF vont aussi dans la RAM sous-jacente (relecture impossible, mais utile pour les save states): `UNKNOWN - to confirm`; defaut: la RAM n'est pas modifiee pour $F0-$FF.
Ports (cote S-CPU, decrits dans `02_BUS_TIMING.md`): lecture de `$2140+(a&3)` = `port_out[a&3]`; ecriture = `port_in[a&3]`. Reset: les 8 valeurs a `0`. Le cas "lu au meme cycle qu'ecrit" n'est PAS emule.

### 3.1 Timers
Timer 0 et 1: diviseur `128` cycles SMP (8 kHz). Timer 2: diviseur `16` cycles SMP (64 kHz).
Etat par timer: `stage0: u16` (diviseur interne, tourne en permanence, jamais remis a 0 par CONTROL), `stage1: u8`, `out: u8` (4 bits), `enable: bool`, `target: u8`.
A chaque cycle SMP:
```
stage0 += 1
if stage0 == divider { stage0 = 0; if enable { stage1 = stage1.wrapping_add(1); if stage1 == target { stage1 = 0; out = (out + 1) & 0x0F } } }
```
(`target == 0` equivaut donc a 256, grace au `u8` qui deborde.) Lecture de `$FD+n`: retourne `out`, puis `out = 0`.

## 4. IPL ROM et protocole de demarrage (reference, non a coder separement)
Au reset le SMP execute l'IPL: SP=$EF, efface $00-$EF, ecrit `$AA` -> $F4 et `$BB` -> $F5, attend `$CC` sur $F4, lit l'adresse sur $F6/$F7, transfere les octets (protocole a compteur), puis saute a l'adresse. Test d'integration: l'IPL commence par effacer `$00-$EF` (239 tours de ~10 cycles, soit ~2400 cycles SMP, ~50 000 clocks maitres) puis ecrit `$AA`/`$BB`; apres `Snes::new()` + 100 000 clocks maitres (~4800 cycles SMP), le S-CPU voit `$AA` en `$2140` et `$BB` en `$2141`.

## 5. Modes d'adressage (notation du TSV)
`P` = base de page directe. Toute addition d'index dans la page directe se fait **modulo 256 dans la page** (`(dp + X) & 0xFF`), les adresses absolues modulo 65536.
- `#imm`: octet suivant.
- `dp`: `P | b`. `dp+X`, `dp+Y`: `P | ((b + idx) & 0xFF)`.
- `!abs`: 16 bits LE. `!abs+X`, `!abs+Y`: `(abs + idx) & 0xFFFF`.
- `(X)`: `P | X`. `(Y)`: `P | Y`. `(X)+`: `P | X` puis `X += 1`.
- `[dp+X]`: pointeur 16 bits lu en `P | ((b+X)&0xFF)` (octet bas) et `P | ((b+X+1)&0xFF)` (octet haut); adresse = pointeur.
- `[dp]+Y`: pointeur lu en `P|b` et `P|((b+1)&0xFF)`; adresse = `(pointeur + Y) & 0xFFFF`.
- `abs.bit` (OR1, AND1, EOR1, MOV1, NOT1): operande 16 bits `v`; adresse = `v & 0x1FFF` (adresse **absolue**, pas de page directe), numero de bit = `v >> 13`. `/abs.bit` = bit inverse.
- `rel`: octet signe ajoute au PC apres lecture de l'operande.
- `up` (PCALL): adresse `$FF00 | imm`.
- Octets d'operandes: `dp,#imm` = `op imm dp`; `dp,dp` = `op src dst`; `dp,rel` / `dp.bit,rel` = `op dp rel`.

## 6. Instructions (semantique exacte)
Notation flags: `N,Z` = mis selon le resultat 8 bits. Tous les calculs 8 bits.

### 6.1 MOV (41 opcodes) - aucun flag sauf indication
- Chargements `MOV A|X|Y, src`: `N,Z` selon la valeur. Idem `MOV A,X`, `MOV A,Y`, `MOV X,A`, `MOV Y,A`, `MOV X,SP`. `MOV SP,X`: pas de flag. `MOV A,(X)+`: lit `(X)` puis `X+=1`.
- Stockages (`MOV dst, A|X|Y`, `MOV dp,#imm`, `MOV dp,dp`, `MOV (X)+,A`, `MOV [dp+X],A`, ...): pas de flag. Chaque stockage fait une **lecture factice** de la destination avant l'ecriture (sauf `MOV dp,dp` qui lit la source puis ecrit la destination) (`UNKNOWN - to confirm` via les cycles des tests). Important pour `$FD-$FF` (lecture efface le compteur).
- `MOVW YA,dp`: lit octet bas puis haut (haut en `P|((b+1)&0xFF)`), `YA = mot`, `N` = bit 15, `Z` = (YA==0). `MOVW dp,YA`: lecture factice de l'octet bas, puis ecrit bas (A) puis haut (Y); pas de flag.

### 6.2 Logique et arithmetique 8 bits
- `OR/AND/EOR`: resultat -> destination (A, ou memoire pour `dp,dp`, `dp,#imm`, `(X),(Y)`), `N,Z`.
- `ADC a,b`: `r = a + b + C`; `C = r > 0xFF`; `H = ((a & 0xF) + (b & 0xF) + C_in) > 0xF`; `V = (~(a ^ b) & (a ^ r) & 0x80) != 0`; `N,Z` sur `r & 0xFF`.
- `SBC a,b`: equivaut a `ADC a, ~b` avec les memes definitions (donc `C = 1` si pas d'emprunt, `H = ((a&0xF) + ((~b)&0xF) + C_in) > 0xF`, `V` avec `b' = ~b`).
- `CMP a,b`: `r = a - b` (sur 9 bits); `C = (a >= b)`; `N,Z` sur `r & 0xFF`; V et H inchanges. `CMP (X),(Y)`, `CMP dp,dp`, `CMP dp,#imm` comparent sans ecrire.
- `INC/DEC` (A, X, Y, dp, dp+X, !abs): `N,Z` seulement (C inchange).
- `ASL`: `C = bit7; r = v << 1`; `LSR`: `C = bit0; r = v >> 1`; `ROL`: `r = (v<<1)|C, C=bit7`; `ROR`: `r = (v>>1)|(C<<7), C=bit0`. `N,Z,C` (LSR met N=0).
- `XCN A`: echange les quartets, `N,Z`.
- `DAA A`: `if C || A > 0x99 { A += 0x60; C = 1 }; if H || (A & 0xF) > 9 { A += 6 }`; `N,Z`.
- `DAS A`: `if !C || A > 0x99 { A -= 0x60; C = 0 }; if !H || (A & 0xF) > 9 { A -= 6 }`; `N,Z`.
- `MUL YA`: `r = Y * A` (16 bits); `A = r & 0xFF; Y = r >> 8`; `N,Z` selon **Y**.
- `DIV YA,X`: 
  ```
  ya = (Y << 8) | A
  V = (Y >= X); H = ((Y & 15) >= (X & 15))
  if Y < (X << 1) { A = ya / X; Y = ya % X }
  else { A = 255 - (ya - (X << 9)) / (256 - X); Y = X + (ya - (X << 9)) % (256 - X) }
  N,Z selon A   // calculs en u32; X = 0 ne doit pas paniquer
  ```
### 6.3 16 bits (operande `dp`, octet haut en `P|((b+1)&0xFF)`)
- `ADDW YA,dp`: `C` ignore a l'entree (CLRC implicite); `A = ADC(A, bas)`, puis `Y = ADC(Y, haut)` (retenue chainee); flags `N V H C` du 2e ADC; `Z = (YA == 0)` (16 bits); `N` = bit 15.
- `SUBW YA,dp`: SETC implicite; `A = SBC(A, bas)`, `Y = SBC(Y, haut)`; memes regles de flags.
- `CMPW YA,dp`: `r = YA - mot` (17 bits); `C = YA >= mot`; `N` = bit 15 de r, `Z = (r & 0xFFFF == 0)`; V,H inchanges.
- `INCW/DECW dp`: mot +-1 (modulo 65536), `N` = bit 15, `Z`.

### 6.4 Bits
- `SET1/CLR1 dp.n` (opcodes `n*0x20 + 0x02` / `+0x12`): positionne/efface le bit n de `dp`. Pas de flag.
- `BBS/BBC dp.n,rel` (`+0x03` / `+0x13`): saute si le bit est 1 / 0. Pas de flag.
- `TSET1 !abs`: `t = M`; flags `N,Z` calcules sur `A - t` (comme CMP); `M = t | A`. `TCLR1`: idem mais `M = t & ~A`.
- `OR1 C,m.b`: `C |= bit`; `OR1 C,/m.b`: `C |= !bit`; `AND1 C,m.b`: `C &= bit`; `AND1 C,/m.b`: `C &= !bit`; `EOR1 C,m.b`: `C ^= bit`; `MOV1 C,m.b`: `C = bit`; `MOV1 m.b,C`: ecrit le bit; `NOT1 m.b`: inverse le bit. Seul C change (sauf NOT1/MOV1 memoire: aucun flag).

### 6.5 Flags et pile
`CLRC`, `SETC`, `NOTC` (C), `EI`/`DI` (I), `CLRV` (V=0 **et** H=0), `CLRP`/`SETP` (P). `PUSH A|X|Y|PSW`: ecrit `[$100|SP]`, `SP -= 1`. `POP`: `SP += 1`, lit `[$100|SP]` (`POP PSW` charge tous les flags, sans effet de flag pour les autres POP).

### 6.6 Controle de flux (cycles dans le TSV; `branch_taken_extra` s'ajoute si la branche est prise)
- `BPL BMI BVC BVS BCC BCS BNE BEQ rel`: saut conditionnel. `BRA rel`: toujours (4 cycles).
- `CBNE dp,rel` / `CBNE dp+X,rel`: saute si `A != M` (aucun flag). `DBNZ Y,rel` / `DBNZ dp,rel`: decremente puis saute si non nul (aucun flag).
- `JMP !abs`; `JMP [!abs+X]`: pointeur 16 bits lu en `(abs+X) & 0xFFFF` (+1 modulo 65536).
- `CALL !abs`: empile `PCH` puis `PCL` (adresse de l'instruction suivante), `PC = abs`. `PCALL up`: pareil vers `$FF00|imm`. `TCALL n` (n = 0..15, opcode `n*0x10 + 0x01`): empile PC suivant, `PC = lecture16($FFDE - 2*n)`.
- `BRK`: empile `PCH`, `PCL` (PC apres BRK), puis `PSW`; `B = 1; I = 0`; `PC = lecture16($FFDE)`.
- `RET`: depile `PCL` puis `PCH`. `RETI`: depile `PSW`, puis `PCL`, `PCH`.
- `NOP`. `SLEEP` / `STOP`: le coeur reste arrete (le PC ne change plus; chaque `step` consomme 1 cycle factice) tandis que timers et DSP continuent (`UNKNOWN - to confirm`).

## 7. Timing d'un cycle SMP
- 1 cycle SMP = 24 tics du resonateur (`APU_RESONATOR_HZ / 24` = 1 025 280 Hz). Chaque acces bus (lecture, ecriture, cycle factice `idle`) = 1 cycle.
- Nombre de cycles d'une instruction = colonne `cycles` du TSV (+ `branch_taken_extra` si branche prise). L'ordre exact des acces: (1) lecture opcode a `PC`; (2) lecture(s) operande(s) a `PC+1..`; (3) acces donnees; les cycles restants sont des lectures factices (`idle`) placees au plus pres de leur place reelle. `UNKNOWN - to confirm`: le journal par cycle des tests SingleStepTests fixe l'ordre; tant que le format n'est pas lu, on ne compare que **l'etat final + le nombre de cycles**.
- A chaque cycle: `timers.tick()` puis `dsp.tick_cycle()` (le DSP calcule 1 echantillon stereo tous les 32 cycles SMP, voir `07b_DSP.md`).

## 8. Interface Rust
```rust
pub trait SmpBus { fn read(&mut self, addr: u16) -> u8; fn write(&mut self, addr: u16, v: u8); fn idle(&mut self); }
pub struct Spc700 { pub a: u8, pub x: u8, pub y: u8, pub sp: u8, pub pc: u16, pub psw: u8, pub halted: bool }
impl Spc700 {
    pub fn new() -> Self;
    pub fn reset(&mut self, bus: &mut impl SmpBus);      // PC = read16($FFFE)
    pub fn step(&mut self, bus: &mut impl SmpBus) -> u32; // execute 1 instruction, retourne le nombre de cycles
}
pub struct Apu { /* ram[65536], spc700, dsp, timers[3], port_in[4], port_out[4], control, dspaddr, acc: i64, last_master: u64 */ }
impl Apu {
    pub fn new() -> Self;  pub fn reset(&mut self);
    pub fn run_to(&mut self, master: u64);                 // rattrapage (voir 7.1)
    pub fn cpu_read_port(&mut self, n: u8) -> u8;          // $2140+n, appelle run_to avant par le bus
    pub fn cpu_write_port(&mut self, n: u8, v: u8);
    pub fn take_audio(&mut self) -> Vec<i16>;              // paires L,R
}
```
### 8.1 Rattrapage `run_to` (entier uniquement)
```
acc += (master - last_master) as i64 * APU_RESONATOR_HZ as i64; last_master = master
while acc > 0 { spc.step(bus) }          // chaque cycle SMP: acc -= 24 * MASTER_HZ (signe: peut devenir negatif = dette d'une instruction)
```
`MASTER_HZ` = NTSC ou PAL selon la region. Le S-CPU appelle `run_to(master)` juste avant tout acces `$2140-$2143`. `UNKNOWN - to confirm`: le SMP peut etre en avance de moins d'une instruction.

## 9. Tests (prefixe = id de tache)
- `spc-test`: format JSON SingleStepTests (voir 06): etat initial, RAM plate (aucun registre mappe), 1 instruction, compare registres + RAM + nb de cycles. Les opcodes sont testes par groupes (1 tache par groupe).
- Unitaires: `DIV` (cas V/H, X=0), `MUL`, `DAA/DAS`, `ADDW/SUBW/CMPW`, tous les modes d'adressage avec wrap de page directe, TCALL/BRK/RETI, timers (cible 0 = 256, remise a 0 a la lecture, CONTROL transition), ports ($F4-$F7 sens unique, effacement via CONTROL), IPL visible/cache.
- Integration: handshake `$AA/$BB`; envoi d'un petit programme via le protocole IPL (octets du wiki S_SMP) puis verification de son execution (ecrire dans un port).
