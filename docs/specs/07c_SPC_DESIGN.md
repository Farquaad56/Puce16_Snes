# SPEC 07c - SPC700: conception du code (contrat, dispatch, recettes de cycles, tests)

Complete `07_SPC700.md` (semantique des instructions) pour que chaque tache d'instruction ne touche QU'UN fichier. Fichiers: `puce16-core/src/apu/spc700/{mod,table,addr,testbus}.rs` + familles `{mov,alu,incdec,word,bits,flow,misc}.rs`.

## 1. Tables generees
`docs/tools/gen_spc_tables.py` lit `docs/specs/data/opcodes_spc700.tsv` et ecrit `spc700/table.rs` (en-tete `// GENERATED by docs/tools/gen_spc_tables.py - do not edit`):
`pub static BYTES: [u8; 256]`, `pub static CYCLES: [u8; 256]`, `pub static BRANCH_EXTRA: [u8; 256]`, `pub static NAME: [&str; 256]` (texte exact de la colonne `mnemonic`). Le dispatch se fait par **valeur d'opcode** (litteraux hexa avec le mnemonique en commentaire), jamais par le texte.

## 2. Contrat
```rust
pub const F_C: u8 = 0x01; pub const F_Z: u8 = 0x02; pub const F_I: u8 = 0x04; pub const F_H: u8 = 0x08;
pub const F_B: u8 = 0x10; pub const F_P: u8 = 0x20; pub const F_V: u8 = 0x40; pub const F_N: u8 = 0x80;
pub trait SmpBus { fn read(&mut self, addr: u16) -> u8; fn write(&mut self, addr: u16, v: u8); fn idle(&mut self); }
#[derive(Clone, Debug)]
pub struct Spc700 { pub a: u8, pub x: u8, pub y: u8, pub sp: u8, pub pc: u16, pub psw: u8, pub halted: bool, cyc: u32, taken: bool }
```
Methodes (toutes generiques `B: SmpBus`, definies dans `mod.rs`; seules elles touchent le bus):
| Methode | Effet |
|---|---|
| `new()` | a=x=y=0, sp=0, pc=0, psw=0x02, halted=false |
| `rd(bus, addr) -> u8` / `wr(bus, addr, v)` / `idle(bus)` | un acces bus; `cyc += 1` |
| `fetch8(bus) -> u8` / `fetch16(bus) -> u16` | lit a `pc`, `pc += 1` (16 bits: octet bas d'abord) |
| `dp(&self) -> u16` | `0x0100` si flag P sinon `0x0000` |
| `rd16(bus, lo_addr, hi_addr) -> u16` | lit `lo_addr` puis `hi_addr` (bas, haut) |
| `flag(f) -> bool`, `set_flag(f, on)`, `set_nz(v: u8)` | N = bit 7, Z = (v == 0) |
| `ya(&self) -> u16`, `set_ya(&mut self, v: u16)` | `(y << 8) \| a` |
| `push8(bus, v)` / `pull8(bus) -> u8` | pile `0x0100 \| sp`; push: ecrit puis `sp -= 1`; pull: `sp += 1` puis lit |
| `branch(bus, rel: u8)` | `pc = pc.wrapping_add(rel as i8 as i16 as u16)`; `taken = true` (le cycle supplementaire est ajoute par `step`) |
| `step(bus) -> u32` | voir section 3 |
| `reset(bus)` | `pc = rd16(0xFFFE, 0xFFFF)`; a=x=y=0; sp=0; psw=0x02; halted=false |
`Spc700::cyc` compte les acces du step courant. Les fonctions d'ALU pures/flags sont dans `alu.rs`: `Spc700::adc_op(&mut self, a, b) -> u8`, `sbc_op`, `cmp_op(a, b)` (met N,Z,C), `or_op/and_op/eor_op(a, b) -> u8` (met N,Z).

## 3. Dispatch et cycles
```
step(bus): if halted { idle; return 1 }
  cyc = 0; taken = false; op = fetch8(bus)
  exec = mov::exec(op) || alu::exec(op) || incdec::exec(op) || word::exec(op) || bits::exec(op) || flow::exec(op) || misc::exec(op)   // chaque exec(cpu,bus,op) -> bool (true = opcode traite)
  si aucun: panic!("unimplemented opcode {:02X} ({})", op, NAME[op])
  target = CYCLES[op] + (if taken { BRANCH_EXTRA[op] } else { 0 })
  tant que cyc < target { idle(bus) }     // les cycles non modelises sont des cycles factices
  return max(cyc, target)                // si une famille fait plus d'acces que le TSV, c'est le nombre REEL qui est renvoye
```
Consequence: dans une famille on n'emet QUE les acces utiles (lectures/ecritures reelles, dont les lectures factices de destination decrites en 07 section 6.1); `step` complete avec des `idle`. Si une instruction fait plus d'acces que `CYCLES[op]`, le nombre renvoye est le nombre reel et l'ORACLE le signale (comparaison du nombre de cycles): c'est alors soit un bug de la famille, soit une erreur du TSV (`UNKNOWN - to confirm`, ex. `MOVW dp,YA` : TSV 4 cycles mais 5 acces decrits en 07 section 6.1) a trancher par une question `spec` (Claude corrige le TSV).

## 4. Recettes d'adressage (`addr.rs`, ordre des acces utiles)
Ces fonctions consomment les octets d'operande et retournent l'adresse effective; le cycle supplementaire (index) est un `idle`. `P` = `dp()`.
| Fonction | Octets lus | Adresse |
|---|---|---|
| `ea_dp(cpu,bus)` | `b = fetch8` | `P \| b` |
| `ea_dpx(cpu,bus)` / `ea_dpy` | `b = fetch8`; idle | `P \| ((b + X) & 0xFF)` / avec Y |
| `ea_abs(cpu,bus)` | `fetch16` | valeur |
| `ea_absx` / `ea_absy` | `fetch16`; idle | `(abs + idx) & 0xFFFF` |
| `ea_x(cpu,bus)` / `ea_y` | idle | `P \| X` / `P \| Y` |
| `ea_dpx_ind(cpu,bus)` | `b = fetch8`; idle; pointeur: bas en `P\|((b+X)&0xFF)`, haut en `P\|((b+X+1)&0xFF)` | pointeur |
| `ea_dp_ind_y(cpu,bus)` | `b = fetch8`; pointeur: bas en `P\|b`, haut en `P\|((b+1)&0xFF)`; idle | `(pointeur + Y) & 0xFFFF` |
Motifs communs des 6 familles ALU (OR=0x00, AND=0x20, EOR=0x40, CMP=0x60, ADC=0x80, SBC=0xA0), `kind = op & 0xE0`, `form = op & 0x1F`:
`0x04` A,dp ; `0x05` A,!abs ; `0x06` A,(X) ; `0x07` A,[dp+X] ; `0x08` A,#imm ; `0x09` dp,dp ; `0x14` A,dp+X ; `0x15` A,!abs+X ; `0x16` A,!abs+Y ; `0x17` A,[dp]+Y ; `0x18` dp,#imm ; `0x19` (X),(Y).
Formes memoire: `dp,dp` = `src = fetch8` puis `dst = fetch8` (ordre des octets: source d'abord), lit source, lit destination, ecrit destination (rien d'ecrit pour CMP); `dp,#imm` = `imm = fetch8`, `dp = fetch8`, lit dp, ecrit dp; `(X),(Y)` = lit `(Y)`, lit `(X)`, ecrit `(X)`. (Pour CMP aucune ecriture.)

## 5. Tests unitaires (tous les fichiers de test `tests/e06_NN_*.rs`)
`testbus.rs` fournit `FlatSmpBus` (64 Kio, `poke`, `peek`, journal `log`). Aide de test:
```rust
fn run(setup: impl FnOnce(&mut Spc700, &mut FlatSmpBus), prog: &[u8]) -> (Spc700, FlatSmpBus, u32) {
    let mut cpu = Spc700::new(); let mut bus = FlatSmpBus::new();
    cpu.pc = 0x0200; bus.poke(0x0200, prog); setup(&mut cpu, &mut bus);
    let cyc = cpu.step(&mut bus); (cpu, bus, cyc)
}
```
Un test = un programme d'UNE instruction a `0x0200`, un `step`, verification des registres, de la memoire et du nombre de cycles renvoye (colonne `cycles` du TSV, +2 si branche prise). Valeurs calculees a la main dans l'enonce.
